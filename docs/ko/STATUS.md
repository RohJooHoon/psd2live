# 에이전트 기능 실측

[문서 목록](../README.md) · [MCP 사용법과 인터페이스](agent/MCP_AUTHORING.md) · [에이전트 설계와 검수](agent/AGENT_DESIGN.md)

이 페이지는 MCP를 통해 에이전트가 실제 모델링 작업을 수행한 수동 실측 결과를 기록합니다. 인터페이스가 있다고 작업을 안정적으로 끝낼 수 있는 것은 아니므로, 실제 실행한 사례만 기록합니다. 없는 정보는 "미기록"으로 표시하며 추측하지 않습니다.

이미지 생성이 필요한지는 작업에 따라 다릅니다. 기존 파라미터나 물리 조정에는 필요하지 않지만, 가려진 영역을 그려 넣거나 소재를 추가하려면 호스트가 이미지 생성 기능을 제공해야 합니다.

## 평가 기준

| 평가 | 의미 |
| --- | --- |
| 매우 좋음 | 안정적으로 완료 |
| 사용 가능 | 완료하지만 소량의 수동 수정 필요 |
| 간신히 가능 | 많은 재작업이나 수동 보완 필요 |
| 사용 불가 | 완료하지 못했거나 결과를 받아들일 수 없음 |

소수의 성공 사례가 다른 소재에서도 같은 안정성을 보장하지는 않습니다.

## 새 기록 제출 방법

각 기록에는 다음을 포함해 주세요.

- 앱 버전 또는 commit, 호스트, 모델
- 작업 설명과 원본 소재, 이미지 생성 사용 여부
- 표본 수, 재작업 횟수, 소요 시간과 사용량
- 결과 파일 또는 히스토리 노드, 명확한 통과 / 실패 이유

검수할 때는 실제 모델의 중립 포즈, 파라미터 끝점과 동작 효과를 비교하고, 저장 후 다시 열기와 내보내기 결과를 확인합니다. 참고 이미지, 도구의 성공 응답, 스크린샷 한 장만으로는 작업 완료를 입증할 수 없습니다.
