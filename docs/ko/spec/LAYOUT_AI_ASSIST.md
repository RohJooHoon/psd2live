# Layout의 AI 보조(후속 기능, 기본 Layout 범위 밖)

[문서 목록](../../README.md) · [소재와 Layout 작업 공간](MATERIAL_LAYOUT_WORKSPACE.md) · [로드맵](../ROADMAP.md)

이 페이지는 **설계안**이며 아직 구현되지 않았습니다. Layout 작업 공간에서 외부 AI로 파츠를 생성하는 데 의존하는 기능, 즉 기준 좌표계, 자동 배치, 비교 보조, 배경 제거, 파츠 보완과 보완 지표, 부분 복구, 페인팅 분할을 모았습니다. 기본 Layout(소재, 배치, 의미 태그, 먼저 배치한 뒤 생성)은 [소재와 Layout 작업 공간](MATERIAL_LAYOUT_WORKSPACE.md)을 참고하세요. 이 페이지의 기능은 모두 그 위에 구축되며, 기본 Layout은 이미 구현되었습니다.

설계 근거는 외부 AI 보조 모델링 흐름의 실측 기록(전신 캐릭터 두 개, 각각 27개와 41개 레이어)과 캐릭터 전체의 모든 파츠를 통째로 다시 생성했다가 실패한 시도 한 번입니다(“파츠 보완” 참고).

검증 원칙은 기본 Layout과 같습니다. 눈으로 확인하는 검증을 우선하며 품질 검사는 안내만 하고 작업을 막지 않습니다.

## 기준 좌표계와 머리 클로즈업

전신 이미지의 얼굴은 너무 작아 실제 작업에서는 고해상도 머리 클로즈업을 별도로 생성하는 경우가 많습니다. 둘은 서로 다른 기준 좌표계이며 Layout이 이를 기본 개념으로 지원해야 합니다.

- Layout 하나에 여러 참고 항목을 둘 수 있으며, 각 항목은 자체 표시 변환과 기준 좌표계 태그(`FULL_BODY`, `HEAD_CLOSEUP`, `PART`)를 갖습니다.
- 머리 클로즈업에서 전신으로의 매핑은 **유사 변환**입니다. 파츠 레이어는 클로즈업 좌표에 배치하고 매핑으로 캔버스에 옮깁니다. 매핑은 한곳에 하나만 저장하며, 이를 바꾸면 모든 머리 레이어가 함께 움직입니다.
- 머리 클로즈업은 작은 파츠(눈, 눈썹, 입, 방울)의 픽셀 원본이지 단순한 참고가 아닙니다. 기준 원화에서는 이 파츠가 수십 픽셀이지만 클로즈업에서는 수백 픽셀입니다. 위치와 색은 기준 원화, 픽셀은 클로즈업을 따르며 정렬은 기준 원화 해상도에서 평가합니다(“파츠 크기에 따른 픽셀 원본 선택” 참고).
- 매핑의 회전은 0에 가까워야 합니다. 실측에서는 자체적으로 1.7° 기울어진 클로즈업에 정합으로 3° 회전이 추가되어 눈 선이 -4.7° 기울었고 완성품의 “얼굴이 비뚤어졌습니다”. 따라서 매핑을 풀 때 기본적으로 회전을 0으로 잠그며, 회전이 필요하면 명시적으로 켜고 결과의 눈 선 각도를 표시합니다.

## 자동 배치

목표는 파츠를 참고 이미지의 올바른 위치와 크기로 놓는 것입니다. 실측에서 핵심 난점은 생성 도구가 매번 자기 기준으로 다시 그린다는 점이었습니다. 위치는 수십 픽셀까지 어긋나고 배율은 약 0.6–1.4배였습니다. 효과가 확인된 방법은 SIFT와 유사 변환 계산, 배율 탐색이 있는 ECC, 짝 파츠의 변환 차용, 랜드마크와 미러링입니다. 수치 지표끼리 모순될 수 있으므로 겹쳐 보기로 재확인해야 한다는 점도 확인했습니다. 이를 바탕으로 아래와 같이 개선합니다.

### 점수: “이 레이어가 보이는” 픽셀만 비교

자동 배치의 목적 함수는 레이어 전체와 참고 이미지 전체를 비교하면 안 됩니다. 파츠의 일부는 다른 레이어에 가려지거나 새로 그린 부분이어서 참고 이미지에는 없기 때문입니다.

- `V(p)`를 배치 후 레이아웃 합성에서 이 레이어가 최상단에 보이는 픽셀 집합으로 정의합니다(레이어 순서와 다른 레이어의 alpha로 계산). 사용자가 “추가로 그린 영역”으로 표시한 부분도 제외합니다.
- 점수 = `V(p)` 안에서 이 레이어 색과 참고 색의 강건한 차이(Charbonnier 또는 절단 L1, Lab 공간) + 레이어 경계와 참고 경계의 거리 변환 항입니다.
- 같은 함수를 최적화 목표, 후속 검수 지표와 시각적 히트맵에 모두 쓸 수 있어 “정렬 신뢰도는 높은데 겹쳐 보면 어긋나는” 상황을 피합니다.

### 단계별 계산

1. **거친 정합**: alpha 윤곽과 경계 이미지에서 푸리에-멜린(로그 극좌표 위상 상관)을 수행해 텍스처에 의존하지 않고 배율, 회전, 이동 후보를 한 번에 구합니다. 애니메이션 그림은 텍스처가 적고 단색 면이 커서 특징점이 부족한 경우가 많으며 윤곽과 선화가 더 안정적입니다.
2. **특징점**: 텍스처가 충분하고 점 수와 인라이어 수가 기준에 도달하면 SIFT / AKAZE와 RANSAC으로 유사 변환을 구해 거친 정합 결과를 대체합니다.
3. **정밀 정합**: 점수 함수를 Powell 또는 CMA-ES 등으로 거친 단계부터 세밀한 단계까지 최적화합니다. 자유도는 이동, 회전, 등방 배율이며 선택적으로 두 축의 배율을 둡니다. 저해상도 피라미드에서 먼저 풀고 단계별로 정밀화하며, 각 단계는 이전 결과 근처만 탐색해 이탈을 막습니다.
4. **선택적 학습 기반 매칭**: LoFTR 계열의 조밀한 매칭은 플러그인으로 둘 수 있지만 필수 의존성으로 삼지 않습니다.

### 짝과 대칭 제약

- 짝 파츠(흰자, 홍채, 속눈썹, 눈썹, 귀, 다리, 신발)는 함께 풉니다. 중선을 공유하고 좌우 변환은 미러 관계에 작은 잔차만 허용합니다. 한쪽이 불확실하면(실측에서 흰자와 눈썹은 독립 정렬이 잘 되지 않음) 같은 쪽의 신뢰할 수 있는 파츠 변환을 빌립니다.
- 대칭축은 Layout의 기본 오브젝트입니다. 양쪽 홍채 중심이나 얼굴 바탕 레이어 윤곽에서 추정하고 기준선을 표시할 수 있습니다. 눈 전체가 중선에서 12 px 벗어나는 문제 등을 한눈에 볼 수 있습니다.
- 미러 배치: 포즈가 잘못된 쪽은 반대쪽을 뒤집어 사용할 수 있습니다. 뒤집은 뒤에는 점수를 기준으로 이동만 미세 조정하고 배율은 바꾸지 않습니다.

### 신뢰도와 실패 처리

- 숫자 하나 대신 최적 점수, 차선 후보와 최적 후보의 비율(구별 가능성), 최적점 부근 점수 표면의 곡률(어느 자유도가 불확실한지)을 출력합니다.
- 구별 가능성이 낮으면 첫 후보를 조용히 적용하지 않고 UI에 여러 후보를 보여 주어 사용자가 고르게 합니다.
- 점수와 곡률 조건을 만족하지 못하면 바로 “신뢰할 수 없음”을 보고하고 수동 모드로 돌아갑니다. 추측한 값은 내보내지 않습니다.
- 모든 자동 배치 결과는 실행 취소 가능한 편집 한 번이며, 히트맵 오버레이를 기본적으로 한 번 켭니다.

### 랜드마크 모드

점 두세 개(예: 턱, 양쪽 볼)를 골라 가로와 세로에 서로 다른 배율을 적용합니다. 얼굴 바탕 레이어에서 자주 씁니다. 랜드마크는 윤곽의 곡률 극값에 스냅해 수동 클릭 오차를 줄일 수 있습니다.

## 비교 보조

사람과 AI가 볼 수 있도록 Layout의 참고 이미지와 파츠 표시를 각각 조정할 수 있습니다.

- **불투명도**와 **단색 모드**: 참고 이미지를 한 색(예: 청록), 파츠를 보색(예: 빨강)으로 칠해 겹치면 맞는 부분은 중성색, 어긋난 부분은 색 테두리로 나타납니다. 단색 모드는 “휘도” 또는 “선화”(경계 먼저 추출)를 고를 수 있으며 후자가 선 위치 비교에 더 적합합니다.
- **차이**, **슬라이드 비교**(좌우로 움직이는 분할선), **깜빡임**(두 프레임 빠른 전환), **윤곽선** 모드
- **오차 히트맵**: 앞서 정의한 `V(p)`의 픽셀별 강건한 차이
- **비교 이미지 원클릭 내보내기**: 참고 / 합성 / 차이를 나란히 놓고 좌표 격자와 번호가 붙은 레이어 바운딩 박스를 표시해 AI에 바로 첨부할 수 있습니다. 내용은 캡처된 Layout 버전만으로 렌더링하며 실시간 GUI 상태를 읽지 않습니다.
- **측정값**: 눈 선 각도, 양쪽 귀 높이 차, 양쪽 파츠의 대칭축 편차, 머리·몸 비율이 임계값을 넘으면 안내합니다(전송 전 점검 참고).

## 배경 제거와 가장자리 처리

### 기본 배경은 초록 대신 흰색

실측에서는 순수 초록 배경으로 생성한 뒤 크로마 키를 적용했습니다. 흰 배경으로 바꾸는 편이 좋습니다.

- 생성 도구는 흰 배경에서 가장 안정적이고 기준 원화 자체도 흰 배경이어서 파츠와 원화의 색조가 더 잘 맞습니다. 초록 배경은 머리카락, 반투명 그림자와 하이라이트에 초록색이 섞이게 합니다.
- 초록은 색 번짐을 제거해야 하며 실제 초록색 내용(초록 눈, 초록 옷)을 보존하기 어렵습니다.
- 흰 배경의 단점은 전경에도 흰색(흰 머리카락, 흰 소매, 흰 베일)이 있으면 구분하기 어렵다는 점입니다. 고정 초록색으로 돌아가는 대신 아래 “배경 선택 + 연결성 판별”로 해결합니다.

### 흰 배경 제거 파이프라인

목표는 직선 alpha(straight alpha)와 배경색 오염을 제거한 전경색을 얻는 것입니다.

1. **배경 확정**: 이미지 테두리에서 플러드 필을 수행해 배경색에 충분히 가깝고 테두리와 연결된 픽셀을 확정 배경으로 고릅니다. 전경 내부의 흰색(흰 머리, 흰 소매)이 테두리와 연결되지 않으면 배경으로 오인하지 않습니다.
2. **전경 확정**: 배경이 아닌 영역을 침식합니다. 사용자는 브러시로 추가하거나 제외해 흰 전경이 테두리에 직접 닿거나 흰 영역이 가는 선으로만 분리된 경우에 대응할 수 있습니다.
3. **미확정 띠**: 배경과 전경 사이의 좁은 띠입니다.
4. **전경색 추정**: 미확정 띠의 픽셀마다 인접한 확정 전경에서 전경색 `F`를 추정합니다(다단계 전경 추정 또는 이웃 가중치, 배경색을 섞지 않도록 보장).
5. **alpha 계산**: 배경색 `B`를 알 때 관측색은 `C = αF + (1−α)B`이므로 `α = ((C−B)·(F−B)) / |F−B|²`를 구해 [0, 1]로 제한합니다. `F`와 `B`가 가까워 분모가 0에 접근하는 픽셀은 이 식 대신 연결성 판별과 이웃 평활화로 결정합니다.
6. **선택적 닫힌형 매팅**: 미확정 띠가 넓고 머리카락이 많으면 닫힌형(Levin) 또는 근사 해법을 사용합니다. 트라이맵은 앞 단계로 만들며 사용자에게 직접 그리도록 요구하지 않습니다.
7. **색 오염 제거**: 미확정 띠의 출력색은 추정한 `F`를 쓰고 배경과 섞인 색을 유지하지 않습니다. 흰 테두리를 제거하는 핵심입니다.
8. **작은 연결 요소**: 면적이 임계값보다 작은 잔여 덩어리를 제거합니다(실측에서 3%–10%의 낮은 불투명도 잡음 때문에 가져오기가 바운딩 박스 전체를 메시로 취급한 결함이 있었음). 면적 임계값과 alpha 임계값을 미리보기에 직접 표시하고 버리는 픽셀에는 반투명 빨강을 겹칩니다.

### 배경색 선택

생성 작업 묶음은 배경색을 선택할 수 있으며 기본값은 흰색입니다. 파츠가 주로 흰색(흰 머리, 흰 소매, 흰 베일)이면 파츠와 가장 먼 색을 권장합니다. 파츠 색을 집계해 후보 중 “모든 전경색과의 거리 최솟값이 가장 큰” 색을 고르고 작업 묶음을 내보낼 때 안내합니다. 이때 배경 제거 파이프라인 1단계의 배경색만 해당 색으로 바꾸고 나머지는 유지합니다.

### 두 배경을 이용한 정확한 매팅(선택 사항)

같은 파츠에 대해 흰 배경과 다른 배경색(예: 검정)의 **픽셀 정렬된** 두 이미지를 얻을 수 있다면 `α = 1 − |C_w − C_b| / |B_w − B_b|`이고 전경색을 닫힌형으로 복원할 수 있습니다. 외부 생성 도구가 픽셀 정렬된 두 버전을 제공하지 못하면 이 방법은 쓸 수 없습니다. 프로그램이 직접 합성한 소재(예: PSD 하위 레이어로 만든 비교 이미지)에만 사용합니다. 주 경로가 아닌 선택적 모듈입니다.

### 가장자리 처리

- 수축 / 확장(서브픽셀), 페더링(가우시안, 반경은 소수 픽셀 단위)
- 색 테두리 제거: 전체를 어둡게 하지 않고 추정 전경색으로 가장자리를 다시 칠합니다.
- 헤일로(halo) 검출: 가장자리 바깥 띠의 휘도가 배경과는 임계값 안으로 가깝지만 전경과는 크게 다르면 안내합니다.
- 선화 보호: 선화 픽셀의 alpha가 페더링으로 옅어지지 않게 합니다.
- 반투명 소재(홍조, 그림자)는 배경 제거를 거치지 않습니다. 흰 배경으로 생성해 “곱하기” 레이어로 가져오고 `Placement.blend`에 기록합니다.

## 파츠 보완

**보완은 필수입니다.** 파츠가 원화와 정확히 맞기만 하고 가려진 부분을 채우지 않으면 리그에는 심각한 오류입니다. 고개를 돌리거나 흔들거나 위 레이어를 숨길 때 빈 부분이 드러납니다. 따라서 보완 결과 평가는 “얼마나 채웠는가”를 우선하고, “원화와 얼마나 닮았는가”는 그다음입니다.

### 실패한 시도 한 번(철회한 결론)

이 페이지의 이전 버전은 “외부 AI로 파츠 전체를 한 번에 그리기”를 모든 파츠의 주 경로로 정했습니다. 같은 캐릭터의 팔은 한 번에 성공하고 다리는 마스크 인페인팅으로 반복 실패한 사례가 근거였습니다. 이후 외부 AI로 전신 캐릭터의 40개 넘는 파츠를 전부 다시 생성하고 정렬·합성한 결과, **각 파츠는 대체로 쓸 만했지만 합친 전체는 “기준 원화의 보이는 픽셀을 유지하고 가려진 부분만 채우는” 방식보다 확연히 나빴습니다**.

- 파츠마다 따로 재설계하면서 편차가 누적되었습니다. 다리와 부츠가 가늘어지고 꼬리가 홀쭉해지며 표정이 바뀌고 허리띠 세부가 사라졌습니다. 소매가 짧아지자 원래 소매 끝에 달렸던 장식이 공중에 떠 보였습니다.
- 두 다리 사이에 세로 틈이 생겼습니다. `coverage` 보고서상 참고 전경의 11.7%가 어떤 레이어로도 덮이지 않았으며 큰 빈틈은 두 다리 사이, 소매 밑과 꼬리 옆에 있었습니다.
- 모든 파츠가 여전히 기준 원화 해상도여서 작은 파츠의 픽셀 부족은 해결되지 않았습니다.

교훈:

1. 팔이 성공한 이유는 단일 재질의 볼록한 관 형태이고, 가려진 부분이 소매 안쪽이라 접합부와 잘린 부분이 보이지 않았기 때문입니다. 세부가 풍부하고 경계가 길고 복잡한 파츠(치마, 소매, 꼬리, 머리카락, 부츠, 머리 장식)에 일반화할 수 없습니다.
2. 재생성은 디자인을 바꿉니다. “원래 보이는 부분이 적은” 파츠에는 맞지만 “보이는 부분의 세부가 풍부한” 파츠에는 맞지 않습니다. 후자는 기준 원화 픽셀 자체가 가장 좋은 참고이며 다시 그리면 편차만 생깁니다.
3. 앞선 “마스크 인페인팅 실패”의 원인은 마스크 형태였습니다. 길고 불규칙하며 경계가 여전히 보이는 곳에 있고 여러 재질, 드리운 그림자와 눌린 자국이 섞여 있었습니다. “보이는 픽셀 유지”라는 발상 자체의 문제가 아닙니다. 접합부를 위 레이어 아래에 두면 이를 피할 수 있습니다(아래 참고).
4. 수치 검수(픽셀별 일치율)와 시각적 검수는 별개입니다. 어느 경로든 최종적으로 합성된 전체 이미지를 봐야 합니다.

### 수정된 원칙

1. **기준 원화는 위치와 색을 담당하며 선명도를 담당하지 않습니다.** 파츠 픽셀은 필요한 해상도의 원본에서 가져오고 기준 원화는 정렬과 색의 기준으로만 씁니다.
2. **기준 원화의 보이는 픽셀을 보존할 수 있으면 보존**하고 가려진 연장 부분만 채웁니다(아래 혼합 파츠). 그러면 전체가 기준 원화와 일치하고 편차는 보이지 않는 영역에만 생깁니다.
3. **파츠 전체 교체는** 원화에서 보이는 부분이 아주 적거나 형태가 단순하며 대부분 가려진 파츠에만 사용합니다. 팔 피부, 목, 허벅지 피부, 뒷머리, 기준 원화에서 완전히 보이지 않는 파츠가 해당합니다. 교체 가능 여부는 `overlap_fidelity`와 합성 전체 이미지로 판단하며 편차가 뚜렷하면 혼합 파츠로 돌아갑니다.
4. **부분 복구**는 여전히 작은 결함에만 사용합니다.
5. 어떤 경로의 결과든 합성 전체 이미지에서 기준 원화와 영역별로 비교해야 합니다.

### 파츠 크기에 따른 픽셀 원본 선택

기준 원화에서의 파츠 크기로 픽셀 출처를 정합니다(수치는 출발점이며 보정 필요).

| 기준 원화에서의 크기 | 예 | 픽셀 원본 | 이유 |
| --- | --- | --- | --- |
| 큼, 약 150 px 이상 | 치마, 소매, 꼬리, 뒷머리, 다리, 부츠 | 기준 원화 픽셀의 2× 초해상도화(프로젝트의 기존 [텍스처 고해상도화](../guide/TEXTURE_UPSCALE.md) 또는 유사 모델) | 선과 색면이 명확해 초해상도화는 디자인을 바꾸지 않고 세부만 보충 |
| 중간, 약 60–150 px | 앞머리, 귀, 머리 장식, 손 | 기준 원화의 같은 영역에서 생성한 고해상도 클로즈업을 원화에 다시 정렬 | 이 크기부터 초해상도화가 세부를 지어내고 가장자리를 변형함 |
| 매우 작음, 약 60 px 이하 | 눈, 홍채, 눈썹, 입, 방울, 술 장식 | 고해상도 머리 클로즈업 | 기준 원화에 정보가 부족하며 초해상도화는 새 파츠를 다시 그리게 됨 |

- 고해상도 원본은 세부만 담당합니다. 정렬과 충실도는 **기준 원화 해상도**에서 비교합니다. 고해상도 후보를 원화 크기로 줄여 비교하고 “더 선명하지만 위치는 그대로”여야 합격입니다.
- 배치 배율은 배치 크기만 바꾸며 고해상도 원본 픽셀은 그대로 유지합니다(“핵심 가치” 참고).
- 초해상도화와 재생성 모두 세부를 보충하는 것이지 복원이 아닙니다. 검수 기준은 픽셀 일치가 아니라 스타일 일관성과 올바른 위치입니다.
- 사용 가능한 초해상도 모델이 없으면 명확히 오류를 보고하고 일반 보간으로 가장하지 않습니다.

### 혼합 파츠: 보이는 픽셀 + 연장 부분

세부가 풍부한 파츠는 레이어 = 보이는 부분의 픽셀 원본 + 연장 영역 `E`로 만듭니다.

- `E`는 정렬된 전체 파츠 생성 결과에서 “원화 윤곽 바깥이며 위 레이어 아래 또는 그 근처”인 픽셀만 가져옵니다.
- 보이는 부분과 연장 부분의 **접합부는 의도적으로 위 레이어의 가장자리 아래에 놓습니다**. 원화에서 잘라낸 이미지를 가려지는 경계에서 위 레이어 아래로 몇 픽셀 더 연장하고 그곳부터 `E`를 시작합니다. 정지 포즈에서는 위 레이어가 접합부를 덮고, 위 레이어가 움직여야 드러납니다.
- 먼저 `E`에 저주파 색상 매칭을 적용합니다(전체 색 치우침만 보정하고 생성 이미지의 세부는 유지). 이어 `E` 쪽의 좁은 띠 안에서 페더링하며 보이는 영역은 전혀 수정하지 않습니다.
- 연장 영역의 스타일 일관성은 `style_drift`와 `seam_score`로 시각 확인을 권할 뿐 숫자로 통과시키지 않습니다.
- 접합부 밖에서도 보이는 경계(예: 맞닿은 다리 사이, 양말 입구)는 이 방법의 적용 범위가 아닙니다. 이런 파츠는 전체 교체나 부분 복구로 바꿀지 종합적으로 평가해야 합니다.

### 파츠 분할 방식

작업은 가려진 영역 기준이 아니라 **의미와 재질** 기준으로 나눕니다.

- 다리: 피부색 허벅지 / 스타킹 / 가터와 장식 / 부츠를 각각 별도 파츠로 둡니다. 한 번의 생성에 여러 재질을 섞지 않습니다.
- 짝 파츠는 작업마다 한쪽만 포함하고 반대쪽은 이미지에 넣지 않습니다. 좌우 대칭이면 한쪽을 미러링한 뒤 미세 조정할 수 있습니다.
- 참고로는 맥락이 있는 전체 이미지나 큰 잘라내기 이미지를 사용해 모델이 인물에서 파츠의 위치를 이해하게 합니다. 출력에는 해당 파츠만, 순수 흰 배경으로 나오도록 요구합니다.
- 위 레이어의 영향(드리운 그림자, 눌린 자국)은 파츠에 나타나면 안 되며 프롬프트로 명시합니다.

### 작업 묶음

파츠 작업마다 디렉터리 하나를 생성합니다. 참고 이미지(맥락을 포함한 원화), `part.json`(파츠, 좌우 구분, 슬롯, 캔버스 크기, 배경색, 전략), 프롬프트 템플릿(뿌리까지 완성, 자연스러운 끝맺음, 그림자 없음), 선택적인 “원화에서 잘라낸” 소재를 넣습니다. 외부 처리 후 이미지 한 장을 다시 가져옵니다.

검증할 변형으로 “완성형”이 있습니다. 주 참고를 전체 이미지 대신 해당 파츠만 있고 가려진 곳이 잘린 원화 추출 이미지로 삼고, 전체 이미지는 맥락으로만 사용합니다. 프롬프트는 보이는 부분의 포즈와 비율을 유지하고 잘린 끝만 채우도록 요구합니다. 여전히 한 번 생성하며 원본을 다시 붙이지 않지만, 입력이 보이는 부분의 비율을 고정합니다. 전체 이미지 참고보다 안정적인지는 실측 결론이 없습니다.

### 다시 가져오기

1. 흰 배경 제거(“배경 제거와 가장자리 처리” 참고).
2. 원화에 자동 배치합니다(점수는 보이는 겹침 영역에서만 계산, “자동 배치” 참고). 원화보다 좋아지는 것은 허용합니다. 정렬에는 유사 변환만 쓰며 새 윤곽을 원화에 억지로 맞추지 않습니다. 비율 표류가 심하면(`overlap_fidelity`가 낮고 윤곽 거리가 큼) 쓸 수 없는 결과로 판단해 다시 만들고 강제로 채택하지 않습니다.
3. 파츠 전략에 따라 전체 파츠를 교체하거나 `E`를 취해 혼합 파츠로 라이브러리에 넣습니다.
4. 파생 소재로 등록하고 원화 추출 이미지와 `PartPair`를 만듭니다.

### 두 가지 지표

`PartPair` 하나(원화 추출 이미지 `O`, 새 레이어 `N`, 둘 다 같은 캔버스 좌표에 배치됨)에 대해 계산하고 MCP와 GUI가 공유하는 읽기 작업으로 반환합니다.

**겹침 영역: 원화 일치도 `overlap_fidelity`**, 범위는 0–1입니다. 새 레이어가 원화에서 보이는 영역과 얼마나 가까운지 측정합니다.

- 픽셀별 유사도 `s(p) = exp(−ΔE(p)/ΔE₀)`: `ΔE`는 Lab 공간에서 계산합니다. 비교 전 두 이미지에 같은 작은 반경 흐림을 적용하고 ±2 px 안에서 최근접 픽셀을 골라 서브픽셀 어긋남을 과도하게 벌점화하지 않습니다. 선화 픽셀에는 경계 거리 비교를 추가합니다.
- `overlap_fidelity = Σ min(αO, αN)·s / Σ αO`. 구성 요소인 `coverage = Σ min(αO, αN) / Σ αO`(원화의 보이는 부분을 새 레이어가 얼마나 덮는지)와 `color_similarity`도 반환합니다.
- 1에 가까울수록 무조건 좋은 것은 아닙니다. 원화의 결함(흔들린 선, 색면, 남은 그림자)을 고쳐야 하면 약 0.7로 낮아진 결과가 더 좋을 수 있습니다. 따라서 참고용일 뿐 작업을 막지 않습니다. 수용 여부는 이미지를 보고 결정하며 사용자나 에이전트가 자체 안내 하한을 정할 수 있습니다.

**새 레이어 전체 부피: 원화 대비 `completion_ratio`**, 1보다 커야 합니다.

- `completion_ratio = Σ αN / Σ αO`(2차원에서 “부피”는 alpha 질량).
- 파츠에 가려진 부분이 있다면 보완 후 반드시 1보다 커야 합니다. 1에 가까우면 원화를 되풀이했을 뿐 보완하지 않은 것입니다.
- 모든 파츠가 1을 넘어야 하는 것은 아닙니다. 완전히 보이는 파츠(예: 고립된 장식)는 1이어도 됩니다. 원화 추출 윤곽에서 실제 배경이 아니라 위 레이어 경계에 붙은 비율인 `hidden_boundary_fraction`으로 판단합니다. 이 비율이 높은데 `completion_ratio ≈ 1`이면 가장 눈에 띄는 `NOT_COMPLETED` 안내와 함께 위 레이어에 붙은 원화 윤곽 위치 이미지를 제공하고 사람이 보완 필요성을 확인하게 합니다. 파츠에 `fully_visible`을 명시해 예외로 둘 수 있습니다.

함께 반환하는 진단:

- `hidden_gain`: 추가 면적 중 위 레이어 아래에 놓인 부분의 `Σ αO` 대비 비율로, 합리적인 보완을 나타냅니다.
- `visible_spill`: 추가 면적 중 위 레이어에 가려지지 **않아** 합성 인상을 바꾸는 부분입니다. 0보다 크면 합성이 원화와 다르므로 복구인지 표류인지 확인해야 합니다.
- `composite_fidelity`: 원화 추출 이미지를 새 레이어로 교체한 뒤 전체 합성과 참고 이미지의 유사도입니다. 파츠 사이 빈틈과 스타일 단절이 없으면 1에 가깝습니다.
- `style_drift`: 추가 영역과 원화 영역의 스타일 통계 거리입니다(팔레트 분포, 경계 기울기 히스토그램, 선 굵기 분포, 선택적으로 이미지 임베딩 코사인 거리). 새 레이어가 더 좋아질 수는 있어도 스타일이 달라져서는 안 되므로 시각 확인을 유도합니다.
- `seam_score`: 추가 영역과 원화 영역의 경계에서 색과 기울기가 급변하는 정도입니다.

반환 구조(`resultSchema`에 엄격히 선언):

```
{ pair_id, overlap_fidelity, coverage, color_similarity,
  completion_ratio, hidden_boundary_fraction, hidden_gain, visible_spill,
  composite_fidelity, style_drift, seam_score,
  flags: [ { rule, level, detail, evidence? } ],
  images: { compare_sheet, overlay, heat, ... } }
```

`flags`의 `rule`과 수준은 규칙 열거형으로 정하며(“전송 전 안내” 참고) 번역된 문구에서 추론하지 않습니다. `evidence`는 바로 볼 수 있는 이미지와 위치를 가리킵니다. `images`는 수치와 함께 반환하며 에이전트는 먼저 이미지를 보고 숫자를 해석해야 합니다.

### 부분 복구(마스크 인페인팅)

접합부 하나, 얼룩 하나, 작은 빈틈 등 작은 범위의 결함에 계속 사용합니다. 흐름은 작업 묶음(배경색 바탕 + 보이는 픽셀 + 예약색 마스크) → 외부 처리 → 다시 가져오기입니다. 마스크 밖 픽셀은 바꾸지 않고 안쪽만 생성 픽셀을 사용하며 좁은 경계 띠를 혼합합니다. 엄격한 제약을 갖는 부분 도구로, 파츠 전체를 채우는 데 쓰지 않습니다. 가져오기 전에 마스크 바깥에서 정합을 보정하고 바깥이 바뀌지 않았는지, 안쪽에 예약색이 남았는지 검사합니다.

**마스크 안을 흐리거나 색을 뽑아 채운 뒤 생성한 것처럼 취급하지 않습니다.** 외부 도구가 이런 결과를 줄 때가 있으므로 실제 이미지 생성 픽셀만 신뢰하고, 필요하면 중간 단계의 원본 생성 이미지를 사용합니다.

## 페인팅과 분할

[페인팅 시스템](PAINT_SYSTEM_ARCHITECTURE_AND_PRD.md)의 래스터 엔진과 세션을 계속 사용하며 도구를 추가합니다.

- 선택 영역: 올가미 / 마술봉(허용 오차와 연결성 포함) / 사각형, 더하기·빼기와 페더링
- 복제, 문지르기, 복구 브러시: 수동 세부 복구용
- 대칭 페인팅: Layout 대칭축을 기준으로 획을 미러링
- 레이어 분할:
  - alpha 열이 최소인 곳에서 좌우 절반으로 분할(짝 파츠)
  - 연결 요소별 분할
  - 손으로 그린 선을 따라 분할
  - 분리된 하위 레이어를 각각 파생 소재로 만들고 원본 소재와의 관계 유지
- 병합과 정리: 여러 레이어를 소재 하나로 합치고 복원할 수 있도록 원본 이미지를 유지합니다.
