# 알고리즘 템플릿 목록: 머리카락과 몸

> 이 목록은 부위·모듈 아키텍처보다 먼저 작성되어 “슬롯 / 템플릿”이라는 표현을 유지합니다. 같은 슬롯에서 서로 배타적인 방법은 해당 부위의 **기본 알고리즘**으로, 함께 적용할 수 있는 기능은 **모듈**로 등록됩니다. `*/current`는 각 부위의 `legacy` 기본 알고리즘에 해당합니다. 구현 상태는 등록표(MCP `module_catalog`)를 기준으로 합니다. 이 페이지의 P0/P1/P2는 계획 우선순위일 뿐이며, “구현됨”은 등록표를 도입하기 전에 이미 존재했던 알고리즘을 뜻합니다. [리그 프리셋 아키텍처](RIG_PRESETS.md)를 참고하세요.

[문서 목록](../../README.md) · [프리셋 아키텍처](RIG_PRESETS.md) · 템플릿 목록: [얼굴](RIG_TEMPLATES_FACE.md) · [머리카락과 몸](RIG_TEMPLATES_HAIR_BODY.md) · [물리와 모션](RIG_TEMPLATES_PHYSICS_MOTION.md) · [구조와 표현](RIG_TEMPLATES_STRUCTURE.md)

이 페이지는 [리그 프리셋 아키텍처](RIG_PRESETS.md)의 템플릿 목록 중 하나입니다. 각 영역 슬롯에는 여러 알고리즘 템플릿을 등록할 수 있으며, 모델 프리셋은 슬롯별 템플릿 하나와 파라미터 값을 선택합니다. 같은 문제를 해결하는 서로 다른 방법은 같은 슬롯의 별도 템플릿으로 공존합니다. 일반적인 Live2D 제작 관행을 바탕으로 설계했으며, 수치는 모두 권장 기본값과 조절 범위입니다. 구현 후 출력 결과에 맞춰 조정합니다. 각 슬롯의 `*/current`는 기존 알고리즘이며 기본 템플릿으로 등록됩니다. 이를 선택하면 출력은 바뀌지 않습니다.

## 0. 규약

**단위**: H 캐릭터 키, Hh 머리 높이, Wf 얼굴 너비, heye 눈 높이, L 물체의 주축 방향 길이, W 물체 너비, s ∈ [0,1] 주축을 따라 뿌리에서 끝까지의 정규화 호 길이. 파라미터 “최대값”은 ±1로 표기합니다(내보낼 때 ±30 / ±10 등 기존 범위로 매핑). 모든 수치는 설계 기본값과 조절 범위입니다.

**슬롯**: 이 문서는 `hair.front`, `hair.side`, `hair.back`, `hair.strand`, `hair.accessory`, `neck`, `body.turn`, `body.lean`, `breath`, `arm`, `hand`, `leg`, `chest`, `skirt`, `cloth`, `ribbon`, `tail`, `wing`, `prop`를 다룹니다. 보충 슬롯 네 개를 추가합니다. `hair.variant`(헤어스타일 변형), `body.root`(골반 뿌리 체인과 서기 자세), `ornament`(펜던트, 매달린 장식, 단추, 목걸이 등 작은 소품)이며, “가늘고 긴 물체의 체인”은 `hair.strand`에 통합하고 리본, 꼬리, 끈, 사슬이 이를 참조합니다.

**물리 슬롯과의 경계**: 템플릿은 “물리 출력이 몇 개 필요한지, 각 출력이 어느 층에 연결되는지, 부호 규약(같은 방향 / 반전)”만 선언합니다. 질점 수, mobility / delay / acceleration, 입력 가중치, Angle / X형, 가진(호흡, 충격), 필터층은 `physics.chain` / `physics.cascade` / `physics.excitation` / `physics.filter` 템플릿이 담당합니다.

**공유 구성 요소**(여러 템플릿이 재사용하므로 먼저 라이브러리 함수로 만들어야 함):

| 번호 | 구성 요소 | 설명 | 현황 |
| --- | --- | --- | --- |
| C1 | 띠 기술(strip descriptor) | 중심축(스켈레톤화 + 최장 경로 + 평활화), 뿌리 끝, 길이 L, 반너비 w(s), 정지 곡률, 부착점 | 없음(뼈대에는 뼈가 있지만 레이어에서 중심축을 자동으로 구하지 않음) |
| C2 | 길이 보존 굽힘 | k번째 구간은 s ≥ k/n 부분만 굽힘, 중심선 길이 보존, 단면 평행 유지 가능 | `SwingDeformer`에 있음 |
| C3 | 원호 밀집 키 | 현 높이 오차에 따라 적응적으로 키 삽입: Δθ ≤ 2·acos(1 − ε/R). 또는 해석적 형상과 선형 보간의 차이가 가장 큰 곳에 중간 키 삽입 | 없음(흔들림과 아홉 포즈는 끝점 + 중간점만 있음) |
| C4 | 부착점 국소 회전각 평가 | 부모 디포머 체인을 임의의 키에서 한 점과 그 주변에 대해 평가하고, 야코비안 극분해로 회전각과 변위를 구함 | `buildDeformerWorlds` + `SkeletonRig.inverse` 재사용 가능 |
| C5 | 가산층 | 2차 움직임을 블렌드 셰이프로 작성. 구버전 대상에서는 “파라미터마다 중첩 warp 한 층”으로 낮추고 손실 보고서 작성 | 엔진과 내보내기는 블렌드 셰이프를 지원하지만 생성기는 만들지 않음 |
| C6 | 이음새 글루 | 분할 구간 이음새, 계층을 넘는 인접 부품 이음새, 같은 토폴로지 중복 부품의 전체 정점 이음새 | Glue 도구와 `GlueSeam`은 있으나 생성 규칙 없음 |
| C7 | 그리기 순서 키폼 | 인접 키 계단 전환, 그룹 level 파라미터(그룹 안의 상대 오프셋 유지) | 채널 키폼만 작성 가능, 생성기의 그리기 순서는 정적 |
| C8 | 메시 분할 | 레이어 하나를 절단선을 따라 여러 drawable로 나눔, 안정 ID = 레이어 id + 구간 번호(무작위 사용 안 함) | 없음 |

**우선순위**: P0 이번 단계에서 구현, P1 다음 단계, P2 연구 또는 소재 규약에 의존. 난이도: 쉬움 / 중 / 어려움 / 연구.

## 1. hair.front(앞머리)

#### `hair.front/current` 두상 추종 + 단일 파라미터 흔들림 · 기준선 · 구현됨
- **현황**: `DeformHairFrontFollow`(AngleX×AngleY[×AngleZ]×BodyLean, 3×4, 가로 이동은 고개 돌림 방향과 반대, `0.62+0.38v` 행 가중치, 세로 이동과 중앙부 원근) → `DeformHairFrontPhysics`(`ParamHairFront` −1/0/1, 끝 가중치 v³로 가로 흔들림 + 들림, 3×4). 물리는 단일 구간·단일 출력이며 입력은 머리·몸 네 항목으로 고정됩니다. 머리카락 시뮬레이션을 켜면 흔들림층을 삭제합니다.
- **부족한 점**: 단일 출력, 3키(중간에서 현이 짧아짐), 모든 머리 다발이 같은 위상, “덩어리 + 다발” 계층 없음, 세로 탄성 움직임 없음, 그룹별 깊이 시차 없음.
- **위치**: 기본값으로 유지합니다. 새 템플릿은 follow와 physics 사이에 층을 끼우거나 physics 층을 교체합니다.

#### `hair.front/group-parallax` 머리카락 그룹 깊이 시차층 · **P0** · 쉬움
- **목적**: 고개를 돌릴 때 앞머리, 옆머리, 뒷머리, 머리 장식이 두상으로부터의 깊이에 따라 서로 다르게 가로 이동하게 하여 “종이 한 장이 통째로 도는” 느낌을 없앱니다.
- **적용 대상**: 앞머리 / 옆머리 / 뒷머리 / 머리 장식 태그가 있는 레이어 그룹. 다발별 길이는 선택 사항입니다.
- **출력**: 각 머리카락 그룹마다 head container 아래, 흔들림층 위에 단일 축 `ParamAngleX` warp 한 층을 끼웁니다(3키, 회전각 ≥ 30°이면 5키, C3). 메시는 3×3–5×5입니다. 긴 다발(> 0.4 Hh)은 각 흔들림 warp 아래에 AngleX 보정 warp를 한 층 더 끼워(“고개 돌림 / 흔들림” 교대 샌드위치) 흔들린 뒤의 형상도 올바른 깊이에 있게 합니다.
- **알고리즘**:
  1. 그룹 깊이 z(머리 반지름 R 단위): 코 1.0, 머리 장식 0.95, 앞머리 0.9, 눈 / 입 0.8, 얼굴면 0.75, 옆머리 0.3, 귀 0, 뒷머리 −0.6.
  2. AngleX = ±최대값 θ일 때 그룹 가로 이동 잔차 Δx = (z − z얼굴면)·R·sin θ(얼굴면 층이 이미 준 변위에 대한 상대값으로, 중복 적용을 피함). 회전 방향에서 먼 쪽 가장자리는 5–10% 압축합니다.
  3. 샌드위치: k번째 흔들림 warp 아래 보정층 Δx_k = d_k·sin θ, d_k는 층마다 0.02–0.05 Wf씩 증가합니다.
  4. 뒷머리 그룹의 시차 방향은 얼굴면과 반대입니다(머리 뒤에 있으므로).
- **조절 파라미터**: `depthFront` 앞머리 깊이(R) 0.9 [0.6, 1.2], `depthSide` 0.3 [0, 0.6], `depthBack` −0.6 [−0.9, −0.3], `depthHeadwear` 0.95 [0.7, 1.2], `farCompress` 7% [3, 12], `layerDepthStep` 0.03 Wf [0.02, 0.05], `minStrandLen` 0.4 Hh.
- **실패 양상과 확인**: 깊이가 너무 크면 앞머리 뿌리가 헤어라인에서 떨어짐 → 최대값에서 앞머리 뿌리와 얼굴 피부의 겹침 면적이 줄어들면 안 됩니다. 기존 follow의 가로 이동과 겹쳐 이중으로 계산됨 → 모두 잔차 기준으로 계산합니다.
- **엔진 기능**: 단일 축 warp, 키폼 평가기(잔차).
- **차이점**: 기존 follow에는 통일된 시차층 하나만 있습니다.

#### `hair.front/block-then-strand` 덩어리가 먼저 흔들리고 다발이 뒤따라 날림 · **P0** · 중
- **목적**: 앞머리가 먼저 하나의 덩어리로 지연되고, 이어서 각 다발이 따로 날립니다. 느슨하게 착용한 물건(모자, 머리 장식, 안경)은 덩어리와 같은 단계로 움직입니다.
- **적용 대상**: 앞머리 그룹에 여러 다발(하위 레이어 또는 연결 요소)이 있는 경우. 단단한 머리카락 한 가닥(바보털(아호게), 더듬이)은 따로 처리합니다.
- **출력**: 파라미터 `ParamHairFrontBlock`(물리 질점 1 읽기), `ParamHairFrontStrand`(질점 2 읽기, 여러 다발이 공유하며 `hair.strand/group-drive`의 다발별 진폭을 겹칠 수 있음). 구조: follow → 덩어리 warp(단일 축 또는 X×Y 2D, 그룹 전체를 덮고 위 가장자리 고정) → 각 다발의 메시 키폼(또는 다발 단위 작은 warp). 단단한 머리카락 한 가닥: 뿌리 회전 디포머(원점은 머리뿌리, ±10–15°) + 메시 끝 굽힘.
- **알고리즘**:
  1. 다발 식별: 하위 레이어 또는 연결 요소로 찾고, C1로 중심축과 뿌리(헤어라인 쪽 끝)를 구합니다.
  2. 덩어리층: 덩어리 전체를 헤어라인 중점 기준으로 평행 이동 + 약간 회전합니다. 가중치는 헤어라인 0에서 아래 가장자리 1까지이며, 아래 가장자리 변위 ≤ 0.05 L입니다.
  3. 다발층: C2 길이 보존 굽힘, 굽힘각 θ = θmax·s^p, C3에 따라 키를 추가합니다.
  4. 다발층 진폭은 덩어리층의 1.1–1.4배(scale은 `physics.chain`이 설정)입니다. 모자, 머리 장식, 안경은 덩어리층 파라미터를 읽으며 진폭은 자기 높이의 5–10%입니다.
- **조절 파라미터**: `blockShift` 0.04 L [0.02, 0.08], `strandBend` 20° [15, 30], `strandExp` p 1.5 [1, 2], `ahogeRoot` 12° [8, 18], `looseWearAmp` 자기 높이의 7% [5, 10].
- **실패 양상과 확인**: 모자와 앞머리의 지연 차이가 크면 틈이 드러남 → 모자 아래에 머리색 바탕이 있어야 합니다. 다발층 진폭이 크면 인접 다발이 서로 파고듦 → 인접 다발 진폭 차이 ≤ 30%.
- **엔진 기능**: 메시 키폼, 같은 물리 그룹의 다중 출력.
- **차이점**: 앞머리에는 덩어리 전체 흔들림 파라미터 하나뿐이며 물리는 질점 1만 출력합니다.

#### `hair.front/nested-warp-chain` 중첩 warp 다중 질점 채찍 체인 · **P0** · 중
- **목적**: 머리 조각 메시 하나로 뿌리→끝으로 전파되는 S자 굽힘과 채찍 끝 움직임을 메시를 자르지 않고 만듭니다. 넓은 머리 조각(너비 / 길이 > 0.4)에 가장 먼저 고려할 체인 형태입니다.
- **적용 대상**: 앞머리, 옆머리, 뒷머리 그룹. 치마 조각, 넓은 리본에도 적용됩니다.
- **출력**: 바운딩 박스가 같은 K층 중첩 warp(바깥층은 그룹 전체를 덮고, 안쪽 층은 먼 쪽 0.4–1.0 L만 덮을 수 있음, 바운딩 박스 10% 확장). k번째 층 파라미터 `Param<Group>X_k`는 물리 질점 k를 읽습니다. 선택적으로 층마다 두 번째 축 `Param<Group>Y_k`(세로)를 두어 2D 키를 만듭니다. 각 축은 C3에 따라 5–13키를 둡니다.
- **알고리즘**:
  1. k번째 층은 s ≥ (k−1)/K 부분만 굽힙니다(C2). 굽힘 중심은 s_k이고 [s_k, s_k + 0.2] 안에서 smoothstep으로 전이하며 길이를 보존합니다.
  2. 층 진폭 A_k = A_1·r^(k−1), r ≈ 0.7(중첩 변위가 누적되므로 바깥은 크고 안쪽은 작게).
  3. 단계적 중첩: 바깥층은 모든 출력을 받고 안쪽 층은 먼 쪽 출력만 받습니다.
  4. 2D 축: 모서리 키 = a를 먼저 적용한 뒤 b를 적용(warp 국소 좌표에서 합성). 부호가 같은 모서리 키는 범위를 넘지 않도록 0.7–1로 축소합니다. 두 번째 축에는 `hair.side/s-curve`의 분리 가능 합성을 사용할 수 있습니다.
  5. 같은 영역의 여러 다발은 같은 층 묶음과 파라미터를 공유하며, 각 다발은 자기 중심축으로 s를 계산합니다. 그 그룹의 머리카락 그림자와 포니테일 뿌리도 같은 층 묶음에 연결해 동기화합니다.
- **조절 파라미터**: `layers` K 3 [2, 4], `ampDecay` r 0.7 [0.6, 0.8], `tipDisp` 끝부분 최대 변위 0.2 L [0.1, 0.3], `innerStart` 0.4 L [0.35, 0.5], `arcTol` 현 오차 0.5 px [0.3, 1], `keysSmall` 5(|θ| ≤ 20°), `keysLarge` 9 [7, 13].
- **실패 양상과 확인**: 안쪽 층이 머리끝을 덮지 못해 접힘 자국이 생김 → 모든 정점이 안쪽 층 범위 안에 있는지 확인합니다. 부착점 근처 가중치가 0이 아니어서 머리뿌리가 떠다님 → s < 0.05에서 변위 0. 층이 너무 많으면 안쪽 층이 바깥층 떨림을 증폭함 → K ≤ 4. 키 수 팽창 → 2D는 S자가 필요한 그룹에만 사용합니다.
- **엔진 기능**: 중첩 warp, 다중 출력 물리, C3 원호 키, 선택적으로 C5 블렌드 셰이프로 두 번째 축 대체.
- **차이점**: `SwingDeformer`에는 이미 구간 개념이 있지만, `RigSwingEdits`는 파라미터마다 3키만 두고 모든 구간 축을 같은 warp에 곱합니다(3^(2n)개 키폼). 각 구간의 물리 파라미터와 scale도 같습니다. 머리카락 프리셋은 단일 구간·단일 출력입니다.

#### `hair.front/blend-modes` 같은 warp 위의 뿌리 / 중간 / 끝 블렌드 셰이프 모드 · P1 · 중
- **목적**: 곱셈 키폼 격자 대신 가산 블렌드 셰이프를 사용하여 여러 모드를 동시에 겹쳐도 폭발하지 않게 하고, 같은 그룹의 여러 다발을 동기화하면서도 똑같아 보이지 않게 합니다.
- **적용 대상**: 이미 고개 돌림 곱셈 축이 있는 머리카락 그룹. 대상 런타임이 블렌드 셰이프를 지원하면 그대로 출력하고, 아니면 낮춥니다(C5).
- **출력**: 각도 warp 안쪽에 “모드 warp”(10–20행 × 5–14열, 긴 축은 머리 다발 방향)를 끼웁니다. 키폼 축은 없고 K = 2–3개의 블렌드 셰이프 `Param<Group>Mode_k`(±1)만 연결합니다. 물리 축마다 별도 층을 둘 수도 있습니다(순서: 세로 Y → 가로 흔들림 X → 말림 Z, 느리고 큰 것이 바깥, 세밀한 것이 안쪽).
- **알고리즘**:
  1. 모드 1(뿌리): 머리뿌리를 중심으로 강체 회전, 끝 변위 0.3–0.4 L.
  2. 모드 2(중간): Δ = n·a2·L·smoothstep(0.25, 1, s)².
  3. 모드 3(끝): Δ = n·a3·L·s³. 짧고 넓은 앞머리는 부호를 반대로 하여 S자 굽힘을 얻습니다.
  4. 각 모드는 s = 0에서 정확히 0입니다.
  5. 같은 쪽의 여러 다발은 모드 1 파라미터를 공유하고, 모드 2, 3은 각자 파라미터를 가집니다(scale에 ±10–30% 결정적 지터).
  6. 넓은 머리 조각(너비 / 길이 > 0.5)은 모드 3을 열마다 독립적으로 둡니다.
- **조절 파라미터**: `mode1Tip` 0.35 L [0.3, 0.4], `mode2Amp` a2 0.25 [0.2, 0.3], `mode3Amp` a3 0.15 [0.1, 0.2], `tipReverse`(앞머리는 true), `sumClamp` 끝 총변위 상한 0.6 L.
- **실패 양상과 확인**: 여러 모드가 같은 부호로 겹쳐 범위를 넘음 → √Σp²로 진폭을 제한합니다. 부모층 회전각이 클 때 “국소 오른쪽” 방향이 틀어짐 → 모드층은 반드시 각도 warp 안쪽에 있어야 합니다. 중첩 warp로 낮춘 뒤에는 키 수를 추정해 보고합니다.
- **엔진 기능**: C5.
- **차이점**: 생성기가 블렌드 셰이프를 만들지 않습니다.

#### `hair.front/xyz-axes` 가로 흔들림 / 말림 / 신축 3축 · P1 · 중
- **목적**: 고개 젓기, 고개 기울이기, 끄덕이기마다 고유한 머리카락 반응을 주어, 모두 가로 흔들림 형상을 빌려 쓰지 않게 합니다.
- **출력**: 머리카락 그룹마다 파라미터 세 벌: X 가로 흔들림(변위 ∝ s^1.5), Z 말림(주축에 수직, ∝ s², 끝 너비 10–20% 좁아짐), Y 신축(주축 방향, 양수는 늘어남, 음수는 짧아지며 약간 넓어짐, 끝이 최대). 블렌드 셰이프 warp 세 층(또는 중첩 warp 세 층)으로 만듭니다. Y층은 AngleX와 2D 키를 만들어 세로 튕김 방향이 방향 전환에 따라 바뀌게 할 수 있습니다.
- **알고리즘**: 진폭비 X : Z : Y ≈ 1 : 1.5 : 2.5(%H 기준). Y의 중간값에 형상을 하나 추가해 짧아질 때 직선으로 납작해지지 않게 합니다. 세 축은 각각 “가장 관련 있는 머리 입력”이 주도합니다(`physics.*` 설계).
- **조절 파라미터**: `xTip` 0.6% H [0.4, 1], `zTip` 1.5% H [1, 2], `yTip` 2% H [1.5, 2.5], `zNarrow` 15% [10, 20].
- **실패 양상과 확인**: 짧은 앞머리의 Y 신축이 너무 커서 이마가 드러남 → 앞머리 Y ≤ 0.05 L. 넓은 다발의 Z 말림이 인접 다발을 찢어 놓음 → 인접 다발이 Z 형상을 공유하거나 글루를 추가합니다.
- **엔진 기능**: C5 또는 중첩 warp, 물리 세 그룹.
- **차이점**: 가로 흔들림 파라미터 하나뿐입니다.

## 2. hair.side(옆머리 / 귀밑머리)

#### `hair.side/current` 독립 분기 없음 · 기준선
- **현황**: 옆머리는 태그에 따라 앞머리 또는 뒷머리 분기에 들어가거나(또는 head container에 바로 연결) 독립된 시차, 흔들림, 층 교체가 없습니다.
- **위치**: 옆머리는 독립된 머리카락 그룹으로 두고 `hair.front/*` 템플릿을 재사용하며(깊이 z = 0.3), 아래의 옆머리 전용 템플릿을 추가합니다.

#### `hair.side/s-curve` 인접 질점 2차원 키로 만드는 진행파 S자 · P1 · 중
- **목적**: 단일 파라미터 흔들림은 “전체가 한쪽으로 휘는” 것만 가능합니다. 인접한 두 질점을 2D 키의 두 축으로 삼으면 모서리 키에서 각각 “뿌리는 휘고 끝은 곧음 / 뿌리는 곧고 끝은 휨 / 같은 방향 굽힘 / 반대 방향 S”가 되어, 흔들릴 때 곡률이 머리 다발을 따라 전파됩니다.
- **출력**: 2D warp(행은 긴 축 방향), 축 p = 질점 j, q = 질점 j+1(두 번째 축은 기본으로 반전하여 S자가 기본 결과). 아홉 키는 두 기본 형상의 분리 가능 합성으로 만듭니다.
- **알고리즘**: 가로 변위 = p·f(s) + q·g(s), f(s) = s², g(s) = 4·max(0, s − 0.5)². 모서리 키 (±1, ±1)는 둘의 합이며 0.7–1로 축소합니다. 두 층 중첩 시 바깥층은 (v1, v2), 안쪽 층은 (v3, v4)입니다.
- **조절 파라미터**: `fExp` 2 [1.5, 2.5], `gStart` 0.5 [0.4, 0.6], `secondReflect` true, `cornerScale` 0.85 [0.7, 1].
- **실패 양상과 확인**: 긴 축 방향을 잘못 판단하면(행이 가로 방향) 물결 모양 가장자리로 뒤틀림 → C1 중심축으로 행 방향을 정합니다.
- **엔진 기능**: 2D 키, “네 모서리 자동 합성”(분리 가능 합성).
- **차이점**: 물체마다 축 하나. 네 모서리 자동 합성은 후속 과제입니다.

#### `hair.side/turn-depth-swap` 고개 돌림 시 층 교체(머리 다발과 고리형 머리 장식) · P1 · 중
- **목적**: 회전각이 최대값에 가까워지면 가까운 쪽 귀밑머리, 포니테일, 고리형 머리 장식의 먼 쪽 반원이 얼굴 앞에서 얼굴 뒤로(또는 그 반대로) 이동합니다. 필요한 대상에만 계층 키를 추가합니다.
- **적용 대상**: 옆머리, 귀밑머리, 포니테일, 왕관 / 머리띠 / 후광(머리 중심선 기준으로 좌우 반으로 자름).
- **출력**: 대상의 그리기 순서 키폼(축 AngleX). 층 교체 각도 θs ± Δ에 인접 키 한 쌍을 넣습니다. 2–3단계로 나누어 내려갈 수 있습니다(앞머리 아래 → 얼굴 위 → 뒷머리 위). 중심선에서 정확히 전환해야 하는 부품은 0과 −ε 키 한 쌍으로 계단 전환합니다. 먼 쪽 절반은 동시에 타원체 원근에 따라 압축합니다.
- **알고리즘**:
  1. 뿌리 또는 부품 중심의 경도 φ = asin((x − xc)/r_head).
  2. 고개를 θ만큼 돌렸을 때 겉보기 경도 φ' = φ + κθ, 깊이 z = cos φ'.
  3. |φ'| > 90° − δ이면 얼굴 뒤에 있어야 합니다. 머리 그리기 스택에서 z에 따라 삽입 위치를 찾고, θs가 파라미터 범위 안이면 θs ± Δ에 키를 넣습니다.
  4. 층이 바뀌는 순간 대상은 대부분 가려져 있어야 하며, 그렇지 않으면 반전 마스크로 전이합니다(마스크 템플릿).
  5. 키 값이 무관한 층을 건너뛰지 않게 합니다(그리기 순서는 두 키 사이에서 정수 보간).
- **조절 파라미터**: `swapDelta` Δ 3° [2, 5], `swapMargin` δ 10° [5, 15], `kappa` 1 [0.8, 1.2], `levels` 2 [1, 3], `epsilon` 범위의 0.01%.
- **실패 양상과 확인**: 층 교체 키가 파라미터 범위 밖에 놓여 무효가 됨 → 생성 시 검증합니다. 층이 바뀌는 순간 색 차이가 크면 깜빡임 → 반전 마스크를 쓰거나 가려진 곳에서 층을 교체합니다.
- **엔진 기능**: C7, 반전 마스크.
- **차이점**: 생성기의 그리기 순서는 정적입니다(앞머리를 통과하는 복제본 제외).

#### `hair.side/carrier-split` 몸 / 팔 위에 걸친 긴 머리를 받치는 부위별로 분할 · P2 · 어려움
- **목적**: 긴 머리가 머리를 따라 흔들리면서 팔, 가슴, 몸통의 움직임도 따라가게 하여 두 움직임이 모두 맞게 합니다.
- **출력**: 긴 머리를 “정지 상태에서 어느 부위 위에 눌려 있는가”에 따라 구간으로 자르고, 각 구간을 해당 부위 디포머(머리, 가슴 물리 warp, 몸통, 위팔, 아래팔)의 하위 warp에 연결하며 구간 사이에 글루(C6)를 둡니다. 머리카락 물리 한 그룹을 블렌드 셰이프로 모든 구간에 더하고, 변위장은 전체 호 길이 s를 따라 연속으로 정의하며 각 구간은 자기 구간만 잘라 씁니다.
- **알고리즘**: 각 머리카락 정점은 화면 깊이상 그 뒤에서 덮고 있는 몸 메시로 소속을 정하고, 없으면 머리에 둠 → 연결 영역 평활화(최단 구간 ≥ 머리카락 너비 2배) → C8 구간 분할 + 글루 → 블렌드 셰이프 진폭은 s에 따라 증가하고, 부위에 눌린 구간은 압착 계수를 곱합니다.
- **조절 파라미터**: `pressFactor` 0.45 [0.3, 0.6], `segments` 2–4, 머리 roll 입력이 주도.
- **실패 양상과 확인**: 팔을 크게 들면 구간이 벌어짐 → 글루에 여유를 두거나 팔 각도를 축으로 하는 보정 warp를 추가합니다. 경계에서 소속이 떨림 → 평활화합니다.
- **엔진 기능**: 계층을 넘는 공유 블렌드 셰이프, C6, C8.

#### `hair.side/drill-ring-chain` 드릴 컬 고리 체인 · P2 · 어려움
- **목적**: 나선형 컬은 거의 강체인 고리들의 연결이며, 각 고리는 위 고리의 가장자리를 중심으로 돌고, 흔들릴 때 다음 고리의 어두운 안쪽이 드러납니다.
- **출력**: 뿌리 회전(AngleX×AngleY) → 고리마다 회전 하나(블렌드 셰이프 ±α_k) + 고리마다 AngleX×AngleY warp 하나(피치는 입구 타원의 단축을 바꾸고, 요는 깊이에 따라 시차를 줌). 각 고리는 앞띠 / 안쪽으로 나누고, k번째 고리는 k−1번째 고리의 앞띠 아래, 안쪽 위에 그립니다.
- **알고리즘**: 주축을 따라 너비 국소 최소점이나 어두운 안쪽 띠에서 N개 고리로 자릅니다. k번째 고리의 지점은 k−1번째 고리 아래 가장자리와 축의 교점(고리 너비 0.3만큼 아래로 오프셋)입니다. 물리는 긴 체인을 쓰고 출력 scale은 단계마다 0.88을 곱합니다(중첩 누적).
- **조절 파라미터**: `rings` N 4 [3, 5], `ringAngle` 20° [15, 25], `scaleDecay` 0.88 [0.85, 0.92].
- **실패 양상과 확인**: 고리 분할과 앞뒤 띠 분리는 소재 주석에 의존합니다.

#### `hair.side/curl-spring` 곱슬머리 스프링 신축 · P2 · 어려움
- **목적**: 가는 곱슬머리를 휘두르면 먼저 늘어나고 고리 간격이 커지지만 곱슬 형태는 유지됩니다.
- **알고리즘**: 중심선을 나선(반지름 r(s), 고리 간격 p)으로 매개변수화합니다. 키폼 p → p·(1 + k|x|), 전체를 흔들림 방향으로 θ·x만큼 편향하고 단면 너비는 유지합니다. 메시는 중심선을 따라 배치합니다(단면 3–5점).
- **조절 파라미터**: `stretch` 1.3 [1.2, 1.5], `deflect` 30° [20, 40].
- **실패 양상과 확인**: 자기 교차하는 그림 방식에는 중심선 모델이 맞지 않음 → 일반 흔들림으로 되돌립니다.

## 3. hair.back(뒷머리)

#### `hair.back/current` 추종 + Angle Z 역회전 + 단일 파라미터 흔들림 · 기준선 · 구현됨
- **현황**: `DeformHairBackFollow`(`HairRoll` 포함: 머리 길이가 턱을 넘으면 AngleZ 축을 추가하고, 턱 아래 점은 smoothstep·hold에 따라 머리 지점을 중심으로 반대로 역회전) → `DeformHairBackPhysics`(`ParamHairBack`, 3×6).
- **부족한 점**: 덩어리 전체가 단일 파라미터이고 가닥으로 나뉘지 않음. 아홉 포즈 3×3 때문에 목을 감싸는 뒷머리의 원형 궤적이 현을 따라 움직임. 앞머리와 같은 위상. 역회전은 warp에서만 처리하고 옆머리, 땋은 머리, 장식에는 적용되지 않음.

#### `hair.back/split-strips` 넓은 뒷머리를 가닥으로 나눠 각자 흔들림 · P1 · 중
- **목적**: 넓은 뒷머리를 여러 가닥(왼쪽, 오른쪽, 중심선 기준 두 반쪽)으로 잘라 각자 흔들리게 합니다. 세로 입력을 한쪽에서 반전하면 대칭으로 벌어지고 오므라드는 움직임을 얻습니다.
- **출력**: 가닥마다 흔들림층 한 벌(`hair.front/nested-warp-chain` 사용 가능), 파라미터 `ParamHairBack<Side>_k`. 중심선 위의 넓은 머리 조각은 중심선을 따라 반으로 자릅니다. 인접 가닥은 서로 어긋나게 조율한 흔들림 파라미터 두 벌을 번갈아 사용합니다(진자 길이 비 1.1–1.3).
- **알고리즘**: 절단선은 원화의 머리 가르마 틈(alpha 또는 밝기 골)에 놓고, 가닥 너비 ≤ 0.35 Hh로 합니다. 가닥 사이 겹침은 메시 칸 1개 이상으로 두고 글루를 추가하거나, 아래층에 머리색 바탕이 있게 합니다.
- **조절 파라미터**: `strips` 4 [2, 6], `maxStripWidth` 0.35 Hh, `detuneRatio` 1.2 [1.1, 1.3].
- **실패 양상과 확인**: 절단선이 머리 틈에 있지 않으면 흔들릴 때 균열이 드러남. 머리끝이 치마나 팔에 가려진 경우 뚫고 나옴.
- **엔진 기능**: C8 또는 하위 레이어, C6.
- **차이점**: `ParamHairBack` 하나뿐입니다.

#### `hair.back/strand-two-stage` 다발별 2구간 체인 + 회전에 따른 뿌리 벌어짐 · P1 · 중
- **목적**: 뒷머리 다발마다 뿌리 구간과 끝 구간의 2단 흔들림으로 S자를 만들고, 고개를 돌릴 때 가까운 쪽 / 먼 쪽 다발이 벌어지거나 오므라들어 부피감을 연출합니다.
- **출력**: 뿌리 회전(지점은 뿌리 R, 키 AngleX×AngleY, 각도 = k·요·측면 부호, 돌아서 멀어질 때 벌어짐) → 파동 회전(세로 파라미터 Wave) → 원근 warp(8×4, AngleX×AngleY) → 끝 회전(지점은 0.5 L 위치, 키는 흔들림 파라미터 × 요 × 피치, 옆을 향할 때 진폭 × cos 요) → 끝 warp. 뿌리 회전은 180° 기본 각도를 써서 국소 y축이 머리 다발을 따라 아래를 향하게 하며, 좌우 미러는 부호만 바꿉니다.
- **조절 파라미터**: `rootFlare` 요 45°당 3° [2, 5], `tipSway` 20° [15, 30], `wave` 7° [5, 10].
- **실패 양상과 확인**: 기본 각도 규약이 통일되지 않으면 미러 부호가 틀림 → “캔버스 방향” 규약을 전역으로 고정합니다.
- **엔진 기능**: 회전 체인, 다차원 키.

#### `hair.back/vertical-splay` 세로 흔들림을 좌우 벌어짐·오므라듦으로 변환 · P1 · 중
- **목적**: 끄덕이거나 위아래로 흔들릴 때 양쪽에 늘어진 물체(옆머리, 뒷머리, 리본)가 벌어지거나 모여 부피감을 보여 줍니다.
- **적용 대상**: 매달린 지점이 중심선의 어느 쪽에 있는지로 그룹을 나눈 늘어진 물체. 중심선 위의 물체에는 이 층을 추가하지 않습니다.
- **출력**: 늘어진 영역마다 세로 파라미터 한 쌍(질점 1, 2 읽기). 형상: +1이면 각 다발이 부착점을 중심으로 중심선에서 멀어지는 방향으로 θ = θmax·|x − xmid|/반너비만큼 돌고 끝이 0.05 L 올라감. −1이면 안쪽으로 0.5θ 돌고 3% 늘어남. 중간값은 |u|^1.3으로 완만하게 진입(C3로 베이크). 물리 측: 세로 입력을 한쪽에서 반전합니다(`physics.chain`에 맡김).
- **조절 파라미터**: `splayMax` 15° [8, 25], `innerRatio` 0.5 [0.3, 0.6], `ease` 1.3 [1, 1.6], 변위는 부착점에서 끝까지의 길이에 비례.
- **실패 양상과 확인**: 오므라들 때 몸, 팔과 파고듦 → 오므라듦 ≤ 벌어짐의 절반. 좌우 비대칭 원화는 각자의 중심선으로 계산합니다. AngleY 사인 스윕을 렌더링하여 양쪽 끝의 가로 변위 부호가 반대인지 확인합니다.
- **차이점**: VERTICAL 흔들림은 피치를 가로 변위로 취급하고, 모든 체인이 같은 부호이며, 벌어짐·오므라듦 형상이 없습니다.

#### `hair.back/cylinder-turn` 원기둥 프록시 밀집 키 고개 돌림 · P2 · 어려움
- **목적**: 뒷머리, 목 뒤, 옷깃은 목 축을 중심으로 원운동(가로 이동 ∝ sin θ, 보이는 너비 ∝ cos θ)을 하므로, 3키 선형 보간은 중간 각도에서 오차가 뚜렷합니다.
- **출력**: 뒷머리 그룹 AngleX×AngleY warp, 키 7×7(10°마다), 필요하면 13×13(5°마다)을 프록시로 일괄 생성합니다. 그 아래에는 평소처럼 각도 Z층과 물리층을 연결합니다.
- **알고리즘**: 원기둥 축 = 목 중심선, 반지름 r은 머리 너비의 약 0.55이며, ±최대값에서 뒷머리 가장자리가 여전히 머리 윤곽보다 머리 너비의 2–5% 바깥에 있도록 제약합니다. 제어점은 각좌표 φ를 θx(세로축 중심), θy(피치는 cos로 압축)만큼 회전한 뒤 정사영합니다. 머리에 가려진 앞쪽 점은 변위만 주고 가림은 바꾸지 않으며, 가림 변화는 `hair.side/turn-depth-swap`에 맡깁니다.
- **조절 파라미터**: `radius` 머리 너비의 0.55 [0.45, 0.65], `keyStep` 10° [5, 10], `perspective` 0.1 [0, 0.2].
- **실패 양상과 확인**: 반지름을 잘못 추정하면 뒷머리가 머리 윤곽 밖으로 미끄러짐. 키 수 팽창 → 보통 7×7이면 충분합니다.
- **엔진 기능**: 밀집 키 일괄 베이크. 얼굴의 13×13 머리 방향 전환 템플릿과 프록시 평가를 공유할 수 있습니다.
- **차이점**: 아홉 포즈 3×3.

## 4. hair.strand(가늘고 긴 물체의 공용 체인: 머리 다발, 땋은 머리, 포니테일, 리본 꼬리, 끈, 덩굴. 리본과 꼬리가 참조)

#### `hair.strand/skinned-chain` 구간 분할 스키닝 회전 체인 · P1 · 어려움
- **목적**: 가늘고 긴 물체가 큰 S자 굽힘과 채찍 끝 움직임을 하면서도 구간 길이를 보존하고 이음새가 갈라지지 않게 합니다.
- **적용 대상**: 종횡비 ≥ 3(또는 의미 태그 strand / braid / ponytail / ribbon-tail / rope / tail / vine), 길이 ≥ 0.06 H. 너비/길이 비 > 0.4인 넓은 조각은 `hair.front/nested-warp-chain`을 사용합니다.
- **출력**:
  - 메시: 원본 레이어를 중심축 법선 방향으로 N개 구간으로 자르고(C8), 절단선 양쪽에 겹치는 정점 열을 하나씩 남겨 강도 1로 짝지은 글루를 둡니다(C6).
  - 디포머: 구간마다 중첩 회전 디포머 하나, 원점 = 구간 시작 관절. 첫 마디의 기본 각도 = 뿌리의 절대 방향, 이후 기본 각도 = 앞 구간에 대한 중심축 회전각(정지 상태에서 원화 곡선을 복원).
  - 파라미터: 관절마다 `Param<Chain>_j` ±1 → ±45°(3키로 충분, 회전 보간은 원호를 따름). 파라미터는 체인 이름의 접이식 그룹에 넣습니다.
  - 겹침층: 하이라이트, 무늬 겹침층은 자르지 않고 모든 구간 메시의 합집합을 마스크로 사용하여 무늬가 이어지게 합니다.
  - 물리: 체인 하나의 그룹, 출력은 각 관절에 연결(매핑 규칙은 `physics.chain`에 맡김: 적은 질점으로 여러 관절 구동, 뿌리 공유, scale 뿌리→끝 경사, 고정 구간은 파라미터를 내지 않음).
- **알고리즘**:
  1. C1: 거리 변환 + 스켈레톤화, 뿌리에서 가장 먼 끝까지의 최장 경로를 취해 평활화. 뿌리 = 부모 부품과 겹치거나 가장 가까운 끝. 반너비 w(s)를 구합니다.
  2. 구간 수 N = clamp(round(L / (k·w̄)), 3, 9), k ≈ 2. 또는 길이 기준: < 0.08 H는 3, 0.08–0.2 H는 5, 0.2–0.5 H는 7, 능동 사지(꼬리)는 9.
  3. 관절 위치는 앞쪽을 촘촘하게, 뒤쪽을 성기게 하거나 곡률에 따라 적응: 중심축 회전각 > 30°인 곳에 절단점을 추가합니다. 꽈배기 땋은 머리는 국소 너비 최소점에 맞춥니다(땋은 매듭은 통째로 강체). > 0.93 L 위치에는 관절을 두지 않습니다.
  4. 절단선은 하이라이트와 강한 텍스처를 피하고, 양쪽 겹침 띠는 구간 길이의 0.03–0.06입니다.
  5. 정리: 삼각형 < 3 또는 면적 < 0.5%인 끝 구간은 앞 구간에 합칩니다(빈 구간을 남기지 않음).
  6. 고정: 두피에서 자라는 머리 다발은 앞쪽 15–25%에 파라미터를 만들지 않고 머리카락층 warp 아래에 바로 연결합니다. 매듭점에서 늘어진 물체는 뿌리 마디가 움직일 수 있습니다. 허리띠가 관통하여 뿌리가 고정된 띠는 첫 마디를 물리에 연결하지 않습니다.
  7. 체인 뿌리는 머리카락층 warp(고개 돌림 시차 계수가 얼굴면보다 10–30% 큼) 아래에 연결합니다. 머리 원근을 상속해야 하면 `warp-baked-chain` 또는 `segment-perspective-keys`를 참고합니다.
- **조절 파라미터**: `segments` N [3, 9], `segLenToWidth` k 2 [1.5, 2.5], `anchorRatio` 0.2 [0.15, 0.25], `jointRange` ±45° [30, 45], `overlap` 구간 길이의 0.04 [0.03, 0.06], `glueStrength` 1 [0.8, 1], `maxBend` 마디당 30°.
- **실패 양상과 확인**: 퇴화한 끝 구간. 절단선 UV가 일치하지 않아 가는 틈이 생김. 가려진 부분이 완전히 그려지지 않았는데 잘라서 빈 곳이 드러남(소재 요구 사항). 두 체인이 교차할 때 그리기 순서가 고정되어 파고듦. 마디당 회전각 > 30°이면 안쪽이 눌리고 글루가 벌어짐 → scale을 제한합니다. 파라미터 팽창 → 접이식 그룹 + 자동 명명.
- **엔진 기능**: C8(레이어 하나 → 여러 drawable, 안정 ID = 레이어 id + 구간 번호), 중첩 회전, C6, 다중 출력 물리.
- **차이점**: `RigSwingEdits`는 단일 warp에 구간별 키폼을 쓸 뿐 메시를 자르지 않고, 회전 체인을 만들지 않으며, 글루로 꿰매지도 않습니다. 뼈대 꼬리에는 체인이 있지만 구간을 자르지 않습니다. 긴 머리와 리본은 기본으로 warp 흔들림을 사용합니다.

#### `hair.strand/warp-baked-chain` 머리 원근 아래에서 회전 체인을 중첩 warp로 베이크 · P1 · 어려움
- **목적**: 머리 warp 아래에 연결된 머리 다발은 머리 warp의 원근 압축을 상속해야 합니다. 회전 디포머는 원점과 방향만 받으므로 머리 다발이 종잇장처럼 보입니다.
- **출력**: `skinned-chain`으로 구한 관절에 따라 중첩 warp 체인을 생성합니다(관절마다 “그 구간부터 끝까지”를 덮는 warp 하나, 약 16×7, 긴 축은 머리 다발 방향). 키폼 = 강체 회전 후 제어점의 부모 warp 국소 좌표 위치. 물리 출력은 여전히 관절각 기준이며, 바인딩만 회전에서 warp 파라미터로 바뀝니다. 머리 밖에 연결된 체인은 회전 형태를 유지합니다.
- **알고리즘**: 관절마다 샘플링 간격은 현 높이 오차로 정합니다(C3). Δθ = 2·acos(1 − ε/R), R = 관절에서 끝까지 거리, ε ≤ 0.5 px. R < 0.05 H이면 6–10°, R > 0.1 H이면 1.5–3°.
- **조절 파라미터**: `arcTol` 0.5 px [0.3, 1], `warpCols` 16 [12, 16].
- **실패 양상과 확인**: 중첩이 너무 깊으면 오차와 비용(warp 칸 수 × 키 수 × 마디 수)이 누적됨. 샘플링이 부족하면 끝부분이 직선으로 움직이며 늘어남.

#### `hair.strand/segment-perspective-keys` 체인 구간 메시로 부모 원근 잔차 보정 · P2 · 어려움
- **목적**: 체인 구간이 기하 키폼이 있는 warp(머리 방향 전환, 상체 원호 측면 기울기, 몸 방향 전환) 아래에 연결될 때, 회전 디포머가 전달하지 못하는 굽힘과 원근을 보충합니다.
- **알고리즘**:
  1. 조상 체인을 따라 기하 warp의 파라미터 축 A를 수집합니다(물리층 제외).
  2. 각 구간 메시와 A의 각 키 조합 a에 대해: 전체 warp 체인으로 P_warp(a)를 평가하고, “회전은 원점과 방향만 전달”하는 방식으로 P_rot(a)를 평가합니다. 구간 키폼 = 정지 형상 + (P_warp − P_rot)를 구간 국소 좌표로 변환한 것.
  3. 키 수는 부모 warp 키 수를 따릅니다. 3축을 넘으면 변위가 가장 큰 2–3개만 남기고, 변위 < 0.01 heye인 축에는 키를 넣지 않습니다.
  4. 생성기 산출물로 등록하고, 부모 warp 키폼이 바뀌면 다시 계산합니다. 인접 구간 이음새의 보정량은 일치해야 합니다(글루 검사).
- **조절 파라미터**: `minAxisDisp` 0.01 heye, `maxAxes` 2 [2, 3].
- **실패 양상과 확인**: 차원 폭발 → “체인 뿌리에 받침 warp 한 층을 추가하고 체인은 warp 밖에 연결”하는 방식을 우선합니다. 큰 각도에서 구간 사이 이음새가 벌어짐 → 글루.

#### `hair.strand/gravity-hold` 늘어진 물체의 중력 유지(부착점 역회전) · **P0** · 중
- **목적**: 머리나 몸이 기울어도 머리 다발, 땋은 머리, 귀걸이, 사슬, 리본 꼬리, 어깨 베일이 아래로 늘어진 상태를 유지하게 합니다. 정지 스크린숏에서부터 올바르게 보이고, 물리는 정적 평형에서 벗어난 흔들림만 표현합니다.
- **적용 대상**: 의미상 늘어진 물체(머리 다발, 땋은 머리, 술, 사슬, 리본 꼬리, 귀걸이, 펜던트, 어깨 베일, 매달린 털가죽). 정지 상태 주축과 중력의 사잇각 < 45°, 매달린 점이 위쪽 끝. 위를 향한 물체(깃털, 바보털(아호게))와 몸에 붙은 머리 조각은 제외합니다.
- **출력**: 체인 뿌리(또는 부착 구간 다음의 첫 관절)에 조상 회전 원천마다 회전 디포머 R_g 한 층을 끼웁니다(원점 = 부착점 p).
  - 머리 Z 원천: 축 `ParamAngleZ`(머리 관성 파라미터가 있으면 AngleZ × 관성 3×3).
  - 몸 Z 원천: 축 `ParamBodyAngleZ`(× 몸통 관성).
  - 전신 기울기 원천(`body.root/pelvis-chain`의 전신 기울기 파라미터가 있는 경우).
  - 각도 키폼 = −k × 해당 키에서 p 위치의 조상 누적 회전각. 물리층은 R_g 아래에 둡니다.
- **알고리즘**:
  1. C4: 각 끝점 키에서 p 근처의 짧은 벡터 방향 변화를 구해 누적 회전각 Θ(key)를 얻습니다.
  2. 부착 구간: 주축에서 여전히 운반체와 겹치는 앞부분 ℓ_attach > 0.1 L이면, R_g를 ℓ_attach를 지난 첫 관절 뒤에 끼우고 부착 구간은 운반체를 따라 돌게 합니다.
  3. 충돌 클리핑: 각 끝점에서 늘어진 물체가 몸, 얼굴, 팔 윤곽과 교차하는지 검사하고, 교차하는 쪽은 k를 줄입니다(받침에 닿게 될 쪽은 0으로 둘 수 있음). 결과적으로 좌우 비대칭 각도 범위를 얻습니다.
  4. 부착점이 크게 도는 사지 위에 있으면 k를 사지 각도에 따라 줄이고 보정에 상한을 둡니다.
  5. 물리는 Z 방향 Angle 입력을 유지하되 scale을 작게 하여 동역학만 담당합니다(`physics.*`에 맡김).
  6. 검증: 끝점을 렌더링하여 주축과 수직의 사잇각 ≤ (1 − k)·부모 회전각 + 3°인지 확인합니다.
- **조절 파라미터**: `kHead` 0.85 [0.75, 0.9] (귀걸이 0.8, 사슬 0.9), `kBody` 1.0 [0.8, 1], `kRigid` 단단한 매달림 장식 0.45 [0.3, 0.6], `attachLen` 0.2 L [0.15, 0.25], `innerOuterRatio` 0.8 [0.6, 1], `limit` 50° [40, 60].
- **실패 양상과 확인**: k = 1이면 늘어진 물체가 공중에 얼어붙은 것처럼 보임. 넓은 머리 다발에 R_g 하나만 쓰면 머리뿌리가 두피에서 떨어짐 → 반드시 부착 구간 규칙을 사용합니다. 부착점이 강한 warp 영역(얼굴 옆)에 있으면 warp 자체가 회전각을 가짐 → `hang-jacobian-compensation`을 겹칩니다. 몸에 밀착한 목걸이는 보정하지 않습니다.
- **엔진 기능**: C4, 회전 디포머, 2D 키.
- **차이점**: 기존 `HairRoll`은 뒷머리 follow warp에서 턱 아래 부분만 역회전합니다(단일 원천, warp 형태). 옆머리, 땋은 머리, 장식에는 중력층이 없습니다. `SwingDeformer`는 정적 평형과 동역학을 구분하지 않습니다.

#### `hair.strand/hang-jacobian-compensation` 머리 방향 전환 warp가 부착점에 만드는 국소 회전각 보정 · P1 · 어려움
- **목적**: 머리 방향 전환은 주로 warp로 처리되며, warp는 부착점에 전단과 국소 회전각을 만듭니다. 보정하면 늘어진 물체가 아홉 포즈 모두에서 수직을 유지하면서 머리를 따라 올바른 시차 변위를 냅니다.
- **출력**: 체인 뿌리(`gravity-hold` 층 바깥)에 AngleX×AngleY 3×3 회전층을 추가합니다. 각도 = −k_turn·θ(key)이며, θ는 부착점에서 부모 warp 야코비안 J = R·S를 극분해하여 얻습니다. |θ| > 1°일 때만 층을 만듭니다. 다른 용법: 각도는 항상 0이고 원점이 AngleX×Y 키에 따라 이동하는 “위치 지정 회전”으로, 부착점이 머리 표면을 따라가게 합니다(부착점은 머리 타원체 프록시 위에서 머리와 함께 돈 뒤의 투영). 위를 향한 물체는 이 층에서 보정하지 않고 대신 g·θ만큼 추가로 기울입니다.
- **조절 파라미터**: `kTurn` 0.9 [0.8, 1], `upwardGain` g 1 [0.5, 1.5], `minAngle` 1°.
- **실패 양상과 확인**: 부착점이 정확히 warp 메시 꺾임선에 있으면 야코비안이 불연속 → 주변 평균을 사용합니다. warp 키폼이 바뀌면 반드시 다시 계산 → 생성기 의존성으로 등록합니다. 아홉 칸마다 주축 각도를 측정합니다.

#### `hair.strand/upward-strand` 위를 향한 부속물(깃털, 바보털(아호게), 더듬이) · P1 · 쉬움
- **목적**: 물리 체인은 본질적으로 늘어진 진자이므로, 위를 향한 물체에서는 같은 방향 전환이 끝을 반대쪽으로 밀어냅니다.
- **출력**: 정지 방향 d(뿌리→끝)가 d·g < −0.3을 만족하면 해당 체인의 모든 물리 출력을 반전합니다. 진폭은 늘어진 체인의 1.5–2.5배입니다. 머리 기울기에 따르는 층(`hang-jacobian-compensation`의 반대 부호 버전)을 추가합니다. 바보털(아호게): 뿌리 회전(±10–15°) + 메시 끝 굽힘. 아치형 바보털: 3–6마디 체인 + 글루, 기본 각도는 아치 접선 방향이며 뿌리 마디도 흔들릴 수 있습니다.
- **조절 파라미터**: `upThreshold` −0.3, `scaleMul` 2 [1.5, 2.5], `ahogeSegments` 4 [3, 6].
- **실패 양상과 확인**: 수평으로 뻗은 경우(|d·g| < 0.3) 부호 판정이 불안정 → 측면 성분으로 판정합니다. 단단한 물체에는 체인을 쓰지 않습니다. 검증: 머리에 계단 입력을 준 뒤 깃털 끝과 머리끝의 변위 방향이 같고 둘 다 머리보다 늦게 따라와야 합니다.

#### `hair.strand/branch-and-cascade` 분기 체인과 연쇄 하위 체인 · P2 · 어려움
- **목적**: 머리 한 가닥의 끝이 여러 갈래로 나뉘거나, 부드러운 모자 끝에 금속 고리가 매달린 복합 물체: 하위 체인은 부모 체인을 따르다가 부착점을 지나면 각자 움직입니다.
- **출력**: 스켈레톤 그래프에서 차수 ≥ 3인 노드를 분기점으로 삼습니다. 줄기 = 뿌리에서 가장 먼 끝까지, 가지 길이가 줄기의 15% 미만이면 줄기 윤곽에 합칩니다. 가지의 첫 관절은 분기점이 속한 줄기 구간의 회전 아래에 연결하고(원점 = 분기점), 분기선에서 줄기와 글루로 잇습니다. 하위 체인 뿌리 관절은 강체(출력 0–5%)입니다. 복합 물체: 하위 체인 뿌리 축심이 어느 체인의 어느 구간 메시에 들어가는지(삼각형 적중) 판정해 그 구간의 회전 아래에 연결합니다. 부모 구간 위의 장식층(광채, 옆면)은 구간과 함께 연결합니다. 물리 매핑: 하위 체인은 부모 체인 연결 구간의 질점보다 뒤쪽(1–2 질점 깊이)부터 읽습니다.
- **조절 파라미터**: `minBranchRatio` 0.15 [0.1, 0.25], `branchRootStiff` 0–5%, `childOffset` 1 [1, 2], `maxDepth` 3.
- **실패 양상과 확인**: 분기점이 뿌리에서 길이의 15% 미만이면 두 개의 독립 체인으로 취급합니다. 연결 깊이가 3단계를 넘으면 각도 누적이 통제되지 않음 → 하위 체인 scale을 제한합니다.

#### `hair.strand/group-drive` 그룹 구동 + 다발별 결정적 진폭 · **P0** · 쉬움
- **목적**: 적은 파라미터로 많은 머리 다발 / 매달린 장식을 구동하되 다발마다 진폭을 다르게 하여 “한 덩어리가 동시에 흔들리는” 느낌을 깹니다.
- **출력**: 같은 그룹의 머리 다발(또는 같은 종류의 작은 장식)은 파라미터 한 벌을 공유하고, 다발마다 키폼 진폭을 따로 스케일합니다.
- **알고리즘**:
  1. 같은 그룹 안에서 길이로 진폭을 정규화합니다(긴 것은 크게, 짧은 것은 작게).
  2. 결정적 계수 c_i ∈ [0.5, 1.5]를 곱합니다(대상의 안정 id 해시를 시드로 사용하며 난수 금지).
  3. 몸에서 먼 바깥쪽 다발은 1.2–1.3을 추가로 곱합니다.
  4. 작은 장식: 흔들림각 φ_i = φ0·(1 + j_i), j_i ∈ [−0.5, 0.3], 방향은 ±15° 지터.
  5. 좌우 미러 부품은 지터를 주지 않고(미러 관계 유지), 같은 쪽의 같은 종류 부품에만 지터를 줍니다.
- **조절 파라미터**: `jitterMin` 0.5, `jitterMax` 1.5, `outerBoost` 1.25 [1.2, 1.3], `dirJitter` 15°.
- **실패 양상과 확인**: 인접 부품이 흔들린 뒤 서로 파고듦 → 끝점 겹침을 검사합니다.
- **차이점**: 흔들림이 여러 대상에 같은 형상 파라미터를 쓰며 결정적 개체 차이가 없습니다.

#### `hair.strand/float-wave` 떠 있는 긴 머리: 모션 진행파 × 물리 잔여 2축 · P2 · 중
- **목적**: 중력을 거스르며 떠 있는 긴 머리 / 리본은 손으로 작성한 진행파로 구동하고, 물리는 머리 움직임이 남기는 잔여만 겹칩니다. 둘은 서로 다른 파라미터에서 더해지므로 서로 덮어쓰지 않습니다.
- **출력**: 쪽마다 진행파 파라미터 W_k N개와 물리 파라미터 P_k N개. 마디마다 회전을 (W_k, P_k) 3×3 키로 둡니다. 각도 = a_k·W_k + b_k·P_k, a_k는 뿌리→끝으로 증가하며, 같은 쪽의 서로 다른 머리 다발에는 0.5–1.2의 결정적 계수를 곱합니다. 진행파 곡선은 `motion.idle`에 속합니다. 정지 상태 스타일 편향은 정지 메시에 합치고 모션에 쓰지 않습니다.
- **조절 파라미터**: `tipAmp` 20° [15, 25], `physScale` 뿌리→끝으로 감소.

## 5. hair.accessory(머리 장식)

#### `hair.accessory/current` head container에 연결 · 기준선
- **현황**: HEADWEAR 등은 기본으로 head container에 연결되어 두상을 따라 변형되며, 시차층, 물리 단계, 층 교체가 없습니다.

#### `hair.accessory/soft-shell` 머리에 쓰는 부드러운 외피의 2단 지연 · P1 · 중
- **목적**: 모자, 안대, 머리띠 위의 인형 같은 부드러운 외피는 조임으로만 고정되므로, 머리가 움직이면 반 박자 늦게 따라오며 살짝 미끄러져야 합니다. 앞쪽 조각은 많이 움직이고 뒤통수에 붙은 부분은 적게 움직입니다.
- **적용 대상**: “머리에 쓰는 부드러운 외피”로 표시된 레이어 그룹. 앞쪽 조각(두피에서 떨어짐), 머리에 붙은 조각(뒤통수에 붙거나 머리카락에 눌림), 끈으로 나눕니다.
- **출력**: 머리 방향 전환 warp → 물리 바깥층 warp(P1×P2) → 물리 안쪽 층 warp(P3×P4) → 국소 원근 warp(AngleX×AngleY, 소품 중심으로 원근을 다시 구함) → 메시. 머리에 붙은 조각은 바깥층을 건너뜁니다. 소품 위의 부속물(귀, 리본 매듭)은 반드시 물리층 아래에 연결합니다.
- **알고리즘**: P1은 전체 평행 이동(머리 접선 방향 ±0.3–0.5 heye), P2는 위 가장자리 중점을 중심으로 작은 회전(±4–6°). P3, P4도 같지만 진폭은 절반이고 변형은 아래 가장자리에 집중합니다(가중치는 위 가장자리 0에서 아래 가장자리 1). 물리: 같은 체인 그룹에서 바깥층은 질점 2, 안쪽 층은 질점 3을 읽습니다.
- **조절 파라미터**: `outerShift` 0.4 heye [0.2, 0.5], `outerTurn` 5° [3, 8], `attachedDamp` 0.45 [0.3, 0.6].
- **실패 양상과 확인**: 머리 아홉 칸마다 P 극값을 더했을 때 소품 위 가장자리와 머리카락의 접촉선 이탈이 < 0.15 heye여야 하며, 그렇지 않으면 P1을 줄입니다. 소품에 눌린 머리카락이 함께 변형되지 않으면 틈이 드러납니다.

#### `hair.accessory/floating-halo` 떠 있는 부속물(후광, 떠 있는 관) · P1 · 쉬움
- **목적**: 머리와 사이에 공간이 있는 부속물은 머리를 따라 움직이지만 자기만의 떠다니는 리듬이 있습니다. 고개 돌림 원근 변위는 머리카락보다 작습니다.
- **적용 대상**: 머리 윤곽과 닿지 않고 정수리 위로 > 0.05 Hh 떨어진 레이어(또는 떠 있음으로 표시된 것).
- **출력**: 떠다님 warp(가장 바깥층, 대기 파라미터로 0.08–0.12 Hh 위로 이동. `breath/attachment-bob`으로 구동할 수도 있음) → 원근 warp(AngleX×AngleY, 변위는 정수리 warp의 0.6–0.8) → 스위치. 항상 수평을 유지하려면 머리 롤 밖에 두고 반대 회전을 추가합니다. 고급(P2): 타원을 맞춰 3차원 고리를 복원하고, 머리 자세 + 물리 추가 회전각으로 다시 투영합니다. 바깥층은 전체가 떠다니고 안쪽 층은 부품별로 지연되며(꼬리 띠 ×1.3), 머리 뒤를 지날 때는 앞뒤 두 반쪽으로 잘라 그리기 순서를 설정합니다.
- **조절 파라미터**: `floatAmp` 0.1 Hh [0.08, 0.12], `perspRatio` 0.7 [0.6, 0.8], `keepLevel` false.

#### `hair.accessory/thin-card` 얇은 판 장식의 측면 드러남 · P2 · 중
- **목적**: 정면에서 거의 옆으로 보이는 얇은 고리, 얇은 판, 보석의 측면이 고개 돌림 / 몸 돌림 때 펼쳐지거나 드러나게 하며, 투영을 “회전 + 스케일 + 페이드 인”으로 근사합니다.
- **알고리즘**: 평면 법선과 시선의 사잇각 φ0를 추정합니다(주석 또는 종횡비로 추론). yaw θ에서 보이는 너비 ∝ |sin(φ0 + θ)|이며, θ를 축으로 3키를 넣습니다. 스케일 = |sin(φ0 + θ)|/|sin φ0|, 상한 3. 회전각은 투영 주축의 변화를 사용합니다. 불투명도 = smoothstep(0.1, 0.4, 보이는 너비 비율). 보석 측면층은 정면 키 0, 양 끝 1, 중간 0.5.
- **조절 파라미터**: `phi0`, `maxScale` 2.5 [2, 3], 페이드 인 임계값.
- **실패 양상과 확인**: 스케일 > 3이면 흐려짐 → 차분 그림을 사용합니다. 단색 대칭 물체에만 적합합니다.

#### `hair.accessory/strap-tilt` 끈 / 귀걸이 고리의 머리 기울기 한쪽 보정 · P2 · 쉬움
- **목적**: 머리 윤곽을 가로지르는 끈은 머리가 기울 때 두피 곡면을 따라 변해야 하며, 당겨지는 쪽과 느슨한 쪽이 비대칭입니다.
- **출력**: 끈 물리층 위에 AngleZ 회전 또는 warp 한 층을 추가합니다. 각도 = −k·Δθ_tangent(뿌리점에서 머리 윤곽 접선의 변화). 당겨지는 쪽 k 0.8–1, 느슨한 쪽 0.3–0.5, 최대 보정 ≤ 10°. 끈 물리는 몸 입력만 받고 머리 움직임은 계층으로 상속합니다. 양 끝이 모두 머리에 고정된 헤어밴드에는 필요 없습니다.

## 6. hair.variant(헤어스타일 변형, 보충 슬롯)

#### `hair.variant/fold-toggle` 탈착 가능 그룹을 부착점으로 수축한 뒤 페이드 아웃 · P1 · 쉬움
- **목적**: 모델 하나에 여러 헤어스타일 / 액세서리 조합(트윈테일, 한쪽 묶음, 똥머리, 모자, 외투)을 제공하며, 전환 과정이 갑자기 사라지는 대신 “집어넣는” 모습이 되게 합니다.
- **출력**: 탈착 가능 그룹마다 최상위에 회전 디포머 하나를 끼웁니다(원점 = 부착점). 파라미터 `Toggle<Group>` 0..1: 0 → scale 1, opacity 1; 0.6 → scale 0.3, opacity 0.5; 1 → scale 0.001–0.05, opacity 0; 각도는 그대로. 수축 방향은 “부착 부품 안쪽”(부착점 쪽, 또는 머리카락 / 몸 뒤로 부품 높이 하나 정도 가라앉음)이며, 수축 경로는 반드시 가리는 물체 뒤에 있어야 합니다. 동시에 단일 항목과 자주 쓰는 조합의 표정 파일을 생성합니다.
- **조절 파라미터**: `endScale` 0.02 [0.001, 0.05], `fadeStart` 0.6 [0.4, 0.7], `retractDist` 부품 높이 1개, `retractRotate`(선택적으로 뒤로 젖힘).
- **실패 양상과 확인**: 0으로 수축할 때 본체로 이어진 글루가 본체를 부착점 쪽으로 끌어당김 → 탈착 가능 그룹과 본체 사이에는 강한 글루를 만들지 않습니다. 숨겨진 그룹이 다른 대상의 마스크이면 그 대상의 클리핑도 함께 사라짐 → 마스크 참조를 검사합니다. 수축 경로에 가리는 물체가 없으면 얼굴이나 몸 위로 미끄러져 지나갑니다.

#### `hair.variant/deform-restyle` 변형 방식 헤어스타일 변형층 · P2 · 쉬움
- **목적**: 새 그림을 그리지 않고 변형으로 앞머리를 한쪽으로 넘기고, 옆머리를 바깥으로 뻗치거나 안으로 말고, 뒷머리를 부풀리거나 조입니다.
- **출력**: 머리카락 그룹의 “각도 warp”와 “물리층” 사이에 변형층 V(같은 해상도)를 끼우고, 축은 변형 파라미터(0/1 또는 −1/0/1)입니다. 변형 후에도 고개 돌림과 흔들림을 그대로 따릅니다.
- **알고리즘**: 앞머리 넘기기: 가마를 중심으로 한쪽으로 15–25° 회전, 머리끝 쪽은 10–20% 조이고, 눈이 최소 절반은 드러나게 합니다. 옆머리 뻗침: 아래 구간을 바깥으로 1–1.5% H 이동하고 살짝 위로 말아 올립니다. 뒷머리: 가로 스케일 ±8–12%. 드러나는 영역 아래 레이어의 alpha 덮임률을 자동 검사합니다(이마, 눈썹은 완전히 그려져 있어야 함).
- **조절 파라미터**: `sweepAngle` 20° [10, 25], `flipShift` 1.2% H [0.8, 1.5], `backScale` 10% [8, 12].

#### `hair.variant/twin-mesh` 변형 쌍둥이 메시 · P2 · 쉬움
- **목적**: 색 바꾸기, 텍스처 버전 바꾸기, 차분 팔에 있는 같은 장식을 처리할 때 리그 전체를 복제하지 않습니다.
- **출력**: 변형 메시는 원본 메시 토폴로지를 복제하여 같은 디포머 아래에 연결하고, 그리기 순서는 원본 바로 위에 붙이며, 불투명도 축은 변형 스위치입니다. 다차원 조합은 곱 키(헤어스타일 H × 변형 V)를 사용합니다. 쌍둥이 부품은 글루 쌍을 복제합니다. 배타적 차분 위의 같은 장식은 물리 파라미터 한 벌을 공유하고, 각자의 warp는 국소 좌표로 환산하여 화면 변위를 일치시킵니다.

## 7. neck(목과 머리·몸 연결)

#### `neck/current` 머리 회전 지점이 입선에 있음 · 기준선
- **현황**: `DeformHeadRotation`(AngleZ → 원화 기울기 + 회전, 지점 = 얼굴 중심 x, 입선 y)이 `DeformBodyZBreath` 아래에 연결됩니다. 목은 몸 레이어로서 몸 warp를 따릅니다. 목 전용 warp가 없고 머리 Z는 모두 머리 강체 회전이 담당하며, 지점은 방향 전환에 따라 움직이지 않습니다.

#### `neck/tilt-share` 머리 롤을 머리, 목, 상체에 배분 · P1 · 중
- **목적**: 고개 기울이기를 머리 회전만으로 처리하면 스티커가 도는 것처럼, 목이 부러진 것처럼 보입니다. 보이는 기울기를 목 전단과 상체(지연 포함)에 나누면 몸이 함께 움직이는 것처럼 읽힙니다.
- **출력**:
  - 머리 회전각 = r_head × AngleZ의 최대 각도(r_head 0.4–0.6, 물리와 연기에 여유를 남김).
  - 목 warp(축 AngleZ, 필요하면 아래에 AngleX×AngleY를 연결): 위 가장자리는 머리를 따르고 아래 가장자리는 몸통을 따르며, 전단은 약 0.1을 담당합니다.
  - 나머지 기울기는 상체에 맡깁니다: `body.lean/c-arc-tilt`(기하 직접 연결) 또는 `physics.filter`가 파생하는 몸 Z 파라미터(지연 포함).
  - 머리 회전 원점은 AngleX/AngleY 키에 따라 “목 뿌리점을 머리 warp로 평가한 위치”로 이동하여, 고개 돌림과 기울이기를 함께 할 때 목 연결이 어긋나지 않게 합니다.
  - 선택: 머리카락 덩어리 전체에 지연 블렌드 셰이프 한 층(정수리를 중심으로 1–2% H 반대로 회전, 물리 출력으로 구동)을 두어 각 머리카락 그룹의 뿌리 warp에 더합니다.
- **알고리즘**: 목 뿌리점 = 아래턱 아래 목 중심선. 각 AngleX×AngleY 키마다 C4로 평가해 원점을 얻습니다. 전신 서기이고 몸 파라미터가 없으면 `body.turn/head-driven`을 사용합니다.
- **조절 파라미터**: `headShare` r_head 0.5 [0.4, 0.6], `neckShear` 0.1 [0.05, 0.15], `hairLag` 1.5% H [1, 2].
- **실패 양상과 확인**: AngleZ 추적이 머리를 직접 돌리면서 상체도 구동하면 이중 기울기가 됨 → 셋의 합이 원래 최대 각도와 대략 같아야 합니다. 앉은 자세, 반신 모델은 가슴까지만 배분합니다.
- **엔진 기능**: C4, 선택적 물리 파생 파라미터.
- **차이점**: AngleZ는 머리 회전만 구동합니다. 몸 Z는 독립적이며 지점은 고정되어 있습니다.

#### `neck/collar-band` 목 / 허리 / 손목을 감는 띠 모양 물체의 원기둥 매핑 · P1 · 중
- **목적**: 목걸이(초커), 허리띠, 팔찌는 몸을 돌릴 때 원기둥을 따라 미끄러져야 하며(정면은 많이 이동, 가장자리는 압축), 장식은 뒤로 돌아가면 숨겨집니다.
- **적용 대상**: 넓고 얇으며 목 / 허리 / 손목을 감는 띠 모양 레이어(주석, 또는 부위의 좌우 윤곽을 가로지르는지 기하로 판정).
- **출력**: 띠 warp(2–3행 × 12–20열, 띠 방향), 축 BodyAngleX(필요하면 × BodyAngleY). 띠에 매달린 각 장식은 각자 BodyAngleX 키폼 한 층을 가집니다. 뒤로 돌아간 장식은 불투명도나 그리기 순서로 숨깁니다.
- **알고리즘**: 띠 위 점의 정규화 가로 좌표 u ∈ [−1, 1], 몸 X 최대값에서 u' = sin(asin(u) + Δ), 너비 × cos. 몸 Y는 띠의 곡률을 바꿉니다(고개를 숙이면 웃는 호 모양). 장식은 각자의 원기둥 위치에 따라 오프셋합니다.
- **조절 파라미터**: `delta` 최대값 15° [10, 20], 원기둥 반지름 = 띠 반너비.
- **실패 양상과 확인**: 장식과 띠가 어긋남 → 장식을 띠 warp와 나란히 두지 말고 띠 warp 아래에 연결합니다.

#### `neck/cross-glue` 머리·몸을 가로지르는 연결 부품과 계층을 넘는 인접 부품의 자동 봉합 · P1 · 중
- **목적**: 머리와 몸에 걸친 물체(이어폰 줄, 목도리, 목걸이, 어깨에 걸친 머리)는 끊어지지 않고 늘어나야 합니다. 서로 다른 구동 체인에 속한 인접 부품(허리선 위아래, 치마와 허리, 그림자 겹침층과 바탕)은 경계에서 틈이 벌어지지 않아야 합니다.
- **출력**: 경계를 가로지르는 레이어는 목선에서 머리 구간과 몸 구간으로 자르고(메시 칸 1–2개 겹침, C8), 각각 해당 계층에 연결하며 이음새에 글루를 둡니다(가중치 0.5 또는 더 무거운 쪽으로 치우침). 부모 체인이 다른 인접 메시는 공유 경계를 따라 정점 쌍을 샘플링해 글루를 만듭니다(쌍 수 = 경계 길이 / 평균 변 길이, 하한 5). 같은 토폴로지의 중복 부품(그리기 순서나 마스크를 위해 두 곳에 둔 같은 부품)은 전체 정점을 글루로 붙입니다. 긴 이음새는 가장 바깥 경계 정점 한 줄만 꿰맵니다.
- **조절 파라미터**: `boundaryDist` 평균 변 길이의 0.5 [0.3, 1], `strength` 1 [0.5, 1] (부드럽게 따르는 장식은 0.5–0.8), `overlapCells` 1–2.
- **실패 양상과 확인**: 양쪽 메시 밀도 차이가 크면 촘촘한 쪽이 뾰족하게 끌려 나옴 → 먼저 경계에서 다시 샘플링합니다. 강도 1의 긴 이음새는 층 사이 지연을 절반쯤 평균해 버림 → 경계만 꿰맵니다. 자세 전환 시 분리되는 부품은 전환점에서 강도를 0으로 키잉합니다(대상이 글루 키폼을 지원하지 않으면 그룹을 넘는 글루를 피함).

## 8. body.root(골반 뿌리 체인과 서기 자세, 보충 슬롯)

#### `body.root/current` 나란한 뿌리 + 몸 X에 약간의 엉덩이 이동 · 기준선 · 구현됨
- **현황**: `DeformLegs`(두 뼈 IK, 어떤 몸 파라미터에서도 발은 움직이지 않음)와 `DeformBodyXY`가 나란한 뿌리입니다. 몸 X에서 골반은 강체로 `hipShift`만큼 가로 이동하고, 몸 Y의 가라앉음 / 들림은 몸 돌림과 같은 warp에 묶여 있습니다. 독립 엉덩이 파라미터, 전신 기울기, 전체 변환 파라미터, 기본 서기 자세가 없습니다.

#### `body.root/pelvis-chain` 골반을 뿌리로: 전체 변환 → 엉덩이 → 발을 지점으로 한 전신 기울기 · P1 · 중
- **목적**: 무게중심 변화는 골반에서 시작하고 발은 고정점입니다. 골반을 움직이는 뿌리로, 다리를 반대로 회전하는 자식으로 만들면 어떤 엉덩이 동작에서도 발이 땅에 남습니다. “상체 옆으로 굽히기”와 “사람 전체가 발을 중심으로 기울기”는 서로 다른 기울기이므로 분리해야 합니다.
- **적용 대상**: 전신 서기(다리와 발, 또는 뼈대 다리가 있음). 하반신이 화면 밖이면 “발 고정”을 “무릎이 캔버스 아래 가장자리를 넘지 않음”으로 완화합니다.
- **출력**(뿌리 → 잎):
  - `ParamTotalX/Y`(평행 이동) → `ParamTotalZ`(화면 아래 중점을 중심으로 회전): 모션 전용(점프, 전체 흔들림)이며 추적에 연결하지 않습니다.
  - `ParamHipY`(가라앉음 / 들림) → `ParamHipX`(엉덩이 가로 이동).
  - `ParamBodyTilt`(두 발 중점 또는 지지발을 지점으로 한 전신 기울기).
  - 그 아래 두 가지로 나뉩니다. 상체 가지(기존 `DeformBodyXY` / lean / breath / Z). 다리 가지(다리마다 고관절을 원점으로 한 회전 하나, 키 = HipX × BodyTilt [× HipY × BodyX], 각도는 파라미터 조합 모서리에서 두 뼈 IK로 풀어 발의 화면 위치 변화 < 2% H). 그 아래 다리 warp가 무릎 굽힘과 허벅지 뿌리 보정을 담당합니다.
  - 물리 그룹은 HipX / HipY / BodyTilt / TotalY를 입력으로 쓸 수 있습니다(`physics.cascade`에 맡김).
- **알고리즘**:
  1. 레이어 분할이나 뼈대에서 발바닥 고정점 F_L/F_R, 고관절 H_L/H_R, 골반 중심 P를 얻습니다.
  2. 각 파라미터 조합 모서리에서: 부모 체인 변환 후 고관절 점 H′, 허벅지 각도 θ = ∠(F − H′) − ∠(F − H). 고관절에서 발까지 거리가 짧아지면 다리 warp로 무릎을 굽히고(무릎은 관객 쪽), 길어지면 제한합니다(늘어남 ≤ 3%).
  3. IK 비선형성: 각 모서리에서 따로 풀어 곱 키폼을 만듭니다.
  4. 하중을 받는 쪽의 비대칭은 `leg/weight-asymmetry` 참고. 매달린 물체는 BodyTilt에 대해 `hair.strand/gravity-hold`를 적용합니다.
- **조절 파라미터**: `totalXY` 6% H [5, 7], `totalZ` 10° [5, 12], `hipShift` 5% H [3, 8], `hipSink` 3% H [2, 4], `tiltMax` 12° [8, 18], `legCounter` 1.5 [1.2, 1.7] (다리 반대 각도 / 전신 기울기 각도).
- **실패 양상과 확인**: HipY가 너무 크면 무릎 굽힘이 90°를 넘어 그림이 망가짐 → 제한합니다. 긴 치마가 다리를 덮으면 치마는 다리가 아닌 골반을 따릅니다.
- **엔진 기능**: C4, 다차원 곱 키, 뼈대 또는 추론한 다리 관절.
- **차이점**: 두 뼈 IK와 몸 X의 엉덩이 이동은 있지만, 독립 엉덩이 파라미터, 발을 지점으로 한 전신 기울기, 전체 변환 뿌리가 없습니다.

#### `body.root/squat` 쪼그려 앉기 파라미터(IK 해를 다리 체인에 베이크) · P1 · 중
- **목적**: 무릎을 굽힐 때 몸만 내리면 발이 바닥을 뚫고, 무릎만 굽히면 몸이 내려가지 않습니다. 파라미터 하나로 뿌리 가라앉음과 두 다리의 각 관절을 동시에 구동하고 발끝은 고정합니다.
- **출력**: `ParamSquat` [−1, 1] (음수 = 발끝으로 섬), 키 −1, 0, 0.5, 1. 뿌리 가라앉음 h = s·h_max와 다리마다 고관절 / 무릎 / 발목 키폼을 구동합니다(기존 다리 FK 파라미터와 2D 조합).
- **알고리즘**: 각 샘플 s마다: 뿌리를 h만큼 내리고, 다리마다 두 뼈 IK로 발끝이 여전히 P에 있게 하여 θ_hip, θ_knee, θ_ankle을 얻습니다. 무릎 각도와 h는 비선형(≈ arccos(1 − h/L))이므로 최소한 s = 0.5 중간 키를 추가합니다. 음수 방향: 뿌리를 0.01–0.02 H 올리고, 발목을 펴고, 무릎을 폅니다.
- **조절 파라미터**: `squatDepth` h_max 6% H [4, 10], `kneeDir`(관객 쪽 / 바깥쪽), `tiptoeRise` 1.5% H [1, 2].
- **실패 양상과 확인**: 발끝 이탈 < 0.002 H. 몸 Y 가라앉음과 함께 쓸 때 이중으로 가라앉지 않게 합니다.
- **차이점**: 몸 Y 아래 방향의 “가라앉음, 무릎 안쪽으로 모음”이 몸 돌림과 같은 warp에 묶여 있으며 독립 쪼그려 앉기가 없습니다.

#### `body.root/rest-contrapposto` 0이 아닌 기본값으로 편안한 서기 자세 구성 · P1 · 쉬움
- **목적**: 기계적 영점(대칭 제작, 미러 키폼)과 미적 영점(편안한 콘트라포스토 자세)을 분리합니다. 키폼은 여전히 대칭 영점 기준으로 만들고 서기 자세는 기본값만으로 구현하므로, 자세를 바꿀 때는 기본값만 바꿉니다.
- **출력**: 파라미터 기본값만 바꿉니다(기하는 바꾸지 않음). 주도 쪽 s ∈ {−1, +1}(원화의 머리 기울기 방향을 따름). 전신 기울기 = s·(0.15–0.25)·범위. 엉덩이 가로 이동 = −s·(0.15–0.25)·범위(지지 다리 쪽으로 이동). 상체 되돌림 기울기 = 전신 기울기 각도의 40–60%(반대 방향). 머리 기울기는 상체와 반대이며 그 30–60%. 지지 다리 쪽 어깨는 약간 낮추고 반대쪽은 0.2–0.4만큼 으쓱합니다. idle은 기본값을 중심으로 흔들립니다. 다른 용법: “전시 자세”를 idle 상수나 추적 편향으로 생성합니다(머리 X 8–15°, 몸 X는 머리와 같은 방향으로 약 절반, 한쪽 다리에 하중, 아래팔 안으로 모음, 편안한 손).
- **조절 파라미터**: `tilt` 3° [2, 5], `upperBack` 0.5 [0.4, 0.6], `headCounter` 0.45 [0.3, 0.6], `hipShift` 1.5% H [1, 2], `shrugDiff` 0.3 [0.2, 0.4].
- **실패 양상과 확인**: 발은 움직이지 않고 파고듦이 없어야 합니다. 치맛자락과 머리카락 물리가 기본 편향 때문에 상시 치우치면 안 됩니다(기본값을 중심으로 정규화). 방송용 모델은 전시 자세를 모션이 아니라 추적 편향으로 만듭니다.
- **차이점**: 표준 파라미터의 기본값은 모두 0이며 기본 서기 자세 개념이 없습니다.

## 9. body.turn(몸 방향 전환)

#### `body.turn/current` 타원 단면 몸통 방향 전환 · 기준선 · 구현됨
- **현황**: `DeformBodyXY`(12×14, BodyX×BodyY): 몸통의 타원 단면이 중심선을 축으로 `turnDegrees`만큼 돌고, 사타구니 아래 `turnFade` 안에서 점차 사라지며, 원근 카메라를 씁니다. 몸통 바깥 점은 윤곽을 따라 평행 이동하고, 그 뒤 골반이 강체로 가로 이동 / 가라앉음합니다. 상반신은 하나로 방향을 바꾸고 모든 부착물이 같은 깊이이며, 방향 전환은 시간 지연이 아니라 사타구니에서 공간적으로 감쇠합니다.

#### `body.turn/piece-depth` 몸통 원기둥 깊이에 따른 부착물별 시차 · P1 · 중
- **목적**: 몸통은 원기둥이며, 그 위에 걸린 물체는 깊이가 다릅니다(앞쪽 장식 띠, 옆쪽 날개, 몸 뒤의 옷 조각). 부모 warp는 전체 방향 전환만 하고, 자식 warp가 깊이에 따른 보정을 겹칩니다. 몸이 앞으로 기울면 머리가 카메라에 가까워져 커집니다.
- **출력**: 몸 부품(목 장식, 상의 앞판, 뒤판, 옆 날개, 치마, 장식 띠, 소매)마다 몸 warp 아래에 단일 축 BodyAngleX warp 한 층. 머리 전체는 BodyAngleY를 축으로 하는 스케일 회전 아래에 감쌉니다(피벗은 목 뿌리).
- **알고리즘**: 몸통 반지름 = 몸통 반너비. 부품 깊이는 그리기 순서와 위치로 앞 / 옆 / 뒤를 판정합니다. 추가 오프셋 = (z_piece − z_body)·sin ψ·r, 옆쪽 부품은 압축 또는 늘림. 머리 스케일 s = 1 + 0.1·(BodyY / 최대값).
- **조절 파라미터**: `pieceParallax` 몸통 반너비의 0.2 [0.1, 0.3], `headScale` 10% [8, 12].
- **실패 양상과 확인**: 회전각이 크면 앞뒤 부품의 층 교체가 필요할 수 있음 → `body.turn/threshold-swap`과 함께 사용합니다.
- **차이점**: 상반신이 통째로 돕니다. `BodyLean`에는 원근 스케일이 있지만 부품별 깊이 시차와 몸 Y에 따른 머리 스케일이 없습니다.

#### `body.turn/lagged-layers` 상체 → 허리 → 사타구니 / 다리 → 치마의 계층 구동 구조 · P1 · 중
- **목적**: 실제 사람의 몸 돌림은 “파동”입니다. 몸통이 먼저 움직이고 골반, 다리, 옷자락이 차례로 따라오며, 골반은 약간 반대로 비틀립니다(콘트라포스토). 층마다 자기 디포머와 구동 파라미터가 필요하며, 시간 지연은 물리의 단계별 저역 통과로 얻습니다(`physics.cascade`에 맡김).
- **출력**:
  - L0 상체(가슴, 어깨, 머리): 기존 몸 warp, 1단 구동 파라미터를 읽음.
  - L1 허리: 허리띠 영역을 덮는 2D warp(L1 파라미터 × 2단 파라미터).
  - L2 사타구니 / 다리: 다리는 독립 뿌리(상체 Z 아래가 아님)이며 다리마다 고관절을 지점으로 한 회전 하나. 하반신(골반, 치마, 꼬리 뿌리) 회전은 “하반신 비틀기” 파라미터를 축으로 하고, 방향은 상체와 반대, 진폭 0.4–0.7.
  - L3 치맛자락 / 늘어진 물체: 가장 가까운 층의 구동 파라미터를 읽음.
  - 층과 층 경계 메시에 자동 글루(`neck/cross-glue`), 허리선에는 두 축 모두에 바인딩한 전이 warp 하나를 추가.
  - 엉덩이 비틀기 키폼: 골반 영역을 고관절 중심 기준으로 3–4% H 반대 평행 이동, 한쪽 다리 뿌리를 1–2% H 높임.
- **조절 파라미터**: `levels` 4 [3, 5], `lowerRatio` 0.5 [0.4, 0.7], `levelDecay` 층 간 회전 진폭비 0.5 [0.4, 0.6], `hipCounter` 20% [10, 30].
- **실패 양상과 확인**: 층 사이 위상 차가 크면 허리선이 찢어짐 → 글루를 쓰거나 L1 위 가장자리를 잠급니다. reflect 부호가 틀리면 아래층이 반대로 비틀림 → 양의 계단 입력에서 각 층 출력의 부호가 같아야 합니다(의도적 반대 위상 제외). 발이 땅에 붙은 모델에서 다리 영역 가로 이동이 너무 크면 미끄러지는 것처럼 보입니다.
- **차이점**: 방향 전환이 사타구니에서 공간적으로 감쇠할 뿐 층별 시간 지연이 없습니다. 다리와 상체가 동시에 움직입니다.

#### `body.turn/threshold-swap` 몸 돌림 임계값에서 층 교체와 교체 그림 · P1(층 교체) / P2(교체 그림) · 중–어려움
- **목적**: 몸이 범위의 절반쯤 돌고 나면 가림 관계가 바뀝니다(먼 쪽 팔이 몸통 뒤로 물러남, 가슴 겹침이 뒤집힘, 소매와 털의 앞뒤).
- **출력**: 겹치는 부품 쌍마다 거친 3D 프록시(몸통 원기둥, 어깨 오프셋 위치의 팔 원기둥)로 샘플 요에서 투영 깊이를 계산합니다. 순서가 θ*에서 뒤집히면 θ* ± δ에 그리기 순서 인접 키를 만듭니다(뒤집히는 쪽에만). 윤곽 토폴로지가 바뀌는 부품(두 가슴의 겹침, 옷깃 측면)은 |θ| > θ_alt에서 교체 그림으로 바꾸고, [θ_alt − δ, θ_alt] 안에서 교차 전환합니다.
- **조절 파라미터**: `delta` 범위의 0.07 [0.05, 0.1], `altThreshold` 범위의 0.45 [0.4, 0.5].
- **실패 양상과 확인**: 교체 그림은 소재가 필요하거나 생성해야 합니다. 두 키 사이 그리기 순서 정수 보간이 무관한 층을 건너뛰면 안 됩니다.

#### `body.turn/head-driven` 몸 파라미터가 없을 때 머리 각도로 전신을 계층적으로 구동 · P1 · 중
- **목적**: 얼굴 추적만 있는 호스트에서는 몸 파라미터를 만들지 않고 물리 지연도 더하지 않은 채, 전신 뿌리 warp가 머리 각도에 따라 작고 계층적인 변형을 하게 합니다. “고개 기울이기”가 자연스럽게 “전신이 살짝 옆으로 기울고 머리는 조금 더 기우는” 움직임이 됩니다.
- **출력**: 전신 뿌리 체인: AngleZ warp(전신, 6–8×6) → AngleY warp → AngleX warp → 아주 작은 AngleX 회전(±1°). 몸통 가지 Breath → AngleY → AngleX. 옷깃, 목 앞쪽에 각각 AngleZ 한 층. 다리마다 AngleZ warp 한 층을 두고 “그 다리 쪽으로 기우는” 절반에 중간 키를 추가합니다(약 0.4 × 끝점, 무릎 살짝 굽힘, 엉덩이 살짝 올라감).
- **배분**: AngleZ: 머리 회전 0.5 × 파라미터 각도, 전신 뿌리 warp가 어깨선을 0.15–0.25 × 파라미터 각도만큼 기울이고 발바닥은 고정(행 가중치는 발 0에서 머리 1). AngleX: 전신 뿌리는 ≤ 0.03 H 가로 이동과 약한 원근만, 몸통은 가슴 방향 전환, 머리 warp가 주된 방향 전환. AngleY: 몸통 ≤ 0.01 H 신축.
- **조절 파라미터**: `headRollShare` 0.5 [0.4, 0.6], `bodyTiltShare` 0.2 [0.15, 0.3], `legMidKey` 0.4 [0.35, 0.5].
- **실패 양상과 확인**: “몸이 머리를 따르는 물리” 모드와 배타적이며, 함께 쓰면 과도하게 겹칩니다. AngleZ 끝점에서 발바닥 변위 < 0.005 H. 전신 뿌리 warp가 너무 거칠면 치맛자락에 꺾인 모서리가 생깁니다.

#### `body.turn/performance-half` 연기형 몸 축: 절반 구간에 작은 동작 내장 · P2 · 어려움
- **목적**: 같은 파라미터가 반드시 대칭 몸 돌림일 필요는 없습니다. 몸 X의 절반 구간에 자세 조각(다리 들기, 발끝으로 서기, 다리 꼬기)을 겹치고 나머지 절반은 표준 몸 돌림을 유지하여 추적 중에 자연스럽게 발동되게 합니다.
- **출력**: 다리는 고관절 회전 + 무릎 IK를 쓰고, 음의 절반 구간 키: 든 다리 무릎 굽힘 35–50°, 발이 땅에서 0.05–0.08 H 떨어짐, 골반은 지지 다리 쪽으로 3–5° 기울고, 지지 다리는 폄. 다리 메시에는 BodyX × BodyZ × BodyY 조합 보정 키를 둡니다(점별 IK로 정밀 계산).
- **조절 파라미터**: `side`(왼쪽 / 오른쪽 / 끔), `kneeBend` 40° [35, 50], `footLift` 6% H [5, 8].
- **실패 양상과 확인**: “발 고정” 제약과 충돌하므로 명시적 옵션으로 둡니다. 든 다리와 다른 다리, 꼬리 사이의 그리기 순서.

## 10. body.lean(몸 Z 측면 기울기와 앞뒤 기울기)

#### `body.lean/current` 앞으로 기울인 척추 원호 + 단일 지점 측면 기울기 · 기준선 · 구현됨
- **현황**: `DeformBodyLean`(앞으로 기울 때 원호를 따라 척추를 굽히고, 골반이 `pelvisShare`만큼 분담, 원근 카메라). `DeformBodyZBreath`: 몸 Z에서 허리선 위가 허리를 중심으로 기울며, 각 행은 평행 이동만 하고 너비는 그대로인 단일 지점 방식입니다.

#### `body.lean/two-joint-spine` 2관절 척추 옆으로 굽히기 · **P0** · 쉬움
- **목적**: 단일 지점 기울기는 판자 한 장처럼 보입니다. 중첩된 두 지점으로 굽힘을 하나의 원호(아래 구간은 많이, 위 구간은 적게)로 나누고, 허리 이음새는 같은 파라미터의 warp로 전이시켜, 크게 굽혀도 뻣뻣하지 않은 옆 굽힘을 만듭니다.
- **출력**: 몸 Z를 2단으로 바꿉니다(중첩 회전, 또는 기존 warp 점 함수에서 두 지점에 따라 행 변위 생성). 지점 1 = 허리의 가장 좁은 행, 지점 2 = 허리에서 어깨선까지 40% 위치(가슴 아래). 각도 배분은 아래 구간 0.55–0.65, 위 구간이 나머지. 허리·엉덩이 메시는 BodyZ warp 하나 아래에 둡니다. 위 가장자리 행은 지점 1을 따르고, 아래 가장자리 행은 고정, 중간은 smoothstep으로 혼합합니다. 치마와 외투 warp도 같은 파라미터로 키잉합니다. 팔, 머리는 상속합니다. 매달린 물체에는 `hair.strand/gravity-hold`를 추가합니다.
- **조절 파라미터**: `totalAngle` 최대 총각도(스타일에 따라 10–45°, 기본은 기존 진폭 설정을 그대로 사용), `lowerShare` 0.6 [0.55, 0.65], `chestPivot` 허리–어깨의 0.4 [0.3, 0.5].
- **실패 양상과 확인**: 총각도가 크면 “행 평행 이동만”으로는 전단 변형이 생김 → 지점을 중심으로 회전하도록 바꿉니다. 허리 아래가 찢어짐 → 치마와 외투를 같은 파라미터로 키잉합니다.
- **엔진 기능**: 회전 디포머 또는 `bodySecondaryWarpPoint` 개조.
- **차이점**: 기존 몸 Z는 단일 지점이며 행은 평행 이동만 합니다.

#### `body.lean/c-arc-tilt` 머리 Z가 구동하는 상체 C자 원호 측면 기울기 · P1 · 중
- **목적**: 전신 서기 모델을 추적할 때 고개 기울이기를 상체 전체(머리, 팔, 손에 든 물건, 치마 윗부분 포함)의 C자 측면 기울기로 확장하고 발은 움직이지 않게 합니다.
- **출력**: 상체 측면 기울기 warp를 몸 Z 아래, 상체 내용 전체 위에 둡니다. 약 20×20으로 상체 바운딩 박스를 덮고, 축은 AngleZ(또는 그 파생 파라미터), 키 간격 ≤ 5°(C3). 다리는 그 아래에 두지 않습니다.
- **알고리즘**: 사타구니 중심을 지점으로, 높이 y에서 회전각 α(y) = θmax·((y_hip − y)/(y_hip − y_top))^β(위로 갈수록 더 많이 회전). 머리 회전 원점은 `neck/tilt-share`에 따라 방향 전환과 함께 이동합니다.
- **조절 파라미터**: `thetaMax` 7° [4, 10], `beta` 1.4 [1.2, 1.6], `pivotHeight`(사타구니 ↔ 허리).
- **실패 양상과 확인**: 앉은 자세나 반신 모델은 가슴까지만. 머리 회전과 동시에 최대값을 쓰면 이중 기울기가 됩니다.

#### `body.lean/segmented-spine` 척추 3구간 회전 체인 + 전역 / 구간별 가산층 · P1 · 중
- **목적**: 몸 회전 하나만 쓰면 종잇장이 통째로 흔들리는 것처럼 보입니다. 골반 → 허리 → 가슴 3구간을 중첩하고 서로 다른 위상으로 구동하여 아래에서 위로 전달되는 S자 흔들림을 만들며, base 각도는 원화의 콘트라포스토 곡선을 유지합니다.
- **출력**: 3층 중첩 회전(피벗: 고관절 중점, 허리선 중점, 가슴선 중점), base 각도 = 원화 척추 꺾은선의 구간 사이 각도 차. 층마다 전역 lean 블렌드 셰이프(세 층이 같은 파라미터, 각도는 1 : 1.2 : 1.4로 배분) + 그 층 전용 블렌드 셰이프(그 층과 그 위에만 영향)를 연결합니다. 머리 체인은 가슴층 아래에 연결하고, 필요하면 반대 roll을 추가해 시선을 수평으로 유지합니다. 땅에 고정해야 하는 옷자락 맨 아래 행은 따로 뿌리에 연결합니다.
- **조절 파라미터**: `segments` 3 [2, 4], `perSegAmp` 2° [1, 3], 대기 위상 차는 `motion.idle`에 속함.
- **실패 양상과 확인**: 세 층이 동시에 최대값이면 상체 기울기가 너무 큼. 아래 가장자리를 땅에 고정해야 하면 반드시 분리합니다.
- **엔진 기능**: 회전 디포머 위의 블렌드 셰이프(각도 가산).

#### `body.lean/inertia-split` 측면 기울기를 “직접층 + 관성층”으로 분할 · P1 · 쉬움
- **목적**: 추적 입력에는 관성이 없습니다. 몸 Z 기울기를 직접 warp(30–50%)와 관성 회전(나머지, 피벗은 허리 또는 사타구니)으로 나누고, 후자는 물리 출력으로 구동하여 사람 전체의 기울기에 오버슈트와 되돌아옴이 생기게 하며, 모든 자식 물리는 그 위에 겹칩니다.
- **출력**: 몸 뿌리 체인: Breath → [BodyY 관성 warp: 상체 가라앉았다 튀어오름, ≤ 머리 높이의 10%] → BodyZ 직접 warp → [BodyZ 관성 회전] → 몸 XY → 머리. 물리 설계는 `physics.filter`에 맡깁니다.
- **조절 파라미터**: `directShare` 0.4 [0.3, 0.5], `pivotHeight`(허리 / 사타구니).
- **실패 양상과 확인**: 관성이 너무 크면 술 취한 것처럼 보임. 모션에 이미 이즈 인·아웃이 있으면 이중 지연이 됩니다.

## 11. breath(호흡)

#### `breath/current` 어깨 들기 + 가슴 팽창 · 기준선 · 구현됨
- **현황**: `DeformBodyZBreath`: 원화의 어깨선과 허리선으로 위치를 정하고, 어깨와 거기에 딸린 머리, 팔을 들어 올리며, 가슴은 가우시안 너비로 약간 팽창합니다. 허리 아래는 움직이지 않습니다. `ParamBreath`는 어떤 물리에도 들어가지 않습니다.

#### `breath/arm-open` 호흡에 따른 팔의 미세한 벌어짐·오므라듦 · **P0** · 쉬움
- **목적**: 가만히 서 있어도 종잇장처럼 보이지 않게 합니다. 숨을 들이쉴 때 두 팔이 약간 벌어지고 아래팔이 살짝 따라옵니다. 자세에 따라 호흡이 어깨에 작용하는 방향이 다릅니다.
- **출력**: 위팔 회전(뼈대) 또는 `DeformArmHang_*` warp에 Breath 축을 추가합니다. 벌어짐 1–2°, 좌우 부호 반대. 아래팔 메시는 0.3–0.5% 변형으로 따라옵니다. 자세 분기가 있으면 Breath × 자세 파라미터 2D 키를 씁니다(기본 자세는 들이쉴 때 2–3° 벌어짐, 팔짱 자세는 오므리거나 0). 선택: 물리를 거쳐 호흡을 팔꿈치, 손목 2단 지연 흔들림으로 바꿉니다(`physics.excitation`에 맡김, 기하층은 `arm/passive-chain` 참고).
- **조절 파라미터**: `armOpen` 1.5° [1, 3], `foreFollow` 0.4% [0.3, 0.5].
- **실패 양상과 확인**: 호흡 한 주기 안에서 손 변위 ≤ 1–2% H. 물건을 든 팔이나 접촉 중인 팔에는 추가하지 않습니다.
- **차이점**: 호흡은 어깨, 가슴, 머리에만 작용합니다.

#### `breath/physics-only` 전신 서기: 호흡은 주로 물리로 표현 · P1 · 쉬움
- **목적**: 전신 서기 자세에서 전체가 오르내리면 둥둥 떠 보이기 쉽습니다. 호흡을 가슴, 상의, 꼬리, 장식 등 물리의 입력으로 쓰고, 몸통 기하에는 아주 작은 흉곽 팽창만 남깁니다. 반신 모델은 여전히 어깨를 직접 들 수 있습니다.
- **출력**: 다리가 있으면(전신 서기) `breath/current`의 어깨 들기를 아주 작게 줄이고, `ParamBreath`를 물리 입력으로 사용합니다(가중치 배분은 `physics.excitation`에 맡김).
- **조절 파라미터**: `standingLift` 0.3%(전신) / 3%(반신).

#### `breath/attachment-bob` 호흡에 따른 부착물 오르내림 · P1 · 쉬움
- **목적**: 날개가 견갑골을 따라 오르내리고, 떠 있는 소품과 후광이 호흡에 따라 위아래로 떠다녀 부유감과 생명감을 표현합니다.
- **출력**: 날개 뿌리 회전 / 평행 이동을 Breath로 키잉하며, 상승량 = 어깨 상승량 × 1–1.5. 떠 있음으로 표시된 소품은 뿌리 warp에 Breath로 키를 넣습니다: 0.01–0.02 H 위로 뜨고 ±2° 가볍게 흔들림. 떠 있는 부속물의 떠다님층은 같은 호흡이나 전용 대기 주기 파라미터를 쓸 수 있습니다.
- **조절 파라미터**: `wingLift` 1.2 × 어깨 상승량 [1, 1.5], `floatAmp` 1.5% H [1, 2], `floatRock` 2°.

## 12. arm(팔)

#### `arm/current` 늘어진 흔들림 또는 뼈대 FK · 기준선 · 구현됨
- **현황**: 뼈대가 없으면 `DeformArmHang_L/R`(BodyX × BodyLean × Proportion, 3×6. 몸 X에서 어깨를 중심으로 약 4° 반대로 흔들리며, 목표 캔버스 위치를 먼저 계산한 뒤 키폼을 역산). 뼈대가 있으면 위팔은 회전 디포머이고, Body X로 상속된 회전각을 상쇄하며 `armSwing`을 더합니다. 팔과 다리는 명시적으로 물리에 들어가지 않습니다.

#### `arm/passive-chain` 수동으로 늘어진 팔 체인(어깨 → 팔꿈치 → 손목 → 손가락) · **P0** · 중
- **목적**: 얼굴 추적이 손을 추적하지 않으면 팔은 죽어 있습니다. 편안히 늘어진 팔은 원래 진자 체인이므로, 몸이 움직이면 팔이 흔들리고 끝이 가장 많이 흔들려야 합니다.
- **적용 대상**: 늘어진 팔(어깨–팔꿈치–손목이 거의 수직, 손이 팔꿈치 아래, 주축과 수직의 사잇각 < 35°). 물건을 든 팔이나 접촉 중인 팔은 `arm/contact-stabilized`를 사용합니다. 팔에 자세 파라미터 / 모션이 설정되면 가중치를 낮추거나 끕니다.
- **출력**:
  - 뼈대가 있을 때: 어깨, 팔꿈치, 손목 3단 회전. 관절마다 물리 흔들림 파라미터 `ParamArmSwing<Side>_k`를 하나 추가하고, **블렌드 셰이프**(각도 가산)나 독립된 겹침 회전층으로 연결하여 자세와 모션이 구동하는 관절각을 덮어쓰지 않게 합니다. 손가락은 마지막 출력으로 가볍게 벌어지고 오므라듭니다(메시 블렌드 셰이프 또는 손가락마다 작은 warp 하나).
  - 뼈대가 없을 때: 기존 `DeformArmHang_*` 아래에 중첩 블렌드 셰이프 warp 3층을 추가합니다. 위팔층(어깨를 중심으로 4–6° 흔들림), 아래팔층(팔꿈치 바깥으로 약 3° 굽힘), 손층(손목 약 5° 지연). 메시를 자르지 않으며 이음새가 없습니다.
  - 관절 각도 구간은 비대칭: 몸 쪽 한계 = 벌어지는 방향의 0.35–0.65(어깨 약 0.35, 팔꿈치 약 0.65, 손목은 거의 대칭).
  - 물리: 체인 하나가 관절 순서대로 연속 질점을 취하고, scale은 뿌리→끝으로 증가합니다(약 1 : 1.2 : 1.5 : 2, `physics.chain`에 맡김). 좌우 손에 각각 한 그룹, 입력은 한쪽을 반전합니다(날갯짓처럼 보이지 않게).
- **알고리즘**: 안쪽 최대 각도는 “팔과 몸통 윤곽의 최소 간격”으로 구하고(보통 3–8°), 바깥쪽은 15–20°. 손가락 정지 굽힘은 어긋나게 단계적으로 두며, 각 손가락 진폭 = 기본 × (1 + 0.3k)(k는 검지에서 새끼손가락 방향).
- **조절 파라미터**: `shoulderOut` 15° [10, 20], `innerRatio` 0.5 [0.35, 0.65], `elbow` ±15° [10, 20], `wrist` ±10° [8, 12], `fingerFan` 0.3.
- **실패 양상과 확인**: 몸이 크게 앞으로 기울어도 진자의 중력 방향은 그대로라 팔이 뒤로 떠오름 → 입력에 몸 Y를 추가합니다. 흔들림과 모션이 충돌 → 물리 파라미터와 자세 파라미터를 분리합니다(2D 키 또는 블렌드 셰이프). 손 변위는 3–10% H 이내.
- **엔진 기능**: 회전 디포머 위의 블렌드 셰이프, 다중 출력 물리, 뼈대 관절.
- **차이점**: `skeletonRules`는 팔을 명시적으로 물리에서 제외합니다. `DeformArmHang`은 정적 키폼일 뿐입니다.

#### `arm/outside-chain` 몸통 warp 밖의 회전 체인으로서의 팔 · P1 · 중
- **목적**: 팔을 몸통 warp 안에 두면 몸을 돌릴 때 늘어나고, 큰 각도 변형이 통제되지 않습니다. 독립 회전 체인은 어깨점에서만 몸통 위치를 “읽습니다”.
- **출력**: 어깨점 회전 R_S(원점 S, 키 = 몸 X×Y[× 으쓱]: 원점은 몸통 warp로 평가한 S(key)로 평행 이동, 각도는 S에서 몸통 국소 회전각의 0.1–0.3배) → 위팔 회전 R_U → 위팔 단축 warp(0…1: +1은 축을 따라 75–85%로 압축하고 끝을 약간 넓힘, −0.5는 105–110%로 늘림) → 아래팔 회전 R_F(원점 E) → 아래팔 단축 warp → 아래팔 보정 warp → 손목 회전 R_W → 손. 어깨 보정 warp(키 = 위팔 각도): 팔을 들면 어깨 윤곽이 올라가고 겨드랑이가 좁아지며, 변위 ∝ sin(각도). 몸 Z는 어깨점에 따로 회전을 추가해야 합니다.
- **조절 파라미터**: `upperRange` −35…+50°, `shorten` 0.8 [0.75, 0.85], `shoulderFollow` 0.2 [0.1, 0.3].
- **실패 양상과 확인**: 몸 Y가 큰 각도일 때 어깨선과 위팔 뿌리 사이에 틈이 생김 → 어깨 보정층으로 덮거나 위팔 뿌리를 몸통 아래에 그립니다.

#### `arm/wide-fk-corrective` 넓은 범위 팔 FK + 각도별 샘플링 보정 · P2 · 어려움
- **목적**: 손 들기, 얼굴 가리기, 턱 괴기, 허리에 손 얹기, 머리 뒤로 손 넘기기를 모두 팔 메시 하나로 처리합니다. 아래팔은 한 바퀴 돌 수 있고 모션은 최단 경로로 보간합니다.
- **출력**: 위팔 회전(파라미터가 곧 각도, 약 −160…+30°, 기본 = 원화 자세) + 어깨 보정 warp(위팔 각도 × 몸 X, 0, 25%, 50%, 100%에 키. > 60%이면 겨드랑이 가림층 페이드 아웃) + 위팔 길이 스케일 0.9–1. 아래팔 회전 0…360(0과 360의 키 형상이 같아 순환 보장) + 보정 warp(자주 쓰는 구간 0–90°, 270–360°는 15°마다, 나머지는 30°마다, 또는 일괄 45°마다). 팔꿈치 캡 작은 메시는 90°마다 키 하나, 회전량은 아래팔 각도의 절반. 팔오금 주름 조각은 |θ| < 45°에서 불투명도 0, ≥ 90°에서 1(0으로 스케일하지 말 것). 손목, 팔꿈치에는 작은 평행 이동을 하는 “접촉 보정” 파라미터를 하나씩 추가합니다(±0.01 H).
- **보정 키폼**: 두 구간의 강체 변환을 팔꿈치를 중심으로 아래팔 길이 0.3 너비의 smoothstep으로 혼합한 뒤 부피를 보존합니다. 바깥쪽은 법선 방향으로 r·(1 − cos(θ/2))·0.5만큼 밀어내고, 안쪽은 그 절반만큼 오므립니다. 또는 ARAP 피팅으로 아래팔 근위부가 팔꿈치를 중심으로 반지름 0.5–0.6 팔 너비인 팔꿈치 캡 원을 덮게 합니다.
- **조절 파라미터**: `keyStepCommon` 15°, `keyStepRare` 30°, `volumeKeep` 0.5 [0.3, 0.7], `creaseAngle` 60° [45, 90], `perspScale` ±20% [15, 25].
- **실패 양상과 확인**: 5° 간격으로 스캔하여 팔꿈치 틈 면적과 아래팔 길이 변화가 < 5%인지 확인합니다. 손이 몸을 가로지르면 `arm/depth-level`과 함께 사용합니다.

#### `arm/joint-mask` 관절 클리핑 사각형 · P2 · 중
- **목적**: 아래팔이 돌 때 위팔 먼 끝과 소맷부리가 관절 반대편으로 드러납니다. 아래팔 각도에 따라 변환되는 4정점 보이지 않는 메시가 동적 절단선 역할을 합니다.
- **출력**: 부모 구간 사지 디포머 아래에 4정점 보이지 않는 메시를 만듭니다. 한 변은 관절 중심을 지나고 방향은 부모 구간과 자식 구간 방향의 각 이등분선에 수직이며, 부모 구간 쪽 반평면을 덮습니다(변 길이 ≥ 사지 너비 2배). 자식 구간 각도 90°마다 키 하나(굽힘 > 120°이면 45°로 촘촘하게). 부모 구간 먼 끝과 관절 근처 겹침 메시의 마스크로 사용합니다. 팔꿈치, 무릎, 손목에 적용됩니다.
- **조절 파라미터**: `quadSize` 사지 너비의 2.5 [2, 3], `keyStep` 90° [45, 90].

#### `arm/contact-stabilized` 들어 올린 / 접촉 중인 팔: 끝 안정화 · P1 · 중
- **목적**: 손을 가슴 앞에 두고 무언가를 쥐고 있을 때 몸이 흔들리면 위팔은 끌려가지만 손은 대체로 제자리에 있어야 합니다. 손가락과 쥔 물체는 같은 파라미터로 함께 키잉하여 보간 중에 접촉점이 떠다니지 않게 합니다.
- **출력**: 위팔은 같은 부호(질점 2 읽기), 아래팔은 반대 부호(질점 3, scale ≈ s·L_upper/L_fore), 손은 반대 부호(질점 4, 약간 크게). 관절에 글루를 두어 반대로 돌 때 틈이 드러나지 않게 합니다. 수동 각도 범위는 관절 가동 범위를 따르며(위팔 ±20°, 아래팔 ±40°, 손 ±30°), 물리는 그 20–30%만 사용합니다. 접촉 쌍: 상호작용 파라미터 하나가 손가락 메시와 쥔 물체 메시를 동시에 바인딩하고, 쥔 물체는 접촉 반지름 r_c 안에서 손끝 변위를 따르며(가중치는 부드럽게 감쇠), 두 궤적 차이 < 0.02 heye가 되도록 적응적으로 키를 추가합니다.
- **조절 파라미터**: `counterRatio` 0.8 [0.6, 1], `contactRadius` 0.45 heye [0.3, 0.6], `endDispRatio` < 0.3.
- **실패 양상과 확인**: 몸 Z 최대 진폭에서 손 중심 변위는 위팔 끝점 변위의 0.3배 미만이어야 합니다. 반대 위상이 너무 크면 손이 반대 방향으로 휘둘림. 쥔 물체의 다른 쪽 끝이 몸에 고정되어 있으면 접촉 근처의 짧은 구간만 손을 따르게 합니다.

#### `arm/depth-level` 팔 그룹 그리기 순서 level 파라미터 · P1 · 중
- **목적**: 손이 몸 앞에서 몸 뒤로 지나가거나, 허리에 손을 얹거나, 팔짱을 낄 때의 교차를 연속적인 level 파라미터 하나로 표현하고, 그룹 안의 상대 순서(손가락은 항상 손바닥 위)는 바뀌지 않게 합니다.
- **출력**: 그룹마다(팔 L/R, 날개, 소품, 하위 캐릭터에도 사용) `Param<Group>Level` 하나. 범위 = [스택에서 삽입 가능한 가장 낮은 위치, 스택 최상단], 기본 = 원화 위치. 그룹 안 각 메시의 그리기 순서 = level + δ_i(δ는 그룹 내 순위 × 작은 간격, 끝점은 |δ_i|만큼 바깥으로 넓혀 잘림 방지). 단순화 형태: 위팔, 아래팔+손에 3값 계단 파라미터 두 개(몸 뒤 / 기본 / 몸 앞).
- **조절 파라미터**: `levelStep` 스택 간격 0.25–0.5, `innerStep` 0.01–0.05.
- **실패 양상과 확인**: 두 메시의 그리기 순서가 같으면 떨림 → δ로 어긋나게 하고 그룹 밖 인접 메시와 간격을 둡니다. 마스크가 있는 그룹은 마스크 메시도 함께 이동합니다. 대상이 부품 단위 그리기 순서를 지원하면 부품에 두는 것을 우선합니다.

#### `arm/pose-branches` 같은 사지의 다중 자세 그림 분기 · P2 · 어려움
- **목적**: 아래팔이 큰 각도로 돌면 원근과 손 모양이 모두 바뀌어, 그림 한 장을 억지로 변형하면 뒤틀립니다. 팔짱, 주먹 쥐고 손 들기, 악기 들기, 손 흔들기 같은 큰 자세는 전용 그림을 쓰고, 전환 중에 반투명 잔상이 나타나지 않게 합니다.
- **출력**: 어깨점에서 공유 뿌리 회전(으쓱, 호흡 × 자세, 몸 X/Y 보정, 팔 흔들기). 그 아래 자세마다 분기 컨테이너 하나(회전, 원점은 어깨, 불투명도는 자세 파라미터로 구동). 분기 안에 FK 체인과 분기 전용 미세 조정 파라미터(±10–20°). 2차 물리(소매, 손목 띠)의 같은 출력을 각 분기의 해당 부품에 모두 바인딩합니다(키 값은 그 자세의 주축 방향으로 다시 투영). 단일 슬라이더 2단 방식: P ∈ [0, s]에서 기본 그림이 FK로 인계 자세 Ph까지 돌고, 목표 그림은 Ph로 역변형되어 유지(보이지 않음). s → s + ε에서 하드 컷. [s + ε, 1]에서 목표 그림이 Ph에서 원래 자세로 변형되어 돌아오며, 뒷구간에는 중간 키 1–2개를 추가합니다. 인계 자세는 두 그림의 윤곽 차이(alpha IoU / Chamfer)가 최소가 되는 비율로 정합니다. 깊이를 가로지르는 사지의 뒤쪽 조각은 몸통 부품에 넣고, 다른 체인에서 같은 파라미터로 움직임을 재현합니다. 드러나는 몸통 영역에는 패치층을 생성합니다. 먼 끝 구간만 바꿀 때는 기본 구간의 불투명도를 모든 스위치 파라미터 격자에서 “모두 0인 곳에서 1”로 둡니다.
- **조절 파라미터**: `handoff` s 0.5 [0.4, 0.6], `eps` 0.01 [≤ 0.02], `alignTol` 사지 면적의 3%.
- **실패 양상과 확인**: P = s와 s + ε 두 프레임을 렌더링하여 사지 alpha 차이 면적 < 3%. 두 그림의 분할이 일치하지 않으면 먼저 부품을 통일합니다. 자세 배타성은 생성기 출력 제약이나 우선순위로 보장합니다.

#### `arm/hidden-hand-peek` 등 뒤로 숨긴 손이 흔들릴 때 살짝 드러남 · P2 · 중
- **목적**: 완전히 정지한 뒷짐은 용접된 것처럼 보입니다. 몸이 흔들릴 때 가끔 손가락이 조금 드러나 구조와 무게를 암시합니다.
- **출력**: 가려진 사지 끝을 warp 두 층으로 감쌉니다. A: 손이 어깨·팔꿈치 방향을 중심으로 바깥으로 흔들리며, 드러나는 양은 손 길이의 0.3–0.5. B: 손목 뒤집기와 손가락 벌어짐·오므라듦. 그리기 순서는 몸, 머리카락 뒤이며, 드러나는 부분은 윤곽에 자연스럽게 가려집니다. 좌우 손 중 한쪽은 세로 방향을 반전합니다.
- **실패 양상과 확인**: 원화에 가려진 손이 완전히 그려져 있어야 합니다. 너무 많이 드러나면 뒷짐 설정이 깨집니다.

## 13. hand(손)

#### `hand/current` 손은 팔 끝의 메시 한 조각 · 기준선
- **현황**: 손 생성이 없습니다. 뼈대로 손가락 체인을 수작업으로 만들 수는 있지만 마디 분할 규칙, 손가락 파라미터, 제스처 라이브러리가 없습니다.

#### `hand/finger-chain` 손가락 3마디 체인: 쥐기 × 펴기 · P1 · 중
- **목적**: 파라미터 두 개로 “쥐기 ↔ 펴기”와 “붙이기 ↔ 벌리기”를 다룹니다. 주먹을 쥘 때 손끝은 손가락 뿌리를 중심으로 한 원호가 아니라 나선을 따라갑니다.
- **적용 대상**: 손가락이 이미 레이어로 나뉘어 있거나(손가락마다 하나 또는 이미 마디로 잘림), 손 전체 메시 + 키포인트로 자동 분할(손 분할 필요).
- **출력**: 손가락마다 3마디 중첩 회전(원점 MCP, PIP, DIP, 손가락 길이 0.45 : 0.30 : 0.25로 자름), 엄지는 2마디. 파라미터 `ParamFingerCurl<Side>`(−1 꽉 쥠 … +1 원화 형태), `ParamFingerSpread<Side>`(근위 마디에만 작용, 가운뎃손가락에 대한 방위각 기준 ±5–15°, 엄지 ±20°), 2D 3×3 키. 관절 글루는 가장 가까운 정점 1–2쌍. 손톱, 관절 주름은 해당 마디를 마스크로 씁니다. 반지 등 부착물은 해당 마디 회전 아래에 연결합니다. 손가락이 약 120° 넘게 굽으면 원위 마디의 그리기 순서를 손바닥 뒤로 내립니다.
- **알고리즘**:
  1. 완전히 쥔 각도: 근위 마디 약 60°(ease-out), 중간 마디 90–100°(선형), 원위 마디 약 70°(ease-in). c = 0.5일 때 대략 최대값의 (0.7, 0.5, 0.3). 키 c ∈ {−1, −0.5, 0, 0.5, 1}.
  2. 새끼손가락에서 검지 쪽으로 쥠 각도를 10–15%씩 줄입니다(척측이 더 꽉 쥠).
  3. 시점 보정: 손가락 평면과 화면의 사잇각 φ가 크면(옆에서 봄) 굽힘을 각도로 표현하고, φ가 작으면(손등을 정면에서 봄) 축 방향 단축으로 바꿉니다. 각도 계수 × sin φ, 길이 × cos φ.
  4. 굽힐 때 바깥쪽 관절이 손가락 너비의 0.1만큼 볼록해집니다(관절 warp).
- **조절 파라미터**: `curlMax` (60°, 95°, 70°), 각각 [(55, 65), (80, 110), (60, 80)], `easeExp` 2 [1.5, 2.5], `spread` 10° [5, 15], `ulnarExtra` 12% [10, 15].
- **실패 양상과 확인**: 손바닥을 정면으로 보는 손은 회전으로 굽힘을 표현할 수 없음 → 제스처를 바꿉니다. 반쯤 굽힌 상태에 중간 키를 넣지 않으면 “짧아지며 파고듦”이 생깁니다.
- **엔진 기능**: 중첩 회전, 관절 글루, 마스크, 그리기 순서 키폼.

#### `hand/gesture-library` 제스처 라이브러리: 정수 자세로 여러 손 그림 전환, 손가락 파라미터 공유 · P2 · 어려움
- **목적**: 펴기, 편안함, 가리키기, 쥐기, 주먹, 브이, 턱 괴기 등은 그림 한 장의 변형으로 얻을 수 없습니다. 제스처 파라미터는 “그림을 바꾸고”, 손가락 파라미터는 “그 그림 위에서 손가락을 움직이며”, 둘은 직교합니다.
- **출력**: `ParamHandPose<Side>` ∈ [0, K−1] (기본 = 원화 제스처). 손 그림 한 벌마다 불투명도 그룹 컨테이너 하나([k − 0.5 + ε, k + 0.5]에서 보임, 양쪽 0.05–0.15 교차 띠 또는 인접 키 계단 전환)를 두고, 모두 같은 손목 회전 아래에 연결합니다(손목점과 손바닥 방향으로 강체 변환을 구해 컨테이너 기본 각도와 스케일에 기록). 각 벌 안의 손가락 체인은 `hand/finger-chain`을 재사용하며, 키 = 손가락 파라미터 × 그 제스처 구간 끝점. 손바닥 warp는 제스처만 키잉합니다. 전이 띠 양 끝에서 두 벌의 손가락 각도를 손끝 포락선이 가장 가까운 곳으로 맞춥니다. 모션 중 계단 전환은 손목 각속도가 가장 큰 프레임에 둡니다.
- **조절 파라미터**: `K` 4 [3, 7], `band` 0.1 [0.05, 0.15], 전환 방식(계단 / 2–4프레임 페이드).
- **실패 양상과 확인**: 같은 순간 Σ opacity ≤ 1. 제스처 구간 밖의 손가락 키폼도 합리적이어야 합니다.

#### `hand/palm-flip` 손바닥 / 손등 뒤집기 · P2 · 연구
- **목적**: 손목 돌리기(손바닥이 앞 → 옆 손 → 손등이 앞)를 연속 파라미터 하나로 처리합니다.
- **출력**: `ParamHandFlip` θ ∈ [−180, 180] (기본 = 원화 시점). 시점마다 한 구간을 맡고, 경계(±90°)에서는 그 시점의 키폼이 손 너비를 옆으로 선 너비(손 너비의 약 0.25)로 압축합니다(다리 형태, 양쪽 기하 동일). 약 0.1° 떨어진 키 두 개로 불투명도를 계단 전환합니다. 손가락 관절 각도는 “벌림·오므림 × θ” 2D 격자(θ ∈ {−180, −90+ε, 0, 90+ε, 180})로 두며, 면 안의 굽힘각은 α·|cos θ_rel|, 관객 쪽을 향한 성분은 마디 스케일 1 − k·|sin θ_rel|·c로 표현합니다. 옆모습 지점을 지날 때 손가락 회전각을 ±360으로 바꿔(아주 가까운 겹친 키) 먼 길로 돌지 않게 합니다. 손가락 뿌리 위치는 θ에 따라 손바닥 너비를 따라 다시 배치합니다.
- **조절 파라미터**: `edgeWidth` 손 너비의 0.25 [0.2, 0.3], `eps` 0.1°, `views` 2 또는 4.
- **실패 양상과 확인**: 최소한 손바닥, 손등 두 시점의 소재가 필요합니다. 원근 투영각과 축심 재배치는 평가기에 의존합니다.

## 14. leg(다리)

#### `leg/current` 두 뼈 IK, 발 고정 · 기준선 · 구현됨
- **현황**: `DeformLegs`(8 × 10–20, BodyX×BodyY×Proportion 27키): 골반 강체 + 다리마다 두 뼈 IK. 무릎은 관객 방향으로 굽고 `kneeIn`만큼 안으로 모이며 발은 고정됩니다. 뼈대 다리 아래에는 서기 자세 warp가 받칩니다. 좌우 다리는 대칭으로 따라갑니다.

#### `leg/weight-asymmetry` 하중 다리 비대칭(콘트라포스토 무게중심) · **P0** · 쉬움
- **목적**: 서 있는 캐릭터가 옆으로 기울거나 엉덩이를 옮길 때 하중을 받는 다리는 펴지고 다른 다리는 살짝 굽으며, 발은 여전히 땅에 고정됩니다. 대칭으로 따라가면 기둥 두 개처럼 보입니다.
- **출력**: 기존 다리 IK 키폼에 비대칭을 더합니다. 기울기 / 엉덩이 이동 방향 쪽이 하중 다리(펴고 약간 바깥으로 밀림, 각도 a_near), 반대쪽은 무릎을 굽히고(a_far = 0.3–0.5 a_near) 엉덩이가 약간 올라갑니다. 미러 다리는 서로 맞바꿉니다. 몸 파라미터 없는 모드에서는 다리마다 AngleZ warp의 “그 다리 쪽” 절반에 중간 키(약 0.4 × 끝점)를 추가합니다. 다리가 상체 기울기를 따르는 비율은 0.3–0.6입니다.
- **알고리즘**: BodyX, BodyZ(또는 전신 기울기)의 각 끝점 키마다 하중 쪽에 따라 목표 무릎 각도와 엉덩이 높이를 정한 뒤 두 뼈 IK로 발이 움직이지 않는 해를 구합니다. 중간 키는 따로 풉니다(비선형).
- **조절 파라미터**: `asymRatio` 0.4 [0.3, 0.5], `followUpper` 0.45 [0.3, 0.6], `maxLegAngle` 3° [2, 4], `midKey` 0.4 [0.35, 0.5].
- **실패 양상과 확인**: 비율이 너무 크면 절뚝이는 것처럼 보임. 끝점에서 발바닥 변위 < 0.005 H.
- **엔진 기능**: 기존 `BodyStance` 두 뼈 IK.
- **차이점**: 다리는 몸 파라미터에서 대칭이며 무릎만 굽힐 뿐 하중을 구분하지 않습니다.

#### `leg/front-back-level` 어느 다리가 앞에 있는지 나타내는 계층 파라미터 · P1 · 쉬움
- **목적**: 다리를 꼬거나, 걸음을 내딛거나, 발차기를 할 때 두 다리의 앞뒤 관계가 바뀝니다.
- **출력**: 다리 그룹 그리기 순서 계단 파라미터(또는 `arm/depth-level`과 같은 구조의 level 파라미터). 두 다리가 교차할 때 전환합니다.

#### `leg/fk-corrective` 다리 3단 FK 뼈대 + 단계별 보정 · P2 · 어려움
- **목적**: 발차기, 다리 찢기, 발등 굽히기·펴기처럼 90° 이상의 동작은 회전 체인을 써야 합니다. 회전은 자세를, 보정 warp는 살을 담당하며 둘을 분리합니다.
- **출력**: 고관절 R(θ_hip) → 무릎 R(θ_knee) → 발목 R(θ_ankle), 원점은 세 관절점. 파라미터 매핑은 인체 가동 범위에 따라 비대칭입니다(고관절은 앞차기가 크고 뒤로 빼기가 작음, 무릎은 한쪽으로만 굽고 약간의 과신전 허용, 발목은 약 ±90°). 각 회전 아래 메시 전용 보정 warp를 연결합니다(허벅지 약 13×6, 종아리 20×5, 발 10×6). 축 = 해당 관절 파라미터(인접 관절 파라미터와 다시 2D). 보정 키는 25%, 75%(곡률 변화가 가장 큰 곳)와 100%에 둡니다. 바깥 윤곽은 원호로 채우고(반지름 = 관절 위치 사지 너비의 0.5), 안쪽은 압축하며 약간 바깥으로 부풉니다. 고관절에 ±0.03 H 평행 이동 보정을 추가합니다(발차기 > 90°이면 고관절점이 위·바깥으로 이동). 피치는 마디 스케일(±15–30%)로 원근을 표현합니다.
- **조절 파라미터**: 관절 범위(인체 가동 범위 기준), 보정 중간 키 20–35% / 65–80%.
- **실패 양상과 확인**: 무릎을 > 90° 굽히면 종아리를 허벅지 앞에 그려야 함 → 그리기 순서 키 또는 복제본.

#### `leg/view-swap` 회전 방향 부호에 따라 즉시 전환하는 쌍 시점 · P2 · 중
- **목적**: 발이 정면에서 옆으로 돌면 형상 차이가 너무 커서 변형으로 얻을 수 없고, 교차 페이드는 반투명한 발 두 개를 만듭니다. 같은 방식이 손, 날개, 신발에도 적용됩니다.
- **출력**: 파라미터 p ∈ [−1, 1], 정면 그림 F가 [−1, 0], 옆면 그림 S가 [0, 1]을 담당합니다. 두 그림은 p = 0에서 모두 중간 형상(키포인트 평균 위치, TPS / ARAP)으로 변형됩니다. 불투명도 F {−1:1, 0:1, +ε:0}, S {−ε:0, 0:1, 1:1}. 그림자, 끈 등 세부층은 0 → 0.5 → 1 반 구간 선형 페이드입니다.
- **조절 파라미터**: `eps` 매우 작게, `bridge` 중간 형상 치우침 0.5 [0.3, 0.7].
- **실패 양상과 확인**: p = ±ε 양쪽을 렌더링한 차이 이미지에서 윤곽 차이 < 1 px.

#### `leg/shoe-proxy` 신발 부품별 3축 근사 3D · P2 · 연구
- **목적**: 전신 방송인의 발끝으로 서기, 발끝 바깥으로 향하기, 신발 밑창 드러내기.
- **출력**: 신발을 밑창, 옆면, 갑피, 굽, 끈으로 나눕니다. 프록시 3D 신발(윤곽 돌출, 높이는 신발 길이의 0.3–0.4, 정사영)을 구성하고, (요, 피치, 다리 시점) 3×3×3 조합에서 프록시 정점을 구해 각 warp 제어점을 맞춥니다. 각 면의 가시성은 법선과 시선 내적의 부호로 결정합니다(계단 전환 또는 뒷면 컬링). 끈 끝점은 단일 글루 쌍으로 갑피의 구멍 위치에 고정합니다.

#### `leg/gait-rig` 제자리 걷기 다리 구조 · P2 · 어려움
- **목적**: 버추얼 방송인에게 “걷고 있는” 대기 동작을 줍니다.
- **출력**: 쪽마다 상반신과 독립된 다리 warp 체인: [걸음 오르내림 × 흔들림] → [엉덩이 가로 이동] → [허벅지 × 무릎 2D warp, 길이 방향 ≥ 20행 × 5열] → [발목 warp] → [몸 추종 혼합]. 오르내림 B, 흔들림 S, 깊이 D(그리기 순서, 두 다리가 교차할 때 전환)를 공유합니다. 상체는 회전 원점 평행 이동으로 움직입니다(오르내림 2–2.5% H, 흔들림 1.5–2%). B, S는 물리 입력으로 씁니다. 걸음 곡선은 `motion.*`에 속합니다.

## 15. chest(가슴)

#### `chest/current` 호흡 팽창만 있음 · 기준선
- **현황**: 호흡할 때 가슴이 가우시안 너비로 약간 팽창합니다. 가슴 영역 인식도, 가슴 흔들림도 없습니다.

#### `chest/nested-bounce` 가슴 단계별 중첩 warp 다위상 튕김 · P1 · 중
- **목적**: 연부 조직의 움직임은 바깥층의 전체 이동 + 안쪽 층의 더 늦은 위상 떨림입니다. 부호를 번갈아 각 층을 반대로 움직이게 하여 평행 이동이 아닌 “출렁임”을 만듭니다. 가슴 위를 덮는 옷, 리본, 장식도 함께 움직입니다.
- **적용 대상**: 가슴 영역이 있는 경우(의미 주석, 또는 상의 윤곽과 어깨선으로 양쪽 가슴 중심과 반지름을 추정).
- **출력**:
  - L0 영역 warp(양쪽, 비교적 촘촘, 약 26×26–30×40). 치마 물리층 안쪽, 각 부품의 몸 X 보정 바깥에 둘 수 있으며 앞쪽 몸 전체(장식 띠, 옆 날개, 치마 윗부분, 상체)를 감쌉니다.
  - 쪽마다 L1 한쪽 warp(몸 X×Y 자세 키) → L2 한쪽 표면 warp.
  - 물리 파라미터: 세로 그룹 Y1/Y2/Y3, 가로 그룹 X1/X2/X3(질점 1/2/3 읽기, 가로 2, 3번째 출력은 반전). `physics.chain`에 맡깁니다.
  - 바인딩: (X1, X2)는 2D 키(진행파, `hair.side/s-curve`와 같은 구조)로, 나머지는 블렌드 셰이프로 L0/L1/L2의 서로 다른 부분집합에 연결합니다. 몸 X를 가장 안쪽 물리 warp의 세 번째 축(−, 0, +)으로 두어 흔들림 방향이 몸 돌림 자세마다 체형에 맞게 할 수 있습니다.
  - 가슴 면 두 벌을 채널 부분집합이 다른 warp 아래에 연결하고 전체 정점을 글루로 붙입니다(변형은 평균되고 선화와 채색이 분리되지 않음). 단추 등 세부는 L2 아래에 두거나 가슴 면에 글루로 붙입니다.
  - 가슴 영역과 겹치는 몸에 붙은 옷 메시에는 같은 블렌드 셰이프를 가중치 0.6–1(밀착도에 따라)로 추가하고, 바깥 외투, 리본은 0.3–0.6.
- **알고리즘**: 변위장은 가슴 중심을 기준으로 한 방사형 감쇠(가우시안 σ = 가슴 너비의 0.5–0.6). Y = 세로 평행 이동 + 아래 가장자리 압착(아래 가장자리 변위가 큼). X = 가로 평행 이동 + 약간의 회전, 아래쪽이 지연. 쇄골 위는 0으로 감쇠. 진폭은 가슴 높이 기준 X1 ±0.12, X2 ±0.06, Y1 ±0.10, Y2 ±0.05.
- **조절 파라미터**: `ampX` 1.5% H [1, 2], `ampY` 1.8% H [1.5, 2], `sigma` 가슴 너비의 0.55 [0.5, 0.7], `clothFollow` 0.8 [0.6, 1], `outerFollow` 0.45 [0.3, 0.6].
- **실패 양상과 확인**: 진폭이 너무 크면 옷깃과 목 장식이 끌려감 → 쇄골 위는 엄격히 0. 체형이 겹치는 가장자리는 메시를 자르거나 반전 마스크가 필요합니다.
- **엔진 기능**: 중첩 warp, C5, C6(전체 정점 글루).
- **차이점**: 가슴 물리 템플릿이 없습니다.

## 16. skirt(치마)

#### `skirt/current` 몸 warp 추종 + 선택적 천 시뮬레이션 / 흔들림 · 기준선 · 구현됨
- **현황**: 치마는 `DeformBodyXY` / breath 아래에 연결되어 몸 키폼을 따릅니다. 모델 프리셋의 “옷 시뮬레이션”으로 베이크하거나(이름이나 실루엣으로 치마 / 바지 구분) `SwingPreset.CLOTH` 단일 흔들림을 쓸 수 있습니다. 층 깊이 개념이 없고 안팎 층의 진폭과 위상이 같습니다.

#### `skirt/layer-gradient` 여러 겹 치마의 안팎 순서에 따른 진폭 경사 + 2모드 · **P0** · 중
- **목적**: 바깥층이 먼저 끌려가고, 안쪽 층은 바깥층 너머로 반 박자 늦게 작은 진폭으로 움직입니다. 가볍고 얇은 층(망사, 레이스)은 더 나풀거립니다. 좌우 흔들림과 위아래 튕김은 서로 다른 두 모드입니다.
- **적용 대상**: 치마 부품 ≥ 1층. 다리는 독립(다리와 신발은 치맛자락층에 넣지 않음).
- **출력**:
  - 그리기 깊이로 치마층을 정렬합니다. ℓ = 0(가장 바깥) … L−1(속치마 / 뒤판).
  - 치마 그룹 변형 스택: 먼저 Y 모드(밑단 세로 늘림 / 압축 + 벌어짐 / 오므라듦), 그다음 X 모드(밑단 가로 길이 보존 흔들림), 각각 2–3층 중첩(`hair.front/nested-warp-chain`의 치마 버전: 허리선 고정, 밑단 자유, 진폭은 허리까지 거리의 제곱으로 증가).
  - 층별 진폭 계수: 가장 바깥층 1.0, 가장 안쪽 층 0.15–0.3, 선형 보간. 가볍고 얇은 층은 ×1.5–2를 추가.
  - 물리 출력은 층 깊이에 따라 질점을 읽습니다. 층 ℓ의 주 구동 질점 = 1 + ℓ·(N−1)/(L−1)(바깥층은 얕은 질점, 안쪽 층은 깊은 질점). 층이 질점보다 많으면 인접 층이 공유하고 0.5로 혼합합니다(체인과 입력은 `physics.chain`에 맡김).
  - 선택 채널로 Z(밑단이 반지름 방향으로 벌어짐, 회전하며 부풀어 오름을 모사)를 추가합니다.
- **알고리즘**: X: 허리선을 축으로 한 가로 흔들림, 밑단 최대, 허리선 0. Y: 밑단 전체가 올라가며 약간 짧아짐. Z: 반지름 방향으로 벌어짐. 진폭: X 1–2% H, Y 2.5–4.5% H, Z 2–4% H(허리에서 밑단까지 거리의 약 6–12%).
- **조절 파라미터**: `innerAmp` 0.25 [0.15, 0.3], `sheerMul` 1.7 [1.5, 2], `xAmp` 1.5% H [0.8, 2], `yToX` 2 [1, 3], `zEnable` false.
- **실패 양상과 확인**: 안쪽 층 변위가 바깥층보다 크면 바깥층 아래 가장자리 밖으로 드러남 → 안쪽 층 X 진폭 ≤ 바깥층, 또는 바깥층 윤곽을 마스크로 사용합니다. 위로 튕길 때 다리 뿌리가 드러나면 안 됩니다.
- **엔진 기능**: 중첩 warp, 다중 출력 물리, 선택적으로 C5.
- **차이점**: 치마는 몸 키폼이나 단일 흔들림 / 시뮬레이션만 따릅니다. 층 깊이 진폭 경사와 기본 2모드가 없습니다.

#### `skirt/depth-gradient-nest` 같은 체인의 여러 깊이 → 여러 층 warp의 변위 경사(매달림 트리) · P1 · 중
- **목적**: 치마 조각이 먼저 허리에 끌려 통째로 평행 이동하고, 이어서 중간이 부풀고, 마지막으로 밑단이 휙 뻗칩니다. 치맛자락 아래 매달린 리본은 세 번째 층에서만 추가 꼬리 흔들림을 얻습니다. 연결된 옷은 같은 물리 warp를 공유해 찢어지지 않습니다.
- **출력**:
  - 매달림 트리: 늘어진 부품마다 부착점 깊이를 구합니다(허리 → 치마 몸판 → 치맛자락 아래 리본 / 술). k번째 물리 출력은 깊이 ≥ k인 모든 부품을 감싸는 warp 하나를 구동합니다(집합이 단계마다 줄어들며 중첩).
  - 전형적인 3층: W1(P1 × P2, 조각 전체) → W2(P3, 중간과 밑단) → 바깥층 추가 W3(P3 × P2, 바깥층 밑단 메시만, 진폭은 W2의 0.3–0.5).
  - 키폼: P1 조각 전체 평행 이동 ±0.03 H(가중치 허리 0.6 → 밑단 1). P2 허리선을 축으로 굽힘(허리 0 → 밑단 1, 선형). P3 밑단 휘두름(가중치 s²). 매달림선 위는 엄격히 변위 0.
  - 계층 순서: 사타구니 warp(몸 X × 사타구니 파라미터)가 바깥 → 물리층 → 가슴층 → 각 부품의 몸 X 보정이 가장 안쪽.
- **조절 파라미터**: 층 수 3 [2, 4], 층 진폭비 1 : 0.6 : 0.35, `outerBoost` 0.4 [0.3, 0.5], 감쇠 전이 0.15 Hh [0.1, 0.2].
- **실패 양상과 확인**: P1 최대 진폭에서 각 메시 변위의 변동 계수 < 0.15. P3 최대 진폭에서 밑단과 허리의 변위비 > 4. 매달림 트리가 틀리면(리본을 치마 몸판으로 취급) 끝이 휘둘리지 않음. 중첩이 3층을 넘으면 W3을 W2에 합칩니다.

#### `skirt/axis-channels` 운동 축별로 나눈 치맛자락 채널 중첩 · P1 · 중
- **목적**: 치마는 몸 돌림(가로 흔들림), 오르내림(들리며 벌어짐), 기울기(지속적인 치우침), 급정지(튕김), 비틀림에 서로 다르게 반응합니다. 채널마다 파라미터 그룹 하나를 두고 같은 warp나 층별 warp에서 곱하지 않고 더합니다.
- **출력**: 앞 / 뒤 치마마다 촘촘한 warp 하나(길이 방향 약 30행, 너비 방향 약 40열) 또는 축마다 warp 한 층(순서: Lift → Twist → Sway → 전체 비틀림, 허리선 고정). 채널: 가로 흔들림(출력 3개, 부호 +, −, −, 이득 1, 0.6, 0.4로 치맛자락을 따라 S파 형성), 들림·벌어짐(출력 2개, 밑단이 넓어지며 올라감), 기울기(출력 1개, 허리를 중심으로 강체 기울기), 튕김(출력 2개, 세로 압착·늘림), 비틀림(선택). 세로 튕김층은 AngleX / BodyX와 2D 키를 만들어 튕김 방향이 몸 방향을 따르게 할 수 있습니다. 겉치마는 모든 채널을, 속치마는 비틀림 + 가로 흔들림만 연결합니다. 치마에 매달린 부품(사슬, 허리띠)은 같은 채널을 회전의 각도 블렌드 셰이프로 사용합니다. 물리 그룹 분할은 `physics.chain`에 맡깁니다.
- **조절 파라미터**: 채널별 최대 치맛자락 변위 3–7% H, 안쪽 층 상속 비율, 앞뒤 비율.
- **실패 양상과 확인**: 여러 채널이 동시에 최대값이면 범위를 넘음 → 조합 극값을 검사하고 제한합니다. 블렌드 셰이프를 지원하지 않는 대상에서는 채널마다 중첩 warp 한 층으로 낮춥니다.

#### `skirt/panel-glue` 조각별 독립 움직임 + 이음새 글루 · P1 · 중
- **목적**: 좌우 앞판, 앞뒤판, 세로 구간이 각자 흔들리고, 이음새는 양쪽 움직임의 평균이 되어 벌어지거나 교차하지 않습니다. 옷 전체를 큰 메시 하나로 두는 것(대칭 흔들림만 가능)보다 생동감이 있습니다.
- **출력**:
  - 가로 분할: 공유 변 양쪽에 좁은 띠 메시를 하나씩 자르고(너비 0.02–0.04 H) 각자의 warp 분기 아래에 두며, 짝지은 글루를 둡니다(강도 1, 또는 변 중심 1 → 양 끝 0.5). 좌우 조각의 물리 입력은 미러합니다(`physics.*`에 맡김).
  - 세로 구간: 각 조각을 길이의 1/3, 2/3(또는 주름선)에서 가로로 자르고, 이음새에 겹침 행을 남겨 글루로 잇습니다. k번째 구간 키폼은 그 구간 출력으로 키잉합니다(위 가장자리 이음새를 중심으로 a_k만큼 회전하고 전단을 더해, 밑단에 가까울수록 부채꼴). 맨 아래 구간은 (s_(k−1) × s_k) 3×3 곱 키를 씁니다. 양쪽 체인 파라미터는 각자 ±10–25% 지터를 줍니다(미러 동기화를 깸).
- **조절 파라미터**: `seamBand` 0.03 H [0.02, 0.04], `glueStrength` 1 [0.5, 1], `segments` 2–3, `segAngle` 10° [6, 15], `sideDetune` 15% [10, 25].
- **실패 양상과 확인**: 두 조각 파라미터가 서로 반대 극값일 때 이음새 정점 간격 < 0.005 H. 글루는 짝지은 점의 UV 일관성 요구가 높으므로 절단선에 겹침 한 줄을 남깁니다. 양쪽 움직임 차이가 너무 크면 좁은 띠가 전단됨 → 띠를 넓히거나 이음새 근처 양쪽 가중치를 낮춥니다.
- **엔진 기능**: C6, C8.
- **차이점**: Glue 도구는 있지만 생성기가 천 조각 이음새에서 좁은 띠를 자동으로 잘라 글루를 만들지 않습니다. 치마 물리는 좌우 조각을 나누지 않습니다.

#### `skirt/root-drape` 긴 뒷자락 / 망토를 뿌리 계층에 연결하고 몸 Z는 물리로만 영향 · P1 · 중
- **목적**: 허리에서 무릎 아래까지 늘어진 긴 망사, 긴 치마 뒷자락, 망토가 몸 Z를 따라 강체 회전하면 밑단이 멀리까지 가로로 쓸려 딱딱한 판처럼 보입니다. 뿌리 계층(다리와 같은 계층)에 연결하고, 몸 Z는 물리를 통해서만 지연되어 흔들려 돌아오게 합니다.
- **적용 대상**: 길이 > 0.25 H인 늘어진 천 조각.
- **출력**: 천 조각을 뿌리 계층에 연결합니다(몸 Z 회전 아래가 아님). 위 가장자리 받침 warp는 상체 측면 기울기 파라미터와 몸 X/Y를 축으로 하여 위 가장자리 근처만 이동시키며(가중치는 위 가장자리 1에서 0.3 H 위치의 0까지 감쇠), 위 가장자리가 허리선을 따르게 합니다. 흔들림층은 2단 출력, 2단은 5–13키 원호. 좌우 두 조각은 입력을 반전해 대칭으로 벌어지고 오므라들게 합니다.
- **조절 파라미터**: `followFade` 0.3 H [0.2, 0.4], `secondKeys` 9 [5, 13].
- **실패 양상과 확인**: 몸 Z 최대 진폭에서 위 가장자리가 허리에서 떨어짐 → 받침 warp에 BodyZ 키를 보충하거나 글루로 위 가장자리를 붙입니다.
- **차이점**: `DeformBodyXY`가 치마를 덮으며, 긴 뒷자락도 몸 Z / 호흡 아래에 있습니다.

#### `skirt/pleat-thigh` 주름 조각의 진폭 경사 + 허벅지가 치맛자락을 밀어 올림 · P2 · 어려움
- **목적**: 다리를 들면 치마가 밀려 올라갑니다. 조각마다 진폭이 단계적이고, 위상이 다른 두 모드를 조합해 치마 가장자리를 따라 전파되는 파동을 만듭니다.
- **출력**: 주름선이나 명암 교대에 따라 치마를 5–9조각으로 자릅니다. 부모 warp는 양쪽 허벅지 피치 × 다리 시점을 축으로 합니다. 무릎을 앞으로 들면 그 허벅지 위의 치맛자락 행이 Δy = −k·무릎 들림량(k ≈ 0.5)만큼 올라가고, 가로로는 가우시안 감쇠(σ = 다리 너비의 0.6)합니다. 조각마다 흔들림 블렌드 셰이프 두 개(진폭 a_i = a_0·(1 − 0.4·i/N), 두 번째 모드는 조각 순서를 다르게). 뒤집힘 모드에서는 밑단이 바깥으로 뒤집혀 안쪽이 드러납니다.
- **조절 파라미터**: `pleats` 7 [5, 9], `ampGradient` 0.4 [0.3, 0.5], `flipHeight` 치마 길이의 7% [5, 10], `thighPush` 0.5 [0.4, 0.6].

## 17. cloth(소매, 망토, 앞치마 등 천)

#### `cloth/current` 천 시뮬레이션 프리셋과 단일 흔들림 · 기준선 · 구현됨
- **현황**: 모델 프리셋 “옷”이 Wear에 따라 상의 / 옷깃 장식 / 소매 / 다리 장식 시뮬레이션으로 나누어 베이크하거나, `SwingPreset.CLOTH` 단일 층 흔들림을 씁니다. 공간적으로 계층화한 중첩 흔들림과 단단한 부속물 규칙이 없습니다.

#### `cloth/nested-arc-drape` 넓게 늘어진 천: 같은 크기 중첩 warp 체인 + 공간 계층화 · P1 · 중
- **목적**: 후리소데 소매, 퍼프 소매, 망토, 앞치마는 “띠”가 아니라 “판”입니다. 바깥층은 전체가 진자처럼 무게감 있게 움직이고, 안쪽 층은 아래쪽만 더 크게 굽으며, 소맷부리 레이스에는 다시 잘게 남는 여운이 있습니다.
- **출력**: 천의 바운딩 박스에 W0을 만듭니다(행 수 ≈ 종횡비 × 10–14, 팔 회전이나 몸 아래에 연결). K층 자식 warp(같은 바운딩 박스, 같은 해상도, 또는 공간 영역별로 단계적으로 축소: 전체 → 아래 절반 → 소맷부리 / 밑단 → 레이스). 층 k는 v ≥ v_k = k/(K+1)만 굽힙니다(v는 부착선에서 밑단까지의 정규화 거리). i번째 층은 물리 질점 i+1을 읽고, scale은 층에 따라 커집니다(체인은 `physics.*`에 맡김).
- **알고리즘**: 층 k는 행을 체인 마디로 보고 v_k 행부터 행마다 회전 α_i = θ·smoothstep((v − v_k)/(1 − v_k))를 누적하며, 회전 중심은 위 행의 중점입니다. θ는 −θmax에서 +θmax까지 9–13키를 샘플링합니다(C3). 레이스층: 인접 주름이 번갈아 천 길이의 0.05만큼 법선 방향으로 변위하며, 주름 수는 그대로입니다.
- **조절 파라미터**: `layers` K 3 [2, 4], `thetaMax` 28° [20, 35], `laceWave` 천 길이의 0.05, `res` ≥ 10×8(안쪽 층).
- **실패 양상과 확인**: 바깥층이 크게 회전하면 안쪽 층 격자가 따라 변형됨 → 안쪽 층 격자를 충분히 촘촘하게 합니다. 끝점까지 흔들리면 소매가 늘어남 → 원호 키.

#### `cloth/rigid-hardware` 변형 가능한 천에 고정한 단단한 장식 · P1 · 쉬움
- **목적**: 단추, 배지, 리벳, 금속 버클을 천 warp 안에 바로 두면 주름을 따라 전단 변형됩니다. 회전 디포머 아래에 두면 천은 원점만 이동시키고 부속물은 강체를 유지합니다.
- **적용 대상**: 면적 < 소속 천의 1%, 윤곽이 천과 분리되고 색 대비가 강한 작은 부품(또는 하드웨어로 표시된 것).
- **출력**: 하드웨어마다 회전 디포머 하나(원점 = 하드웨어 중심, 천 가장 안쪽 warp 아래에 연결, 각도 키 0 또는 천 국소 회전의 0–50%) → 3×3–5×5 작은 warp(키 BodyAngleX: 관객에게서 멀어지는 쪽으로 가로 5–15% 압축) → 메시(12–20정점).
- **조절 파라미터**: `rotFollow` 0.25 [0, 0.5], `perspCompress` 10% [5, 15], `meshVerts` 16 [12, 20].
- **실패 양상과 확인**: 하드웨어가 천에서 떨어짐 → 원점은 반드시 천 warp에서 평가합니다(C4).
- **차이점**: 천 위의 부품이 몸 warp와 함께 변형됩니다.

#### `cloth/sleeve-cylinder` 독립 원기둥으로서의 소매: 흔들림, 피치, 비틀림 · P2 · 중
- **목적**: 헐렁한 소매가 팔에 대해 흔들리고, 피치가 바뀌고, 비틀리며 천의 독립성을 보여 줍니다. 비틀릴 때 소매 표면의 단추와 줄무늬가 원기둥을 따라 미끄러집니다.
- **출력**: 소매 레이어를 팔과 분리하고 “연동 회전”을 생성합니다(지점과 각도 키폼을 아래팔 회전에서 키마다 복사, 작성 상태에서 연동을 기록하고 재실행 시 다시 복사) → 흔들림 SleeveZ(소매 위 가장자리를 중심으로 ±8°) → 피치 SleeveY(입구 타원의 단축이 변해 안감이 드러남) → 비틀림 SleeveX: 특징점 θ0 = asin((x − c)/r), Δθ만큼 비튼 뒤 x' = c + r·sin(θ0 + Δθ), 너비 × cos(θ0 + Δθ), cos < 0이면 페이드 아웃. 기본값은 그림 속 비틀림 상태(반드시 0은 아님)로 합니다.
- **조절 파라미터**: `twistMax` 75° [60, 90], `swing` 8° [6, 10].

## 18. ribbon(리본 띠, 리본, 나비매듭, 망사)

#### `ribbon/current` 흔들림 프리셋 ACCESSORY / HAIR · 기준선 · 구현됨
- **현황**: 리본을 머리카락이나 액세서리로 취급하고 `SwingDeformer` 단일 warp 구간 흔들림을 사용합니다. 매듭과 띠를 구분하지 않으며 체인도, 쌍 벌어짐·오므라듦도 없습니다.

#### `ribbon/frame-aligned-hang` 프레임 정렬 정적 회전 + 구동 회전 + 연쇄 warp · **P0** · 쉬움
- **목적**: 먼저 정적 회전 하나로 국소 좌표를 장식의 정지 방향에 맞추면, 이후 구동 회전의 ±θ가 곧 “장식에 수직인 흔들림”이 되고 아래 warp의 행도 장식 길이를 따라 배열되어 키폼을 계산하고 미러하기 쉽습니다.
- **적용 대상**: 작은 매달린 물체(꼬리 띠, 매달린 장식, 십자 펜던트, 술). 종횡비 > 3이면 연쇄 warp를 추가합니다. 아주 작으면(< 인물 면적의 0.05%) 4정점 사각형을 사용합니다.
- **출력**: 정적 회전(원점 = 부착점, 각도 = atan2(주방향), 파라미터 없음, 스케일 보정은 부모 공간으로 계산하고 하드코딩하지 않음) → 구동 회전(파라미터는 소속 영역의 “매달린 장식 흔들림” 출력, ±20–30°) → [종횡비 > 3] 연쇄 warp 2–4개(긴 축을 따라 행을 나누고, 각각 물리 v2…v4를 축으로 단계적 꺾임을 표현, 마지막 두 개는 v1/v2로 가로세로 ±5% 신축) → 메시. 같은 운반체 위의 같은 종류 작은 매달린 장식은 파라미터를 공유하고, 부착점 x 좌표에 따라 ±10% scale 차이를 주거나 파라미터 2–3개를 돌아가며 씁니다.
- **조절 파라미터**: `swing` 25° [15, 35], `cascade` 0–4, `stretch` 5%, `sharedGroups` 2 [1, 3], `quadArea` 인물 면적의 0.05%.
- **실패 양상과 확인**: 공유 파라미터가 완전히 같은 위상이면 기계적으로 보임 → scale 차이 또는 교대. 정적 회전의 스케일 보정은 반드시 부모 공간으로 계산합니다.
- **엔진 기능**: 회전 디포머(파라미터 없는 정적층), 연쇄 warp.
- **차이점**: 흔들림이 아주 작은 매달린 장식과 긴 꼬리 띠를 구분하지 않으며, 프레임 정렬 정적 회전을 생성하지 않습니다.

#### `ribbon/bow-knot` 나비매듭: 매듭에 2D warp 한 층 + 띠 체인 · P1 · 중
- **목적**: 매듭은 단단하여 조금만 흔들리고, 띠는 부드러워 크게 굽습니다. 리본은 머리카락보다 무거워 중간이 부풀고 끝은 다시 내려가며, 머리카락처럼 채찍 끝 움직임을 하지 않습니다.
- **출력**: 매듭(중심 덩어리) + 띠 2–4개(매듭에서 뻗은 가늘고 긴 띠)를 식별합니다. 매듭은 2D warp 한 층(Pa × Pb: ±0.02 H 평행 이동, ±5° 회전). 띠는 `hair.strand/skinned-chain`(관절 3–7개)이나 중첩 warp 체인으로 만들고, 뿌리 관절은 매듭 warp 아래에 연결합니다. 띠 출력 scale 곡선 f(s) = sin(π·(0.2 + 0.7·s))(중간이 최대, 끝은 약 0.7). 매듭과 띠는 서로 다른 물리 그룹을 씁니다(띠는 감쇠가 더 낮음). 띠가 아주 짧으면(< 0.3 heye) 체인 대신 warp를 씁니다.
- **조절 파라미터**: `knotAmp` 0.02 H [0.01, 0.03], `tailPeak` 중간, `tipFall` 0.75 [0.6, 0.9].

#### `ribbon/whip-charm` 긴 띠: 뿌리 회전 + 굽힘 warp + 끝 강체 매달린 장식의 독립 회전 · P1 · 중
- **목적**: 뿌리 흔들림 + 중간 굽힘 + 끝 장식의 독립 회전이 채찍 끝 움직임을 이룹니다. 강체 장식은 warp가 아닌 회전을 써서 늘어나지 않게 합니다. 장식의 회전각이 뿌리보다 커서 끝이 더 크게 휘둘립니다.
- **적용 대상**: “긴 띠 + 끝의 조밀하고 세부가 많은 덩어리”(같은 레이어 또는 분리된 레이어).
- **출력**: 뿌리 회전(지점 = 부착점, θ_root ±15–20°, 키 = 가로 출력 v1 × 세로 v1) → 굽힘 warp(긴 축 방향 약 18행 × 5열, 키 = v2 × v3, 구간별 길이 보존 굽힘) → 끝 회전(지점 = 장식과 띠의 연결점, θ_end = 1.5 θ_root, 키 = v3 × 세로) → 장식. 띠 메시는 성기게, 장식 메시는 촘촘하게 합니다.
- **조절 파라미터**: `rootAngle` 18° [15, 20], `endRatio` 1.5 [1.2, 2].

#### `ribbon/mirrored-pair` 쌍을 이루는 긴 망사 / 고리: 미러 벌어짐·오므라듦 · P1 · 쉬움
- **목적**: 좌우 두 장의 얇은 망사나 가슴 앞 나비매듭의 좌우 고리가 같은 방향으로 흔들리면 딱딱한 판 하나처럼 보입니다. 한쪽을 반전하면 대칭으로 벌어지고 오므라들어, 옷자락이 몸 돌림에 따라 “숨 쉬는” 것처럼 보입니다.
- **출력**: 쌍을 식별합니다(같은 장식의 좌우 두 반쪽, 기본 각도 차 약 180° 또는 정지 방향이 세로축에 대해 대칭). 조각마다 warp 두 층(전체 흔들림 + 2차 굽힘), 흔들림 진폭 > 10% H이면 키를 촘촘하게(C3). 모드 선택: 몸에 붙은 쌍 부품(가슴 앞 매듭, 치마 옆판) → 한쪽 반전(벌어짐·오므라듦). 몸에서 떨어져 매달린 부품(귀걸이, 목 앞 리본 띠) → 같은 방향. 물리 입력은 혼합비 λ에 따라 반전합니다(`physics.*`에 맡김).
- **조절 파라미터**: `lambda` 0.6 [0.5, 0.7] (1은 완전 미러, 0은 같은 방향), `detachDist` 장식 길이의 0.3(떨어짐 판정).
- **실패 양상과 확인**: 기본 각도가 이미 메시 수준에서 미러되어 있는데 다시 반전하면 같은 방향이 됨 → 실제 화면 방향으로 판단합니다. 완전 미러는 급하게 몸을 돌릴 때 관성에 맞지 않습니다.

#### `ribbon/stiff-joints` 띠 체인에서 일부 관절을 건너뛰어 단단한 구간 남기기 · P2 · 쉬움
- **목적**: 리본, 레이스 띠에는 강성이 있어 매듭이나 두 겹이 겹친 곳은 어디서나 굽지 않습니다. 인접한 두 구간을 단단한 막대로 합쳐 꺾이는 점을 더 적고 크게 만들어 두께 있는 천 띠처럼 보이게 합니다.
- **알고리즘**: 관절마다 굽힘 가능도를 계산합니다. 원화 중심축 곡률 > 임계값이거나 비틀림이 있음 → 반드시 굽힘 가능. 매듭 / 두 겹 겹침 영역 → 굽힘 불가. 재질 강성(리본, 레이스는 비교적 단단하고 머리카락은 비교적 부드러움). 굽힘 불가 관절은 파라미터는 유지하지만 물리에 연결하지 않습니다(scale 0). 굽힘 가능 관절은 차례로 v1, v2…를 읽습니다. 연속으로 건너뛰는 관절은 2개 이하. 끝의 마지막 구간은 항상 굽힘 가능합니다.
- **조절 파라미터**: `skipRatio` 단단한 재질 30% [20, 40], 부드러운 재질 0%.

## 19. tail(꼬리)

#### `tail/current` 뼈대 꼬리 체인이 물리를 따름 · 기준선 · 구현됨
- **현황**: 뼈대가 있으면 꼬리뼈 체인이 회전 디포머이며, 2번째 마디부터 부모 뼈 파라미터를 물리로 따릅니다(단일 구간). `SkeletonFlexWarps`는 관절마다 중첩 warp 한 층을 두어 체인을 따라 굽힘을 부드럽게 분담합니다. `TailSwing` 모션 프리셋이 있습니다. 뼈대가 없으면 꼬리는 몸 뿌리 아래에 연결됩니다(`DeformBodyXY`가 덮음).

#### `tail/corrective-chain` 회전 체인 + 인접 관절 2차원 보정 warp + 구간 사이 글루 · P1 · 중
- **목적**: 순수 강체 회전 체인은 관절에서 뾰족하게 꺾이고 바깥쪽 털 덩어리가 벌어집니다. “이 관절 × 다음 관절”을 키로 하는 warp가 굽힘을 두 구간에 나누어 꺾이는 곳을 원호로 만듭니다.
- **출력**: 중심축을 같은 호 길이(또는 곡률 기준)로 N구간으로 자릅니다(`hair.strand/skinned-chain`, 두툼한 털 꼬리는 3–4구간, 가늘고 긴 꼬리는 5–7구간). 구간 시작점마다 회전 하나를 두고 중첩하며, 관절 범위는 ±60°. 구간 k는 회전 k 아래에 그 구간을 덮는 warp(길이 방향 ≥ 10행)를 연결하고, 키 (θ_k, θ_{k+1}) 3×3: 근위 끝은 θ_k 방향으로 절반, 원위 끝은 θ_{k+1} 방향으로 절반 굽힙니다(보정 = 매끄러운 스플라인으로 맞춘 중심선 형상 − 강체 회전 결과). 구간 사이 윤곽 글루(가중치 0.5). 꼬리 뿌리는 상반신이 아니라 하반신 비틀기 회전(`body.turn/lagged-layers`)에 연결합니다. 끝 털 뭉치는 끝에서 2번째 마디의 출력을 입력으로 2단 물리 블렌드 셰이프(바깥으로 퍼짐, 구간 길이 0.05 떨림, `physics.cascade`에 맡김)를 따로 둡니다. 중첩 시 출력 scale은 체인을 따라 감소시켜(ρ 0.6–0.75) 끝이 과도하게 말리지 않게 합니다.
- **조절 파라미터**: `segments` 5 [3, 7], `jointRange` ±60°, `correctionShare` 0.5, `scaleDecay` 0.7 [0.6, 0.75], 보정 warp 수 1–3(2번째 마디 이후 한 마디 걸러 하나).
- **실패 양상과 확인**: 호흡이나 주기 가진이 체인의 고유 진동수와 가까우면 공진 → 마디당 최대 편향 ≤ 25°. 인접 구간의 보정량은 일치해야 합니다(글루 검사).
- **차이점**: `SkeletonFlexWarps`에 관절별 중첩 warp와 부드러운 분담은 이미 있지만, 인접 관절 2D 보정, 회전 + warp 혼합 형태, 꼬리 뿌리를 하반신에 연결하는 규칙이 없습니다. 차이는 작은 편입니다.

#### `tail/active-tail` 능동 사지: 꼬리 들기 회전 + 메시 수준 S 파형 · P1 · 중
- **목적**: 꼬리는 근육으로 능동 제어되는데, 물리는 몸이 움직일 때만 움직이므로 가만히 있으면 꼬리가 죽어 버립니다. 대기 진행파로 각 마디를 구동하고(물리는 뿌리 관성만 주거나 절반 가중치), 메시 수준 S 파형으로 구간 안의 부드러운 굽힘을 주며, 감정에 따라 꼬리 드는 높이를 바꿉니다.
- **출력**:
  - 뿌리 꼬리 들기 회전 `ParamTailRaise` [0, 1] → 0…150–180°(늘어짐에서 치켜듦까지).
  - 관절 체인(`tail/corrective-chain`과 같음). 물리는 뿌리 마디만 구동하거나 앞쪽 40–50% 마디에 0.5 가중치로 작용합니다.
  - 뒤쪽 절반 메시에 K = 3개의 S 파형 블렌드 셰이프: 법선 변위 = A·sin(2π(s − c_k)/λ), λ = 꼬리 길이의 0.3–0.5, A = 꼬리 너비의 0.3–0.6, C3 원호 키.
  - 진행파 곡선(마디별 위상 지연, 뿌리→끝 진폭 증가, 정적 말림 편향)은 `motion.idle`에 속하고, 감정 매핑은 `motion.*` / `param.system`에 속합니다.
- **조절 파라미터**: `raiseAngle` 160° [90, 180], `physWeight` 0.5 [0.3, 0.7], `waveLen` 꼬리 길이의 0.4 [0.3, 0.5], `waveAmp` 꼬리 너비의 0.45 [0.3, 0.6].
- **실패 양상과 확인**: 호스트가 대기 모션을 재생하지 않으면 꼬리가 얼어붙음 → 호흡을 물리 가진으로 함께 써서 대비합니다. 진행파와 물리가 충돌 → 물리는 뿌리만 담당합니다.

#### `tail/pattern-roll` 꼬리 무늬가 윤곽 마스크 안에서 위상을 달리해 미끄러짐(가짜 3D 구르기) · P2 · 어려움
- **목적**: 윤곽은 움직이지 않고 표면 무늬만 미끄러져, 꼬리가 3차원에서 구르거나 비틀리는 것처럼 읽히게 합니다(원기둥 텍스처 굴림).
- **출력**: 표면 무늬와 윤곽을 분리합니다. 무늬 메시는 윤곽과 같은 구간 디포머 아래에 연결하고 윤곽 메시 합집합을 마스크로 씁니다. 구간마다 표면 굴림 파라미터 r_k: 무늬가 중심선에 수직인 방향으로 구간 너비의 ±(30–50)% 평행 이동하고, 가장자리 근처는 cos 감쇠로 압축합니다. r_k는 같은 입력이지만 지연이 더 작은 두 번째 진자로 구동합니다(위상 차). 무늬 텍스처는 윤곽 밖으로 충분히 연장해 둡니다.
- **조절 파라미터**: `rollAmp` 구간 너비의 40% [30, 50].
- **실패 양상과 확인**: 무늬 / 윤곽 분리와 텍스처 연장이 필요합니다(소재 요구 사항).

## 20. wing(날개)

#### `wing/current` 뼈대 날개뼈가 물리를 따름 · 기준선 · 구현됨
- **현황**: 뼈대가 있으면 날개뼈가 몸 Z를 입력으로 물리를 따르며, `wingFlap`은 호흡에 따른 모션입니다. 뼈대가 없으면 날개는 몸 warp만 따릅니다. 원근과 펼침 파라미터가 없습니다.

#### `wing/yaw-perspective` 몸 방향 전환에 따른 날개 원근: 가까운 쪽 좁아짐, 먼 쪽 펼쳐짐 · P1 · 중
- **목적**: 날개는 등 뒤에서 양옆으로 뻗어 나온, 화면과 거의 평행하지만 뿌리는 몸 뒤에 있는 평면입니다. 몸이 돌면 두 날개와 화면의 사잇각이 하나는 커지고 하나는 작아지므로, 너비가 cos에 따라 변해야 합니다. 그렇지 않으면 등에 붙인 판지처럼 보입니다.
- **출력**: 각 쪽 날개의 각 구간 아래에 BodyAngleX × BodyAngleY warp 한 층. 날개 뿌리 위치 지정 회전(각도 0, 원점은 등 warp로 평가, C4). 호흡에 따라 날개 뿌리가 올라갑니다(`breath/attachment-bob`).
- **알고리즘**: 날개마다 뿌리점이 등에 있고 바깥으로 뻗은 평면으로 근사하며, 초기 화면과의 사잇각은 α0입니다. 몸 X 각도 β: 가까운 쪽 날개의 긴 축 방향 너비 × cos(α0 + β′)/cos α0, 먼 쪽 × cos(α0 − β′)/cos α0, β′ = β × 추종 계수, 뿌리는 고정. 몸 Y: 위아래 가장자리를 피치에 따라 세로로 3–8% 압축합니다.
- **조절 파라미터**: `alpha0` 20° [15, 25], `follow` 0.65 [0.5, 0.8], `pitchCompress` 5% [3, 8].
- **실패 양상과 확인**: 가까운 쪽 날개가 몸 뒤로 돌아갔는데도 몸 앞에 그려짐 → 날개 그룹 level 파라미터(`arm/depth-level`과 같은 구조)나 마스크를 함께 사용합니다.

#### `wing/rigid-plates` 단단한 날개 조각: 4점 패치 + 축심에서 먼 큰 회전 · P1 · 쉬움
- **목적**: 얼음 결정, 금속, 빛 조각 같은 단단한 날개는 변형이 필요 없습니다. 4정점 패치는 비용이 거의 없고, 축심이 등에 있어 먼 끝 변위가 자연스럽게 축심과의 거리에 비례합니다(큰 날개는 많이, 작은 날개는 적게 휘저음).
- **출력**: 단단한 날개 조각 메시는 4정점을 씁니다. 쪽마다 회전 하나(축심은 부착점), 좌우 각도 범위를 비대칭으로 두어(약 [−a, 0.35a]와 [0, 0.9a], a ≈ 12°) 미러 동기화를 피합니다. 대기 주기 파라미터나 호흡으로 구동합니다.
- **조절 파라미터**: `a` 12° [8, 18], `asym` 0.35 / 0.9.
- **실패 양상과 확인**: 부드러운 날개(깃털, 박쥐 날개)에는 맞지 않습니다. 4점 패치는 투명한 가장자리에서 텍스처 면적을 낭비합니다.

#### `wing/three-segment-fold` 날개 뼈대: 뿌리 변위 + 3구간 관절, 펼침 × 날갯짓 2차원 · P2 · 어려움
- **목적**: 새 날개는 팔뼈와 손바닥뼈로 이루어져, 접을 때 각 구간이 차례로 모이고 깃털이 겹칩니다. 전체 warp로 펼치면 깃털이 늘어나 변형됩니다.
- **출력**: 날개 뿌리 평행 이동 회전(ROOT_X/Y, 각도 0) → 날개 뿌리 회전(ROOT_Z ±30°) → 구간 1(원점은 날개 뿌리 P0) → 구간 2(손목 P1) → 구간 3(손바닥 P2). 각 구간 아래에 깃털 그룹 warp를 연결하고, 큰 깃털 한 장마다 작은 warp 하나. 펼침 파라미터 s1 ∈ [−1, 2] (−1 접힘, 0 원화, 2 완전히 펼침, 4키), 위아래 날갯짓 파라미터 s2 ∈ [−1, 1] (주로 구간 1을 ±10–15° 돌리고, 구간 2, 3은 같은 방향으로 ±15–20° 지연각을 추가). 세 구간 각도비는 약 1 : 3 : 4. 접을 때는 Z자로 접고(구간 2를 약 80° 되접고, 구간 3을 다시 약 100° 되접음), 완전히 펼치면 세 구간이 거의 일직선으로 수평 바깥을 가리킵니다. 깃털 조각은 각 s1 키에서 자기 뿌리점을 중심으로 돌아 부채꼴로 고르게 분포합니다(접으면 사잇각 → 0). 관절점은 같은 그룹 깃털 뿌리 연결선의 교점으로 추정할 수 있습니다.
- **조절 파라미터**: 구간 각도비, 접힘 각도 80° / 100°, 날갯짓 지연.
- **실패 양상과 확인**: s1을 스캔할 때 인접 깃털 조각이 뿌리 쪽 30% 길이 안에서 겹침을 유지하고 날개 끝 궤적이 매끄러워야 합니다. 날개 전체 그림 한 장뿐이면 3구간만 만들 수 있고, 펼치면 가려졌던 깃털의 빈 곳이 드러납니다(덧그림 필요).

#### `wing/flap-view-swap` 날갯짓이 옆모습을 지날 때 조각 교체 · P2 · 중
- **목적**: 날갯짓은 몸 축을 중심으로 한 3D 회전이라, 2D에서는 “보이지 않는” 옆모습 지점을 지나갑니다. 옆모습 지점 근처에서 뒷면 그림으로 바꾸면 앞면 한 장, 뒷면 한 장으로 완전한 날갯짓을 그릴 수 있습니다.
- **출력**: 날개 조각마다 회전(축심은 날개 뿌리), 파라미터 f ∈ [0, 1] → 펼침에서 모음까지 100–150°. 옆모습 지점 f_s 근처 [f_s − 0.05, f_s + 0.05]에서 앞면 / 뒷면 불투명도를 교환합니다(뒷면은 앞면을 미러하고 어둡게 하여 생성 가능). 조각마다 5×5 warp를 연결해 f = 0, 0.45, 0.55, 1에서 굽힘을 보정합니다(내려칠 때 날개 끝이 지연되어 위로 휨).
- **조절 파라미터**: `flapRange` 125° [100, 150], `swapBand` 0.1 [0.05, 0.1].

## 21. prop(소품)

#### `prop/current` 모든 레이어를 캐릭터 뿌리에 연결 · 기준선
- **현황**: 소품 분류가 없습니다. 장면 물체, 손에 든 물체, 착용 물체 모두 일반 레이어로 캐릭터 트리에 연결됩니다.

#### `prop/scene-root` 장면 소품을 독립 뿌리에 배치 · **P0** · 쉬움
- **목적**: 책상, 컴퓨터, 마이크 스탠드, 의자는 장면에 속하므로 캐릭터가 고개를 돌리거나 몸을 기울일 때 따라 기울면 안 됩니다. 스위치 하나로 “방송실”을 전환합니다.
- **적용 대상**: scene으로 표시된 레이어(또는 명명 규약). held는 해당 손 디포머에 연결하고(`prop/held-socket`), worn은 몸 부위에 연결합니다.
- **출력**: 장면 뿌리 warp(5×5, 캐릭터 뿌리와 나란하며 어떤 캐릭터 파라미터의 영향도 받지 않음), 스위치 불투명도 키 `ParamSceneProps`만 가집니다. 그리기 순서는 장면 앞뒤에 따릅니다(책상은 캐릭터 앞, 의자는 뒤). 선택적으로 캔버스 단위 위치 파라미터와 독립 깊이 파라미터. 미러 사본은 메시와 키폼을 수평 뒤집기로 생성하고 방향 파라미터로 선택합니다.
- **조절 파라미터**: `sceneToggle` 기본 1, 깊이.
- **실패 양상과 확인**: 소품과 캐릭터의 가림 관계가 고정되어 캐릭터가 크게 움직이면 파고듦(손이 책상 뒤로 들어감) → 겹칠 수 있는 영역을 보고합니다.
- **차이점**: 모든 레이어가 캐릭터 뿌리에 연결되며 장면 뿌리가 없습니다.

#### `prop/held-socket` 손에 든 소품: 쥐기 소켓 체인 + 3자유도 흔들림 + 글루 쥐기 · P1 · 중
- **목적**: 소품을 손의 변환 체인 아래에 연결하여 팔이 어떻게 흔들리든 소품이 따라오게 합니다. 소품 자체의 파라미터는 “손 안에서 쥐는 방식”만 표현하며 팔 자세와 분리됩니다. 손에 든 무거운 물체에는 진자, 요(옆면 드러남), 손잡이를 축으로 한 비틀림 세 가지 성분이 있습니다.
- **출력**: 손목 회전 → 소켓 평행 이동(원점 = 손바닥 쥐는 점 A, 파라미터 X/Y: 쥐는 위치 오프셋 ±30% 소품 길이) → 방향 회전(Z, ±60° 또는 ±180°) → 변형 선택 그룹(부호 있는 전환) → 나타남(opacity) → 스케일(소환 0.1 → 1) → 소품 자체 회전 warp(원기둥 또는 구면 투영으로 요 / 피치 키폼 생성). 손에 든 무거운 물체: 진자 회전(원점은 쥐는 점, ±15–40°) → 요 warp(정면 너비 × cos ψ, ψ ≤ 25°, 옆면 띠는 0에서 sin ψ·깊이까지 펼침. 옆면 소재가 없으면 3–5% 사다리꼴 원근만) → 비틀림 회전(원점은 손잡이 중심, 약 −10°…+16°). 같은 진자 체인의 서로 다른 질점으로 구동합니다(`physics.*`에 맡김). 쥐기: 손 메시를 손목 구간과 손바닥 구간으로 자르고, 손바닥 구간은 진자 아래에, 손목 구간은 팔 아래에 두며 경계에 글루를 둡니다. 소품 그리기 순서 = 손의 level + 오프셋(쥐는 층은 손바닥과 손가락 사이, 엄지는 소품 위를 덮음). 소품 기본 각도 = 원화에서 소품과 아래팔의 사잇각. 긴 소품은 회전 아래에 연결합니다(아래팔 보정 warp 아래가 아님).
- **조절 파라미터**: `gripOffset` 소품 길이의 ±30%, `orient` ±60°, `swing` 30° [15, 40], `yaw` 15° [5, 25], `summonScale` 0.1.
- **실패 양상과 확인**: 소품이 크면 진자 운동 중 다리, 치마와 파고듦 → 각도를 제한하거나 그리기 순서로 처리합니다. 옆면 소재가 없으면 요는 작은 각도만 가능합니다.

#### `prop/handoff` 소품 인계: 서로 다른 부모에 연결한 두 사본 + 교차 · P2 · 중
- **목적**: 런타임에는 부모를 바꿀 수 없습니다. 소품이 옷깃이나 허리 옆에서 손으로 옮겨질 때, 두 사본을 각각 올바른 부모에 연결하고 손이 가리는 순간 교차시킵니다.
- **출력**: 사본 P_A(놓여 있는 부모)와 P_B(손, 기하를 손 국소 공간으로 환산하고 인계 시점 위치에 맞춤). 파라미터 swap 0..1: P_A 부모 디포머 불투명도 1 → 0, P_B 0 → 1, 전이 띠는 범위의 20–30%. 모션 중 swap 전환은 손과 소품이 겹치는 프레임에 둡니다.

#### `prop/rigid-3d-proxy` 단단한 소품의 3D 프록시 베이크(우산, 칼, 부채, 책, 후광) · P2 · 연구
- **목적**: 작은 3D 렌더링을 파라미터 격자에 베이크하여, 돌 때 각 조각의 원근과 가림 순서가 모두 올바르게 합니다.
- **출력**: 소품을 평면 패치(조각마다 4정점)로 나누거나 원뿔 / 원환 프록시를 맞춥니다. 파라미터 yaw, pitch(간격 5–7.5°), 상태(접힘 / 펼침), roll(회전 디포머 3키로 한 바퀴), 열림·닫힘(회전 스케일 1 → 0.1), 주기적 자전(범위는 우산살 간격 하나와 정확히 같고 처음과 끝이 같음). 각 샘플 조합마다 회전 → 약원근 투영 → 패치 네 모서리 키폼 기록. 패치 중심 깊이 순위 → 그리기 순서 키폼(기준 ± 순위), 깊이가 같은 곳은 가산 그리기 순서 파라미터로 보정. 법선이 뒤를 향하면 불투명도 0 또는 뒷면 컬링. 우산 면은 극좌표 메시를 씁니다(우산살마다 반지름 방향 정점선 하나).
- **조절 파라미터**: 샘플 간격, 패치 수 10–50, 원근 강도.

#### `prop/liquid` 용기 속 액체 · P2 · 중
- **목적**: 컵이 손을 따라 흔들릴 때 액면이 중력에 대해 수평을 유지하며 출렁이고, 컵 몸체로 클리핑됩니다.
- **출력**: 액체는 용기를 마스크로 씁니다. 액체 warp는 2마디 진자 (sx, sy)를 축으로 합니다. 액면선이 반대로 기울고 한쪽이 올라가며(진폭은 용기 너비의 0.1–0.2), 중간에 비선형 키를 추가해 “출렁임”을 만듭니다. 유리층은 부분 불투명(상한 0.1–0.6). 액체 메시는 위쪽으로 충분한 여유를 둡니다. 용기는 손 체인의 흔들림을 상속합니다.
- **조절 파라미터**: `tiltMax` 15° [10, 20], `slosh` 용기 너비의 0.15.

#### `prop/companion-rig` 하위 캐릭터: 완전한 작은 rig를 독립 뿌리로 · P2 · 어려움
- **목적**: 동반 캐릭터(애완동물, 인형)가 독립적으로 연기하고 주인공과 상호작용합니다(몸 뒤로 숨기).
- **출력**: 동반 캐릭터 레이어에 대해 단순화한 rig 생성을 한 번 실행합니다(머리 XYZ, 몸, 사지 roll, 눈과 표정 슬롯). 모든 파라미터에 접두사를 붙입니다. 바깥에 나타남, 전체 평행 이동, 구르기 ±180°, 계층 파라미터를 추가합니다. 동반 모션은 `motion.*`에 속합니다.
- **조절 파라미터**: 동반 캐릭터 크기 0.2–0.35 H.

## 22. ornament(작은 장신구: 펜던트, 귀걸이, 매달린 장식, 사슬, 보충 슬롯)

#### `ornament/shared-bus` 영역 장신구 물리 버스 + 부품별 키폼 · **P0** · 쉬움
- **목적**: 장신구마다 물리를 따로 조정하면 비용이 큽니다. 같은 몸 영역의 작은 장식은 움직임에 대한 반응이 원래 일치해야 하므로, 체인 하나를 공유하면 리듬이 통일되고, 부품마다 자기 키폼 형상과 진폭을 써서 움직임에는 여전히 차이가 있습니다.
- **적용 대상**: 면적 < 인물 면적의 1%이고 옷이나 몸에 매달린 작은 부품(나비매듭, 신발 끈, 허리 옆 매듭, 소맷부리 천, 목 장식, 옆 날개), 그리고 같은 종류의 반복 부품(유사한 연결 요소 ≥ 3개).
- **출력**:
  - 부착 영역(머리, 목, 가슴, 위팔, 허리, 다리, 발)으로 군집화하고, 영역마다 버스 하나: 가로 2단 출력 b1x, b2x, 세로 2단 b1y, b2y(물리 그룹에 맡김, 빠르고 작은 흔들림).
  - 부품마다: 중첩 warp (b1x × b1y) > (b2x × b2y)(또는 단일 층 5×5 warp). 키폼 = 자기 부착점을 중심으로 ±10–15° 회전(끝 변위는 부품 크기의 약 0.25), 세로로 ±8° 위아래 뒤집힘. 펜던트류는 회전에 연결하고 (bx × by)를 축으로 하여 ±1에서 ±45–60°.
  - 진폭은 부품 길이에 비례하며 `hair.strand/group-drive`의 결정적 지터를 곱합니다.
  - 같은 종류이면서 화면 거리 > 0.3 H인 매달린 장식(예: 귀걸이와 허리 장식)은 출력 한 벌을 공유할 수 있으며, 길이에 따라 각도를 스케일하여 끝 변위를 비슷하게 유지하고, 뿌리에는 BodyX / AngleX를 키로 하고 각도는 항상 0인 위치 지정 회전을 추가하여 부착점 평행 이동을 담당하게 합니다.
  - 배타적 차분(다른 팔, 다른 의상) 위의 같은 장신구는 버스 파라미터를 공유하여 전환 시 위상이 일치합니다.
- **조절 파라미터**: `busPerRegion` 1, `itemSwing` 12° [10, 15], `itemFlip` 8°, `pendantMax` 50° [45, 60], `shareDist` 0.3 H [0.2, 0.4].
- **실패 양상과 확인**: 영역이 너무 크면(머리와 몸에 걸침) 리듬이 맞지 않음. 같은 부품을 두 버스가 구동하면 과도하게 겹침. 아주 가까운 좌우 쌍 부품이 공유하면 동기화되어 보임 → 쌍 부품은 각자 한 벌을 쓰거나 반전합니다.
- **차이점**: 흔들리는 대상마다 물리 그룹을 따로 생성하므로 물리 그룹 수가 장식 수에 따라 선형으로 늘어납니다. 펜던트 식별이 없습니다.

#### `ornament/rigid-on-chain` 강체 매달린 장식이 체인 끝을 따라감 · P1 · 중
- **목적**: 보석, 체리, 방울, 펜던트 같은 단단한 매달린 장식이 뼈 가중치로 굽으면 고무처럼 보입니다. 체인 파라미터를 축으로 하는 warp로 장식 전체를 강체 평행 이동·회전시켜 형상은 그대로 두고 항상 끝에 연결된 상태를 유지합니다.
- **출력**: 강체 장식과 그것이 매달린 체인 및 부착점(가장 가까운 관절)을 표시합니다. 부착점 위의 각 뼈에 대해 바깥에서 안쪽으로 warp 한 층씩 감싸며, 중첩 순서는 뼈 순서와 일치합니다. 키 ±θ의 형상 = 장식을 관절 i를 중심으로 ±θ만큼 강체 회전한 뒤의 격자점 위치. 뼈가 많으면 인접한 두 뼈를 2D warp 하나로 합칩니다. 마지막 뼈는 장식 메시 키폼에 바로 만들 수 있습니다. 장식 방향 계수 α(1은 뼈를 따라 회전, 0은 수직을 유지하며 평행 이동만, 진자식). 장식은 글루에 넣지 않습니다. 하이라이트층은 장식을 마스크로 함께 움직입니다. 각도가 크면 C3 밀집 키를 씁니다.
- **조절 파라미터**: `alpha` 0.5 [0, 1], `followBones` 전체 또는 마지막 2개.
- **실패 양상과 확인**: 3키이면 중간 자세에서 장식이 약간 짧고 좁아짐. 장식이 체인보다 훨씬 넓으면 warp 외곽이 흔들림 범위 전체를 감싸야 합니다.

#### `ornament/surface-follow` 흔들리는 표면에 붙은 장식이 표면 물리를 읽음 · P1 · 쉬움
- **목적**: 가슴 앞 펜던트, 브로치는 가슴에 붙어 있으므로 가슴이 흔들리면 함께 움직여야 합니다. 표면의 물리 파라미터를 장식 체인의 입력층 하나로 직접 쓰면 물리 그룹을 따로 만드는 것보다 저렴하고 동기화됩니다.
- **출력**: 장식 체인에 표면 물리 파라미터를 축으로 하는 회전 / 변위층을 끼우고(진폭 = 장식 뿌리에서의 표면 변위 × 1.0), 그 아래에 장식 자체의 흔들림을 연결합니다. 몸에 붙은 옷도 마찬가지입니다(`chest/nested-bounce` 참고).
- **조절 파라미터**: `surfaceFollow` 1.0 [0.8, 1].

#### `ornament/chain-links` 강체 사슬 고리의 2모드 흔들림 · P2 · 중
- **목적**: 목걸이, 쇠사슬의 고리는 항상 강체(금속)라 회전만 하고 늘어나지 않습니다. 전체가 원호를 그리며 흔들리고 + 고리마다 S자 채찍 끝 움직임을 합니다.
- **출력**: 한 선을 따라 반복되는 작은 연결 덩어리를 식별하고 고정점부터 정렬합니다. 모드 1: k번째 고리가 고정점을 중심으로 A1·(k/n)^γ 회전. 모드 2: k번째 고리가 자기 위쪽 끝을 중심으로 A2·(k/n)^γ2 회전. 고리마다 몸 X/Y를 키로 하는 방향 회전을 추가해 사슬이 중력에 따라 늘어지게 합니다. 두 파라미터는 각각 물리에 연결합니다(모드 2는 진자가 더 짧음).
- **조절 파라미터**: `A1` 15° [10, 20], `A2` 25° [20, 30], `gamma` 1.2 [1, 1.5].

## 24. 다른 슬롯과의 인터페이스

- **physics.chain / physics.cascade**: 이 목록의 체인 템플릿에는 “적은 질점으로 많은 관절 구동” 매핑(뿌리 공유 질점, scale 뿌리→끝 경사, 고정 구간 출력 0), 재질별 체인 파라미터 분포, 좌우 그룹의 세로 입력 한쪽 반전, 인접한 같은 종류 부품의 비동기화, 몸 계층 지연 체인(상체 → 허리 → 사타구니 → 치마), 물리 출력을 다음 물리 그룹의 입력으로 쓰기가 필요합니다.
- **physics.filter**: 몸 X/Y/Z, 머리 Z의 “입력 파라미터 → 단진자 → 구동 파라미터” 필터층. `body.turn/head-driven`과 “몸이 머리를 따르는 물리”는 배타적입니다.
- **physics.excitation**: 물리 입력으로서의 호흡(전신 서기), 충격으로서의 스위치 전환, 모션이 기록하는 가진 채널.
- **motion.idle**: 꼬리 / 떠 있는 긴 머리의 마디별 위상 진행파, 몸 3구간 위상, 전시 자세 상수, 걷기 걸음.
- **deformer.layering / param.system**: C3 적응형 원호 키, C5 가산층과 낮추기, “자세는 곱셈 키폼, 2차 움직임은 가산층”이라는 역할 분담 규칙.
- **draw-order**: C7 그룹 level 파라미터, 인접 키 계단 전환(팔, 다리, 날개, 소품, 고리형 머리 장식, 몸 돌림 층 교체).
- **mask / lighting**: 머리카락 그림자 체인(투영 복제본이 투사체를 따르고 그림자가 지는 면을 마스크로 사용), 고개 돌림에 따라 그림자 겹침층이 바탕에 대해 상대적으로 미끄러짐. 여기서는 머리카락 그룹 층을 이런 복제본이 재사용할 수 있게 보장하는 것만 다룹니다.
- **toggle**: 탈착 가능 그룹의 접기 스위치(`hair.variant/fold-toggle`), 착용형 스위치의 슬라이드 인 애니메이션.
- **animal-ear**: 동물 귀의 수축 숨김과 회전 밀집 키(얼굴 슬롯에 속함).

## 25. 핵심 결론

1. **“가늘고 긴 물체의 체인”은 머리카락과 몸 템플릿의 가장 핵심적인 공유 구성 요소입니다**: 머리 다발, 땋은 머리, 리본, 꼬리, 끈, 소매, 치마 조각은 모두 “띠 기술 + 두 가지 구현(중첩 warp 다중 질점 체인 / 구간 분할 스키닝 회전 체인) + 물리 출력 매핑”입니다. 구간 분할 스키닝 체인은 가늘고 긴 물체를 수작업으로 만들 때 흔한 방식이지만, 자동 생성하려면 메시 분할과 안정 ID가 필요해 비용이 큽니다. PSD2Live의 `SwingDeformer`에는 이미 구간 개념이 있으므로, 이번 단계에서는 먼저 이를 “층마다 파라미터 하나인 중첩 warp + 원호 밀집 키 + 다중 출력”으로 업그레이드하고(P0), 구간 분할 회전 체인은 다음 단계로 미룹니다.
2. **중력 유지는 비용 대비 효과가 가장 큰 외관 개선입니다**: 고개를 기울이거나 몸을 옆으로 기울일 때 늘어진 물체가 통째로 함께 기우는 것은 2D 모델이 가장 싸 보이는 순간입니다. 방법은 부착점에서 조상 누적 회전각에 따라 반대 회전을 끼우는 것이며(10–25% 추종 유지, 부착 구간, 충돌 쪽 비대칭), 물리는 동역학만 담당합니다. 이는 “부모 체인의 부착점 국소 회전각 평가기”에 의존하며, 이 평가기는 머리 warp 야코비안 보정, 체인 구간 원근 잔차, 어깨점 추종, 천에 고정한 하드웨어 등 여러 템플릿을 함께 뒷받침하므로 기반 시설로 먼저 만들어야 합니다.
3. **2차 움직임은 반드시 가산층을 거쳐야 합니다**: 물리 출력, 세로 튕김, 머리카락 모드, 가슴 튕김을 모두 곱셈 키폼 축으로 만들면 조합이 폭발합니다(기존 흔들림의 “모든 구간 축을 같은 warp에 곱하는” 문제가 바로 이것입니다). 자세(머리 / 몸 방향 전환)는 곱셈 키폼을, 2차 움직임은 블렌드 셰이프나 “파라미터마다 중첩 warp 한 층”을 씁니다. 생성기에는 블렌드 셰이프 출력과 구버전 대상용 낮추기가 필요합니다.
4. **몸은 계층, 좌우, 시간으로 나누어야 합니다**: 기존 `DeformBodyXY` / `DeformLegs`는 일회성 공간 감쇠와 대칭 IK입니다. 가장 저렴한 두 단계는 2관절 척추 옆 굽히기와 하중 다리 비대칭(P0)이며, 그다음은 골반을 뿌리로 하는 체인(전체 변환 → 엉덩이 → 발을 지점으로 한 전신 기울기 → 상체 / 다리 분기), 기본 서기 자세, 층별 지연, 그리고 팔이 자세를 덮어쓰지 않으면서 물리에 들어가게 하는 “수동으로 늘어진 팔 체인”입니다.
5. **큰 동작에는 그리기 순서와 시점 전환이 빠질 수 없습니다**: 고개 돌림 시 옆머리 / 왕관 층 교체, 몸 돌림 시 먼 쪽 팔이 뒤로 물러남, 팔이 몸을 가로지름, 다리 꼬기, 손 뒤집기, 날개가 옆모습 지점을 지남은 모두 “인접 키 계단 전환 + 전환점에서 양쪽 형상 정렬(다리 형태)” 또는 “그룹 level 파라미터”에 의존합니다. 손, 다리, 날개, 소품의 넓은 범위 자세 템플릿은 대부분 P2 / 연구이며, 소재 규약(다중 시점, 손가락 마디 분할, 쌍 시점)이 전제이므로 PSD 규약을 먼저 정한 뒤 생성기를 만들어야 합니다.
