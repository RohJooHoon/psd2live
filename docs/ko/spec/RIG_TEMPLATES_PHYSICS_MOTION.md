# 알고리즘 템플릿 목록: 물리와 동작

> 이 목록은 부위·모듈 구조 이전에 작성되어 ‘슬롯 / 템플릿’이라는 용어를 사용합니다. 같은 슬롯의 배타적 방식은 해당 부위의 **기본 알고리즘**, 중첩 가능한 기능은 **모듈**로 등록하며 `*/current`는 부위별 `legacy` 기본 알고리즘에 대응합니다. 구현 상태는 등록부(MCP `module_catalog`)가 기준입니다. 이 문서의 P0/P1/P2는 계획 우선순위일 뿐이고 ‘구현됨’은 등록부 도입 이전부터 있던 알고리즘을 뜻합니다. [Rig 프리셋 구조](RIG_PRESETS.md)를 참고하세요.

[문서 목록](../../README.md) · [프리셋 구조](RIG_PRESETS.md) · 템플릿 목록: [얼굴](RIG_TEMPLATES_FACE.md) · [머리카락과 몸](RIG_TEMPLATES_HAIR_BODY.md) · [물리와 동작](RIG_TEMPLATES_PHYSICS_MOTION.md) · [구조와 표현](RIG_TEMPLATES_STRUCTURE.md)

이 문서는 [Rig 프리셋 구조](RIG_PRESETS.md)의 템플릿 목록 중 하나입니다. 영역 슬롯마다 여러 알고리즘 템플릿을 등록하고 모델 프리셋이 슬롯별 템플릿과 파라미터 값을 선택합니다. 같은 문제를 푸는 여러 방식은 같은 슬롯의 서로 다른 템플릿으로 공존합니다. 설계는 일반적인 Live2D 제작 관행을 따릅니다. 수치는 권장 기본값과 조절 범위이며 구현 후 렌더링 결과로 조정합니다. 슬롯별 `*/current`는 현재 알고리즘을 기본 템플릿으로 등록한 것이며 선택해도 출력이 바뀌지 않습니다.

## 범위와 규칙

- 담당 슬롯: `physics.*`(입력 필터·구동 파라미터, 입력 혼합, 진자 체인, 연쇄 연결, 가진, reflect·반전), `motion.*`(대기, 깜빡임, 입 모양, 2차 움직임, 위상·주기), `breath`의 물리·동작 측면. 머리카락·의상의 **물리 파라미터**는 이 그룹, 기하(구간 분할, Glue, 메시, 키폼 형상)는 hair-body 그룹입니다. 여기서는 ‘물리 출력을 어느 계층에 어떤 이득으로 연결하는가’만 규정합니다.
- 보충 슬롯: `physics.input`, `physics.axis`, `physics.carrier`(연결 규격), `physics.gravity`, `physics.role`, `motion.phase`, `motion.layer`, `motion.effect-clock`, `host.mapping`.
- 기호: 질점(particle) 번호 v=1..n, v=1은 뿌리에 가장 가까운 움직이는 질점. `r`은 구간 길이(Cubism 물리 단위), `m` mobility, `d` delay, `a` acceleration. 입력 타입 `X`(평행 이동, 과도 응답만 발생) / `Angle`(각도, 정상 상태 편향 발생). `reflect`는 반전. H = 캐릭터 높이, h_head = 머리 높이, L = 부품 주축 길이, W_f = 얼굴 너비.
- 방향 규칙(전체 목록 공통): 좌우 짝 부품 키폼은 **캔버스 방향**(+1 = 끝이 캔버스 +X 방향)을 사용합니다. reflect 규칙도 이를 전제합니다. ‘바깥쪽 양수’ 미러 규칙으로 바꾸면 가로·세로 규칙을 모두 반전해야 합니다(`physics.reflect/vertical-flare` 실패 유형 참조).
- 기존 구현은 현재 소스를 기준으로 슬롯별 `*/current`에 등록합니다.

## physics.filter: 입력 필터와 구동 파라미터

‘추적·동작이 쓰는 입력 파라미터’와 ‘기하에 바인딩된 구동 파라미터’를 분리하고 사이에 물리 그룹을 2차 필터로 둡니다. 모든 몸 수준 관성, 연쇄 연결, 결합의 기반입니다.

### `physics.filter/current` — 표준 파라미터에 기하 직접 바인딩
- 현재: `DeformBodyXY`, `DeformBodyLean`, `DeformBodyZBreath`, 머리 회전 모두 `ParamAngle*`, `ParamBodyAngle*`를 직접 축으로 씁니다. 물리는 머리카락, 안구 젤리, 뼈대 추종, 흔들림, 시뮬레이션 파라미터만 출력합니다. `PhysicsGenerator.headAndBodyInputs`는 AngleX 60 X / AngleZ 60 Angle / BodyAngleX 40 X / BodyAngleZ 40 Angle로 고정됩니다.
- 문제: 머리·몸이 완전히 동시에 움직여 스티커 같고 추적 떨림을 머리카락·치마가 증폭하며 관성·오버슈트가 없습니다.

### `physics.filter/drive-param` — 입력 파라미터 → 단진자 → 구동 파라미터(그림자 파라미터)
- 목적: 큰 덩어리(몸, 선택적 머리 롤)에 80–250 ms 지연과 5–15% 오버슈트를 주고 추적 노이즈를 걸러냅니다.
- 적용: 모든 생성 모델. 몸 3축은 기본 활성화, AngleZ는 선택(옆 기울기 지렛팔이 가장 김). AngleX/Y(시선 방향)는 기본으로 필터링하지 **않거나** 매우 단단한 스프링(d ≥ 0.92)만 사용합니다.
- 출력:
  - 파라미터: 필터링할 축 P마다 구동 파라미터 `P★` 추가(ID `<P>Drive`, 범위·기본값은 P와 같음). P는 표준 ID를 유지하고 추적·동작·표정의 쓰기 입구로 쓰되 기하에 바인딩하지 않습니다. 생성 키폼은 모두 `P★`로 바꿉니다.
  - 물리 그룹 `PhysicsDrive_<P>`: P 입력(Angle 100 또는 80 + 결합 20), 움직이는 질점 1개(전체 2질점 체인), `P★` 출력(Angle, v=1).
  - 선택적으로 같은 입력에서 두 구동을 생성합니다(몸통은 매끄러운 설정, 다리·하체는 감쇠가 20–30% 낮은 탄성 설정).
- 알고리즘:
  1. 설정 선택: 강체 스프링(몸) r 9–12, m 0.7, d 0.85, a 1.5; 머리 롤 r 8–15, m 0.8, d 0.92, a 1.2; 다리 탄성 d 0.6.
  2. 이득 보정: 오프라인에서 P에 최대 진폭 계단 입력을 주고 정상 상태까지 시뮬레이션한 뒤 P★/P = 1.0(0.9–1.1)이 되는 scale을 구합니다. 90% 상승 시간(목표 0.12–0.3 s)과 오버슈트(목표 ≤ 10–15%)도 기록하고 초과하면 d/a를 조정하여 재계산합니다. scale을 고정하지 않아 파라미터 범위·정규화 각도에 관계없이 일관됩니다.
  3. 출력 제한: 오버슈트는 파라미터 범위에 잘립니다. 키폼 끝점이 최댓값의 ≤ 1.15배를 견디게 하거나 scale을 5% 줄입니다.
  4. 하류 물리(머리카락, 치마, 가슴, 꼬리 등)의 입력은 P★를 읽습니다(`physics.cascade/staged-inputs` 참조).
  5. 내보내기 대체: 대상이 물리를 지원하지 않거나 호스트가 끄면 P★는 0으로 고정되어 몸이 멈춥니다. ‘직통’ 옵션으로 P★ 바인딩을 P로 되돌리거나 물리 그룹 삭제·파라미터 이름 변경을 하고 손실 보고서에 기록합니다.
  6. 동작 제약: MotionGenerator와 표정은 P만 씁니다. P★ 쓰기는 외부에 노출하지 않습니다(써도 물리가 매 프레임 덮어씀).
- 조절: `lag`(시정수 0.06–0.25 s, 기본 0.12), `overshoot`(0–15%, 기본 8%), `gain`(0.9–1.1, 기본 1.0), `axes`(기본 {BodyX,BodyY,BodyZ}; AngleZ / AngleX / AngleY / BodyPositionY 추가 가능), `split_lower`(하체용 탄성 구동 별도 생성).
- 실패·검수: 계단 응답 검사(상승 시간, 오버슈트, 정상 이득, 정지 드리프트 없음). 두 지연층 때문에 머리카락이 둔해지면 둘째 층 d를 낮춥니다. 과도한 오버슈트는 젤리처럼 보입니다. 호스트가 P★에 매핑하면 매 프레임 덮어쓰므로 내보내기 안내와 `host.mapping/vts-profile` 기본 매핑이 필요합니다.
- 엔진 기능: 일반 파라미터로 물리 출력, used-by가 0인 ‘순수 입력 파라미터’, 대상별 내보내기 기능 저하.
- 난도: 중(파라미터 체계, 생성기 바인딩, 내보내기, MCP 문서를 함께 수정). 우선순위: P1(가장 가치 있는 구조 변화지만 모든 몸 생성기·내보내기 경로에 영향, 별도 작업 주기 필요).
- 현재 차이: 입력→구동 계층이 없고 `headAndBodyInputs`는 원래 값을 읽으며 물리 없는 내보내기 대체가 없습니다.

### `physics.filter/head-leads-body` — 얼굴 추적만 있을 때 머리 각도로 몸 물리 생성
- 목적: 몸 추적이 없어도 ‘머리 먼저, 몸 반 박자 뒤, 팔·옷은 또 한 박자 뒤’의 계층 관성을 만듭니다.
- 적용: 얼굴 추적 방송 모델. `drive-param` 구동 파라미터를 공유하며 몸 추적이 있으면 혼합으로 전환합니다.
- 출력: BodyX★ ← AngleX, BodyY★ ← AngleY, BodyZ★ ← AngleZ 물리 그룹 3개(Angle 타입, 2질점). 선택적으로 어깨 X·골반 X 과도 그룹(AngleX 입력, X 타입).
- 알고리즘:
  1. 정상 추종비 k = 몸 최댓값 / 머리 최댓값의 비율. 기본 0.35(추종형), 최대 0.9(동시 회전형). 계단 시뮬레이션으로 scale을 역산합니다.
  2. 몸 Y에 가장 긴 진자(가장 느림), X/Z에는 그다음 길이를 사용. r 7–12, m 0.65–0.7, d 0.85, a 1.5.
  3. 과도 그룹(어깨 X·골반 X): 머리 X를 X 타입으로 입력, 피크는 파라미터 범위의 20–50%, m 0.9(몸보다 늦음), 정지하면 중앙 복귀.
  4. 추적 혼합 스위치: 몸 추적이 있으면 0.5·머리 + 0.5·몸 추적으로 바꾸거나 규칙을 끕니다.
  5. 머리와 부호 규칙이 반대면 reflect를 사용합니다.
- 조절: `follow_ratio` 0.25–1.0(기본 0.35), `lag` 0.2–0.5 s, `overshoot` 0–10%, `transient_peak` 0.2–0.5.
- 실패·검수: idle이 몸 파라미터를 쓰면 덮어씌워짐(머리 각도 또는 입력 파라미터로 변경). 드래그 시 물리 진폭 제한. 한 파라미터를 호스트와 물리가 동시에 쓰면 안 됩니다.
- 엔진 기능: drive-param과 같음. 난도: 쉬움(drive-param 위의 입력 레시피만 추가). 우선순위: P1(drive-param과 함께 입력 레시피 옵션으로 제공).
- 현재 차이: 몸은 추적·동작으로만 직접 구동됩니다.

### `physics.filter/root-inertia` — 직접 바인딩은 유지하고 뿌리에 관성 회전 추가
- 목적: 추적 직결의 즉각 반응을 유지하며 기울기에 오버슈트·복귀를 더해 몸통 무게감이 끝으로 전달되게 합니다. drive-param보다 변경이 작아 먼저 구현할 수 있습니다.
- 적용: 몸 Z(옆 기울기), 몸 Y(상하), 전신·반신.
- 출력: `ParamBodyZInertia`, `ParamBodyYInertia`; `DeformBodyZBreath` 내부를 ‘직접 부분(기울기의 30–50%) + 관성 회전(나머지)’으로 분리, 피벗은 허리·골반. 단진자 물리 그룹 2개.
- 알고리즘:
  1. 뿌리 체인 순서: 호흡 → [BodyY 관성 warp] → BodyZ 직접 warp → [BodyZ 관성 회전] → 몸 XY → 머리.
  2. 물리: BodyZ 입력(Angle 100), r 10, m 0.55, d 1.2, a 0.8, 관성 파라미터 출력. BodyY도 동일(BodyY 입력, X 타입).
  3. BodyY 관성은 상체 침하·반동만, 진폭 ≤ 0.1 h_head. 전신 서기에서는 전체 이동 대신 무릎 굽힘으로 흡수(`DeformLegs`의 ‘발 고정’과 일치).
  4. 꼬리, 치마 뿌리, 긴 뒷자락을 관성 파라미터 아래에 두어 자연스러운 지연을 얻습니다.
- 조절: `direct_share` 0.3–0.6(기본 0.4), `overshoot`(출력 scale 제어, 기본 10%), `pivot_height`(허리 ↔ 골반).
- 실패·검수: 관성이 과하면 취한 듯 보입니다. 동작 파일에 이미 이징이 있으면 중복 지연되므로 신호 출처(추적/동작)에 따라 가중치를 낮출 수 있습니다.
- 엔진 기능: 물리, 회전 디포머. 난도: 쉬움. 우선순위: P1(body.lean / body.turn 생성기와 조율 후 구현).
- 현재 차이: 몸 파라미터가 기하에 직접 작용하고 물리는 매달린 부품에만 사용됩니다.

### `physics.filter/derived-rule` — 일반 ‘파생 파라미터 규칙표’(물리를 2차 필터로 사용)
- 목적: ‘B가 A를 반 박자 늦고 오버슈트하며 따른다’는 관계를 데이터 규칙 하나로 적어 생성기가 물리 그룹으로 통합 변환합니다. drive-param, head-leads-body, 표정 결합은 그 사례입니다.
- 출력: `target ← Σ wᵢ·sourceᵢ` 규칙, 필드 {k 최대 범위 비, T 응답 시간, o 오버슈트, X형 잔진동 성분 추가 여부}; 규칙마다 `PhysicsDerive_<target>` 그룹 하나.
- 알고리즘:
  1. Angle 입력, 가중치 wᵢ(합 100), 단일 진자. `scale = k_target / (Σw/100 · θn_rad)` 후 계단 시뮬레이션으로 미세 조정.
  2. (T, o)로 진자 파라미터표 조회: T≈0.3 s, o≈5–10% → r 7–12, m 0.65–0.7, d 0.85, a 1.5. T≈0.5 s, o≈20% → r 10, m 0.8, d 0.9, a 1.5. 구간을 하나 더해 잔진동을 늘릴 수 있습니다.
  3. ‘지속 + 잔진동’이 필요하면 같은 입력에 작은 가중치 X형 규칙을 추가합니다.
  4. 파생 파라미터를 동작이 쓰려 하면 동작 생성 단계에서 제외합니다.
- 조절: k 0.3–1.0, T 0.15–0.6 s, o 0–25%, 가중치.
- 실패·검수: 파라미터 범위에 출력이 잘림, 규칙 순환(검출 후 거부).
- 엔진 기능: 물리. 난도: 메커니즘은 쉬움 / 규칙표에는 경험 필요. 우선순위: P1(drive-param 구현 기반).
- 현재 차이: 물리 입력 집합이 고정되어 있고 파생 파라미터 규칙이 없습니다.

## physics.input: 입력 혼합

### `physics.input/current` — 고정 머리·몸 입력
- 현재: 머리카락, 가로 흔들림, 새 그룹, 시뮬레이션 기본값은 모두 `headAndBodyInputs`(AngleX 60 X / AngleZ 60 Angle / BodyX 40 X / BodyZ 40 Angle). 세로 흔들림은 AngleY 60 X / BodyAngleY 40 X / AngleZ 20 Angle. 호흡을 포함하지 않고 부착점별 구분도 없습니다.

### `physics.input/mount-recipe` — 부착 계층과 국소 움직임으로 입력·타입·가중치 선택
- 목적: 각 물리가 부착점의 실제 움직임을 받도록 회전은 Angle(늘어짐 유지), 이동은 X(한 번 밀림)로 쓰고 머리·몸에서의 거리에 따라 비율을 나눕니다.
- 적용: 모든 생성 물리 그룹(머리카락, 흔들림, 장신구, 옷, 팔다리).
- 출력: 그룹 입력 목록(파라미터, 타입, 가중치, reflect).
- 알고리즘:
  1. 부착점의 계층 뿌리 판별: 머리(머리 회전 아래), 상체(몸 Z 회전 아래), 하체·다리(루트), 팔.
  2. 입력 후보마다 끝점에서 부착점 국소 야코비안을 구합니다. 회전 성분 비 > 0.5면 Angle, 아니면 X. 기본표:
     - 머리 장식: AngleX X, AngleY X, AngleZ Angle, BodyX X, BodyZ Angle, 머리 : 몸 ≈ 2 : 1.
     - 목 뒤·긴 뒷머리: 머리 : 몸 ≈ 2 : 3(몸 영향이 더 큼).
     - 상체 장식: 몸만 사용, BodyZ Angle 100, BodyX/Y X 30.
     - 다리·루트 장식: BodyX/Y/Z 모두 X(10–30). 치마에 쓸리는 부품은 치마 구동 파라미터도 추가(X 0.2–0.5).
     - 팔: 몸 X/Y X 50, BodyZ Angle 100(내려온 팔의 늘어짐 유지).
  3. `physics.filter/drive-param` 활성 시 몸 입력은 모두 P★를 읽습니다.
  4. 없는 파라미터는 기존 `available` 방식으로 제외합니다.
- 조절: `head_body_ratio`(부착 종류별), `angle_threshold`(0.5), `sweep_coupling`(0–0.5).
- 실패·검수: 모두 Angle이면 정지 후 중앙으로 돌아오지 않고 자세가 치우칩니다. 모두 X면 고개를 기울일 때 매달린 것도 함께 기웁니다(`physics.gravity` 병용). 입력별 계단 응답 방향이 ‘관성으로 늦게 따라옴’과 맞는지 검사합니다.
- 엔진 기능: 물리, 평가기(야코비안). 난도: 쉬움. 우선순위: P0(생성기 입력표만 변경).
- 현재 차이: 큰 부품 분류별 고정 입력이고 부착점 국소 움직임으로 타입을 선택하지 않습니다.

### `physics.input/hair-class-recipe` — 머리카락 종류별 입력 레시피
- 목적: 길고 뒤쪽인 다발일수록 고개 돌리기 가중치는 낮추고 기울임(중력)·몸 가중치는 높입니다. 앞머리는 머리가 중심입니다.
- 출력: 앞머리 / 옆머리 / 뒷머리 / 긴 다발 네 단계 입력표, 길이로 보간.
- 알고리즘:
  1. 뿌리 위치·길이·너비에 따른 분류는 `physics.chain/scale-ramp` 참조.
  2. 기본값(가중치, 타입):
     - 앞머리: AngleX 60 X, AngleZ 60 Angle, AngleY 15 X, BodyZ 30 Angle, 호흡 10.
     - 옆머리: AngleX 45 X, AngleZ 70 Angle, AngleY 30 X, BodyZ 40 Angle, 호흡 15.
     - 뒷머리·긴 다발: AngleX 35 X, AngleZ 50 Angle, AngleY 30 X, BodyX 40 X, BodyZ 50 Angle, 호흡 20.
  3. L/h_head 0.5–2.0에서 앞머리→긴 다발을 선형 보간합니다.
  4. 좌우 쌍의 AngleY / BodyY reflect는 `physics.reflect/vertical-flare`로 결정합니다.
- 조절: 단계별 가중치(±30%), 길이 보간 끝점.
- 실패·검수: 고개를 돌릴 때 앞뒤 머리가 같은 위상이라면(시간 차가 있어야 함) 뒷머리의 머리 가중치가 너무 높습니다.
- 난도: 쉬움. 우선순위: P0.
- 현재 차이: 앞뒤 머리 입력 집합이 같습니다.

## physics.chain: 진자 체인 설계와 부위별 파라미터

### `physics.chain/current` — 단일 진자와 균일 파라미터 분할
- 현재: `PhysicsHairFront`(1구간 r 7.9 m .77 d 1.45 a .8, ±10°), `PhysicsHairBack`(1구간 r 15 m .95 d .8 a 1.5, ±30°)는 v=1만 출력합니다. `swingRules`는 모든 구간이 같은 파라미터(`List(segments){segment}`), 모든 출력이 같은 outputScale, 구간 길이는 length/segments, 출력은 v=k+1입니다. 뼈대 추종은 본마다 그룹 하나를 만들고 부모 본 파라미터만 입력합니다. `SwingPresets`는 HAIR / ACCESSORY / CLOTH 스칼라 세 단계입니다.

### `physics.chain/material-profile` — 재질별 체인 분포 곡선 m(t), d(t), a(t), r(t)
- 목적: 재질감은 단일 값이 아닌 **체인을 따른 분포**로 정합니다. 채찍 끝은 갈수록 민감하고 감쇠가 작으며, 늘어진 소재는 끝으로 갈수록 둔하고 단단한 장식은 빠르고 짧습니다.
- 적용: 모든 진자 체인(머리카락, 리본, 천, 꼬리, 사슬, 팔다리). 재질은 의미 태그·세장비·면적으로 추론하고 사용자가 바꿀 수 있습니다.
- 출력: 코드 분기 대신 재질 프로필 데이터. 항목 = 노드 수 규칙 + 체인 곡선 네 개의 끝점(t∈[0,1] 선형/지수 보간).
- 알고리즘(설계 기본값, t = 0 뿌리, 1 끝):

  | 프로필 | 노드 수 | r(상대) | m | d | a | 대표 부품 |
  | --- | --- | --- | --- | --- | --- | --- |
  | whip(채찍 끝) | 4–5 | 1 → 0.6 | 0.95 → 0.8 | 0.75 → 0.45 | 1 → 3 | 긴 귀밑머리, 강조 모발, 포니테일, 가는 리본 |
  | hair(일반 머리) | 3–5 | 1 → 0.7 | 0.95 → 0.9 | 0.9 → 0.8 | 0.9 → 1.2 | 앞머리, 옆머리, 뒷머리 |
  | drape(늘어진 천) | 4–5 | 1 → 0.8 | 0.9 | 0.8 → 0.95 | 1 → 0.7 | 치마, 소매, 망토, 두꺼운 꼬리 |
  | silk(긴 리본) | 6–10 | 0.6 균일 | 0.65 | 2.0 | 0.6 | 긴 날림 리본, 끈 |
  | spring(단단한 스프링) | 1 | — | 0.7 | 0.85 | 1.5 | 구동 파라미터(filter) |
  | bounce(탄성) | 3 | 1 | 0.85 | 0.85 → 0.7 | 1.5 → 2.5 | 가슴, 동물 귀 |
  | trinket(작고 가벼움) | 2–3 | 0.6 | 0.9 | 0.9 | 0.9 | 나비 리본, 작은 펜던트 |
  | rigid(단단한 장식의 빠른 흔들림) | 1–2 | 0.8 | 0.9 | 0.6 | 1.5 | 신발 꽃, 버클 장식 |
  | sweep(균일한 느린 체인) | 6 | 1 균일 | 0.6 | 1.1 | 0.8 | 스윕 광택, 별 무리(가진용) |

  - r 절댓값: 총길이 Σr을 부품 길이에 따라 20–50으로 조절합니다. 기존 `lengthPx/30`을 3..16으로 제한하는 규칙과 하나의 함수로 통합하고 두 곳에 따로 쓰지 않습니다.
  - 구간 길이 분포는 `taper`(끝으로 짧아져 끝 해상도 증가, 머리·리본에 적합), `grow`(끝으로 길어져 더 느리고 무거움, 긴 머리의 무거운 끝에 적합) 두 가지이며 기본은 taper입니다.
- 조절: `profile`(확장 가능 열거), `stiffness`(전체 d 배율 0.7–1.3), `liveliness`(전체 a 배율 0.7–1.5), `radius_profile`(taper / grow), `length_scale`.
- 실패·검수: a > 4 및 d < 0.4면 발산하기 쉬우므로 30 fps로 60 s 시뮬레이션하여 최댓값을 검사합니다. 구간이 많고 m이 낮으면 너무 느립니다. 계단 입력에서 끝으로 갈수록 위상 지연이 단조 증가하고 정지 출력이 0인지 검사합니다.
- 엔진 기능: 물리(노드별 독립 파라미터, 이미 지원). 난도: 쉬움. 우선순위: P0(`SwingPresets`, `hairRule`, 뼈대 추종 상수를 프로필표 조회로 변경).
- 현재 차이: 생성 체인의 구간 파라미터가 같고 재질 프리셋은 천 시뮬레이션에만 있습니다.

### `physics.chain/particle-map` — 적은 질점으로 많은 관절 구동: 관절→질점 매핑
- 목적: 적은 물리 질점으로 안정성을, 많은 시각 관절로 매끄러운 곡선을 얻습니다. 한 질점을 연속 여러 구간에 나누어 꺾임을 호로 바꾸고 끝은 더 먼 질점을 읽어 파동이 내려가게 합니다.
- 적용: N ≥ 3 관절 체인, 중첩 warp 체인, 여러 형상 머리 다발.
- 출력: 출력별 (파라미터, v).
- 알고리즘:
  1. 움직이는 질점 수 M = clamp(round(0.6·N), 3, 6). N ≤ 3이면 M = N.
  2. v_i = clamp(ceil(M·(i/N)^γ), 1, M), γ 기본 1.3(뿌리 여러 구간이 v=1 공유).
  3. 오프셋 o: 자유 띠 o=0, 한 점에 매단 체인(귀걸이, 안경 줄, 장식의 하위 체인) o=1로 한 박자 늦은 질점을 읽습니다.
  4. 잔머리·중간부터 휘두르는 형태는 중간 관절이 M−1을 읽습니다.
  5. 체인은 M+1질점, material-profile의 r 곡선으로 길이를 분배합니다.
- 조절: `M` 3–6, `gamma` 1.0–1.5, `offset` 0–2.
- 실패·검수: M ≤ 2면 강체 같고 M > 6이면 고주파 떨림. 같은 질점 공유 구간이 너무 많으면 위상 손실(최대 3구간). 계단 입력에서 관절별 피크 시점이 단조로 늦어지는지 검사합니다.
- 엔진 기능: 물리 다중 출력. 난도: 쉬움. 우선순위: P0.
- 현재 차이: `SwingPhysics`는 구간마다 질점 하나여서 구간이 많으면 체인이 길어지고 쉽게 떨립니다.

### `physics.chain/scale-ramp` — 부위별 체인 출력 이득 곡선
- 목적: 같은 체인도 scale 곡선으로 성격을 바꿉니다. 포화 = 이마에 붙은 앞머리의 전체 흔들림, 선형 = 끝으로 자유로워지는 긴 머리, 급증 = 눈에 띄는 귀밑머리 채찍, 중간 피크 = 무게 있는 천 띠, 감소 = 중첩 누적 보상 또는 전체는 뒤집히고 끝은 끌리는 단단한 천.
- 적용: 모든 다중 출력 체인.
- 출력: 출력별 scale_k.
- 알고리즘:
  1. 정규화 곡선 f(s), s = 체인에서 관절 상대 위치:
     - `saturate`(앞머리): f = min(1, s/0.35).
     - `linear`(뒷머리·옆머리): f = 0.1 + 0.9·s, s > 0.75에서 포화.
     - `whip`(긴 귀밑머리·포니테일): f = 0.2 + 0.3·s + 0.5·max(0,(s−0.7)/0.3)².
     - `pinned-root`(잔머리·두피 부착 다발): s < 0.25에서 0, 이후 0.8까지 선형.
     - `mid-peak`(리본·천 띠·두꺼운 꼬리): f = sin(π(0.2 + 0.7s)), 끝은 약 0.7.
     - `falling`(단단한 천 뒤집힘·중첩 warp 누적 보상·팔): f = ρ^(k−1), ρ 0.7–0.9.
     - `flat`(짧은 체인·가벼운 리본): f = 1, 체인 자체 누적으로 확대.
  2. scale_k = s_max · f(s_k). s_max는 ‘최대 입력 시 관절 각도 = 가용 범위의 45–60%’로 역산합니다.
  3. 중첩 캐리어(회전 체인·중첩 warp)는 누적을 검사합니다. 계단 입력에서 Σ scale_k·θ_k ≤ 150°(회전) 또는 끝 변위 ≤ 0.6 L(warp). 초과하면 s_max 전체를 낮추거나 `falling` 사용.
  4. 마지막 1–2구간은 0.75–0.85로 낮춰 끝이 뒤집히지 않게 할 수 있습니다.
  5. 뿌리 고정은 `root-anchor` 참조.
- 조절: `curve`(열거), `s_max`(20–100), `tip_falloff` 0.75–1, `rho` 0.6–0.9.
- 실패·검수: scale 증가가 너무 빠르면 끝이 경련(scale_n/scale_1 ≤ 2.5, whip 제외), 너무 감소하면 끝이 굳습니다.
- 엔진 기능: 물리. 난도: 쉬움. 우선순위: P0.
- 현재 차이: 모든 출력이 같은 outputScale을 공유합니다.

### `physics.chain/root-anchor` — 뿌리 고정, 부착 구간과 단단한 관절
- 목적: 머리 뿌리·관통 고정된 리본 뿌리는 흔들리지 않아야 하고 두꺼운 천은 몇몇 접힘점에서만 굽어야 합니다.
- 적용: 모든 체인. 부착 방식은 캐리어와 뿌리의 중첩 길이, 관통·눌림(허리띠, 매듭, 이중층)으로 판별합니다.
- 출력: 고정 관절 scale = 0(나중에 켜도록 파라미터 유지), 또는 해당 구간을 캐리어에 직접 붙이고 파라미터를 만들지 않음.
- 알고리즘:
  1. ℓ_attach = 주축에서 캐리어 레이어와 겹치는 시작 구간. ℓ_attach / L을 구간 수로 반올림하여 고정 수 결정(기본 15–25%).
  2. 피부에서 자람(머리) → 첫 구간 또는 첫 15–25% 고정. 매듭점에서 늘어짐(리본·펜던트·꼬리) → 고정 안 함. 눌리거나 관통함 → 눌린 지점까지 고정.
  3. 관절마다 굽힘 가능도 계산: 원화 중심축 곡률 > 임계값(굽혀야 함), 매듭·이중층(굽힐 수 없음), 재질 강성(리본·레이스는 단단함). 단단한 재질은 관절 20–40%를 건너뛰되 연속 ≤ 2, 마지막 끝 관절은 항상 굽힘 허용.
  4. 굽힐 수 있는 관절에 순서대로 v를 배정(particle-map과 통합 계산).
- 조절: `anchor_ratio` 0.1–0.25, `stiff_skip` 0–0.4, `root_softness`(고정 구간 scale 0–0.1·s_max, 기본 0).
- 실패·검수: 너무 고정하면 급회전 때 뿌리가 뻣뻣함. 고정·가동 구간 사이에 Glue 필요(기하 그룹).
- 난도: 쉬움. 우선순위: P0.
- 현재 차이: SwingDeformer의 softness가 뿌리 강성을 제어하지만 모든 구간이 굽힘에 참여하며 고정·관절 건너뛰기 규칙은 없습니다.

### `physics.chain/tiered-taps` — 뿌리 거리·느슨함에 따라 한 체인으로 여러 부품 구동
- 목적: 여러 부품이 체인을 공유해 가까운 것은 먼저 적게, 먼 것은 늦게 많이 움직이면서 위상을 맞추고 물리 그룹 수도 줄입니다. 서로 다른 깊이를 읽어 획일성을 피합니다.
- 적용: 같은 영역(머리·몸)에서 일관된 응답이 필요한 가동 부품들.
- 출력: 영역 체인(머리·몸 각각 X, Y 두 그룹), 단계별 출력 파라미터.
- 알고리즘:
  1. 부품마다 ‘느슨함 × 영역 피벗 거리 / 영역 높이’ 계산. < 0.5는 1단계(모자, 머리 장식, 앞머리 덩어리, 어깨, 외투 위), 0.5–1.0은 2단계(개별 다발, 아래팔, 소매, 치마), > 1.0은 3단계(손, 소매 끝, 든 물건, 옷자락).
  2. 체인 노드 수 = 단계 수 + 1–2. k단계는 v=k, 배율 q^(k−1), q 1.1–1.3.
  3. 같은 부품의 전체·국소에는 인접 단계 사용(덩어리+다발, 바깥층+안층).
  4. 단계별 진폭: 모자 ≈ 높이 5–10%, 앞머리 덩어리 ≈ 길이 5%, 개별 다발 ≈ 10%; 어깨 ±10–15°, 아래팔 굽힘·폄 비 1.4–2.
- 조절: 단계 임계값, q, 단계별 진폭 비율.
- 실패·검수: 모자·머리 지연 차이가 크면 틈(모자 아래 머리 바탕 필요). 팔이 추적·동작으로 직접 구동되면 해당 단계 가중치를 낮춥니다.
- 난도: 중. 우선순위: P1(영역 의미와 carrier에 의존).
- 현재 차이: 객체마다 물리 그룹을 만들며 모자·머리 장식 지연 단계와 덩어리+다발 두 계층이 없습니다.

### `physics.chain/accessory-bus` — 같은 작은 장식의 물리 버스 공유와 결정적 개체 차이
- 목적: 작은 장식을 하나씩 물리 조정하는 비용을 줄입니다. 빠른 흔들림 하나를 공유해 리듬과 비용을 맞추고 개체 형상·진폭 차이로 복제 느낌을 없앱니다.
- 적용: 캐릭터 면적의 < 1% 장식, 반복 장식(비슷한 연결 요소 ≥3개), 배타적 차분에 반복되는 같은 장신구.
- 출력: 영역별(목, 가슴, 위팔, 허리, 신발) 버스 그룹 한 쌍(X·Y 각 2출력), 장식마다 warp 또는 ‘정적 정렬 회전 + 구동 회전’.
- 알고리즘:
  1. 부착 영역으로 군집화하고 범위가 > 2–3 h_head면 버스를 둘로 나눕니다.
  2. X 그룹은 영역별 입력과 mount-recipe의 X/Angle, Y 그룹은 세로 입력 + 호흡 20. `rigid` 또는 `trinket` 프로필 사용.
  3. 개체 진폭 φ_i = φ₀·(1 + j_i), j_i는 ID 해시로 정하는 −0.4..+0.3 값. 방향은 ±15° 변동. 인접 동종 부품은 버스 출력 2–3개를 번갈아 사용.
  4. 아주 작은 부품(< 0.05% 캐릭터 면적)은 4정점 메시 + 회전 두 개로 만들고 warp는 생략합니다.
  5. 배타적 차분의 같은 장식은 버스 파라미터를 공유하고 각 로컬 좌표로 키폼을 변환하여 화면 변위를 맞춥니다.
  6. 가까이서 동시에 보이는 쌍(좌우 귀걸이)은 공유하지 않거나 적어도 체인 길이를 달리합니다.
- 조절: 버스 세분도, `instance_jitter` 0–0.4, 공유 거리 임계값 0.2–0.4H.
- 실패·검수: 같은 파라미터+같은 형상은 기계적 동기화. 흔들린 인접 장식끼리 관통할 수 있습니다.
- 난도: 중. 우선순위: P1.
- 현재 차이: 흔들림마다 물리 하나이며 버스·개체 차이가 없습니다.

### `physics.chain/limb-pendulum` — 늘어진 팔다리의 수동 진자 체인(팔, 뒷짐, 든 팔)
- 목적: 손 추적 없는 얼굴 추적에서 굳은 팔을 어깨의 복합 진자로 바꿉니다. 몸이 움직이면 팔이 자연스럽게 흔들리고 손이 가장 늦고 크게 움직입니다. 물리·포즈 파라미터를 독립 중첩하여 동작과 덮어쓰지 않게 합니다.
- 적용: 팔 뼈대·회전 체인이 있는 경우(팔 기하는 hair-body 담당). 포즈 분류: 내려온 팔(주축과 수직 각 < 35°, 손이 팔꿈치 아래), 접촉 팔(손·몸통 중첩 또는 접촉 쌍), 뒷짐, 포즈 지정이 필요한 팔(끔).
- 출력: 팔마다 물리 그룹(좌우 각 하나, 입력 반전), `ParamArmSway<L|R>_<k>` 출력. 관절에 **블렌드 셰이프** 또는 독립 회전층으로 추가하고 포즈 파라미터는 쓰지 않습니다.
- 알고리즘:
  1. 입력: 몸 X/Y X 30–50, BodyZ Angle 100(늘어짐 유지), 호흡 15–20. drive-param 활성 시 P★ 사용.
  2. 노드 수 = 관절 수 + 1. r은 위팔 : 아래팔 : 손 ≈ 14 : 12 : 6으로 조절, `hair` 프로필에 감쇠 추가(d 0.9–1).
  3. 내려온 팔은 관절마다 같은 부호, v1..vk, scale 비 1 : 1.2 : 1.5 : 2. 회전 캐리어가 누적되어 `falling`을 쓰면 1 : 0.75 : 0.4. 최대 각도는 어깨 ±10–15°, 팔꿈치 ±15–20°, 손목 ±10–12°. 실제 물리 진폭은 관절 수동 범위의 20–30%.
  4. 비대칭 제한: 몸 방향 범위 = 바깥 방향의 0.35–0.65. 팔·몸 윤곽 최소 간격으로 안쪽 이동 상한을 구합니다.
  5. 손가락은 같은 파라미터, 손가락별 진폭 base·(1 + 0.3k), 시작 각 3–15° 차이. 또는 뿌리·끝이 더 깊은 질점을 읽고 reflect하여 끌림을 표현합니다.
  6. 접촉 팔은 위팔 같은 부호 v2, 아래팔 reflect v3 및 scale ≈ s·L_upper/L_fore, 손 reflect v4. BodyZ 최대 입력에서 손 중심 변위 < 위팔 끝 변위의 0.3배인지 검사하고 아니면 최소제곱 조정합니다.
  7. 뒷짐(가려진 완전한 손이 원화에 있음)은 바깥 warp로 어깨·팔꿈치 주위에서 밖으로 흔들어 손 길이의 0.3–0.5를 드러냅니다. 몸 X/Y/Z 입력, 한쪽 Y reflect.
  8. 손 추적이나 동작이 팔 포즈를 직접 구동하면 물리 가중치를 20–30%로 낮추거나 끕니다.
- 조절: `sway_amp`(손 변위 3–10% H), `inner_outer_ratio` 0.35–0.65, `finger_fan`, `mode`(hang / contact / behind-back / off).
- 실패·검수: 몸을 앞으로 기울일 때 팔이 뒤로 뜨면 몸 Y 입력 추가. 반대 위상이 과하면 손이 반대로 휘둘림. 관절에는 Glue나 덮개층 필요(기하 그룹).
- 엔진 기능: 블렌드 셰이프(또는 추가 회전층), 물리. 난도: 중. 우선순위: P1(팔 물리 금지 해제, 독립 중첩 출력 채널이 전제).
- 현재 차이: `skeletonRules`는 팔·다리를 물리에서 명시적으로 제외하고 `DeformArmHang`의 약 4° 정적 반대 흔들림만 있습니다.

### `physics.chain/dual-band` — 주 흔들림 × 미세 떨림의 이중 주파수 중첩
- 목적: 단일 진자의 한 주파수 대신 ‘전체 큰 흔들림 + 끝 미세 떨림 + 전체 상하 탄성’ 세 대역을 겹쳐 실제 머리카락에 가깝게 합니다.
- 적용: 포니테일, 긴 땋은 머리, 강조 모발 등 시각적 초점의 긴 체인. 기본으로 꺼짐.
- 출력: 같은 체인의 둘째 물리 그룹 `<id>_Fine`, 관절별 미세 떨림 블렌드 셰이프(또는 2D 키 둘째 축), 선택적으로 전체 Y 탄성 / X 흔들림 셰이프(늘어짐 프로필 구동).
- 알고리즘:
  1. 미세 물리는 주 흔들림과 같은 입력, 가중치 ×0.4. 노드 m은 0.7까지 감소, a는 3–4까지 증가(whip), scale은 주 흔들림의 3–5배.
  2. 미세 각도는 주 각도의 5–10%(≤ 12%)만 차지합니다.
  3. Y 탄성은 AngleY 중심 입력, 구간 길이의 3–5% 진폭.
- 조절: `fine_ratio` 0.05–0.12, 미세 마지막 노드 d 0.4–0.55, Y 탄성 0.02–0.06구간 길이.
- 실패·검수: 미세 떨림이 주 흔들림과 비슷하게 크면 경련처럼 보입니다.
- 엔진 기능: 블렌드 셰이프(2D 키 × 본 수 폭증 방지). 난도: 중. 우선순위: P2.
- 현재 차이: 물체마다 진자 그룹 하나뿐입니다.

### `physics.chain/follower-share` — 본체 파라미터를 직접 재사용하는 추종 부품(그림자 체인, 복사본, 변형)
- 목적: 그림자·하이라이트 복사본·차분·만화 기호가 본체와 위상 차이 없이 움직이며 물리 그룹을 중복하지 않게 합니다.
- 출력: 추종 부품 관절·warp가 본체 출력 파라미터를 직접 축으로 사용. 새 물리 그룹 없음. 머리 위에 뜬 만화 기호 등은 추종 비율로 키폼을 줄입니다.
- 알고리즘:
  1. lighting / effect 슬롯이 그림자 짝·기호 앵커를 지정합니다. 이 템플릿은 연결만 담당하여 물리 축마다 본체의 같은 이름 파라미터를 바인딩하고 추종 부품 자체 기하로 키폼을 다시 계산합니다.
  2. 만화 기호는 가장 가까운 머리카락 물리의 첫 출력 두 개로 2D warp, 추종 비율 0.3–0.5(≤ 0.5).
  3. 부모 warp가 달라 시차가 다르면 파라미터만 공유하고 디포머는 공유하지 않습니다.
- 조절: `follow_ratio` 0.3–1.0.
- 실패·검수: 본체 물리를 사용자가 바꿔도 파라미터 공유로 자동 동기화해야 합니다. 설정 복사는 어긋나므로 금지합니다.
- 난도: 쉬움. 우선순위: P1(그림자·기호 생성기와 함께).
- 현재 차이: 추종 부품이 없으며 SeeThrough 복사본 메커니즘을 확장할 수 있습니다.

## physics.cascade: 연쇄 연결

### `physics.cascade/current` — 연쇄 연결 없음
- 현재: 모든 물리 그룹은 표준 입력을 읽고 부모 본 파라미터를 읽는 뼈대 꼬리만 예외입니다. `DocumentGenerators`의 PHYSICS 노드는 하나뿐이며 그룹 의존 그래프가 없습니다.

### `physics.cascade/staged-inputs` — 상류 물리 출력으로 하류 물리 구동(의존 그래프)
- 목적: 2차 시스템을 직렬 연결하면 고차 응답이 되어 몸→옷→머리끝 순으로 시간 층이 자연스럽게 생기고 추적 노이즈가 증폭되지 않습니다.
- 출력: 주 움직임→부착물→끝부분 물리 그룹 DAG, physics3에 위상 정렬 순서로 배치.
- 알고리즘:
  1. 각 그룹이 `reads` 입력, `writes` 출력을 선언하여 DAG 구성. 순환을 검출하고 기존 이슈 타입 `FEEDBACK` 보고.
  2. 위상 정렬로 physics3 순서 결정(Cubism은 설정 순 평가하므로 상류를 앞에 두면 같은 프레임의 새 값을 읽음).
  3. 하류 입력 치환: BodyX → BodyX★(X 40), BodyY → BodyY★(X 40), BodyZ → BodyZ★(Angle 60), 하체 Z★(Angle 40 reflect).
  4. 단계마다 d를 0.05–0.1 줄여 끝을 민첩하게 하고 3단계 이상이면 r을 줄입니다.
- 조절: `stages` 2–3, `per_stage_d_drop` 0.05–0.1.
- 실패·검수: 지연 누적으로 둔하면 둘째 층 d 감소. 순서가 틀리면 1프레임 지연 떨림.
- 엔진 기능: 물리 그룹 순서(기존 `physicsOrder`). 난도: 쉬움. 우선순위: P1(drive-param과 함께).
- 현재 차이: 의존 그래프가 없고 사용자 순서·생성 순서가 섞여 있습니다.

### `physics.cascade/body-lag-chain` — 상체→허리→골반·다리→치마의 단계적 지연
- 목적: 실제 몸 회전처럼 몸통이 먼저, 골반·다리·옷자락이 차례로 따르는 파동으로 상하체 각도 차이의 비틀림을 만듭니다.
- 적용: 전신(반신은 허리까지만), drive-param 필요.
- 출력: `BodyX★`(L0 상체), `BodyXLower★`(L1 허리·골반), `BodyXHem★`(L3 늘어진 부품, 치마·뒷자락 물리가 읽음). 허리띠 2D warp, 다리별 고관절 회전(기하는 body 슬롯, 여기서는 파라미터·물리 제공).
- 알고리즘:
  1. L0은 drive-param에서 얻습니다.
  2. Lk = Pendulum(Lk−1 출력(X형 0.8) + 보조축 0.2 + 원래 입력(Angle 0.3–1.0)). r은 이전 층의 0.85–0.95, m 0.65–0.85, d 0.65–0.9, 마지막 층 d ≥ 0.85.
  3. 원래 입력을 Angle·reflect로 섞으면 지속 반대 방향(하체가 정지 시 약간 반대로 비틂), 원하지 않으면 X만 씁니다.
  4. 층별 회전 진폭 비 0.4–0.6으로 아래로 갈수록 안정화합니다.
  5. 검수: 계단 오버슈트 ≤ 10–15%, 안정화 0.4–0.8 s. 양의 계단 입력에서 각 층 부호가 같아야 합니다(의도적 반대 위상 제외).
- 조절: `layers` 3–5, `r_ratio` 0.85–0.95, `amp_ratio` 0.4–0.6, `raw_mix` 0.3–1.0(클수록 즉각 반응).
- 실패·검수: 저역통과 층이 많으면 물렁함. 큰 위상 차이로 허리선이 찢어지면 Glue 또는 윗가장자리 고정 필수. reflect 오류는 하체 반대 비틀림.
- 난도: 중(계층 재배열·계층 간 Glue도 관련). 우선순위: P1.
- 현재 차이: `DeformBodyXY`는 공간 감쇠만 있고 시간 지연이 없으며 다리·몸이 동기화됩니다.

### `physics.cascade/hip-counter-twist` — 골반 반대 비틀림(대립식 서기)
- 목적: 회전 시 골반이 조금 반대로 비틀어 균형을 잡고 서서 흔들 때 무게중심 이동을 표현합니다.
- 적용: 전신 서기. 스타일 옵션이며 ‘발 항상 고정’과 배타적이거나 발 변위를 제한합니다.
- 출력: `ParamHipTwist★`, `ParamHipLift★`, `ParamShoulderReact★`, 각각 연쇄 출력·reflect를 읽는 물리 그룹 하나.
- 알고리즘:
  1. 골반 비틀림 = Pendulum(Delay(BodyX★ + HeadY)×0.1 + Delay(HeadZ)×0.3), 출력 reflect로 상체와 반대. Delay는 body-lag-chain 이전 층 출력 읽기.
  2. 골반 올림은 같은 지연량의 세로 성분, 한쪽 다리 뿌리를 1–2% H 올림.
  3. 키폼(body 슬롯)은 골반 영역을 고관절 중심 주위에서 화면 안 반대로 2–4% H 이동.
  4. 어깨 반응 = Pendulum(−HeadZ×0.2 − BodyX×0.3 − BodyZ×0.3), 기울일 때 반대 어깨 상승 표현.
- 조절: `counter_ratio` 0.1–0.3, `hip_shift` 2–4% H, `foot_slide_limit`(기본 0).
- 실패·검수: 다리 가로 이동이 크면 미끄러짐. r은 상체의 2배 이하.
- 난도: 중. 우선순위: P2.
- 현재 차이: 골반 반대 비틀림이 없습니다.

### `physics.cascade/attached-subchain` — 부모 체인 구간에 매단 하위 체인이 더 깊은 질점 읽기
- 목적: 복합 물체(모자 끝 금속 고리, 갈라진 머리 다발)가 부모 움직임을 상속하고 부모 굽힘 위에 한 박자 늦은 하위 흔들림을 겹칩니다.
- 적용: 기하 그룹이 부착 그래프 제공(자식 체인 뿌리 피벗이 부모 구간 메시와 맞닿음).
- 출력: 자식 체인 물리 출력. 같은 입력이면 부모와 그룹 병합 또는 더 큰 delay의 별도 그룹.
- 알고리즘:
  1. 병합: 자식 관절 j가 v = v_mother(부착 구간) + ceil(j·(M − v_mother)/N_child)를 읽고 자식 뿌리 scale은 0(분기점 강체).
  2. 별도: 부모와 같은 입력 또는 부모 구간 출력(output-feed), d는 부모보다 0.1–0.2 큼.
  3. 자식 scale은 부모의 1.0–1.2배. 깊이 > 3이면 층마다 ×0.8로 누적 각도 제어.
  4. 자식이 늘어지는 물체면 부착점에 중력층 삽입(physics.gravity).
- 조절: `particle_offset` 1–2, `child_gain` 1.0–1.2.
- 실패·검수: 부모 뿌리가 고정되면 자식이 움직이도록 독립 X 입력을 남겨야 합니다. 자식이 먼저 움직이면 너무 얕은 질점을 읽은 것입니다.
- 난도: 중. 우선순위: P1(분기·부착 기하와 함께).
- 현재 차이: swing끼리 부착할 수 없습니다.

### `physics.cascade/output-feed` — 상위 출력을 읽는 2차 물리(모발 끝, 부속 떨림)
- 목적: 별도 입력 설계 없이 주 흔들림이 도착한 뒤 끝이 한 번 더 떨리게 합니다.
- 출력: 2차 `<id>_Tip` 그룹. 끝에서 둘째 구간 출력 입력(Angle 100, 필요 시 reflect), 3–4질점, 머리끝·모발 무리 벌림 셰이프 출력(구간 길이 0.05).
- 조절: 읽는 구간, 이득.
- 실패·검수: 순환 검출(staged-inputs), 2차 효과가 강하면 경련.
- 난도: 쉬움. 우선순위: P2.

### `physics.cascade/surface-follow` — 부착 표면 물리 파라미터 읽기
- 목적: 흔들리는 가슴·배·치마 표면의 장식·옷이 허공에 뜨지 않게 합니다. 표면 파라미터 재사용은 새 물리보다 저렴하고 동기화됩니다.
- 출력: 부착물 변형 스택에 표면 물리 파라미터 축의 회전·이동층 또는 공유 블렌드 셰이프 삽입. 진폭 = 부착점 표면 변위 × 추종 가중치.
- 알고리즘:
  1. 부착 관계: 메시 중첩 ≥ 50%이고 표면 위에 그려짐.
  2. 가중치: 밀착 1.0, 옷 바깥층 0.3–0.6, 장식 뿌리 1.0에 자체 흔들림 물리 추가 중첩.
- 조절: `follow_weight` 0.3–1.0.
- 난도: 쉬움. 우선순위: P1(chest-bounce와 함께).
- 현재 차이: 장식·옷이 표면 물리를 읽는 연결이 없습니다.

## physics.excitation: 가진

### `physics.excitation/current` — 머리·몸 각도만 사용
- 현재: 추적·동작이 쓰는 머리·몸 파라미터만 가진원입니다. 호흡은 몸통 기하(`DeformBodyZBreath`)만 구동하고 물리에 들어가지 않으며 동작 생성기는 물리를 모릅니다.

### `physics.excitation/breath-feed` — 호흡을 지속적인 저진폭 가진원으로 사용
- 목적: 사용자가 멈춰도 긴 체인·생물·공중 물체가 호흡 리듬과 위상 차이로 움직입니다. idle에 의존하지 않고 자동 호흡 호스트면 동작하며 추적과 충돌하지 않습니다.
- 적용: 모든 생성 물리에 낮은 가중치. 꼬리·날개·동물 귀·더듬이·공중 소품·작은 생물 같은 ‘살아 있는’ 종류는 호흡만 연결 가능.
- 출력: 그룹 입력에 `ParamBreath` 추가, 생물 그룹은 호흡만 포함.
- 알고리즘:
  1. 기본 Angle 가중치: 머리카락 10–20, 치마·옷 5–15(길고 무거운 자락은 하한), 장식 15, 팔 15–20, 가슴 10, 눈 하이라이트 30–50, 꼬리·공중 펜던트·생물 80–100, 깜빡이는 별 무리 80.
  2. 생물 그룹: 호흡 100만 연결(머리·몸 10–20 약하게 추가 가능), 3–4질점, 끝으로 scale 증가(끝/뿌리 2–3). 형제 객체가 v=1/2/3을 순서대로 읽고 reflect 또는 Angle/X 타입을 교대로 사용.
  3. 바보털 같은 튀어 오르는 부품은 호흡 reflect로 내쉴 때 위로 솟게 합니다.
  4. 공진 방지: 고유 주기는 호흡 주기의 0.5–0.8배, m ≤ 0.9 또는 가중치 ≤ 65. 60 s 시뮬레이션에서 호흡 단독 출력 ≤ 범위 20–30%, 구간 편향 ≤ 25°.
  5. 하한: 호흡 주기 내 그룹 진폭 ≥ 최댓값 3–5%, 아니면 가중치 증가.
  6. 호스트가 호흡을 자동 구동하지 않으면 생성 idle이 ParamBreath를 써야 합니다(현재도 작성).
- 조절: `breath_weight`(부위별), `alive_mode`(only-breath / mixed), `phase_spread`(v 오프셋 / reflect / 교대 타입).
- 실패·검수: 너무 크면 바람처럼 보이고 고유 주기와 가까우면 계속 증폭되며 호흡 < 2 s면 떨립니다.
- 엔진 기능: 물리. 난도: 쉬움. 우선순위: P0(입력표+공진 검사만 변경).
- 현재 차이: `headAndBodyInputs`와 세로 입력에 호흡이 없습니다.

### `physics.excitation/kick-channel` — 기하 없는 가진 파라미터에 동작이 충격 기록
- 목적: 게임 일러스트의 큰 연기는 동작 중심인데 몸 파라미터 변화가 작으면 물리가 자극되지 않습니다. 전용 가진으로 정적 변형 없이 ‘여기서 휘두르기’를 지정하고 느린 회전은 얌전하게, 빠른 멈춤은 잔진동을 만들 수 있습니다.
- 적용: 생성 동작 모델. 좌우 대칭 그룹은 kick을 각각 읽거나 한쪽 reflect.
- 출력: `ParamPhysKick_<cluster>`(±30, 바인딩 없음, used-by 0), 앞머리 좌우·뒷머리 좌우·치마·리본 등 물리 군집마다 하나. 그룹에 X 타입 kick 추가, 가중치는 머리 입력의 2–4배.
- 알고리즘:
  1. 몸·머리·팔 파라미터 2차 미분 극값에서 0 → ±피크 → 0 펄스 기록. 상승 0.15–0.25 s, 하강 0.2–0.3 s, 방향은 움직임 반대(관성).
  2. 지속 회전은 같은 주기 구형파, 좌우 반대 위상.
  3. 동작 종료 전 0 복귀, 피크는 대리 범위의 100% 이하 검사.
  4. 이식성: 낮은 가중치 포즈 입력(AngleX 10)을 대체 입력으로 유지.
  5. 런타임에서 동작이 없으면 호스트가 드래그·추적 속도를 주입 가능(`host.mapping`).
- 조절: `kick_weight` 20–40, `pulse_width` 0.3–0.5 s, `amp` 10–30.
- 실패·검수: 뾰족한 펄스는 폭발적 진동, 포즈와 어긋나면 제멋대로 움직임. 대체 입력이 없으면 얼굴 추적 회전이 물리를 일으키지 못합니다.
- 엔진 기능: 물리, 동작 곡선 쓰기, 순수 입력 파라미터. 난도: 중. 우선순위: P1(MotionGenerator 연동).
- 현재 차이: 동작 생성기는 가진을 쓰지 않습니다.

### `physics.excitation/wind-gust` — 전역 바람과 그룹별 돌풍
- 목적: 정지해도 머리카락·리본·옷자락이 다른 리듬으로 미세하게 움직입니다.
- 출력: `ParamPhysWind`(전역, idle 정현파), `ParamPhysGust_<g>`(그룹별, idle 반정현파 열, 결정적 해시로 피크 변화). 입력 추가: 머리 wind 20–50 / gust 40, 천 wind 15–30.
- 조절: 바람 주기 = 주주기, 돌풍 주기 = 주주기의 0.3–0.7, 진폭.
- 실패·검수: breath-feed와 중첩 과다(하나만 선택하거나 반으로 줄임).
- 난도: 중. 우선순위: P2(breath-feed가 대부분 충족).

### `physics.excitation/blink-feed` — 눈 외 부품의 무작위 타이머로 깜빡임 사용
- 목적: 자연스러운 불규칙 계단 입력인 깜빡임을 앞머리·동물 귀·더듬이에 연결하여 별도 동작 없이 매번 살짝 떨리게 합니다.
- 출력: 선택 그룹에 `ParamEyeLOpen`/`ParamEyeROpen` X 입력 추가. 동물 귀는 깜빡임이 주입력.
- 알고리즘:
  1. 가중치: 앞머리 10–20, 동물 귀 50–100(머리 15–30 혼합), 더듬이 30.
  2. 귀는 같은 쪽 눈만 읽고 뒤로 떨리는 방향으로 reflect 결정.
  3. 추적 떨림에는 입력 데드존 0.05 또는 깜빡임 속도 구동(derived-rule의 X 성분).
- 조절: 가중치, 데드존.
- 실패·검수: 오래 감으면 귀가 멈춤(허용), 반쯤 뜬 추적 떨림은 지속 진동 유발.
- 난도: 쉬움. 우선순위: P1.
- 현재 차이: 깜빡임은 `PhysicsEyeJelly`만 구동합니다.

### `physics.excitation/toggle-impulse` — 스위치 전환을 물리 충격으로 사용
- 목적: 호스트의 스위치는 보통 0.3–0.5 s에 1로 가므로 낮은 가중치 X 입력으로 쓰면 포즈 전환의 무게중심 이동·소품 등장 탄성을 만들 수 있습니다.
- 출력:
  - 포즈 스위치: 몸 Y★와 가장 가까운 장식 그룹에 T 입력(X 5–10). 방향은 전환 전후 손 무게중심의 세로 변화 부호.
  - 등장 스위치: 새 `PhysicsPop_<T>`, T 입력(X 100), 3질점, m 0.95 d 1 a 1. 소품 뿌리층 셰이프로 출력(+1 = 세로 10–15% 늘림, 가로 5–10% 축소, 소품 높이 1–2% 상승).
- 알고리즘: T가 0.5 s 선형 0→1일 때 몸 Y 피크가 범위의 약 5–10%, 0.6 s 안에 정지, 등장 첫 피크 0.6–0.8최댓값인지 검사.
- 조절: 가중치 4–10, 탄성 5–15%.
- 실패·검수: 느린 표정 페이드인은 계단 대신 경사 입력이 되어 약해짐(d 감소). 끌 때 반대로 한 번 튀는 것은 허용.
- 난도: 쉬움. 우선순위: P2(toggle 슬롯 스위치 체계 필요).

### `physics.excitation/sway-root` — 전신 뿌리 흔들림을 물리 입력에 포함
- 목적: idle 무게중심 이동이 단순 평행 이동에 그치지 않고 치마·머리·리본에 물리로 전달되게 합니다.
- 출력: 뿌리 파라미터(기하는 body 슬롯)를 X 30–60 물리 입력으로 사용.
- 난도: 쉬움. 우선순위: P2(body 흔들림 파라미터와 함께).

## physics.reflect: reflect와 반전

### `physics.reflect/current` — 사용하지 않음
- 현재: `PhysicsEngine`은 reflect를 지원하지만 생성기는 쓰지 않습니다. VERTICAL swing의 모든 체인이 같은 부호이고 좌우 물리가 대칭입니다.

### `physics.reflect/vertical-flare` — 세로 입력 한쪽 반전으로 끄덕임·상하 흔들림 때 대칭 벌림·모음
- 목적: 좌우로만 흔들리는 늘어진 진자에 세로 움직임을 가로 X 입력으로 주고 한쪽을 반전합니다. 끄덕일 때 양쪽이 함께 벌어지거나 모여 부풀고 수축하는 부피감을 만들고 고개 돌리기 때는 같은 방향을 유지합니다.
- 적용: 몸 중심선 기준 쌍(옆머리, 좌우 뒷머리, 좌우 치마판, 긴 베일, 팔). 중심선 부품(가운데 땋은 머리)은 세로를 연결하지 않거나 조금만 사용. 넓은 중앙 뒷머리는 기하 그룹에서 좌우로 나눌 수 있습니다.
- 출력: 좌우 그룹 세로 입력 reflect. 선택적 개폐 키폼은 θ = θ_max·|x − x_mid|/반너비로 부착점 주위 바깥 회전.
- 알고리즘:
  1. 부착점이 중심선 어느 쪽인지로 그룹 분리.
  2. 가로(AngleX X, AngleZ Angle)는 양쪽 동일, 세로(AngleY, BodyAngleY의 X 입력)는 가로의 0.3–1.0 가중치와 한쪽 reflect.
  3. AngleY 정현파 스캔을 렌더링하여 ‘들 때 벌림’ 또는 스타일상 ‘숙일 때 벌림’에 맞는 쪽을 반전합니다. 양쪽 끝 수평 변위가 반대 부호인지 확인.
  4. 비대칭 머리는 양쪽 총면적으로 세로 가중치 정규화.
- 조절: `vertical_ratio` 0.3–1.0(기본 0.5), `flare_on`(들기/숙이기), `center_policy`(skip / weak / split).
- 실패·검수: ‘바깥쪽 양수’ 키폼이면 규칙이 반대(가로 reflect 필요, 세로 불필요)이므로 생성기는 캔버스 방향을 고정해야 합니다. 안으로 모일 때 몸·팔 관통 방지를 위해 모음은 벌림의 절반 이하.
- 엔진 기능: 물리 reflect. 난도: 쉬움. 우선순위: P0.
- 현재 차이: VERTICAL 그룹은 좌우 구분·reflect가 없습니다.

### `physics.reflect/mirror-pair` — 쌍 부품의 대칭 개폐 / 동방향 / 혼합
- 목적: 양쪽이 같은 방향이면 단단한 판처럼 보이므로 한쪽을 반전해 옷자락이 회전과 함께 호흡하듯 만듭니다. 다만 급회전에서 완전 대칭은 관성에 어긋나므로 혼합 가능해야 합니다.
- 적용: 쌍 날림 리본·베일·긴 리본·가슴 나비 리본 고리·치마 옆판.
- 출력: 한 물리 그룹 공유(출력 쪽 reflect) 또는 두 그룹 입력을 λ로 혼합.
- 알고리즘:
  1. 밀착 쌍(가슴 매듭, 치마 옆판, 앞섶)은 개폐, 몸에서 떨어진 부품(귀걸이, 목 앞 리본)은 동방향. 이격 > 장식 길이 0.3이면 떨어진 것으로 판정.
  2. 개폐는 한 그룹, 반대쪽 모든 출력 reflect로 위상차 0.
  3. 혼합은 두 그룹. 둘째 가로 입력 = (1−λ)·원본 + λ·반전(같은 파라미터 입력 두 개, (1−λ)w는 그대로, λw는 reflect).
  4. 실제 화면 방향으로 판단합니다. 기본 각도가 메시에서 이미 미러링되었다면 다시 reflect하면 동방향이 됩니다.
- 조절: `mode`(open-close / same / blend), `lambda` 0–1(기본 0.6).
- 실패·검수: 기본 각도가 ±180° 근처이면 부호를 틀리기 쉬우므로 렌더링으로 확인.
- 난도: 쉬움. 우선순위: P1.
- 현재 차이: 쌍 미러 논리가 없습니다.

### `physics.reflect/upward-invert` — 위로 향한 부속물 출력 반전
- 목적: 물리 체인은 늘어진 진자이므로 깃털·바보털·더듬이·선 귀 같은 위쪽 물체는 같은 회전 방향에서 끝이 잘못 밀립니다. 반전해야 모발 끝처럼 움직임보다 늦게 따라옵니다.
- 적용: 휴식 방향 d(뿌리→끝)가 d·g < −0.3인 체인.
- 출력: 모든 출력 reflect, scale ×1.5–2.5(가벼운 부품), 머리 기울임 추종층 추가(기하 그룹).
