# 내부 조형 작성

[문서 목록](../../README.md) · [中文](../../zh/spec/INTERIOR_SURFACE.md) · [English](../../en/spec/INTERIOR_SURFACE.md) · [토론 #44](https://github.com/tsunehimatoi/psd2live/issues/44)

## 범위와 작업 흐름

선택 사항인 메시 키폼 생성기로, 가상의 곡면을 통해 기존 내부 텍스처의 형태를 바꿉니다. 텍스처나 그림자를 합성하지 않고, 물리적인 천을 시뮬레이션하지 않으며, 깊이 모델도 필요하지 않습니다. 이 기능을 쓰지 않는 프로젝트는 기존 경로를 그대로 따릅니다.

생성된 레이어를 선택하고 오른쪽 도크에서 **내부 조형**을 켭니다. 슬라이더를 놓으면 히스토리 편집 하나가 커밋됩니다. 생성에 실패하면 초안과 이전의 유효한 결과가 유지됩니다. 끄면 다시 베이크하지 않고 설정을 유지합니다. 삭제하면 레시피와 그것이 소유한 물리가 제거되며 실행 취소할 수 있습니다. 다른 작성 내용이 참조하는 비공개 입력은 넘겨받아 유지됩니다. **단독 표시 / 중앙**은 선택한 레이어에 일시적으로 맞추며, 한 번 더 클릭하면 모델 오브젝트를 움직이지 않고 그 캔버스의 가시성과 카메라를 복원합니다.

네이티브 2D 파라미터 패드는 실제 소스 범위와 기본값을 사용하며, 오른쪽/아래쪽이 양수입니다. 놓으면 물리가 계속되는 동안 목표를 유지합니다. 선택적인 마우스 추적은 기본적으로 꺼져 있으며 패드와 동시에 쓸 수 없습니다. 그 중립점은 분리된 레이어의 기본 상태 중심이거나, 전체 보기에서는 메인 캔버스 중심입니다. 마우스 배율은 시험 재생에만 영향을 줍니다. 명시적인 파라미터 포즈와 내보내는 범위는 바뀌지 않습니다.

로컬 시험 재생은 편집 캔버스에서 임시 별칭을 사용하므로, 몸/머리 입력과 문서 히스토리는 바뀌지 않습니다. 프로젝트, 작업 공간, 캔버스, 대상을 바꾸면 임시 투영이 지워집니다. 캐릭터 전체 재생은 기존 미리보기 작업 공간을 사용합니다.

## 설정

| 설정 | 범위 | 의미 |
| --- | --- | --- |
| 가로 / 세로 강도 | 각각 0–2 | 소재 축별 독립 게인 |
| 부풀기 / 기울임 | 각각 0–2 | 가상의 아치와 치우침. 어느 하나라도 0이면 곡면 변위가 없어짐 |
| 주름 양 | 0–2 | FOLD 가이드의 기여도. 주름 가이드가 없으면 효과 없음 |
| 윤곽 유지 | 0–1 | 0은 보이는 윤곽을 풀어 주고, 1은 원본 알파 윤곽을 보호함. 위쪽 고정 없음 |
| 완화와 전달 | 토글 | 프로젝트 네이티브 물리가 형태 영역을 구동 |
| 반응 시간 | 0–0.6초 | 첫 단계의 반응. 전역 시계는 바꾸지 않음 |
| 전달 시간 | 0–0.5초 | 따라오는 영역의 지연 |
| 전달 강도 | 0–1 | 따라오는 영역의 가중치. 0이면 분할이 없어짐 |
| 방향 끝점 | 각 좌표 0–1 | 레이어 기준 전달 방향. 거리는 0.05 이상 |
| X / Y 마우스 배율 | 각각 0.1–1 | 균일 게인. 마우스 시험 재생 전용 |

가이드는 원본 픽셀 좌표의 점, 양수 반경, 양, 그리고 선택적인 세로 전용 플래그를 저장합니다. `layer_mesh_structure`가 찾은 선은 `detected`(`FOLD`, `SHADE`, `PATTERN`)도 기록합니다. TOPOLOGY 가이드는 주름을 만들지 않고 FOLD 가이드는 주름을 만들며, 감지된 선은 작성자가 FOLD로 표시해야 비로소 주름이 됩니다. 가이드는 패널에서 수치로 편집하거나, 아래의 캔버스 핸들로 그리고 편집할 수 있습니다.

## 곡면과 생성 표현

`InteriorSurface.compile/evaluate`가 정적 공식을 담당합니다. 원래 메시, RGBA, 설정, 가이드로부터 바뀌지 않은 토폴로지 위의 변위를 만듭니다. 아치의 호 길이 정합이 텍스처를 재분배하고, 윤곽 유지는 전역 정합과 행/열 정합 및 가장자리 가중치를 섞습니다. 중립에서는 원래 좌표를 반환합니다. 알파 윤곽은 직사각형 메시 경계와 다르며, 매달린 루트 제약은 없습니다. 소재 축 분리와 세로 방향 종횡비 보정은 유지됩니다. 면적 가드가 접힘을 제한하지만, 샘플링 검사는 연속 영역에 대한 증명이 아닙니다.

`InteriorBasisKeyforms`는 작성 시점에 X/Y 커브와 국소적으로 게이트된 혼합 보정 행을 샘플링한 뒤 네이티브 블렌드 필드를 내보냅니다. 새 항목은 원본 픽셀 4개 간격으로 샘플링한 목표를 사용하며, 보수적인 스케일링 오차가 진단에 포함됩니다. 예산/안전성 검사에 실패하면 생성을 거부합니다. 한 소재에서 시각적으로 통과했다고 해서 모든 소재에서 오차가 보이지 않는다고 확정되지는 않습니다.

`NativeInteriorAuthoring`은 `LayerTexture.rasterOfUv`로 원본 래스터 위치를 구한 다음, 원래 UV 삼각형의 미분을 이용해 변위를 메시 로컬 좌표로 매핑합니다. 기존 메시, UV, 스킨 가중치, 부모 디포머, 작성된 키폼은 그대로 유지됩니다. 베이크는 메시를 절대 바꾸지 않으며, 리메시는 별도의 `layer_mesh_structure` 명령입니다.

기존 NORMAL/BLEND 입력은 반복되지 않고 기본값이 범위 안에 있으면 읽을 수 있습니다. 바인딩을 생략하면 표준 몸 X/Y를 우선하고, 없으면 비공개 소스로 대체합니다. 빈 ID를 명시하면 소스를 만듭니다. 0이 아닌 기본값은 Cubism 블렌드 중립 VALUE 0을 유지하면서 F(0) 상수와 게이트된 잔차로 표현합니다. 적용되는 필드에는 현재 격자 기본 오프셋과 스칼라 참조가 포함되어, 네이티브 뺄셈 의미와 일치시키고 중립 드리프트를 막습니다.

메시의 내부는 `layer_mesh_structure`로 텍스처 구조를 따라 다시 만들 수 있습니다([명세](TEXTURE_STRUCTURE_MESH.md)). 윤곽 행과 가장자리 띠는 유지되고, 내부는 감지된 주름, 음영 경계, 무늬 선을 따르며, 내부 효과가 있는 메시는 같은 히스토리 노드에서 다시 베이크됩니다. 수동 메시 도구는 따로 구현되어 있습니다.

## 캔버스 핸들

오브젝트 모드의 **내부 조형 핸들** 도구(`ShortcutRegistry`의 `TOOL_INTERIOR`, 기본 Shift+I. 패널 도구 모음의 **캔버스에서 편집**으로도 열 수 있으며, 다른 모드에서는 둘 다 오브젝트 모드로 전환)는 선택한 메시의 활성화된 효과를 표시합니다. 오브젝트 모드는 메시 정점을 그리지 않으므로 핸들이 정점과 겹치지 않습니다. 편집 모드에서는 더 이상 이 도구를 제공하지 않습니다. 메시에 효과가 없거나 효과가 꺼져 있으면 옵션 바가 그렇다고 알리고 **내부 조형 켜기**를 제공합니다. 핸들과 가이드를 벗어난 곳을 누르면, 그 아래에 다른 오브젝트가 있을 때는 오브젝트 모드처럼 그 오브젝트를 선택하고(핸들은 그 효과로 옮겨 감), 현재 메시나 빈 캔버스에서는 주름 선을 시작합니다. 편집할 효과가 없으면 클릭은 그 아래의 오브젝트를 선택합니다.

- **가상 곡면**: 점선 상자는 원본 알파가 보이는 범위입니다(곡면의 범위이며 윤곽으로 정해짐. 별도의 중심이나 범위 설정은 없음). 중심 십자의 네 팔은 부풀기(위), 기울임(왼쪽), 가로 게인(오른쪽), 세로 게인(아래)입니다. 팔은 값에 비례해 길어지며 2에서 상자 가장자리에 닿고, 0에서는 핸들끼리 겹치지 않도록 짧은 줄기를 남깁니다. 상자를 가로질러 아치 두 개가 그려집니다. 실선은 기본 상태(높이는 부풀기를 따름), 점선은 최대 입력으로 기울였을 때의 기울기(기울임)입니다. 아치는 곡면을 보여 주는 그림일 뿐 변위 자체가 아닙니다.
- **방향**: 타이밍과 전달이 켜져 있으면 화살표가 전달 방향을 표시합니다. 한쪽 끝을 드래그하거나, 가운데를 드래그해 양 끝을 함께 옮깁니다. 좌표는 메시의 원본 픽셀 경계로 정규화되며, 끝점 사이가 0.05보다 가까우면 거부됩니다.
- **가이드**: 주름은 따뜻한 색으로 그려지며 반경만큼 반투명한 띠가 붙습니다. 감지된 SHADE / PATTERN 선은 종류별 색으로 그려지고, 주름으로 표시하기 전까지는 흐리게 보입니다. 메시나 빈 캔버스를 클릭해 주름 선을 시작하고, 클릭해 점을 추가하며, 마지막 점을 클릭하거나 Enter로 끝내고, Delete로 점 하나를 취소하고, Esc로 취소합니다. 점을 드래그하면 그 점이 움직이고(감지된 선은 선택해야 점이 표시되고 조작할 수 있음), 선분을 드래그하면 선 전체가 움직입니다. 선분을 Ctrl+클릭하면 점을 삽입하고, Alt+클릭하면 점을 제거하며, Delete는 선택한 점을 제거합니다(점을 고르지 않았으면 선 전체). 선택한 주름에는 반경 핸들이 있습니다. 옵션 바에서 선택한 선을 주름으로 표시하거나 해제하고, 삭제할 수 있습니다.
- **피드백**: 마우스를 올린 핸들, 점, 선이 강조되고 상태 표시줄에 핸들의 이름과 값이 표시됩니다. 잡고 있는 핸들은 선택된 상태로 그려집니다. 점과 선은 `MeshLook`을 사용합니다.

핸들 기하, 요청 변환, 가이드 편집은 `core/interior/InteriorHandles.kt`의 순수 함수입니다(`InteriorHandles`, `InteriorGuideEdits`, `InteriorPolylines`). 가이드와 핸들은 원본 픽셀 좌표에 머무르며, `InteriorCanvasMap`이 메시의 UV 샘플링 원본 위치에 대한 무게중심 좌표로 이를 매핑하므로, 그려진 메시를 따라가고 화면 위치는 원본 픽셀로 되돌려 매핑됩니다.

드래그는 패널이 공유하는 `InteriorDraft`를 편집하므로, 패널 값은 핸들을 따라가고 패널에서 편집하면 핸들이 움직입니다. 효과를 시험 재생하는 동안 `InteriorController.previewLater`는 분리된 후보에 같은 `interior_put`을 적용해 초안을 미리 봅니다(중립에서는 효과가 정점을 움직이지 않으며 핸들과 아치만 갱신됩니다). 드래그하는 동안에는 아무것도 기록되지 않습니다. 놓으면 `NativeInteriorAuthoring.request`가 만든 완전한 `interior_put` 하나를 커밋합니다(패널도 이를 통해 커밋합니다). `interior_put` 하나가 히스토리 노드 하나이므로, 드래그 한 번은 한 단계로 기록됩니다. 이전 커밋이 반영되어도 드래그는 중단되지 않습니다. 드래그 중 Esc를 누르면 초안이 복원되고, 커밋되지 않은 시험 재생 미리보기가 철회됩니다. 값이 저장된 레시피와 같은 초안은(이전 커밋이 반영된 뒤 포함) 다시 깨끗한 상태가 되므로, 실행 취소와 MCP 편집이 계속 초안에 반영됩니다. 선 끝내기, 점 제거, 주름 표시는 각각 한 번씩 커밋합니다. 문서 필드는 추가되지 않으며, 재생, 저장/다시 열기, MCP는 기존 레시피를 사용합니다.

## 선택적 타이밍

`InteriorMotionGenerator`는 정적 필드를 매끄러운 두 영역으로 나눕니다. 따라오는 영역의 가중치는 방향성 smoothstep에 강도를 곱한 값이고, 첫 영역은 그 보수를 사용합니다. 각 축은 연쇄된 네이티브 ANGLE 그룹(전체 최대 4개)을 사용하며, 출력마다 소유자는 하나입니다. 정지 상태에서는 두 영역이 같은 정적 형태를 재구성합니다.

기존 PhysicsEngine, PhysicsCatalog, 프로젝트 물리 FPS를 재사용하며, 내보내기는 표준 physics3를 사용합니다. 재생 중에는 이미지 분석, 곡면 평가기, 샘플러를 실행하지 않습니다. 마우스 매핑은 `clamp(input,-1,1)*gain`이며, 명시적인 포즈는 이를 거치지 않습니다. 추가로 600프레임 급반전 면적 검사가 안전하지 않은 구성을 거부하며, 진폭을 조용히 줄이지 않습니다.

메인테이너는 PR #45 리뷰에서 선택적인 완화와 전달을 유지하는 것을 승인했습니다.

## 저장, 재생, 소유권

`rigEdits.interiorEffects`는 스키마 1의 설정, 가이드, 소스/생성 파라미터, 소유한 출력, 네이티브 블렌드 필드, 물리 그룹, 메시 스탬프, 소스 해시를 저장합니다. Float32 필드는 gzip/base64를 사용하며, 레시피 식별에는 안정적인 내용 다이제스트를 사용합니다. 새로 추가된 빈 선택 필드는 이전 문서 리비전을 그대로 보존합니다.

각 `interiorEffect:<id>` 그래프 노드는 생성한 파라미터와 대상 메시 축을 소유하며, 기존 소스는 읽기만 합니다. 추가/제거, 토글, 레시피 변경은 하위의 재정의, 물리, 모션을 무효화합니다. 생성은 작성 저널을 따르며, 수동 편집은 기존 GeneratedOverrides 경로를 유지합니다.

메시, 원본 내용, 입력 범위가 맞지 않으면 레시피는 유지하되 오래된 정점 데이터는 건너뛰고 다시 생성하거나 다시 바인딩하도록 요청합니다. 끄면 편집기에는 정의가 남지만 형태 적용과 활성 그룹은 제거됩니다. 모든 내보내기는 IR 정리를 공유합니다. 소유한 비활성 파라미터는 기하, 다른 물리, 모션, 링크가 참조하지 않을 때만 생략됩니다. 유효하지 않은 효과는 그 물리를 명시적으로 건너뛰고, 생략 사실을 모델 경고나 대상 손실 보고서에 보고합니다. 생성기 캐시 읽기는 소스와 아틀라스를 포함하며, 새 레시피는 처음에 없던 해시도 기록합니다. 공개되지 않은 RigInteriorEdit/interiorSurfaces 실험은 제거되었으며, 이전 경로는 없습니다.

UI와 MCP는 `interior_put`과 `interior_delete`를 공유합니다. `workspace_inspect scope=interiors`는 형태 버퍼 없이 설정, 가이드, 파라미터 ID, 문제 상태를 반환합니다. 중첩된 스키마가 단위와 범위를 설명하며, settings/motion은 부분 업데이트를 받아들입니다. `InteriorController`가 초안, 시험 물리, 보기 분리를 소유하며, 메인 ViewModel은 이를 위임합니다. 대상은 메시 ID나 `mesh:<ID>`이고, 선택 필드는 enabled/settings/motion/parameters/guides이며 네이티브 트랜잭션 상태 검사가 있습니다. target/enabled만 있고 컨텍스트 필드가 붙은 요청은 가벼운 토글입니다. 초안 버전과 프로젝트 주소 검사가 늦게 도착한 비동기 결과를 거부합니다. 임시 시험 재생은 저장되지도 내보내지지도 않습니다.

```bash
./gradlew test
```

커버리지에는 합성 알파/구멍/가장자리, 독립적인 수치 곡면 픽스처, 네이티브 메시/MOC3 궤적, 0이 아닌 비대칭 소스, 토글, 실제 아카이브/히스토리 왕복, 무효화가 포함됩니다. 공개 픽스처는 합성 데이터이며, 참조 동영상, 그림, 비공개 모델은 제외됩니다.

로컬 검사에는 네이티브 GUI/MCP, 저장/다시 열기, 내보내기 생성, CPU/MOC3 궤적 비교가 포함됩니다. 공식 SDK에서의 완전한 애니메이션 시각 검토, 더 넓은 소재 커버리지, 모든 편집 조합은 아직 남아 있습니다. 사람의 피드백과 유한한 수치 검사는 별개의 근거입니다. 극단적인 설정은 면적 검사로 거부될 수 있으며, 통과시키기 위해 메시나 텍스처 품질을 낮추지 않습니다.

### 유지된 파라미터의 패널 재생

삭제할 때는 생성기만 실행하는 것이 아니라, 제거된 효과를 끈 완성 모델에서 지연된 패널 편집을 포함해 참조를 확인합니다. 유지된 비공개 정의는 작성된 파라미터가 됩니다. 그 구조 기록의 내부 `panel_after_generation` ID 목록은 짝짓기와 이동의 원래 단계/순서를 보존합니다. 이후의 연결 해제, 체크포인트, 아카이브 다시 열기도 같은 순서를 따릅니다. 파라미터를 명시적으로 삭제하면 단계 힌트가 끝나므로, ID를 다시 만들어도 예전 짝짓기가 되살아나지 않습니다. 이 메타데이터가 없는 문서는 기존 재생 동작을 유지합니다.

비동기 초안 정리는 요청을 보낸 프로젝트/작업 공간/대상 키를 사용하며, 초안 식별자와 버전을 모두 확인합니다. 늦게 도착한 응답은 새 범위나 더 새로운 초안을 지울 수 없습니다. 마우스 시험 재생과 그 십자선은 프로젝트 세대/작업 공간/활성 캔버스/편집 모드 라우팅을 공유하므로, 비활성 창에 마우스를 올려도 활성 창을 구동할 수 없습니다.
