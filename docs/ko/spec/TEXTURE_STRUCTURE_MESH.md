# 텍스처 구조에 따른 정점 재배치

[문서 목록](../../README.md) · [내부 조형](INTERIOR_SURFACE.md) · [메시 토폴로지와 분할](MESH_TOPOLOGY_AND_SPLIT.md)

## 범위

`layer_mesh_structure`는 기존 메시의 외곽 정점 행과 가장자리 띠를 유지하고, 텍스처에 그려진 구조에 따라 내부를 다시 만듭니다. 주름, 명암 경계, 무늬 선이 정점 행이 되고 변은 그 선을 따라갑니다. 기본적으로 가장자리 행과 이 선 이외에는 정점을 두지 않으며, 수동 정점 배치와 마찬가지로 선과 선, 선과 가장자리 사이에 삼각형을 펼칩니다. `fill`은 선 사이에 밀도가 점진적으로 변하는 채움점을 추가하고, `bands`는 그려진 주름 선 양쪽에 행을 하나씩 추가해 가로대를 연결하므로 메시가 선을 따라 접힐 수 있습니다. 일반 메시와 내부 조형은 이 명령을 공유합니다. 픽셀은 읽기만 하고 수정하지 않습니다. 인식 결과는 토폴로지만 결정하며, 조형에 참여할지는 작성자가 선을 주름(`FOLD`)으로 지정하여 결정합니다.

코드: `core/mesh/structure/TextureStructure.kt`(인식), `StructureMesher.kt`(외곽 유지와 토폴로지), `core/mesh/ConstrainedTriangulator.kt`(제약 삼각분할), `application/WorkspaceStructureMeshEdits.kt`(명령과 미리보기).

## 인식

레이어의 원본 래스터에서 수행하며, 가장 긴 변이 1024를 넘으면 정수 배율의 박스 다운샘플링을 적용합니다. 전체 과정은 난수 없는 결정적 처리이며 각 단계에서 취소를 확인합니다.

1. **채널**: 픽셀을 선형 RGB로 변환한 뒤 OKLab으로 변환합니다. alpha ≥ 0.5이면 재질 영역입니다. 재질 밖 픽셀은 재질 안의 정규화된 가우시안 합성곱으로 채워 윤곽을 명암 단차로 오인하지 않게 합니다. 재구성 영역(유지한 외곽의 안쪽 고리)이 주어지면 영역 안에서만 응답을 취합니다.
2. **세 가지 응답**(어두운 선과 단차는 작업 픽셀 기준 σ = 1, 2, 4, 8 스케일을 사용하며 가장 넓은 단계는 부드러운 명암으로 그린 주름에 대응합니다. 색 경계는 σ = 1, 2를 사용하고 단위는 모두 OKLab 밝기 단차로 환산합니다):
   - **어두운 선**: Hessian의 큰 고유값에서 작은 고유값의 절댓값을 빼고 다시 기울기의 1.2배를 뺍니다. 명암 단차 양쪽의 골 형태 측엽은 상쇄되며, 선 중심에서는 기울기가 0이므로 영향받지 않습니다. 가장 강한 스케일을 선폭 추정값으로 사용합니다.
   - **명암 단차**: 가우시안 기울기 크기에서 주변 어두운 선 응답의 1.2배를 빼 선 양쪽의 기울기 측엽을 없앱니다.
   - **색 경계**: OKLab a/b의 Di Zenzo 다채널 기울기입니다. 단차와 함께 색도 바뀌면 색 경계로 분류합니다.
3. **게이팅**: 구조 텐서 일관성(ρ = 3)이 0.12보다 작으면 0으로 만들고 0.45 이상이면 모두 통과시켜 잡음, 망점, 입자를 제거합니다. 응답은 국소 밝기 표준편차(σ = 12)에 따라 다시 0.6–2.5배 조정합니다. 어두운 천의 옅은 주름과 밝은 천의 진한 선을 동등하게 처리하고 입자를 무한히 증폭하지 않습니다. 각 스케일은 재질 가장자리에서 2σ+1보다 멀리 떨어진 픽셀에서만 응답을 취합니다.
4. **세선화와 연결**: 법선 방향으로 비최대 억제를 수행하고 이중 임계값 히스테리시스(상위 임계값은 민감도에 따라 0.22–0.05, 하위 임계값은 그 절반)를 적용한 뒤 Zhang–Suen 세선화와 m 인접성 추적으로 체인을 만듭니다. 교차점에서는 방향이 마주 보는 두 구간(각도 차이 35° 이내)을 하나의 통과 선으로 연결하고 남는 분기는 T자 접속으로 처리합니다. 자유 끝점 사이의 틈은 접선 방향 30° 원뿔 안에 있고 거리가 선폭의 4배 이하이면 비용 기준 탐욕 방식으로 연결합니다.
5. **분류**:
   - 색 경계는 `PATTERN`, 명암 단차는 `SHADE`입니다.
   - 어두운 선은 주름이라는 근거가 있어야 `FOLD`가 됩니다. 끝이 옅고 가늘어지거나(끝쪽 15%의 선 깊이가 중간 부분의 55% 미만), 한쪽이 일관되게 어두워야 합니다(점의 ≥75%가 같은 부호이며 평균 차이가 0.04 초과). 다음은 주름으로 판정하지 않습니다. 양쪽 색 차이가 서로 다른 재질처럼 큰 경우(밝기 차 중앙값 > 0.2 또는 색상 차 중앙값 > 0.05. 봉제선과 파츠 경계에 해당), 총 회전각 > 120°(천 위 무늬의 외곽), 윤곽과 등거리로 평행한 경우(테두리 장식), 닫힌 선, 길이가 비슷하고 등간격이며 가늘어지지 않는 거의 평행한 선이 세 개 이상인 경우(프린트). 이들은 모두 `PATTERN`입니다.
   - **그림자 쐐기**: 명암 경계가 회전각 100° 초과 지점에서 끊기거나 두 경계의 끝점이 매우 가까우면서 끝점에서 나가는 방향의 사이각이 40°보다 작으면, 하나의 주름 그림자 양쪽 변으로 봅니다. 꼭짓점에서 같은 거리의 점 쌍을 잡아 그 중점으로 쐐기 축을 만듭니다. 쐐기가 계속 벌어지고 양쪽이 방향을 바꾸지 않으며(초기 방향에서 벗어남이 35° 이하), 쐐기 안 밝기가 양쪽 모두와 다를 때 축선을 `FOLD`로 사용합니다(띠는 추가하지 않음). 축선이 덮는 꼭짓점의 짧은 선은 버립니다.
   - 강도는 평균 응답에 길이 계수를 곱한 값입니다. 강도순 상위 `max_lines`개만 유지하고 `min_length`보다 짧은 선은 버립니다.

## 외곽 유지

원본 픽셀 좌표에서 기존 메시 토폴로지로 계산합니다. 경계 변은 삼각형 하나에만 속하며, 경계 정점에서 그래프 거리 BFS를 수행합니다. 유지할 행 수는 레이어 메시 설정의 가장자리 모드에서 가져옵니다(SINGLE 0, DOUBLE 1, TRIPLE 2). 세 정점이 모두 유지 행 안에 있는 삼각형은 그대로 두고, 나머지는 공유 변으로 연결 영역을 나눕니다. 각 영역의 경계 정점은 유지 정점으로 이루어지며, 면적이 가장 큰 고리를 외곽 고리, 나머지를 구멍으로 봅니다. 핀치점(정점 하나에서 여러 변이 나가는 지점)이 있는 영역은 재구성을 포기하고 그대로 유지합니다. 영역의 간격은 내부 변(양 끝점 모두 고리 위에 있지 않은 변) 길이의 중앙값입니다.

## 토폴로지

선 위 간격은 유지한 가장자리 행의 점 간격에 `near_density`(기본 1)를 곱한 값이고, 채우기의 먼 곳 변 길이는 해당 영역의 기존 내부 변 길이에 `far_density`를 곱한 값입니다. 영역별로 독립적으로 구성하고 주름 띠 포함(`bands`만) → 단일 행만 배치 → 선을 배치하지 않음 순서로 단순화하며 처음 삼각분할에 성공한 결과를 사용합니다.

- **선 배치**: 강한 선부터 처리합니다. 각 선은 영역 안에서 근거리 간격의 1/4로 촘촘히 샘플링합니다. 영역 경계까지 거리가 근거리 간격 0.7배 + 띠 폭보다 커야 하고, 이미 배치한 선과의 거리는 근거리 간격 0.75배 + 띠 폭보다 커야 합니다. 조건을 만족하지 않는 곳에서 끊습니다. 약한 선은 강한 선 앞에서 멈추고 교차하지 않으며, 교차점의 빈틈은 채우기로 메웁니다. 남는 구간은 근거리 간격으로 재샘플링해 정거점으로 만듭니다.
- **주름 띠**: `FOLD`이고 그 자체가 필획인 선(`banded`)은 내부 정거점 양쪽에 행을 하나씩 둡니다. 오프셋은 선폭의 1.5배이며 근거리 간격의 0.35–0.8배로 제한합니다. 첫·마지막 정거점에는 옆점을 추가하지 않아 양 끝이 뾰족해집니다. 제약 변은 중심선, 양쪽 행, 각 정거점의 가로대, 각 칸의 같은 방향 대각선입니다. 따라서 각 칸의 두 삼각형이 정해지고 주름을 가로지르는 변은 선에 수직입니다. 옆점이 영역 밖이거나 다른 선에 너무 가까우면 해당 선에는 단일 행만 둡니다.
- **채우기**(`fill`만): 목표 변 길이는 선까지 거리에 따라 근거리와 원거리 사이에서 부드럽게 변합니다(전환 길이는 원거리 간격의 2.5배). 후보점은 근거리 간격 절반의 격자에 해시 지터를 더해 만들고, 선까지 거리와 해시로 정렬합니다. 이미 선택한 점, 선, 고리 모두와 충분히 떨어져 있을 때만 유지합니다.
- **삼각분할**: 먼저 Bowyer–Watson 증분 구성을 수행합니다. 삽입점에서 공동 경계 변이 보이지 않으면(일직선인 경계점) 반대편 삼각형을 공동에 합칩니다. 이어 Sloan 변 뒤집기로 모든 고리 변과 제약 변을 복원하고, 영역 밖 삼각형을 지운 뒤 비제약 변에 Lawson 합법화를 수행합니다. 채우기를 사용하면 마지막에 목표 변 길이 1.5배보다 긴 자유 내부 변을 중점 세분화합니다. 채우기가 없으면 점을 전혀 추가하지 않습니다.
- **결합과 검증**: 유지 삼각형과 새 삼각형은 고리의 기존 정점을 공유합니다. 기존 정점을 먼저 배치하며 순서도 기존 순서를 따릅니다. 이어 퇴화 삼각형 없음, 변당 최대 두 삼각형, 기존 메시와 같은 Euler 특성수, 기존 메시 다수 삼각형과 같은 감김 방향, 정점 수 `max_vertices` 이하를 검증합니다. 어느 단계든 실패하면 오류를 내고 커밋하지 않습니다.

새 정점의 메시 로컬 좌표와 UV는 해당 점이 속한 기존 삼각형에서 얻습니다(원본 픽셀 좌표의 무게중심 좌표). 각 삼각형 안에서 매핑은 아핀 변환이므로 재구성 전후 화면은 움직이지 않습니다.

## 명령과 영속화

- `layer_mesh_structure`: 새 메시를 계산한 다음 `RasterMeshJournal.encode`로 `canvas_mesh_rebuild` 저널 하나를 기록합니다. 키폼, 블렌드 셰이프, 경로, 정점 그룹과 Glue는 일반 재구성과 같은 방식으로 이전합니다. 재실행 때는 픽셀을 다시 분석하지 않으며 결과는 저널에만 의존합니다.
- 대상 메시에 내부 조형이 있으면 명령이 레시피에서 검출된 `TOPOLOGY` 가이드를 새 인식 선으로 교체합니다. 직접 그린 가이드와 이미 `FOLD`로 표시한 검출 선은 유지하고 가장 강한 선으로 정점 배치를 유도하며, 이들과 겹치는 새 선은 추가하지 않습니다. 공유하는 순수 후보 편집은 메시 교체를 먼저 재실행하고 새 메시에서 레시피를 다시 베이크합니다. 단일 MCP, UI, `workspace_apply_edits`의 일괄 멤버는 같은 로직을 실행하고 히스토리 노드 하나만 기록하며, 어느 단계든 실패하면 후보를 게시하지 않습니다.
- 가이드에 선택 필드 `detected`(`FOLD` / `SHADE` / `PATTERN`)를 추가했습니다. 검출 선에만 기록하며 기존 프로젝트의 리비전 번호는 바꾸지 않습니다.
- `layer_mesh_structure_preview`는 캡처 버전으로 같은 결과를 계산하되 아무것도 쓰지 않습니다. 인식 선(원본 픽셀·캔버스 좌표, 형식, 메시 채택 여부, 띠 여부)과 새 메시의 캔버스 점·삼각형을 반환하여 UI 오버레이와 MCP 검사에 사용합니다.

## UI

메시 패널과 내부 조형 패널의 “내부 메시” 절은 `StructureMeshControls`를 공유합니다. 민감도, 선 위 간격, “선 사이 채우기”(켜면 채우기 간격 표시), “주름 띠” 토글, 따라갈 선 형식, “선 표시”, “정점 재배치”가 있습니다. 선을 표시하면 캔버스는 `StructureLook`의 고정 색조로 미리보기를 그립니다. 주름은 따뜻한 색(띠가 있으면 더 굵게), 그림자는 차가운 색, 무늬는 연보라색, 채택하지 않은 선은 옅게 표시합니다. 새 메시는 옅은 와이어프레임으로 표시하며 미리보기는 히스토리에 들어가지 않습니다. 내부 조형 패널의 “내부 메시” 절은 검출 선을 나열하며 선마다 주름으로 지정하고 강도를 조정할 수 있습니다. “국소 주름” 절에는 직접 그린 가이드만 나열합니다.

## 검증과 제한

```bash
./gradlew test --tests "*ConstrainedTriangulatorTest" --tests "*TextureStructureTest" --tests "*StructureMesherTest" --tests "*StructureMeshCommandTest"
PSD2LIVE_TOOLS=1 ./gradlew test --tests "*StructureMeshTool"
```

단위 테스트는 합성 이미지만 사용합니다. 끝이 가늘어지는 주름 필획, 재질을 가로지르는 명암 단차, 색 띠와 등간격 프린트, 입자와 망점, 그림자 쐐기, 윤곽만 있는 레이어를 검사합니다. 토폴로지 테스트는 유지 영역의 점별 불변성, 필획 위 중심선, 모든 정거점의 가로대, 다양체, 결정성, 정점 상한을 확인합니다. 명령 테스트는 저널 하나와 재실행 결과의 일치, 새 메시에서 내부 조형 재베이크, 손으로 그린 주름 유지, 검출 선 기록을 확인합니다. `StructureMeshTool`은 예제 PSD의 의상·머리카락 레이어에서 기존·새 메시와 인식 선을 나란히 그려 육안 검사에 사용합니다.

분류는 일반적인 그림 관례(주름 필획은 가늘어지거나 한쪽 그림자가 있고, 봉제선과 파츠 경계는 양쪽 색이 다름)에 기반하므로 그림체가 크게 다른 소재는 오판할 수 있습니다. 선 형식 토글과 민감도로 조정하거나 내부 조형에서 직접 표시할 수 있습니다. 윤곽 가까이의 선은 가장자리 띠를 남기기 위해 채택하지 않습니다. 선 사이에 교차점 정점은 만들지 않으며, 약한 선은 교차점에서 끊깁니다.
