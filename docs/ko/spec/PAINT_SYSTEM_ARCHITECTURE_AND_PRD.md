# 페인트 시스템

[문서 목록](../../README.md) · [캔버스 편집](../guide/CANVAS_EDITOR.md) · [런타임과 내보내기 경계](RUNTIME_EXPORT_ARCHITECTURE_AND_GAPS.md)

이 문서는 페인트 모드의 사용자 흐름, 구성 요소의 역할, 좌표와 커밋 방식, 확장 시 검증할 시나리오를 설명합니다.

## 사용자 흐름

레이어 선택 → 페인트 모드 → (선택 사항) 선택 영역 만들기 → 브러시 / 연필 / 지우개 / 흐림 / 채우기 / 그라디언트 / 스포이트 / 도형 → 세션 안에서 실행 취소·다시 실행 → 적용 또는 폐기 → 모델 검사 후 프로젝트 저장.

픽셀은 레이어 자체의 래스터에 그립니다(`PaintSpace`, [레이어별 크기](DOCUMENT_LAYER.md#레이어별-크기) 참고). 기존 메시 경계에 제한되지 않고 같은 밀도로 캔버스 가장자리까지 확장합니다. 메시 유지(기본값)로 커밋하면 메시 기준으로 잘라냅니다(`WorkspacePaintOverflow`). 메시 위 픽셀은 레이어에 남고, 메시 밖에 새로 그린 픽셀은 바로 위의 새 레이어로 분리합니다. 새 레이어는 자체 메시를 가지며 같은 부모와 파츠에 연결하고, 소재로도 소재 라이브러리에 추가하여 연결합니다. 메시 밖 지우기는 적용하지 않습니다. 아직 메시가 없거나 메시 재구성을 요청하면 전체 픽셀에 맞춰 레이어를 확장합니다.

## 구성 요소의 역할

| 구성 요소 | 역할 |
| --- | --- |
| `core/RasterPaintEngine` | 브러시, 지우개, 채우기, 도형 등 래스터 작업. `ui/LayerPaintEngine`은 Compose 색과 도형 열거형만 변환 |
| `core/PaintRasterSession` | 초안 래스터와 독립 필획 히스토리. `PaintPixelPatch`가 영향을 받은 64×64 픽셀 타일을 기록하고 복원·교환하여 실행 취소 / 다시 실행하며, 선택 영역과 투명도 보호에 따라 제스처를 제한(`confine`) |
| `core/PaintSelection` | 선택 영역 마스크(래스터 픽셀당 1바이트 피복도): 사각형, 타원, 다각형(올가미), 마술봉. 새로 만들기 / 추가 / 빼기 / 교차, 반전, 페더와 점선 윤곽 |
| `core/PaintStrokeAssist` | 손떨림 보정(`PaintStabilizer`)과 대칭 미러링(`PaintSymmetry`). 포인터 위치만 처리하고 픽셀은 건드리지 않음 |
| `core/PaintSpace` | 초안 픽셀과 캔버스 단위의 아핀 매핑, 자르기, 커밋 픽셀(`PaintPixels`) |
| `application/WorkspacePaintSessions` | 프로세스 내부의 비공개 세션(`WorkspacePaintSession`). 시작 `state`를 캡처하고 GUI와 MCP가 공유하는 제스처, 실행 취소, 이동, 색 추출, 커밋 제공 |
| `ui/PaintSession` | `WorkspacePaintSession` 핸들 하나를 감싸 초안과 변경 영역을 Compose 및 GPU 미리보기에 투영 |
| `core/RasterPaintCommit` | 커밋 시 소스 이미지, 아틀라스, 메시 준비. `WorkspaceRasterCommands`를 통해 문서 후보, 재구성, CAS로 진입 |
| `ui/CanvasEditor` | 세션 시작, 도구 상호작용, 커밋 진입점 |

세션의 모든 픽셀 변경은 `edit` / `willWrite` 같은 기록 진입점을 거쳐야 합니다. 이를 우회하면 실행 취소와 증분 미리보기가 망가집니다. 필획 하나의 피복도는 지나간 영역의 최댓값에 불투명도를 곱하므로 같은 필획이 반복해서 지나가도 계속 짙어지지 않습니다. 지우개는 피복도로 Alpha를 제거합니다.

## 선택 영역, 투명도 보호와 필획 보조

- **선택 영역은 세션에 속하며 필획 히스토리에 속하지 않습니다.** `WorkspacePaintSession.select`는 선택 영역을 바꾸고 세션 버전을 진행시키지만 필획 기록은 추가하지 않습니다. 실행 취소 / 다시 실행은 픽셀만 바꾸고 선택 영역은 유지합니다(선택을 히스토리에 기록하는 Photoshop과 달리, 한 획 취소 시 선택까지 바뀌지 않게 함). 적용, 폐기, 레이어 전환으로 세션이 끝나면 선택도 지웁니다. 빈 선택은 선택이 없는 것과 같습니다.
- **모든 픽셀 편집에 선택 영역을 적용합니다.** 실시간 필획은 `Stroke.land` / `landBlur`에서 피복도에 선택 값을 곱합니다. 채우기, 도형, 그라디언트, 지우기 같은 전체 제스처는 먼저 정상 기록한 뒤 `PaintPixelPatch.confine`이 캡처한 타일에서 선택 값에 따라 결과를 원래 픽셀에 보간합니다(미리 곱한 알파 혼합이므로 투명한 곳으로 색이 새지 않음). 따라서 선택 안 결과는 선택이 없을 때와 픽셀별로 같고, 선택 밖은 그대로이며, 부드러운 가장자리(안티앨리어싱, 페더)는 비율대로 혼합합니다.
- **투명도 보호**(`lock_alpha`): 필획은 기존 픽셀에만 색을 입히고 Alpha를 유지하며, 전체 제스처는 제한 단계에서 원래 Alpha를 복원합니다. UI에서는 투명도 보호 상태의 지우개를 배경색 페인트로 바꿉니다(Photoshop 동작). MCP는 호출자를 대신해 색을 바꾸지 않으며 `lock_alpha`가 있는 `eraser` / `clear`를 바로 거부합니다.
- **흐림 브러시**는 일반 필획처럼 피복도 최댓값으로 적용합니다. 각 구간은 필획 시작 픽셀(`PaintPixelPatch.original`, 합성곱 반경 밖까지 포함)을 읽고 미리 곱한 알파 박스 흐림을 수행한 뒤 피복도 × 강도로 혼합합니다. 따라서 같은 획을 반복해 문질러도 점점 더 흐려지지 않으며 구간 분할 방식도 결과에 영향을 주지 않습니다. 합성곱 반경은 브러시 끝 반경의 1/4(1–16픽셀)입니다.
- **손떨림 보정**은 화면 좌표에서 최근 `등급 + 1`개 포인터 위치를 평균하고 놓을 때 놓은 위치까지 보완합니다. **대칭**은 캔버스 중심을 축으로 캔버스 좌표에서 미러링한 뒤 레이어 자체 프레임으로 변환합니다. 미러 구간들은 같은 필획의 피복도를 공유하므로 겹치는 곳도 한 번만 그립니다. 둘 다 브러시, 연필, 지우개, 흐림에만 적용합니다.
- **Shift + 클릭**은 같은 세션에서 이전 필획 끝점부터 클릭 위치까지 직선을 그립니다.
- **전체 제스처의 범위.** 채우기, 그라디언트, 지우기는 선택 영역의 경계 상자만 처리합니다. 선택이 없으면 레이어 원래 영역과 이미 그린 영역의 합집합만 처리하며 캔버스 전체를 덮지 않습니다. 따라서 메시 유지 커밋에서도 캔버스 크기 레이어가 잘려 나오지 않습니다. UI에서 이 제스처와 선택 연산은 백그라운드 스레드에서 수행하며 실행 중에는 새 포인터 누르기, 실행 취소, 커밋을 일시 중단합니다.
- **올가미 점 수**: 세션은 4096점을 초과한 올가미를 거부합니다. UI는 보내기 전에 거리와 간격에 따라 4096점 이하로 줄입니다. 회전 또는 기울임이 있는 레이어의 사각형 / 타원 선택은 화면 상자를 네 꼭짓점 / 64점 다각형으로 변환하므로 드래그한 상자와 일치합니다.
- MCP: `paint_session_control`의 `select` 동작, `blur` / `fill` / `gradient` 제스처, 페인트 통의 `contiguous`, `lock_alpha`는 UI와 같은 세션·엔진을 사용합니다. 차이는 `lock_alpha`뿐입니다. UI의 지우개는 배경색 브러시로 바뀌고 MCP는 `eraser` / `clear`에서 이 파라미터를 거부합니다. `source_paint_*` 단발 제스처에는 선택 영역 개념이 없습니다.

MCP 진입점은 두 종류입니다. 여섯 가지 단발 `source_paint_*` 제스처는 각각 하나의 백그라운드 작업과 히스토리 노드입니다. `paint_session_begin / paint_session_list / paint_session_control / paint_session_commit`은 GUI와 같은 비공개 세션을 사용합니다. `control`은 제스처, 실행 취소 / 다시 실행 / 이동, 색 추출, PNG 렌더링을 수행하고 `commit`은 백그라운드 작업으로 한 번에 커밋합니다([MCP 인터페이스](../agent/MCP_AUTHORING.md#프로젝트와-내보내기-작업) 참고).

## 좌표와 커밋

포인터, 제스처 점, 반경, 선폭은 모두 캔버스 단위이며 `PaintSpace`로 초안 픽셀에 매핑합니다. 샘플링 도구는 이후 픽셀을 읽습니다. 미리보기는 영향 영역별로 게시하므로 매번 전체 캔버스를 복사할 필요가 없습니다.

적용 시 레이어 원래 영역과 필획이 기록한 영역만 읽고 불투명 픽셀에 맞춰 자릅니다. 래스터는 원래 밀도를 유지하며 캔버스 해상도로 축소하지 않고 아틀라스를 갱신합니다. 메시를 유지하면 캔버스 위치에 따라 텍스처 좌표를 다시 지정합니다. 재구성하면 새 메시를 실제 부모의 중립 변환으로 텍셀 위치에 돌려놓아, 페인트 후 경계 상자 변경 때문에 부모 아래 형상이 다시 스케일되지 않게 합니다. 완전히 지운 레이어는 빈 투명 래스터로 처리합니다.

적용에 성공하면 프로젝트 저장 / 히스토리 흐름으로 들어갑니다. 독립 페인트 실행 취소와 프로젝트 분기 실행 취소는 서로 다른 계층이므로 UI와 문서에서 현재 작업 대상을 분명히 해야 합니다.

## 검증할 시나리오

- 반투명 필획의 왕복·자기 교차와 지우개: 실시간 표시와 놓은 뒤 결과가 일치해야 합니다.
- 여러 번 실행 취소·다시 실행: 픽셀과 미리보기가 함께 복원되어야 합니다.
- 메시 유지 색 보정: 텍스처가 움직이지 않아야 합니다.
- 윤곽 확장 후 재구성: 부모 디포머와 기존 포즈 관계가 예상 밖으로 바뀌지 않아야 합니다.
- 고밀도 레이어: 레이어 래스터에 필획을 그리고 커밋 후에도 밀도가 같아야 합니다.
- 저장·다시 열기, 히스토리 복원, 내보내기: 원본 픽셀과 UV가 계속 대응해야 합니다.

- 선택 영역: 사각형 / 타원 / 올가미 / 다각형 / 마술봉을 각각 한 번 사용하고 추가·빼기·교차를 조합한 뒤, 브러시·채우기·그라디언트·지우기가 선택 안만 바꾸는지 확인합니다. 필획을 취소해도 선택은 같아야 합니다.
- 투명도 보호: 브러시와 그라디언트가 투명한 곳에 픽셀을 남기지 않고 기존 픽셀의 Alpha를 유지해야 합니다.
- 대칭과 손떨림 보정: 축 위에서 미러 필획이 겹쳐도 짙어지지 않고, 놓은 뒤 필획 끝점이 포인터와 같아야 합니다.

## 도구 비교와 차이

화가가 Photoshop과 PaintTool SAI에서 자주 사용하는 도구를 기준으로 합니다. “기존”은 이 절 작성 전에 갖춘 기능, “이번”은 이번 구현(위 설명과 [캔버스 편집](../guide/CANVAS_EDITOR.md#페인트-적용과-폐기) 참고), “후속”은 아직 구현하지 않고 [ROADMAP](../ROADMAP.md)에 기록한 방향입니다.

| 분류 | 비교 기능 | 상태 | 설명 |
| --- | --- | --- | --- |
| 브러시 | 크기 / 경도 / 불투명도, `[` `]` 크기 조절, Alt + 오른쪽 버튼 드래그 조정 | 기존 | 브러시·연필·지우개가 크기를 각각 기억하며 브러시 끝 원이 실제 필획 범위 |
| 브러시 | 한 획 안에서 누적하지 않음(같은 획이 반복해 지나가도 짙어지지 않음) | 기존 | 피복도 최댓값에 불투명도를 곱함 |
| 브러시 | 손떨림 보정(SAI 手ブレ補正 / PS 매끄럽게) | 이번 | 0–30등급, 놓을 때 끝점 보완 |
| 브러시 | Shift + 클릭 직선 | 이번 | 이전 필획 끝점에서 시작 |
| 브러시 | 필압으로 크기 / 불투명도 / 흐름 제어 | 후속 | 데스크톱 Compose / AWT가 태블릿 필압을 제공하지 않아 Windows Ink / WinTab 등 네이티브 입력 연동 필요 |
| 브러시 | 흐름, 간격, 에어브러시, 브러시 텍스처와 프리셋 | 후속 | 현재 필획은 도장 배열이 아닌 연속 피복 형상. 흐름 / 간격은 별도 누적 모델 필요 |
| 혼색 | 흐림 브러시 | 이번 | 강도는 불투명도 슬롯이며 `Alt+Shift+[` `]`로 조절 가능 |
| 혼색 | 문지르기 / 손가락, SAI 수채화·혼색 브러시 | 후속 | 필획을 따라 색을 운반해야 하므로 “한 획은 한 번만 적용” 모델과 충돌. 별도 설계 필요 |
| 지우개 | 부드러운·단단한 지우개, 투명도 보호 상태에서 배경색 그리기 | 기존 / 이번 | 후자가 이번 구현 |
| 선택 | 사각형, 타원, 올가미, 다각형 올가미, 마술봉(허용 오차, 연속) | 이번 | 같은 선택 도구의 다섯 변형이며 `1`–`5`로 전환 |
