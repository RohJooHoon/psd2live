# 메뉴와 계층 노드의 상호작용 규칙

이 페이지는 메뉴와 오브젝트 변환의 공통 상호작용을 설명합니다. 화면 전반의 색상, 크기와 애니메이션 요구 사항은 여전히 [CLAUDE.md](../../../CLAUDE.md)를 기준으로 합니다.

기존 컨텍스트 메뉴의 진입점, 내용 순서, 중복과 누락, 후속 정리 제안은 [컨텍스트 메뉴 현황](CONTEXT_MENU_AUDIT.md)을 참고하세요. 이 현황 문서는 소스 코드의 현재 상태와 미구현 계획을 구분하며 이 페이지의 상호작용 규칙을 대체하지 않습니다.

## 메뉴

- 캔버스와 계층 트리의 컨텍스트 메뉴는 `PressMenu`를 쓰고, 내용은 `GlidingColumn`, `FloatingMenuSection`, `FloatingMenuRow`를 사용합니다. ArtMesh, 참고 이미지와 디포머는 같은 너비, 행 높이, 강조와 스크롤 방식을 사용합니다.
- 그룹화된 메뉴에는 움직이는 강조 표시가 하나만 있습니다. 위험한 동작은 공유 행의 `danger` 표시로 나타냅니다. 열 컨테이너도 위험 행과 사용 가능 정보를 받아 텍스트, 아이콘과 호버 배경을 통일합니다. 비활성 행은 반응하지 않으며 강조도 유지하지 않습니다.
- 일반 동작은 메뉴를 닫고 실행한 뒤 포커스를 캔버스로 돌려줍니다. 대화 상자나 편집 창을 여는 동작은 `opensDialog`로 표시하며 실행 후 해당 창의 포커스를 유지합니다. `keepsMenu` 동작은 메뉴와 키보드 포커스를 유지합니다.
- 공간이 부족하면 1차와 2차 메뉴를 가용 방향으로 펼칩니다. 2차 메뉴를 표시하기 위해 1차 메뉴를 이동하면 안 됩니다.
- 오브젝트 메뉴는 이름 아래에 적용 범위를 설명합니다. 다중 선택이면 “이 항목에만 적용 · N개 선택됨”을 표시합니다. 내용을 바꾸는 동작은 실제 범위(현재 오브젝트, 전체 체인, 이 레이어)에 맞게 이름을 붙이며 모호하게 “삭제”라고만 쓰지 않습니다.
- 파라미터 이름을 왼쪽 클릭하면 속성을 열고, 오른쪽 클릭하면 파라미터 관리 메뉴(속성, 현재값 초기화, 잠금/잠금 해제, 파라미터 복사, 파라미터 ID 복사, 파라미터 삭제…)를 제공합니다. 삭제와 복사는 속성 대화 상자의 확인 절차를 재사용하며 메뉴에서 직접 실행하지 않습니다.
- 오른쪽 클릭의 우선순위는 컨트롤이 소비함 → 현재 제스처/마우스 바인딩 → 컨텍스트 메뉴로 통일합니다. 주 캔버스와 아틀라스가 같으며 메뉴를 열어도 선택이나 포즈를 바꾸지 않습니다.

## 계층 노드

레이어 내부 참고 이미지와 ArtMesh는 모두 `DrawableTreeItem`으로 렌더링하며 유형 아이콘과 전용 표지만 바꿉니다. 둘은 다음을 공유합니다.

- 클릭, Ctrl/Cmd 선택 전환, Shift 범위 선택, Alt 선택 해제
- 호버 피드백, 미리보기 위치 표시, 상위 노드 연결선, 드래그 앤 드롭 등록과 부모 노드 변경
- 레이어 ID로 선택하고 실제 리그 오브젝트 ID로 계층을 수정합니다. 둘을 혼동하면 안 됩니다.

전경과 배경 참고 이미지는 리그 부모가 없으므로 독립 참고 이미지 노드를 사용합니다. 모델 선택과는 여전히 상호 배타적입니다.

## 참고 이미지와 ArtMesh 변환

- 단일 항목 진입점은 오브젝트 이름 바로 아래 첫 행에 있으며, 대상 유형의 아이콘과 “참고 이미지로 변환 / ArtMesh로 변환” 문구를 사용합니다. 툴바, 캔버스와 계층 트리는 같은 변환 가능 정보를 읽습니다.
- 툴바는 일괄 변환의 대상과 개수를 표시합니다. 모두 참고 이미지이면 ArtMesh로, 그렇지 않으면 참고 이미지로 변환합니다. 변환 불가 항목이 하나라도 있으면 전체 작업을 비활성화해 선택 중 일부만 조용히 변경하지 않습니다.
- 레이어 위아래 이동과 유형 변환은 사용 가능 여부를 별도로 판단합니다. 생성된 사용자 생성 메시는 대기 레이어로서 위아래 이동할 수 없어도 변환할 수 있습니다.
- 유형 배지는 상태만 나타내고 숨겨진 변환을 실행하지 않습니다. 단축키 이름은 양방향 전환을, 버튼 문구는 이번 동작의 대상을 표현합니다.
- 변환 한 번은 히스토리 노드 하나만 커밋하며 원래 오브젝트의 선택을 유지합니다. 표시 유형이 바뀌어도 오브젝트 ID를 잃지 않습니다.

## 회귀 테스트 진입점

`ReferenceHierarchyInteractionTest`는 노드 선택, 호버, 드래그 앤 드롭과 히스토리/저장 복원을 다룹니다. `ReferenceConversionMenuTest`는 단일 및 일괄 변환, `MenuActionsTest`는 포커스 수명 주기, `MenuDangerStyleTest`는 위험 및 비활성 상태, `ContextMenuScopeTest`는 계층 삭제 범위와 소재 위치 행 선택을 다룹니다. `UiConsistencyTool`은 합성 콘텐츠로 밝은/어두운 테마와 UI/글꼴 배율별 스크린샷을 출력합니다.
