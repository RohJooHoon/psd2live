# 그림으로 보는 앞뒤 레이어 분리 튜토리얼

[문서 목록](../../README.md) · [中文](../../zh/guide/DEPTH_SPLIT.md) · [English](../../en/guide/DEPTH_SPLIT.md) · [사용자 빠른 참조](USER_GUIDE.md) · [캔버스 편집](CANVAS_EDITOR.md)

한 레이어의 여러 부분이 다른 부위의 앞과 뒤에 동시에 놓여야 할 때가 있습니다. **앞뒤 분리**는 레이어를 앞 레이어와 뒤 레이어로 빠르게 복제하고, 가림 순서를 설정하고, 두 레이어가 함께 변형되도록 글루로 붙입니다. 사용자는 새 앞 레이어에서 뒤로 가야 할 부분만 지우면 됩니다.

이 튜토리얼은 목을 둘러싼 옷깃을 예로 전체 과정을 안내한 다음, 머리카락과 어깨 장식에 쓰는 다른 예를 보여 줍니다. PSD나 이미지로 생성한 모델에서 동작하며, 가져온 CMO3 모델은 아직 지원하지 않습니다. 스크린숏은 중국어 UI입니다.

## 1. 앞뒤 가림이 필요한 곳 찾기

아래 그림에서는 옷깃의 뒷부분이 목을 가리고 있습니다. 옷깃 전체가 한 레이어에 있기 때문에 목의 앞으로 옮기든 뒤로 옮기든 가림의 일부가 어긋납니다.

![수정 전: 옷깃 뒷부분이 목 앞쪽을 가림](../../imgs/depth-split/collar-before.webp)

*수정 전: 목 뒤에 있어야 할 옷깃이 목 앞에 보입니다.*

옷깃의 뒷부분은 목 뒤에 숨기고, 앞쪽 옷깃 조각은 여전히 목의 아래쪽 가장자리를 가리게 하려고 합니다.

![목표: 목이 뒤쪽 옷깃과 앞쪽 옷깃 조각 사이에 놓임](../../imgs/depth-split/collar-target.webp)

*목표: 옷깃 사이로 목이 보이고 앞뒤 가림이 자연스럽습니다.*

가림 순서는 다음과 같습니다.

| 위치 | 부위 | 역할 |
| --- | --- | --- |
| 맨 앞 | 옷깃 레이어 · 앞 | 뒤쪽 옷깃을 지우고, 목 앞에 보여야 할 부분만 남김 |
| 가운데 | 목 | 뒤쪽 옷깃을 가리고, 앞쪽 옷깃 조각에 가려짐 |
| 맨 뒤 | 옷깃 레이어 · 뒤 | 원래 레이어 전체를 유지해 뒤쪽 내용을 제공함 |

스크린숏의 옷깃은 상의 전체인 `topwear` 레이어에 속하므로, 분리하는 대상은 상의 전체입니다. 옷깃을 먼저 잘라 낼 필요는 없습니다.

## 2. 상의와 목을 함께 선택하기

편집 캔버스에서 **오브젝트** 모드로 전환하고, 옷깃이 있는 상의 레이어를 선택한 다음 **Shift**를 누른 채 목을 추가합니다. 계층 트리에서 여러 개를 선택해도 됩니다.

![상의와 목을 함께 선택해 캔버스에 선택 상자 두 개가 보임](../../imgs/depth-split/select-layers.webp)

*두 선택 상자는 상의와 목입니다. 상의는 앞뒤 레이어로 나눌 오브젝트이고, 목은 그 사이에 들어갈 오브젝트입니다.*

사이에 들어갈 ArtMesh는 여러 개 추가할 수 있지만, 한 번에 분리되는 ArtMesh는 하나뿐입니다. 선택한 다른 오브젝트는 모두 앞뒤 레이어 사이로 들어가며, 각자의 그리기 순서를 유지합니다.

## 3. 상의를 오른쪽 클릭해 앞뒤 분리 실행하기

선택을 유지한 채 분리할 **상의**를 오른쪽 클릭하고 **“topwear”을(를) 앞뒤 레이어로 분리**를 고릅니다. 메뉴의 이름은 레이어 이름을 따르므로, 클릭하기 전에 복제할 오브젝트의 이름인지 확인하세요.

![빨간 테두리로 표시된 컨텍스트 메뉴 항목 "topwear"을(를) 앞뒤 레이어로 분리](../../imgs/depth-split/context-menu.webp)

*빨간 상자 안의 메뉴 항목은 앞뒤 레이어를 바로 만들고 앞 레이어에서 지우개를 시작합니다.*

만들어지면 원래 레이어는 새 레이어 두 개, "`topwear · 뒤`"와 "`topwear · 앞`"으로 바뀌며, 둘 다 원래 레이어의 픽셀을 모두 가지고 있습니다. 프로그램은 목을 기준으로 두 레이어의 그리기 순서를 배치하고, 메시와 변형 데이터를 복사하고, 앞뒤 레이어의 대응하는 정점을 글루로 붙여 앞 레이어가 뒤 레이어를 따라가게 합니다. 원래 레이어는 더 이상 레이어 목록에 나타나지 않습니다. 분리하기 전으로 돌아가려면 실행 취소를 사용하세요.

**상의만 선택한 경우:** 계층 트리에서 상의를 오른쪽 클릭하고 **앞뒤 분리…** 항목을 고른 뒤, 대화 상자의 **사이에 끼는 오브젝트**에서 목을 고르고, 앞 / 가운데 / 뒤 배치를 확인한 다음 **만들고 지우기**를 클릭합니다.

## 4. 앞 레이어에서 뒤쪽 옷깃 지우기

만들고 나면 프로그램이 새 앞 레이어를 선택하고 **페인트** 모드와 **지우개**로 전환합니다. 먼저 캔버스 위쪽에 "`topwear · 앞`"이 표시되는지 확인하세요.

옷깃을 확대하고, 목의 가장자리를 따라 앞 레이어에서 목 뒤로 가야 할 옷깃 부분을 지웁니다. 아래 그림의 화살표가 지울 곳을 표시합니다.

![topwear 앞 레이어에서 지우개 사용. 빨간 화살표가 지울 뒤쪽 옷깃을 가리킴](../../imgs/depth-split/erase-front.webp)

*지우는 것은 앞 레이어의 뒤쪽 옷깃입니다. 뒤 레이어는 이 픽셀을 가지고 있으므로, 지우고 나면 가운데의 목이 드러납니다.*

지우개 크기를 조정해 먼저 영역 안쪽을 지우고, 더 작은 브러시로 가장자리를 정리합니다. 앞쪽 옷깃 조각과 목 앞에 있어야 할 부분은 남겨 두세요. 상의 전체를 지울 필요도 없습니다.

너무 많이 지웠다면 페인트 세션의 **실행 취소**로 스트로크를 되돌립니다. 칠하는 동안 다른 부위가 어둡게 보이는 것은 편집 표시 효과일 뿐입니다.

## 5. 적용하고 여러 포즈 확인하기

다 지웠으면 캔버스 위쪽이나 도구 패널에서 **적용**을 클릭합니다. 앞뒤 분리로 만든 앞 레이어는 원래의 메시와 변형을 유지하므로, 적용할 때 메시를 다시 만들 필요가 없습니다.

![적용 후의 옷깃: 목이 보이고 앞쪽 옷깃 조각은 목 앞에 남아 있음](../../imgs/depth-split/collar-result.webp)

*완성된 가림: 뒤쪽 옷깃은 목 뒤에, 앞쪽 옷깃 조각은 목 앞에 있습니다.*

이어서 파라미터 패널에서 머리 회전, 위아래 보기, 몸 회전을 확인하며, 특히 옷깃과 목이 만나는 곳을 살펴보세요. 어떤 포즈에서 뒤쪽 옷깃이 여전히 목을 가리면, 앞 레이어 칠하기로 돌아가 지우개로 가장자리를 계속 정리하고 다시 적용합니다.

앞뒤 레이어는 함께 변형되지만, 어떤 픽셀을 지울지는 여전히 사용자가 정해야 합니다. 마지막으로 `.psd2live` 프로젝트를 저장해 분리, 텍스처 변경, 히스토리를 보존하세요.

## 6. 같은 방법으로 머리카락과 어깨 장식 처리하기

아래의 어깨 장식과 머리카락도 일부는 앞에, 일부는 뒤에 있어야 합니다. 먼저 분리할 장식이 있는 레이어와, 그 사이에 놓일 머리카락 레이어를 찾습니다.

![수정 전: 머리카락과 어깨 장식 사이의 가림을 조정해야 함](../../imgs/depth-split/shoulder-before.webp)

*먼저 장식의 어느 부분이 머리카락 앞에 보이고 어느 부분이 뒤에 숨어야 하는지 정합니다.*

장식 레이어와 관련된 머리카락을 함께 선택하고, **장식 레이어**를 오른쪽 클릭해 앞뒤 분리를 실행합니다. 그런 다음 새 앞 레이어에서 머리카락이 가려야 할 장식 부분을 지웁니다.

![어깨 장식의 앞 레이어에서 지우기](../../imgs/depth-split/shoulder-erase.webp)

*새 앞 레이어에서 뒤로 가야 할 부분만 다듬습니다. 뒤 레이어는 전체 내용을 유지합니다.*

적용한 뒤 머리카락과 장식이 만나는 곳을 확인하고, 관련 파라미터를 움직여 움직일 때의 가림을 살펴보세요.

![수정 후: 머리카락과 어깨 장식이 앞뒤로 엇갈림](../../imgs/depth-split/shoulder-result.webp)

*결과: 장식 레이어 하나가 앞쪽과 뒤쪽 내용을 모두 제공합니다.*

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 캔버스에 빠른 분리 메뉴가 없음 | 오브젝트 모드로 전환하고 분리할 메시와 사이에 들어갈 오브젝트를 하나 이상 함께 선택하세요. 또는 계층 트리의 **앞뒤 분리…** 항목으로 대화 상자를 여세요 |
| 메뉴에 다른 오브젝트 이름이 표시됨 | 복제할 오브젝트를 오른쪽 클릭하세요. 옷깃 예에서는 목이 아니라 상의여야 합니다 |
| 만든 뒤에도 달라 보이는 것이 없음 | 새 앞 레이어는 처음에 전체 복사본입니다. 가려져야 할 부분을 지우세요 |
| 페인트를 먼저 적용하거나 취소하라는 안내가 뜸 | 커밋되지 않은 현재 페인트 세션을 먼저 처리한 다음 앞뒤 레이어를 만드세요 |
| 정면에서는 괜찮지만 돌 때 여전히 튀어나옴 | 관련 파라미터의 여러 포즈를 확인하고, 앞 레이어로 돌아가 더 지우고 가장자리를 정리하세요 |
