# 캔버스 편집 참조

[문서 목록](../../README.md) · [中文](../../zh/guide/CANVAS_EDITOR.md) · [English](../../en/guide/CANVAS_EDITOR.md) · [사용자 빠른 참조](USER_GUIDE.md) · [앞뒤 레이어 분리 그림 튜토리얼](DEPTH_SPLIT.md) · [변형 패스](DEFORM_PATHS.md)

이 문서는 앱 내 입문자 코스의 3강과 6–12강에 해당합니다. 캔버스 편집 규칙을 주제별로 묶어 설명하며, 정확한 버튼 위치와 현재 단축키는 도움말 페이지의 **튜토리얼**을 기준으로 합니다.

## 먼저 모드를 고르고, 그다음 도구를 고르기

캔버스 왼쪽 위의 모드 메뉴(Blender의 모드 드롭다운과 같음)에 모든 모드가 나열됩니다. 메뉴가 열려 있는 동안 1–7로 바로 고르고, 화살표 키로 이동하며 Enter로 확정합니다. **미리보기**도 이 메뉴에 있으며 예전 제목 표시줄의 **미리보기**가 하던 일을 합니다. 미리보기 캔버스에서 다른 모드를 고르면 편집으로 돌아갑니다.

| 모드 | 바꾸는 대상 | 주요 도구 |
| --- | --- | --- |
| 오브젝트 | 오브젝트 선택 | 클릭, 박스 선택, 올가미 선택. 계층과 동기화. 내부 조형 핸들. 툴바의 **만들기** |
| 변형 | 기본 형태 또는 현재 파라미터의 키폼 | 정점 / 변 / 면 선택, 변환, 밀기, 스무딩, 팽창, 패스 제어점 |
| 편집 | 메시 토폴로지와 패스 바인딩 | 정점 / 변 / 면 선택, 정점 배치(점 / 선), 연결, 병합, 세분화, 변 삭제, 재삼각분할, 삭제, 글루(메시 2개를 선택했을 때) |
| 시뮬레이션 | 시뮬레이션이 읽는 정점 가중치 그룹(이 앱 전용) | 가중치 브러시, 가중치 그라데이션. 칠할 그룹(고정, 강성 등)은 그 아래에서 종류별로 전환. 모드 바에서 천 / 머리카락을 만들고 참조 시뮬레이션을 전환(내보내지 않음) |
| 스켈레톤 | 뼈대 | 포즈, 본 편집. 본 편집은 포즈로 전환하거나 모드를 떠날 때 저장 |
| 페인트 | 레이어 픽셀 | 브러시, 연필, 지우개, 흐림 효과, 채우기, 그레이디언트, 스포이트, 도형, 선택 영역 |
| 미리보기 | 없음 | 재생, 마우스 추적, 물리, 프레임 속도 |

시뮬레이션 모드는 편집 모드처럼 선택한 모든 메시에 한꺼번에 작용하며, 현재 가중치 그룹을 항상 Blender의 가중치 색(파랑 0 → 초록 → 노랑 → 빨강 1)으로 표시합니다. 가중치 브러시의 링은 모드에 따라 색이 다르고(더하기 흰색, 빼기 빨간색, 설정 강조색, 스무딩 청록색), 마우스를 올리면 누를 때 영향을 받을 정점을 표시하며, 포인터 옆의 숫자는 가장 가까운 정점의 가중치입니다. Alt + 오른쪽 드래그로 반경 / 경도를 조정하고 감쇠를 미리 봅니다. 가중치 그라데이션은 최대값인 곳에서 사라지는 곳까지 드래그합니다. 시뮬레이션 자체는 편집기 안에서만 실행되며, 내보내려면 시뮬레이션 패널에서 베이크해야 합니다. [시뮬레이션과 베이크](SIMULATION.md)를 참고하세요.

현재 도구의 설정은 여러 곳에 나뉘어 있으며 각자 역할이 있습니다.

| 위치 | 내용 |
| --- | --- |
| 왼쪽 툴바 | 현재 모드의 도구가 한 줄에 하나씩, 구분선으로 나뉜 범주별로 나열됩니다. 오브젝트 모드에서는 마지막 그룹이 Warp, Rotation, 변형 패스를 만듭니다. 선택한 도구의 변형(브러시 모양, 페인트 도형, 선택 종류, 글루와 스켈레톤 하위 도구, 가중치 그룹 종류)은 그 아래에 펼쳐지며 `1`–`5`로도 고를 수 있습니다 |
| 모드 바(캔버스 위쪽) | 모드 메뉴 다음에 캔버스의 동작 방식을 정하는 항목이 옵니다. 변형 / 편집 모드의 선택 도구용 정점 / 변 / 면(`1`–`3`), 그리고 현재 단계(배치, 나이프, 패스, 글루 등)의 확정과 취소입니다 |
| 도구 옵션 바(캔버스 왼쪽 아래) | 현재 도구의 값: 반경, 강도, 경도, 불투명도, 모드 등. 값을 좌우로 드래그해 조정하고, 클릭하면 슬라이더가 뜹니다. 페인트 모드에서는 전경색 / 배경색이 맨 앞에 옵니다 |
| 캔버스 컨텍스트 메뉴 | 모드 바, 옵션 바와 같은 설정(한 줄에 하나씩)에 도구의 동작이 더해지며 각각 아이콘이 붙습니다. 모드 메뉴와 같은 애니메이션으로 열리고 마우스를 올리면 강조됩니다. 오브젝트 모드에서는 Warp, Rotation, 변형 패스, 본, 흔들림 만들기가 **만들기** 하위 메뉴에 모여 있습니다. 오브젝트, 편집, 페인트 모드에서는 레이어 전체에 대한 동작에도 하위 메뉴가 있습니다. **메시**에는 현재 픽셀로 메시 재구성, 연결되지 않은 메시 나누기, 그리고 가능할 때 앞뒤 분리가 들어 있으며, 소재에 연결된 레이어에는 **소재**도 생겨 소재 창에서 열거나 연결을 해제합니다. 나머지가 10줄 안에 들어가면 모두 바로 표시하고, 그보다 많을 때만 가장 큰 그룹(토폴로지, 감쇠 등)을 한 줄로 접어 마우스를 올리면 오른쪽으로 펼칩니다. 패널(계층, 소재, 텍스처 아틀라스, 모션, 물리 등)의 컨텍스트 메뉴도 캔버스 메뉴와 같은 모양으로 열립니다. 누른 위치에서 펼쳐지고 창 가장자리 근처에서는 반대쪽으로 뒤집힙니다 |

모드 바, 옵션 바, 컨텍스트 메뉴는 같은 범위의 정의 하나를 공유해 표시합니다. `[` `]` 같은 브러시 단축키는 옵션 바에 표시된 현재 도구의 같은 값을 조정합니다. 오른쪽의 **도구 상세** 패널에는 공간이 더 필요한 고급 설정만 남아 있습니다. 정밀한 수치 변형, Warp / Rotation의 생성 기본값, 패스 목록, 본 바인딩과 가중치, 페인트 팔레트입니다. 스킨 가중치 표시는 오른쪽 아래 보기 레일에서 켜고 끕니다.

기본적으로 휠은 확대/축소, 가운데 버튼 또는 Space + 왼쪽 드래그는 이동이며, Shift는 선택에 추가하고 Alt는 선택에서 뺍니다.

고정 가중치 브러시와 베이크 과정의 스크린샷은 [시뮬레이션 그림 튜토리얼](SIMULATION_TUTORIAL.md)을 참고하세요.

## 캔버스의 점과 선

편집 가능한 점과 선은 모든 모드에서 같은 모양이며, 각 색에는 정해진 의미가 있습니다.

| 모양 | 의미 |
| --- | --- |
| 밝고 가는 선과 작은 점 | 편집 중인 메시 또는 Warp 격자. 여러 메시를 함께 편집할 때는 각각 고유한 색 |
| 강조색, 흰 테두리로 확대 | 선택한 정점, 변, 면 |
| 흰색 바깥 링 | 마우스를 올린 점, 즉 클릭하면 선택될 점 |
| 빨간 원 | 브러시를 누르면 밀릴 점. 클수록, 진할수록 강하게 영향을 받음. 마우스를 올리면 표시되고 드래그 중에도 유지 |
| 강조색 원 | 선택 브러시를 누르면 선택될 점 |
| 가중치 색(파랑 → 빨강) | 시뮬레이션과 스켈레톤 가중치 |

점의 모양은 그 점이 무엇인지를 나타냅니다. 메시 정점은 원, Warp 제어점은 사각형, 글루 점은 마름모입니다. 직접 클릭할 수 있는 점만 표시됩니다. 오른쪽 아래 보기 레일의 메시 토글은 각 파츠의 메시 선만(파츠마다 고유한 색으로) 그리며 더 이상 점은 그리지 않습니다. 편집 중인 메시나 Warp는 캔버스가 직접 그리므로 보기 레일이 한 번 더 그리지 않습니다.

## 변형과 키폼

파라미터가 바인딩되지 않은 오브젝트는 기본 형태를 편집하고, 바인딩된 오브젝트는 현재 파라미터 조합을 편집합니다. 대상이 메시 디포머(Warp)이면 모드 바에서 **정점**(격자점 편집)과 **베지어**를 전환합니다. 베지어에서는 청록색 앵커와 호박색 핸들만 드래그할 수 있고 세부 격자는 흐리게 표시되어 편집할 수 없습니다. 다른 오브젝트에서는 둘의 차이가 없어 표시하지 않습니다. 먼저 파라미터 패널에서 목표 값을 정한 다음 제어점을 조정합니다. 오브젝트 자체의 축과 부모로부터 물려받은 움직임을 확인해, 부모의 포즈를 현재 오브젝트의 직접 바인딩으로 착각하지 않도록 하세요.

변형 모드 캔버스 컨텍스트 메뉴의 **키폼 미러**는 현재 키의 키폼을 세로선을 기준으로 반사합니다. 결과는 일반 키폼으로 기록되며 취소할 수 있습니다.

| 동작 | 하는 일 |
| --- | --- |
| 대칭 키로 미러 | 현재 키를 반대쪽 키로 미러한 다음(AngleX 30 → −30), 포즈를 그쪽으로 옮겨 결과를 보여 줍니다. 단축키 `Shift+M` |
| 대칭 키에서 미러 | 반대 방향: 반대쪽 키의 형태가 현재 키를 대체합니다 |
| 반대쪽 오브젝트로 미러 | 반대쪽에 있는 같은 종류의 오브젝트에 기록합니다(왼쪽 눈 → 오른쪽 눈). 키도 미러됩니다. 좌우가 있는 파라미터는 반대쪽으로 바뀌고(EyeLOpen → EyeROpen) 좌우 파라미터는 뒤집힙니다 |
| 제자리 좌우 반전 | 현재 키를 오브젝트 자체의 중심을 기준으로 뒤집습니다 |
| 모든 키를 반대쪽으로 / 반대쪽 오브젝트로 미러 | 모든 키를 한꺼번에. 한 오브젝트 안에서는 포즈가 있는 쪽의 키만 복사합니다 |

좌우 파라미터는 범위가 기본값을 중심으로 대칭이고, 2D 링크의 가로축이거나 ID가 X 또는 Z로 끝나는 파라미터입니다(AngleX, AngleZ, BodyAngleX, EyeBallX 등). 반대쪽 오브젝트는 먼저 레이어 의미로, 그다음 ID나 이름의 L/R, Left/Right, 左/右로 짝을 짓습니다. 미러는 기본 포즈에서 부모의 좌표계 안에 있는 오브젝트 자체의 변형만 다루므로, 부모의 키폼은 따로 미러하세요. 레이어를 여러 개 선택하면 각 메시를 미러하고 히스토리 한 단계로 커밋합니다.

같은 컨텍스트 메뉴의 **키폼** 하위 메뉴는 현재 키의 형태를 다룹니다. 결과는 역시 일반 키폼이며 취소할 수 있습니다. 파라미터가 오브젝트의 키 중 하나에 정확히 놓여 있어야 합니다.

| 동작 | 하는 일 |
| --- | --- |
| 키폼 복사 | 현재 파라미터에서 오브젝트가 보이는 형태를 기억합니다. 단축키 `Ctrl+Alt+C` |
| 키폼 붙여넣기 | 복사할 때 고정한 형태를 현재 키에 이동량으로 기록합니다(메시는 원래 형태로부터, Warp나 회전 디포머는 기본 키 형태로부터). 같은 오브젝트, 또는 같은 부모 아래에서 삼각형이 같은(Warp는 행과 열이 같은) 같은 종류의 오브젝트에 붙여 넣습니다. `Ctrl+Alt+V` |
| 기본 키 형태로 재설정 | 현재 키를 파라미터 기본값에서의 형태로 되돌립니다. `Ctrl+Alt+X` |
| 메시 원래 형태로 재설정 | 메시 전용: 변형되지 않은 메시로 되돌립니다 |
| (파라미터)의 인접 키로 보간 | 그 파라미터를 따라 양쪽에 있는 키로 현재 키를 다시 만듭니다. 해당하는 파라미터가 여러 개면 각각 나열되며, `Ctrl+Alt+I`는 첫 번째를 사용합니다 |
| 옵션을 지정해 붙여넣기… | 대화 상자에서 붙여 넣을 항목(형태, 불투명도, 그리기 순서, 곱하기 색과 스크린 색), 블렌드 비율(100%는 붙여넣기, 그보다 작으면 섞기), 좌우 또는 상하 반전(Warp는 열이나 행을 뒤집고, 메시는 미러된 원래 형태로 정점을 짝지으며 원래 형태가 대칭이어야 함), 복사한 각 형태를 어느 오브젝트에 넣을지를 고릅니다 |
| 모든 키를 기본 키 형태로 복원 | 오브젝트의 모든 키를 기본 키 형태로 되돌려 처음부터 다시 시작합니다 |
| 다중 키 편집… | 파라미터 키 값으로 범위를 골라 여러 오브젝트의 많은 키폼의 불투명도, 그리기 순서, 색을 한꺼번에 바꿉니다(덮어쓰기, 더하기, 곱하기, 스크린) |

복사는 선택한 메시마다 형태를 하나씩 기록하고, 붙여넣기는 각 형태를 복사한 그대로 자기 자신이나 그것을 받을 수 있는 다음 선택 오브젝트에 다시 기록합니다. 점을 선택한 상태에서는 붙여넣기, 재설정, 보간이 그 점만 바꾸며 메뉴 줄에 개수가 표시됩니다. 베지어 수준의 Warp와 회전 디포머는 항상 전체로 다룹니다. 생성기가 소유한 키폼에서는 결과가 생성 재정의로 기록됩니다. 파라미터가 오브젝트의 키에 있지 않거나 바인딩된 파라미터가 없으면 메뉴에 그 이유가 표시됩니다.

**소프트 선택**: 선택 또는 변환 도구에서 도구 옵션 바의 **소프트 선택**(`O`)을 켜면, 선택한 점을 드래그하거나 변형할 때 주변 점도 함께 움직이며 가장 가까운 선택 점에서 멀수록 덜 움직입니다. **영향 범위**는 캔버스 단위이며 `[` / `]`로 조정합니다. 감쇠 커브는 변형 브러시와 공유합니다. 영향을 받는 점에는 빨간 링이 표시되며, 링이 클수록 더 많이 따라옵니다. 커밋되는 것은 여전히 일반 기하 편집 하나입니다.

**임시 변형**: `Shift+T` 또는 컨텍스트 메뉴의 **임시 변형(워프)**은 선택한 점 위에(선택이 없으면 메시나 Warp 전체 위에) 일회용 격자를 씌웁니다. 격자 점을 드래그하면 안쪽 점이 쌍선형 보간으로 따라오며, 놓을 때마다 히스토리 한 단계가 됩니다. 키 사이에서 누르면 먼저 포즈를 키에 맞추고, 형태가 다른 곳에서 바뀐 뒤에 누르면 격자를 다시 씌웁니다. 둘 다 드래그를 시작하지 않으므로 다시 누르세요. 툴바의 **격자**에서 1×1–4×4를 전환하고, Enter, Esc 또는 **완료**로 끝냅니다. 격자 자체는 남지 않습니다.

## 여러 캔버스, 파라미터와 애니메이션

한 작업 공간의 모든 캔버스는 파라미터 포즈, 파라미터 잠금, 재생 컨트롤을 공유합니다. 편집과 미리보기를 오가거나, 포커스를 바꾸거나, 캔버스를 숨겨도 다른 포즈로 되돌아가지 않습니다. 선택, 도구, 카메라, 표시 설정은 여전히 캔버스마다 유지되며, 작업 공간이 다르면 각자 포즈를 가집니다.

편집 캔버스에서 파라미터를 드래그하거나 본으로 포즈를 잡으면 애니메이션이 일시 정지되고 편집한 값이 바로 표시됩니다. 파라미터 재설정과 키에 맞추기는 자동으로 잠그지 않습니다. 애니메이션 편집기에서 타임라인을 드래그하면 샘플링한 포즈를 작업 공간으로 보내므로, 편집 캔버스에서 그 포즈를 보며 계속 조정할 수 있습니다. 편집한 값은 이전 재생이 남긴 미리보기 프레임을 사용하지 않으며, 포즈를 잡는 동안에는 마우스 추적과 일시 정지된 물리가 이를 덮어쓰지 않습니다. 재생을 다시 시작하거나 마우스 추적을 전환하면 실시간 미리보기로 돌아갑니다. 미리보기 캔버스에서 파라미터를 조정하면 일시 정지된 물리가 어떻게 반응하는지 계속 보여 줍니다.

애니메이션 트랙 이름 옆의 작은 눈금자는 파라미터의 키를 보여 주며, 커브 보기에는 같은 키가 값과 함께 기준선으로 표시됩니다. 파라미터를 삭제하면 그 애니메이션 트랙도 제거되고, 파라미터 범위를 줄이면 애니메이션 키와 베지어 제어점도 그에 맞게 잘립니다.

재생, 타임라인, 베이크는 스스로 캔버스를 만들거나 표시하거나 전환하지 않습니다. 캔버스가 필요하면 **창** 메뉴나 패널의 캔버스 표시 버튼으로 여세요.

## 변형 브러시

변형 브러시는 텍스처가 아니라 기하를 바꿉니다. 선택한 제어점이 없으면 현재 오브젝트의 모든 점에 작용하고, 선택이 있으면 선택한 점으로 한정됩니다. 반경은 캔버스 단위로 잽니다. 기본적으로 Alt + 오른쪽 드래그로 반경이나 경도를 조정하고, Esc로 현재 제스처를 취소합니다.

브러시 끝 모양은 왼쪽 툴바의 브러시 아래에서 고르며(가중치 브러시도 같음), 나머지 설정은 도구 옵션 바와 캔버스 컨텍스트 메뉴에 있습니다.

| 설정 | 효과 |
| --- | --- |
| **도형** | **원형**, **직선**, **사각형** |
| **반경** / **경도** / **강도** | 닿는 범위, 가장자리의 부드러움, 한 번 칠할 때 미는 세기 |
| **감쇠** | 중심에서 가장자리까지의 가중치 커브: **부드럽게**, **구형**, **루트**, **역제곱**, **날카롭게**, **선형**, **일정**, **무작위** |
| **연결된 것만** | 포인터 아래 메시와 연결된 점에만 영향을 줍니다. 원형 브러시는 대신 메시 변을 따라 거리를 잽니다 |

![변형 브러시 설정과 연결된 것만을 켰을 때의 범위](../../imgs/mesh-brush.webp)

*왼쪽: 브러시 설정. 오른쪽: **연결된 것만**을 켜면 원이 이웃한 머리카락을 덮더라도 영향을 받는 정점(빨강)은 포인터 아래의 가닥에만 머뭅니다. 이 정점들은 마우스를 올린 순간부터 빨간 원으로 표시되며, 원이 클수록 영향이 강합니다. 이웃한 머리카락 가닥이나 윗입술과 아랫입술처럼 가까이 붙은 파츠를 칠할 때 유용합니다.*

## 메시 토폴로지

| 동작 | 결과 |
| --- | --- |
| 변 세분화 / 영역 세분화 | 걸린 변에 점을 추가하고 삼각형을 다시 만듭니다. 이웃 면이 이음매를 함께 처리합니다 |
| 연결 / 병합 | 선택한 점을 연결하거나, 선택한 정점을 하나로 병합합니다 |
| **복제** | 선택한 정점과 그 정점이 완전히 덮는 면을 복사합니다. 복사본이 선택됩니다 |
| **삭제** | 선택을 삭제하고 빈 곳을 다시 만들려고 시도합니다. 유효한 토폴로지를 만들 수 없으면 거부됩니다 |
| 변 삭제 | 선택한 변을 삭제합니다(변 모드에서 `Del`, 또는 토폴로지 메뉴의 **변 삭제**). 안쪽 변은 두 삼각형이 이루는 사각형의 다른 대각선으로 바뀌며, 그 사각형이 원래 형태나 어느 키폼 또는 블렌드 형태에서든 볼록하지 않으면(그 포즈에서 뒤집히므로) 거부됩니다. 윤곽 변은 그 삼각형을 지우고, 더 이상 쓰이지 않는 정점도 함께 지웁니다. 정점이 점 하나로만 이어지게 되거나 삼각형이 하나도 남지 않으면 거부됩니다 |
| 재삼각분할 | 토폴로지 메뉴: 선택한 정점 주변(선택이 없으면 메시 전체)의 가는 삼각형을 더 고른 삼각형으로 바꿉니다. 정점, 윤곽, 텍스처는 그대로이며, 개선할 것이 없으면 알림이 표시됩니다 |
| 정점 배치 | 자동 배치를 점 단위로 보정합니다. **점**은 정점을 추가, 이동, 삭제하고, **선**은 선을 따라 이어진 변을 놓습니다. 아래 참고 |

### 정점 배치

편집 모드 툴바의 토폴로지 그룹 첫 번째 도구이며, 일반 메시와 내부 효과가 있는 메시 모두에 쓸 수 있습니다. 두 가지 모드가 있으며 옵션 바나 툴바의 도구 아래에서 전환하거나, 각각의 단축키로 바로 전환합니다.

| 모드 | 단축키 | 용도 | 저널 명령 |
| --- | --- | --- | --- |
| 점 | `Alt+M` | 정점을 추가, 이동, 삭제하고 밀도를 조정합니다. 클릭이나 스트로크마다 바로 커밋되며 새 점 주변의 연결은 메시가 정리하므로, 점 사이에 **변이 생긴다는 보장은 없습니다** | `add_points`(그리고 `connect` / `delete` / `delete_edges`) |
| 선 | `K` | 점을 하나씩 클릭해 꺾은선을 만들고 Enter로 커밋합니다. 각 점이 직전 점과 변으로 이어지므로 메시가 그 선을 따라 **접힐** 수 있습니다(눈꺼풀, 입 선, 주름) | `knife` |

두 모드 모두 같은 규칙으로 점을 놓습니다. 포인터는 가까운 정점과 변에 스냅되고(스냅 반경은 하나를 공유하며, 선 모드에서는 Shift로 잠시 스냅을 끔), 호버 표시가 누를 때 놓일 위치를 보여 주며, 점은 메시 밖에도 놓일 수 있습니다.

#### 점

| 동작 | 결과 |
| --- | --- |
| 빈 캔버스 클릭 | 그 위치에 정점을 추가합니다. 삼각형 안이면 삼각형을 셋으로 나누고, 변 위면 변을 나누고, 메시 밖이면 가장 가까운 보이는 윤곽 변에서 삼각형 하나를 늘립니다 |
| 빈 캔버스 드래그 | 스트로크를 따라 **배치 간격**(캔버스 픽셀)마다 정점을 추가하며, 한 단계로 커밋합니다 |
| 정점 드래그 | 선택 도구처럼 이동합니다. 텍스처는 그대로이며 글루된 점은 함께 움직입니다 |
| 정점에 Shift + 클릭 | 선택된 정점 하나를 그 정점에 연결하고 선택을 그쪽으로 옮기므로, Shift 클릭을 반복하면 사슬이 그려집니다 |
| Alt + 클릭 | 정점(빈 곳을 채움) 또는 변을 삭제합니다 |

#### 선

클릭할 때마다 앵커가 하나 놓입니다. 정점 위면 그 정점을 쓰고, 변 위면 변을 나누고, 삼각형 안이나 메시 밖이면 새 정점을 추가합니다. 이웃한 두 앵커는 변으로 이어지며, 그 변이 가로지르는 변은 나뉩니다. Enter(또는 모드 바의 **선 완료**)로 선 전체를 한 단계로 커밋하고, Delete로 점 하나를 되돌리며, Esc로 취소합니다. 메시와 겹치지 않고는 이을 수 없는 선은 전체가 거부되고 초안은 유지되므로, 마지막 점을 되돌린 뒤 다시 놓을 수 있습니다.

#### 공통

새 정점의 위치, UV, 키폼, 블렌드 셰이프, 정점 가중치는 모두 주변 정점에서 같은 가중치 세트로 유도되므로, 점을 추가해도 그림은 움직이지 않습니다. 이후 가는 삼각형을 피하려고, 텍스처가 바뀌지 않는 범위에서 주변 변을 뒤집습니다. **좌우 대칭**을 켜면 추가, 삭제, 변 삭제가 메시의 현재 경계의 세로 중심선을 기준으로 한 대칭 위치에서도 일어납니다(그곳에 정점이나 변이 없으면 이쪽에서만). 컨텍스트 메뉴의 선택 그룹에는 **윤곽 정점 선택**과 **안쪽 정점 선택**도 있어 경계나 안쪽만 따로 작업할 수 있습니다.

내부 효과가 있는 메시에서 점을 추가, 삭제, 연결하거나, 변을 삭제하거나, 재삼각분할하거나, 원래 형태의 정점을 움직이면 같은 단계에서 새 메시에 효과를 다시 베이크합니다. 새 메시가 효과의 면적 검사를 통과하지 못해도 편집은 커밋되며, 내부 조형 패널이 메시가 바뀌어 다시 생성해야 한다고 알립니다.

토폴로지 업데이트는 UV, 키폼, 블렌드 셰이프, 글루 정점 참조도 처리하고 패스를 다시 바인딩합니다. 그래도 기존 포즈, 특히 윤곽 점을 삭제한 뒤의 경계 변화는 확인하세요.

## 내부 조형 핸들

오브젝트 모드의 **내부 조형 핸들** 도구(Shift+I, 또는 내부 조형 패널 툴바의 **캔버스에서 편집**. 다른 모드에서는 둘 다 오브젝트 모드로 전환)는 선택한 메시의 [내부 조형](../spec/INTERIOR_SURFACE.md)을 캔버스에서 조정합니다. 오브젝트 모드는 메시 정점을 그리지 않으므로 핸들이 정점 사이에 뒤섞이지 않습니다. 메시에 아직 효과가 없거나 꺼져 있으면 옵션 바가 그렇게 알려 주고 켤 수 있게 합니다. 다른 오브젝트를 클릭하면 그 오브젝트가 선택되고 핸들도 그쪽으로 옮겨 갑니다.

| 핸들 | 효과 |
| --- | --- |
| 중앙 십자 | 위쪽 팔은 볼록함, 왼쪽 팔은 압력, 오른쪽 팔은 가로 게인, 아래쪽 팔은 세로 게인. 팔이 길수록 값이 크며 점선 상자에서 2 |
| 아치 | 실선: 정지 상태의 가상 아치. 점선: 최대 입력에서 기울어진 아치(도해) |
| 화살표 | 타이밍과 전달이 켜져 있을 때 표시. 끝을 드래그하면 시작이나 끝을, 가운데를 드래그하면 둘 다 옮깁니다 |
| 가이드 | 메시나 빈 캔버스를 클릭해 접힘 선을 시작하고, 마지막 점을 클릭하거나 Enter를 눌러 끝냅니다. 점을 드래그하면 점을, 선분을 드래그하면 선을 옮기고, Ctrl+클릭으로 점을 추가, Alt+클릭으로 점을 제거하며, Delete는 선택한 점이나 선 전체를 지웁니다. 선택한 접힘에는 반경 핸들이 있습니다 |

마우스를 올린 핸들과 선은 강조되고 상태 표시줄에 이름과 값이 표시됩니다. 드래그 하나는 놓을 때 히스토리 한 단계로 기록되며 Esc로 취소합니다. 패널 값과 핸들은 서로 동기화됩니다. 시험 동작을 켜면 드래그하는 동안 형태가 갱신됩니다.

## 특징점

오브젝트 모드의 **특징점** 도구(기본 `Shift+Y`)는 맞춤된 이목구비의 핸들을 보여 줍니다. 각 눈의 눈머리와 눈꼬리, 윗눈꺼풀과 아랫눈꺼풀의 가운데, 각 눈썹의 양 끝과 눈썹산, 입의 양 꼬리와 입술 가운데입니다(해당 부위가 맞춤 기반을 쓸 때만). 핸들을 드래그해 놓으면 새 위치에서 특징을 다시 맞추고, 그로부터 만든 모든 포즈(눈 뜨기, 웃는 눈, 감정, 입 모양)가 따라옵니다. 눈꺼풀이나 입술 가장자리는 가운데에서 가장 많이 따라오고 양 끝에서는 꼬리를 따릅니다. 변경은 리그 레시피에 들어가며, 드래그 하나가 히스토리 한 단계이고 다시 생성해도 유지됩니다. 옮긴 핸들은 사각형으로 그려지며, `Alt` + 클릭으로 원화에서의 위치로 되돌립니다. 맞춤을 바꾸지 않고 특징을 조금만 옮기려면 그 특징을 구동하는 격자(눈, 눈썹, 입의 형태 워프)를 드래그합니다. 편집 모드에서, 또는 변형 모드에서 `Ctrl`을 누른 채로 격자를 드래그하면 그 워프의 모든 키폼과 블렌드 셰이프에 더해지므로 모든 포즈가 함께 움직이고, 다시 생성해도 유지됩니다. 옵션 바에는 마지막으로 다룬 부위의 기본값(눈의 아랫눈꺼풀 올라옴과 눈알의 둥글기, 입의 초기 벌어짐과 형태 강도 등)이 표시되며, 드래그 하나가 히스토리 한 단계입니다. **이 특징 초기화**와 **모든 특징 초기화**는 특징 하나 또는 모든 특징의 이동을 한꺼번에 되돌립니다. MCP에서는 `settings_update`의 `changes.rig.moves`로 같은 데이터를 바꿉니다.

## 소재 만들기와 배치

1. 대상을 선택하고 오브젝트 모드 툴바의 마지막 그룹에서 Warp, Rotation 또는 변형 패스를 고르거나 `C` / `R` / `P`를 누릅니다. 계층에서 오른쪽 클릭해 부모 / 자식 Warp나 Rotation을 추가하거나, 오브젝트 모드 캔버스 컨텍스트 메뉴의 **만들기**에서 고를 수도 있습니다.
2. 캔버스에서 배치 미리보기를 조정하고 영향을 받는 오브젝트, 이름, 부모, 분할 설정을 확인합니다.
3. 모드 바의 **확정**을 클릭하거나 Enter를 눌러 프로젝트에 기록합니다. **취소**를 클릭하거나 Esc를 누르면 취소됩니다.

PNG / WebP / TIFF / BMP를 계층으로 끌어다 놓거나, 트리 컨텍스트 메뉴의 **레이어 가져오기…**를 써도 배치 세션이 시작됩니다. 아트메시 위에 놓으면 새 레이어는 그 아트메시의 부모 디포머 아래로 들어갑니다. 배치한 뒤에는 가림과 여러 파라미터 포즈를 확인하세요.

## 변환 상자

**변환** 도구, Warp / 레이어의 배치 상자, 텍스처 아틀라스 페이지에서 선택한 타일은 같은 변환 상자를 쓰며, 모양과 조작이 같습니다. 아무것도 선택하지 않았을 때 변환 도구는 선택 도구처럼 클릭이나 박스 선택을 하고, 무언가를 선택하면 변환 상자가 나타납니다.

| 동작 | 효과 |
| --- | --- |
| 상자 안 드래그 | 이동 |
| 모서리 / 변 중점 드래그 | 반대쪽을 고정한 채 크기 조절. 모서리에서 `Shift`는 비율 유지, `Alt`는 기준점을 중심으로 크기 조절 |
| 위쪽 변 위의 둥근 핸들, 또는 모서리 바로 바깥을 드래그(마우스를 올리면 모서리 바깥에 화살표 달린 호가 켜짐) | 기준점을 중심으로 회전. `Shift`는 15°씩 |
| 기준점(원 안의 윤곽선 십자) 드래그 | 기준점 이동. 중심, 모서리, 변 중점 근처에서 스냅되며, 다시 끌어다 놓으면 기본값으로 돌아감 |

기준점은 선택의 중심(점들의 무게 중심)에서 시작합니다. 상자 안에서 선택에 대한 상대 위치가 유지되므로 이동, 크기 조절, 회전 후에도 선택을 따라갑니다. **정밀 변형**의 회전과 크기 조절도 이 점을 중심으로 씁니다. 선택을 바꾸거나 Esc로 도구를 떠나면 기준점은 기본값으로 돌아갑니다. 드래그하는 동안 포인터에 회전 각도, 두 축의 배율 또는 이동한 캔버스 픽셀이 표시되고 다른 핸들은 흐려집니다. 상자의 너비나 높이가 화면 픽셀 40 미만이면 가운데를 누르면 항상 이동이 되고 기준점은 드래그할 수 없습니다(확대해서 쓰세요). Warp와 레이어의 배치 상자는 사각형으로 만들어지며 이동과 크기 조절만 되고 회전은 되지 않습니다. 텍스처 아틀라스 타일은 모서리에서 밀도를 비례로 조절하며 변 중점이 없습니다.

## 회전 디포머

원점을 드래그해 옮기고 끝점을 드래그해 회전합니다. 기본적으로 `Shift`를 누르면 각도가 스냅되고, `Alt` + 끝점 드래그로 배율을 조정합니다.

## 여러 메시 편집

편집 모드는 선택한 모든 아트메시에 한꺼번에 작용합니다.

- 정점 클릭, 박스 선택, 브러시 선택, 변환 상자, 변형 브러시는 모두 메시를 넘나들며 작동합니다.
- 메시의 정점을 클릭하면 그 메시가 **주 메시**가 됩니다. 정점 배치의 선, 변 / 면 모드, 패스는 주 메시에만 작용합니다.
- 삭제 같은 정점 동작은 선택이 있는 메시마다 한 번씩 커밋되며, 히스토리 항목은 하나입니다.

## 글루

메시 2개를 선택하고 편집 모드에서 글루 도구를 고르면 툴바 아래에 하위 도구 셋이 나열됩니다. **글루 브러시**, **가중치 브러시**, **다시 병합**(`1`–`3`)입니다. 글루 점은 두 메시가 공유하는 점 하나이며 캔버스에 마름모 하나로 표시됩니다. 선택하거나 드래그하면 양쪽 정점이 항상 함께 움직이므로, 편집하는 동안 글루가 어긋나지 않습니다.

Cubism과 마찬가지로 글루는 메시의 원래 형태(모든 파라미터가 기본값)에서 이루어지며, 그곳에서 글루된 점은 양쪽이 일치해 아무것도 당기지 않습니다. 파라미터가 기본값이 아닐 때 글루 브러시, 다시 병합, **글루 생성**, 선택한 정점 글루는 먼저 파라미터를 부드럽게 기본값으로 되돌린 다음 글루합니다. 가중치 조정과 글루 해제는 포즈를 바꾸지 않습니다.

| 동작 | 효과 |
| --- | --- |
| **글루 브러시** | 이미지가 아니라 메시만 바꿉니다. 메시가 겹치는 곳(또는 결합 허용 거리 안)에서 다른 메시에 정점을 추가하거나 밀어 맞추며 UV도 따라옵니다. 삽입한 뒤에는 가는 삼각형을 피하려고 텍스처를 바꾸지 않는 범위에서 변을 뒤집습니다 |
| `Alt` + 드래그 | 글루 해제 |
| **가중치 브러시** | 양쪽 가중치를 텍스처 위에 파랑(A) / 주황(B)으로 표시합니다 |
| **다시 병합** | 칠한 정점의 기존 글루를 제거한 다음 결합 허용 거리로 다시 글루합니다 |
| `Enter` 또는 모드 바의 **글루 생성** | 두 윤곽을 따라 통째로 글루합니다 |
| `Ctrl+G`(모델 내보내기 키이지만 여기서는 내보내기를 열지 않음) | 두 메시 중 어느 쪽에서든 선택한 정점을 글루합니다 |
| 오른쪽 클릭 **이음매 전체 다시 병합** | 두 메시 사이의 모든 글루를 제거하고 윤곽을 따라 다시 글루합니다 |

## 페인트 적용과 폐기

페인트에 들어가기 전에 레이어를 선택하세요. 스트로크는 별도의 페인트 세션에 보관되며, 세션 안에서 실행 취소와 다시 실행이 됩니다. 첫 스트로크 뒤에는 캔버스 위쪽 가운데에 세션 바가 미끄러져 나타나며(텍스처 아틀라스 조정 세션 바와 같음), 칠하고 있는 레이어와 스트로크 수, 그리고 실행 취소, 다시 실행, **폐기**, **적용**을 보여 줍니다. 좁은 캔버스에서는 버튼이 아이콘만 표시하고 마우스를 올리면 이름이 나옵니다. **도구 상세** 패널에도 **폐기**와 **적용**이 있습니다.

팔레트는 Photoshop 방식입니다. 겹친 전경색 / 배경색 견본이 왼쪽 아래 도구 옵션 바의 맨 앞에 있고, 오른쪽 위에 바꾸기(X), 왼쪽 아래에 기본 검정 / 흰색이 있습니다. 견본을 클릭하면 색상 선택기가 열립니다. 왼쪽에 채도 / 명도 영역, 오른쪽에 세로 색조 막대, **새 색상 / 현재 색상** 비교 견본(**현재 색상**을 클릭하면 복원), H S B와 R G B 값, 16진 코드, 아래쪽에 견본과 최근 색상이 있습니다. **도구 상세** 패널에는 전경색의 영역과 색조 막대가 견본, 최근 색상과 함께 바로 들어 있습니다. 브러시, 연필, 지우개, 도형의 크기는 서로 독립적이며, 도형의 선 두께는 브러시 크기를 바꾸지 않습니다.

툴바는 세 그룹입니다. 브러시, 연필, 지우개, **흐림 효과** / 페인트 통, **그레이디언트**, 스포이트 / 도형, **선택 영역**. 각 도구의 옵션은 왼쪽 아래 옵션 바에 있고, 선택 명령은 캔버스 컨텍스트 메뉴의 **선택 영역** 그룹에 있습니다.

| 기능 | 방법 |
| --- | --- |
| 선택 도구(`Alt+L`) | 사각형, 타원, 올가미, 다각형 올가미, 자동 선택, 빠른 선택의 여섯 가지 변형을 `1`–`6`으로 고릅니다. 박스는 드래그합니다. 올가미는 누른 채 윤곽을 드래그합니다. 다각형은 점을 하나씩 클릭하고 첫 점을 클릭하거나 `Enter`를 눌러 닫습니다(`Delete`는 마지막 점을 되돌리고 `Esc`는 버림). 자동 선택은 클릭한 색을 허용 오차 안에서 가져오며, **인접**을 끄면 레이어 전체에서 가져옵니다. 빠른 선택은 지나가는 곳과 그 주변에 이어진 비슷한 색의 픽셀(음영 포함)을 선택하는 브러시로, 색이 급히 바뀌는 가장자리에서 멈춥니다. 스트로크마다 선택에 더해지고 `Alt` 스트로크는 빼며, `[` `]`로 브러시 크기를, **허용 오차**로 색이 얼마나 비슷해야 하는지를 정합니다. 색은 프리멀티플라이드로 비교하므로 투명한 영역은 무엇을 가리든 한 색으로 칩니다. `Shift`를 누르면 추가, `Alt`는 빼기, `Shift+Alt`는 교차이며, 옵션 바에서 조합을 고정할 수도 있습니다. 드래그 없이 클릭하면 선택이 해제됩니다. 선택은 개미 행렬로 표시됩니다 |
| 선택 명령 | `Ctrl+A` 모두 선택, `Ctrl+D` 선택 해제, `Ctrl+I`(또는 `Ctrl+Shift+I`) 반전, `Alt+Backspace` 선택 영역을 전경색으로 채우기(선택이 없으면 레이어 전체), `Del` 선택 영역 내용 지우기. 컨텍스트 메뉴에는 **선택 영역 페더**, **선택 영역 확장**, **선택 영역 축소**(옵션 바의 **페더**와 **확장 / 축소** 거리 사용. 축소는 캔버스 가장자리에서 안으로 들어오지 않음)와 **불투명 픽셀 선택**(레이어의 투명도를 선택으로. Photoshop에서 레이어 썸네일을 Ctrl + 클릭하는 것)도 있습니다 |
| 선택 영역의 효과 | 선택이 있는 동안에는 모든 도구(브러시, 지우개, 흐림 효과, 채우기, 그레이디언트, 도형, 지우기)가 안쪽만 바꾸며, 부드러운 가장자리는 비례해서 섞입니다. 선택은 스트로크 히스토리에 포함되지 않습니다. 스트로크를 실행 취소해도 선택은 그대로이며, 적용, 폐기, 레이어 전환 시 지워집니다 |
| 자유 변형(`Alt+T`, 또는 페인트 모드에서 `T`) | 도구를 고르면 선택 영역의 픽셀(선택이 없으면 레이어 전체 내용)을 변환 상자에 넣고 원래 자리는 비웁니다. 안쪽을 드래그하면 이동, 모서리를 드래그하면 비율 유지 크기 조절(`Shift`로 해제), 변 핸들은 한 방향 크기 조절, `Alt`는 가운데 기준 크기 조절, 바깥을 드래그하면 가운데 기준 회전(`Shift`로 15°씩)입니다. `Enter` 또는 **변형 적용**으로 내려놓고, `Esc` 또는 `Ctrl+Z`로 되돌리며, 다른 도구를 고르면 적용됩니다. **부드럽게**를 끄면 픽셀 아트용으로 최근접 샘플링합니다. 적용하면 변형 전체가 스트로크 히스토리의 한 단계가 되고 선택은 픽셀과 함께 움직입니다 |
| 그레이디언트(`Alt+G`) | 시작점에서 끝점까지 드래그합니다. 선형 또는 원형이며, 전경색에서 배경색으로 또는 투명으로 갑니다. 선택 영역과 투명도 잠금을 지킵니다 |
| 흐림 효과(`Alt+J`) | 지나가는 곳을 부드럽게 합니다. **강도**로 정도를 정하며, 한 스트로크 안에서 오가도 계속 더 흐려지지 않습니다 |
| 손떨림 보정 | 브러시, 연필, 지우개, 흐림 효과의 옵션 바에 있는 **손떨림 보정** 0–30. 높을수록 선이 안정되고 더 늦게 따라옵니다. 포인터를 떼면 선이 그 위치까지 따라잡습니다 |
| 대칭 | 같은 네 도구가 캔버스 가운데를 기준으로 좌우, 상하 또는 4방향으로 미러되며, 점선 축으로 표시됩니다 |
| 투명도 잠금(`/`) | 이미 칠한 픽셀에만 색을 입히고 투명도는 유지합니다. 이때 지우개는 배경색을 칠합니다 |
| 페인트 통 | **인접**을 끄면 그 색의 모든 픽셀을 채웁니다 |
| 직선 | `Shift` + 클릭으로 마지막 스트로크가 끝난 곳에서 직선을 이어 그립니다 |
| 기본 색 | `Alt+D`로 검정 / 흰색을 복원합니다(`X`는 전경색과 배경색 바꾸기) |

필압, 보기 회전 / 뒤집기, 문지르기나 수채화 혼합은 아직 지원하지 않습니다. Photoshop / SAI와의 전체 비교는 [페인트 시스템](../spec/PAINT_SYSTEM_ARCHITECTURE_AND_PRD.md#도구-비교와-차이)을 참고하세요.

페인트는 레이어의 사각형에 한정되지 않고 캔버스 전체에 칠할 수 있습니다. 적용하면 레이어의 메시로 페인트를 잘라 냅니다.

- **메시 위의 부분**은 레이어에 남습니다. 레이어의 메시, 키폼, 바인딩은 바뀌지 않습니다.
- **메시 밖의 부분**은 원래 이름 뒤에 "+"를 붙인 새 레이어로 분리되어 원래 레이어 바로 위에 놓입니다. 새 레이어는 자체 메시를 가지며 원래 레이어의 부모와 파츠 아래에 있으므로 함께 움직입니다. 소재 라이브러리에도 원래 레이어의 소재 옆에(원래 레이어에 소재가 없으면 최상위에) 소재로 나타나며, 레이어는 그 소재에 연결됩니다.
- 메시 밖을 지우는 것은 아무 효과가 없습니다. 그 픽셀은 어차피 표시되지 않으며, 레이어의 기존 부드러운 가장자리가 분리되지도 않습니다.
- 아직 메시가 없는 레이어(예: 첫 스트로크를 받는 투명 레이어)는 잘리지 않으며, 모든 픽셀로 메시를 생성합니다.
- 소재에 연결된 레이어는 메시 위의 부분이 소재에 기록되므로, 그 소재를 쓰는 모든 레이어가 함께 바뀝니다. 메시 밖의 부분은 마찬가지로 새 레이어로 분리됩니다.

레이어 자체의 메시가 새로 칠한 영역을 덮게 하려면 메시 패널의 **현재 픽셀로 재구성**을 쓰세요. 키폼, 패스, 가중치, 글루가 새 메시로 옮겨집니다.

적용한 뒤에는 변형과 마스크를 확인하고 프로젝트를 저장하세요. 구현 세부는 [페인트 시스템](../spec/PAINT_SYSTEM_ARCHITECTURE_AND_PRD.md)을 참고하세요.

## 커밋과 복원

일반 기하 제스처는 드래그하는 동안 미리 보여 주고, 성공적으로 끝나면 프로젝트 히스토리에 들어갑니다. 만들기, 자르기, 페인트에는 각각 확정 단계가 있습니다. "현재 초안", "커밋된 히스토리", "디스크에 기록된 프로젝트"를 같은 상태로 취급하지 마세요.

패스 모드 간의 차이와 내보내기 제약은 [변형 패스](DEFORM_PATHS.md)를, 프로젝트 저장 방식은 [프로젝트 형식](../spec/PROJECT_FORMAT.md)을 참고하세요.
