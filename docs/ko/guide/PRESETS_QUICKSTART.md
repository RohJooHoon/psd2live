# 프리셋 쉽게 시작하기

[문서 목록](../../README.md) · [프리셋 자세한 설명](MODIFIERS.md) · [MCP 사용법과 인터페이스](../agent/MCP_AUTHORING.md)

> 이 페이지는 처음 쓰는 사람을 위한 짧은 안내입니다. 모든 옵션과 규칙은 [프리셋 자세한 설명](MODIFIERS.md)에 있습니다.

## 한 줄 요약

**프리셋은 캐릭터를 움직이게 하는 "부품" 목록입니다.** 눈 깜빡임, 입 벌리기, 고개 돌리기, 머리카락 흔들림 같은 부품을 하나씩 **끼우고, 끄고, 세기를 조절하고, 빼는** 방식으로 리그를 만듭니다.

포토샵의 조정 레이어나 블렌더의 모디파이어를 떠올리면 됩니다.

- 목록의 **위에서 아래로** 차례대로 적용됩니다.
- 부품을 꺼도 지워지지 않습니다. 다시 켜면 그대로 돌아옵니다.
- 부품이 만든 결과를 손으로 고쳐도, 그 수정은 해당 부품에 함께 저장됩니다.

예전에는 "자동 생성" 버튼 하나로 리그를 통째로 만들었습니다. 지금은 그 내용이 부품 단위로 나뉘어 보이고, 하나씩 손댈 수 있다는 점이 다릅니다.

## 1. 처음 시작하기: 그냥 "추천"으로 두세요

1. 시작 화면에서 **PSD에서 생성**을 고르고 PSD 파일을 엽니다.
2. 오른쪽 **빠른 설정**에 **추천 수정자**가 이미 선택되어 있습니다. **그대로 두고 만들면 됩니다.**

| 빠른 설정 | 이럴 때 고르세요 |
| --- | --- |
| **추천 수정자** (기본값) | 잘 모르겠으면 이것. 몸, 얼굴, 눈, 눈썹, 입, 머리카락이 기본으로 움직입니다 |
| **빈 수정자 스택** | 아무 움직임 없이 메시만 받고, 필요한 부품을 직접 하나씩 넣고 싶을 때 |
| **최소 / 기본 / 전체** | 움직임을 적게 또는 많게. 전체로 갈수록 물리, 시뮬레이션, 모션까지 많이 들어갑니다 |
| **사용자 지정** | 머리·몸 강도, 앞머리/뒷머리 방식, 의상 시뮬레이션 등을 직접 고를 때 |

어떤 것을 골라도 나중에 얼마든지 바꿀 수 있으니 처음에는 고민하지 않아도 됩니다.

## 2. 프리셋 패널 보는 법

프로젝트를 열면 **모델 프리셋** 패널(제목은 **프리셋**)에서 부품 목록을 봅니다.

```
┌─ [+ 프리셋 추가] [프리셋 전환] [프리셋 관리] ─────────────────┐
│  [ 설정 | 실행 순서 ]                                         │
├──────────────────────┬────────────────────────────────────────┤
│ ☑ 바인딩 구조         │  [ 조정 | 대상 | 기여 내역 ]           │
│ ☑ 몸                 │                                        │
│ ☑ 얼굴               │   강도  ━━━━━●━━━━  1.00               │
│ ☐ 눈 · 크게 뜨기      │   ...                                  │
│ ☑ 앞머리 흔들림   ✕   │                                        │
│      ↑ 왼쪽: 부품 목록 │      ↑ 오른쪽: 선택한 부품의 설정       │
└──────────────────────┴────────────────────────────────────────┘
```

- **왼쪽**은 부품 목록입니다. 체크박스는 켜기/끄기, ✕는 삭제입니다.
- **오른쪽**은 왼쪽에서 고른 부품의 설정입니다.
  - **조정**: 세기 같은 값을 바꿉니다.
  - **대상**: 이 부품이 어떤 메시에 걸려 있는지 보여 줍니다. 누르면 그 메시로 이동합니다.
  - **기여 내역**: 이 부품이 실제로 만든 파라미터, 디포머 등을 보여 줍니다.
- 가운데 경계선을 끌어서 좌우 폭을 조절할 수 있습니다.

## 3. 자주 하는 일

### 움직임 하나 끄기 / 켜기

목록에서 그 부품의 **체크박스**를 끕니다. 미리보기에서 바로 빠진 모습을 확인할 수 있고, 다시 체크하면 원래대로 돌아옵니다.

> 효과가 마음에 드는지 비교할 때 가장 쉬운 방법입니다.

### 세기 조절하기

1. 목록에서 부품을 클릭합니다.
2. 오른쪽 **조정** 탭에서 슬라이더를 움직입니다.

슬라이더를 놓을 때 한 번만 기록되므로, 실행 취소(Ctrl/Cmd+Z)도 한 번에 됩니다.

### 새 움직임 추가하기

1. 캔버스나 레이어 목록에서 **움직임을 붙일 메시를 선택**합니다. 예를 들어 치마 메시를 고릅니다.
2. **프리셋 추가**를 누릅니다.
3. 부위(얼굴, 눈과 눈썹, 입, 몸, 머리카락, 의상, 물리, 모션 …)를 고르고 원하는 항목을 고릅니다.
4. 추가하기 전에 **무엇이 함께 들어가는지** 미리 보여 줍니다. 필요한 기본 부품이 없으면 자동으로 같이 넣어 줍니다.
5. 확인하면 목록에 추가됩니다.

예시:
- 치마가 흔들리게 하기: 치마 메시 선택 → **프리셋 추가** → 의상 → **치마 흔들림**
- 옷을 물리 시뮬레이션으로 움직이기: 옷 메시 선택 → **프리셋 추가** → 의상 → **의상 시뮬레이션 (자동 가중치)**. 확인하면 백그라운드에서 계산(베이크)하니 잠시 기다리세요.
- 자연스러운 깜빡임 모션 넣기: **프리셋 추가** → 모션 → **자연스러운 동작** 중 깜빡임

이미 같은 부품이 붙어 있는 메시는 메뉴에서 숨겨지거나 "추가됨"으로 표시됩니다. 실수로 두 번 넣을 걱정은 하지 않아도 됩니다.

### 움직임 지우기

목록에서 그 부품의 **✕**를 누릅니다. 실수했다면 실행 취소로 되돌릴 수 있습니다.

### 적용 순서 바꾸기

1. 위쪽 탭에서 **실행 순서**를 고릅니다.
2. 부품을 위아래로 드래그합니다.

순서가 말이 안 되면(예: "눈 깜빡임"이 필요로 하는 "얼굴"보다 위로 올리기) 거부되고 원래 순서가 유지됩니다.

> 대부분은 순서를 건드릴 필요가 없습니다. 추가할 때 알맞은 위치에 들어갑니다.

### 목록 정리하기 (폴더)

**설정** 탭에서는 부품을 폴더로 묶을 수 있습니다. 기본적으로 용도별로 묶여 있습니다. 폴더를 만들고 옮기는 것은 **보기만 정리할 뿐, 실제 적용 순서는 바뀌지 않습니다.**

### 통째로 갈아엎기

**프리셋 전환**을 누르고 하나를 고릅니다.

| 선택 | 결과 |
| --- | --- |
| **신버전 (피팅 알고리즘)** | 그림에 맞춰 피팅하는 새 방식 전체 세트 |
| **구버전 (기존 알고리즘)** | 예전 자동 생성 방식 전체 세트 |
| **비우기** | 부품을 모두 빼고 메시만 남김 |
| 신규 · 경량 / 신규 · 풍부한 움직임 / 기존 · 경량 | 움직임 양을 조절한 세트 |

직접 그린 메시, 직접 만든 파라미터처럼 **프리셋이 만들지 않은 내 작업은 그대로 남습니다.** 한 번에 실행 취소할 수 있습니다.

> 프리셋이 만든 결과를 손으로 고친 내용이 있으면 전환이 막힐 수 있습니다. 그 내용을 먼저 정리하거나 아래의 "확정하기"를 하세요.

### 내 설정을 저장해서 다른 프로젝트에 쓰기

**프리셋 관리**에서:
- **프리셋 저장**: 지금 구성을 이름 붙여 저장합니다. 이후 **프리셋 전환** 목록에 나타납니다.
- **JSON 내보내기 / JSON 가져오기**: 파일로 주고받습니다. 팀원과 공유할 때 씁니다.
- **프리셋 삭제**: 저장한 프리셋을 지웁니다.

저장되는 것은 "어떤 부품을 어떤 값으로" 쓰는지에 대한 **설정**입니다. 손으로 고친 결과나 시뮬레이션 계산 결과는 저장되지 않으며, 적용할 때 다시 계산합니다.

### 확정하기 ("여기까지 적용")

부품 상태로 두면 언제든 끄고 바꿀 수 있습니다. 대신 일반 편집 도구로 자유롭게 고치기는 어렵습니다. **이제 이대로 확정하고 손으로 다듬고 싶을 때** 쓰세요.

1. 목록에서 부품을 고릅니다.
2. 오른쪽 **기여 내역** 탭 아래의 **여기까지 적용**을 누릅니다.

그러면 **목록 맨 위부터 그 부품까지**가 일반 편집 가능한 내용(파라미터, 디포머, 물리, 모션 클립)으로 바뀌고 목록에서 빠집니다. 그 아래 부품들은 그대로 남습니다. 결과 모양은 바뀌지 않으며, 실행 취소로 되돌릴 수 있습니다.

## 4. 이런 표시가 보이면

| 표시 | 뜻 | 할 일 |
| --- | --- | --- |
| **종속 항목 누락** (경고 색) | 이 부품이 필요로 하는 다른 부품이 꺼져 있거나 없음 | 오른쪽에 나온 필요 항목을 켜거나 **프리셋 추가**로 넣기 |
| **비활성** | 체크박스가 꺼져 있음 | 쓰려면 체크 |
| **업데이트 중…** | 계산 중 | 잠시 기다리기 |
| 물리/시뮬레이션 패널의 **프리셋** 배지 | 프리셋 부품이 만든 항목 | 값은 해당 패널이나 프리셋 패널의 그 부품에서 편집. **프리셋 열기**를 누르면 이동 |

## 5. 예전에 만든 프로젝트는?

- 열어도 **아무것도 바뀌지 않습니다.** 예전 프리셋 패널이 그대로 보입니다.
- 새 방식으로 바꾸고 싶으면 그 패널 위쪽의 **수정자 스택으로 변환**을 누릅니다.
  - 변환 전후 결과가 완전히 같을 때만 변환되고, 다르면 거부되며 원래 상태가 유지됩니다.
  - 아직 모든 프로젝트가 변환되지는 않습니다. 실패해도 프로젝트는 안전합니다.
- 새로 가져오는 CMO3 파일은 빈 목록으로 시작합니다. 가져온 모델과 물리는 그대로 일반 내용으로 남습니다.

## 6. 알아 두면 좋은 것

- **새 버전으로 저장한 프로젝트는 예전 버전 앱에서 열리지 않습니다.** 팀원과 같이 쓴다면 앱 버전을 맞추세요.
- 프리셋이 만든 메시나 파라미터의 이름, 범위, 계층을 일반 편집기에서 바꿔도 됩니다. 그 수정은 해당 부품에 저장되어, 부품을 껐다 켜도 유지됩니다.
- 부품을 지웠다가 같은 종류를 새로 추가하면, **예전 부품에 했던 손 수정은 따라오지 않습니다.** 되살리려면 지우기 대신 끄기를 쓰거나, 실행 취소로 되돌리세요.

## 7. 30초 요약

1. PSD를 열 때 **추천 수정자**를 그대로 둡니다.
2. 마음에 안 드는 움직임은 **체크 해제**합니다.
3. 세기는 부품을 고르고 **조정** 탭에서 바꿉니다.
4. 더 필요한 움직임은 메시를 고르고 **프리셋 추가**로 넣습니다.
5. 다 만들었으면 맨 아래 부품에서 **여기까지 적용**을 눌러 확정하고, 손으로 다듬습니다.
