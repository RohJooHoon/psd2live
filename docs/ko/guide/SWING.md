# 흔들림 생성

[문서 목록](../../README.md) · [中文](../../zh/guide/SWING.md) · [English](../../en/guide/SWING.md) · [물리](PHYSICS.md) · [MCP 사용법과 인터페이스](../agent/MCP_AUTHORING.md)

흔들림 생성은 Cubism Editor 5.1의 흔들림 자동 생성에 해당합니다. Warp 디포머를 선택하면 -1 / 0 / 1에서 흔들리는 키폼을 생성합니다. 여기에 더해 다음 기능도 있습니다.

- 메시도 받으며, 맞춤 Warp 디포머로 자동으로 감쌉니다.
- **좌우**와 **상하** 흔들림을 제공하며, 둘을 동시에 켤 수 있습니다.
- 끝을 수평으로 유지하고 아래쪽을 평행하게 흔들 수 있어, 디포머 하나로 여러 가닥의 머리카락이 함께 흔들리는 모습을 흉내 냅니다.
- 그에 맞는 **물리 진자**를 동시에 생성합니다.
- 설정을 프로젝트와 함께 저장하므로 언제든 다시 열어 조정할 수 있습니다.

## 여는 방법

- 캔버스(오브젝트 모드)에서 선택한 메시나 Warp 디포머를 오른쪽 클릭 → **흔들림 생성...**. 여러 개를 선택하면 모두 함께 등록됩니다.
- 계층에서 메시나 Warp 디포머를 오른쪽 클릭 → **흔들림 생성...**. 이미 흔들림이 있는 오브젝트에는 대신 **흔들림 편집...** 항목이 표시됩니다.
- 물리 패널 → **+ 새로 만들기** → **선택 항목에 흔들림 만들기…**. 물리 그룹 목록에서 흔들림에서 온 그룹은 "⋯" 메뉴의 **흔들림 편집**으로 엽니다.

열면 현재 캔버스가 (더 이상 미리보기가 아닌) 편집 캔버스로 전환되고 흔들림 편집이 시작됩니다. 편집은 캔버스 위에 창을 띄우지 않습니다. 형태는 캔버스에서 직접 끌어 만들고, 설정은 작업 공간 왼쪽 아래에 떠 있는 흔들림 패널에 있습니다. 제목을 클릭하면 패널이 접히고, 제목 표시줄의 "↗"는 패널을 별도 창으로 옮깁니다("↙"는 작업 공간에 다시 도킹).

- 여러 대상은 파라미터와 진자 한 세트를 공유합니다.
- 편집하는 동안 캔버스는 잠깁니다. 핸들이 아닌 곳을 클릭해도 다른 오브젝트가 선택되거나 끌리지 않으며, 컨텍스트 메뉴도 열리지 않습니다.
- 대상을 추가하려면 계층에서 다른 메시를 선택하고 패널의 **선택 항목 등록**을 클릭합니다.
- Rotation 디포머는 대상이 될 수 없습니다.

## 캔버스 조작

캔버스에는 흔들림 사각형(너비는 지점 변, 길이는 지점 변의 중점에서 반대쪽 변의 중점까지)의 윤곽 세 개가 그려집니다. 정지 형태(점선), +1 포즈(실선), -1 포즈(흐린 선)이며, 두 포즈의 중심선도 함께 그려집니다. 고정된 변은 더 굵게 그려집니다. 모든 핸들은 편집 중인 방향의 +1 포즈 위에 있으며, 핸들을 어디로 끌든 +1 포즈의 그 부분이 그곳으로 갑니다.

| 핸들 | 위치 | 드래그 효과 |
| --- | --- | --- |
| 점 | 끝 | 옆으로 끌면 양을 정하고, 반대쪽으로 넘기면 방향이 뒤집힘. 축을 따라 끌면 들림 / 처짐을 정함. 늘었다 줄었다 튀는 흔들림에서는 축 방향만 작용함 |
| 마름모 | 중심선 중점 | 부드러움을 정함. 가운데가 끝을 덜 따라갈수록 뿌리가 뻣뻣해짐 |
| 작은 사각형 | 끝의 두 모서리 | 끝이 넓어지거나 좁아지는 정도를 정함. 휠 때는 아래쪽이 얼마나 평행한지(끝 변이 얼마나 수평을 유지하는지)도 정함 |
| 십자 점 | 지점 변 중점 | 흔들림 사각형 전체를 옮기며, 지점 변의 중점이 포인터를 따라감 |
| 속이 빈 원 | 정지 중심선의 연장선 위, 끝 너머 | 지점 중점을 중심으로 흔들림 사각형 전체를 돌림(기울기). 포인터의 방향만 사용하며, 0° 근처에서는 0°로 스냅됨 |
| 속이 빈 사각형 | 나머지 세 변의 중점 | 클릭하면 그 변이 지점이 됨 |

모든 변경은 모델에 실시간으로 표시됩니다. 패널의 **흔들림 미리보기**는 파라미터를 -1과 1 사이에서 앞뒤로 흔듭니다(분할이 여럿이면 엇갈리게, 상하는 좌우와 엇갈리게). **생성** / **적용** 또는 Enter는 히스토리 항목 하나를 기록하며, **취소** 또는 Esc는 아무것도 바꾸지 않습니다.

## 두 가지 흔들림과 지점

**움직임**은 화면에서 끝이 움직이는 방향이고, **지점**은 고정된 채로 있는 변입니다(격자의 행과 열 기준이며, 0행이 위쪽 변). 둘의 조합이 변형을 결정합니다.

| 방향 | 지점 | 변형 | 대표적인 용도 |
| --- | --- | --- | --- |
| 좌우 | 위 / 아래 | 호 굽힘 | 머리카락 가닥, 리본, 꼬리 |
| 상하 | 왼쪽 / 오른쪽 | 호 굽힘 | 옆으로 튀어나온 장식, 옆 리본 |
| 상하 | 위 / 아래 | 신축 튐 | 귀걸이, 푹신한 머리카락 끝, 가슴 |
| 좌우 | 왼쪽 / 오른쪽 | 신축 튐 | 거의 쓰지 않음 |

- **호 굽힘**: 중심선을 따라 휘면서 길이를 유지하므로, 단순히 옮길 때처럼 늘어나지 않고 끝이 흔들려 나가면서 자연스럽게 올라갑니다.
- **신축 튐**: 끝이 지점 방향을 따라 늘어나거나 줄어듭니다. 늘어나면 좁아지고 눌리면 넓어져 부피감이 유지됩니다.
- **자동 지점**:
  - 길고 가는 오브젝트는 위쪽 변을 택합니다.
  - 가로로 긴 오브젝트는 몸의 중심선에 가까운 쪽을 택합니다.

### 흔들림 사각형 돌리기와 옮기기

기본적으로 흔들림 사각형은 디포머에 맞춰져 있습니다. 원화가 비스듬히 늘어져 있는데(옆머리, 비스듬한 장식) 디포머는 똑바로 선 사각형이라면, 끝 너머의 속이 빈 원을 끌어 지점 변의 중점을 중심으로 흔들림 사각형 전체를 ±75° 안에서 돌립니다.

- 양수 값은 끝을 지점 변의 끝(지점이 위 / 아래이면 오른쪽 끝, 왼쪽 / 오른쪽이면 아래쪽 끝) 쪽으로 돌립니다. 부모 공간이 반전되어 있으면 이것도 반전됩니다.
- 사각형은 크기를 유지하고 방향만 바뀝니다. 굽힘은 돌린 축에 수직이며, 호 길이 유지, 들림, 늘어남, 평행은 모두 돌린 사각형 안에서 계산됩니다. 캔버스의 윤곽, 고정 변, 지점, 끝 핸들도 함께 돌아갑니다.
- 고정된 채로 있는 것은 사각형의 지점 변입니다. 그 뒤쪽은 모두 제자리에 있고, 원래 격자 변의 끝이 지점 변보다 앞으로 나와 있는 곳은 뿌리 근처에서 굽힘에 따라 조금 움직입니다.
- 지점 변 중점의 십자 점을 끌면 사각형 전체가 옮겨집니다. 예를 들어 지점을 실제 머리카락 뿌리가 있는 곳까지 내려서 그 위쪽은 제자리에 있게 할 수 있습니다. 회전은 옮긴 중점을 중심으로 이루어집니다.
- 오프셋은 사각형 자체를 기준으로 저장됩니다. 축 방향은 길이 기준, 지점 변 방향은 너비 기준(각각 ±1)이므로, 대상 디포머의 키폼이 어떻게 크기가 바뀌거나 옮겨지든 모든 키폼에서 원화의 같은 지점에 놓입니다.
- 기울기와 오프셋은 흔들림 전체에 속하며 두 방향이 공유합니다. 패널에 현재 값이 표시되며, 각각의 **초기화**로 기본값을 복원합니다. 다른 변을 클릭해 지점을 바꾸면 둘 다 초기화됩니다. 이전에 저장한 흔들림은 0으로 열립니다.

### 좌우와 상하 함께 쓰기

패널의 **움직임**에서 두 옵션을 동시에 체크할 수 있으며, 둘 다 같은 디포머에 작용합니다.

- 각 방향은 자체 파라미터, 형태 설정, 진자를 가집니다.
- 한 지점에서는 하나가 반드시 굽힘이고 다른 하나는 신축입니다. 생성은 신축을 먼저 적용한 다음 굽힘을 적용하므로, 합쳐진 포즈는 두 결과의 단순한 합이 아니라 정확합니다.
- 두 방향이 모두 켜져 있으면 패널에 **편집 중** 행이 생기며, 캔버스 핸들이 어느 방향을 조작할지 고릅니다.

## 평행한 아래쪽 (여러 가닥의 머리카락)

머리카락이 나뉘어 있지 않으면 왼쪽 옆머리, 앞머리, 오른쪽 옆머리가 모두 한 디포머 안에 있습니다. 일반적인 굽힘은 각 단면을 중심선과 함께 돌리기 때문에 전체가 판자처럼 돕니다. 끝 변이 기울어 한쪽은 올라가고 다른 쪽은 내려가서 어색해 보입니다.

평행 설정은 단면이 얼마나 도는지를 조절합니다.

- **0**: 단면이 굽힘과 함께 돌아 전체가 판자처럼 흔들립니다. 단일 가닥과 장식에 적합합니다.
- **1**: 단면이 수평을 유지하고 끝 변이 기울지 않습니다. 각 열은 고정 변의 자기 자리에 매달려 이웃과 나란히 움직이므로, 여러 가닥의 머리카락이 함께 흔들리는 것처럼 보입니다.
- 중심선의 호는 영향을 받지 않으므로 양, 들림, 부드러움의 의미는 같습니다.
- 앞머리처럼 고정 변에 가까운 짧은 가닥은 원래 굽힘이 작은 곳에 있어 자연히 덜 흔들립니다. 나눌 필요도, 디포머를 추가할 필요도 없습니다.

머리카락과 천 프리셋은 기본적으로 평행 쪽에 가깝고(머리카락 좌우 0.7), 액세서리 프리셋은 0을 사용합니다. 캔버스에서 끝의 두 모서리에 있는 작은 사각형을 끌어 조정합니다.

## 설정

패널에는 캔버스에 둘 곳이 없는 옵션(움직임, 편집 중, 추정, 분할 수, 자동 지점, 물리)만 있으며, 나머지 항목은 현재 방향에 대해 읽기 전용으로 표시됩니다.

| 설정 | 효과 |
| --- | --- |
| 흔들림 양 | ±1에서 끝이 얼마나 움직이는지. 지점에서 끝까지의 길이에 대한 비율(0.25 = 길이의 4분의 1) |
| 들림 / 처짐 | 휠 때 끝이 추가로 올라가는 정도(양수) 또는 처지는 정도(음수) |
| 부드러움 | 0: 전체 길이가 고르게 휨. 1: 뿌리는 곧게 유지되고 주로 끝이 움직임 |
| 넓힘 / 좁힘 | ±1에서 끝 근처가 넓어지거나 좁아짐 |
| 평행 | 0: 전체가 판자처럼 돎. 1: 끝 변이 수평을 유지하고 열들이 나란히 흔들림 |
| 기울기 | 지점 중점을 중심으로 흔들림 사각형을 돌린 각도(±75°). 비스듬한 원화용 |
| 오프셋 | 흔들림 사각형의 지점 변 중점이 축 방향 / 지점 변 방향으로 옮겨진 정도. 길이 / 너비 기준 |
| 좌우 반전 | +1과 -1 방향을 맞바꿈 |
| 분할 수 | 방향마다 1–3개의 분할, 분할마다 파라미터 하나. k번째 분할은 그 아래 부분만 휨. 물리에서는 여러 마디로 된 진자 하나를 공유하며, 아래 분할일수록 위 분할보다 한 박자 늦어 채찍 같은 추종 움직임이 생김 |
| 추정 | 머리카락 / 액세서리 / 천. 초기 형태와 진자 값 세트를 제공하며, 진자 길이는 대상의 픽셀 길이로 추정함 |

없는 파라미터는 자동으로 만들어지며(범위 -1..1), 이름은 `ParamSwing<id>`입니다. 두 방향이 모두 켜져 있으면 `_X`(좌우) / `_Y`(상하)가, 분할이 여럿이면 `_1`, `_2`…가 붙습니다. 방향이나 분할 수를 바꾸면 이 규칙에 따라 파라미터 이름이 바뀝니다. 기존 파라미터를 고르면 키는 그 파라미터의 최솟값, 기본값, 최댓값에 놓입니다.

이전에 저장한 흔들림에는 평행 설정이 없으므로 0으로 열리며 예전 모습을 유지합니다.

## 물리

**이 흔들림의 진자 생성**을 체크하면 내보낸 physics3.json과 cmo3에 진자 물리 그룹이 추가됩니다.

- 방향마다 진자 하나. 방향이 하나이면 그룹 이름은 `PhysicsSwing_<id>`, 둘이면 `PhysicsSwing_<id>_X`와 `PhysicsSwing_<id>_Y`입니다.
- **좌우**: 앞머리, 뒷머리와 같은 입력으로, 머리와 몸의 각도 X(X 종류)와 각도 Z(각도 종류)입니다.
- **상하**: 머리와 몸의 각도 Y를 입력으로 하고, 작은 가중치로 각도 Z를 더합니다.
  - Cubism의 진자 막대는 강체이며, 수직으로 매달린 진자는 수직 이동에 반응하지 않습니다.
  - 그래서 여기서는 각도 Y를 옆 방향(X 종류) 자극 입력으로 쓰고, 진자의 각도가 세로 형태를 구동합니다.
- **분할 수**: 각 분할은 물리 그룹의 진자 하나이며, k번째 분할의 파라미터는 진자 k의 출력으로 구동됩니다.

진자는 [물리 패널](PHYSICS.md)에도 나열되며, 거기서 직접 편집할 수 있습니다(입력, 출력, 각 진자의 동역학 등). 물리 패널에서 변경하면 물리 패널의 버전이 우선하고 흔들림 패널의 진자 값은 적용되지 않으며, 패널이 이를 알려 줍니다. 물리 패널의 **생성값으로 초기화**는 흔들림에서 생성된 진자로 되돌립니다. 같은 출력 파라미터에 대해 만든 사용자 지정 그룹은 해당 진자를 대체합니다. 흔들림을 삭제하거나 방향을 바꾸면 이전 진자에 대한 편집도 지워집니다.

## 생성기 의미와 베이크

흔들림은 "생성기"입니다. 모델을 다시 빌드할 때마다 대상 디포머의 현재 형태에서 다시 계산되고, 흔들림 축이 그 뒤에 덧붙여집니다. 따라서 다음과 같습니다.

- 대상의 기존 키 축(예: 각도 X)은 모두 유지됩니다. 기존 키폼 각각이 흔들림의 각 형태로 확장됩니다.
- 흔들림 축은 흔들림에 속하며, 그 축에서 직접 편집한 키폼은 다시 빌드할 때 덮어써집니다.
- 직접 미세 조정하려면 패널의 **키로 베이크**를 클릭합니다.
  - 현재 형태가 일반 키폼으로 기록되며, 이후 자유롭게 편집할 수 있습니다.
  - 진자는 유지되며, 흔들림의 물리 부분만 남습니다.
- **삭제**는 흔들림과 함께 생성된 축과 자동으로 만든 파라미터를 제거합니다.

## 에이전트

MCP에서는 `swing_put`이 흔들림을 만들거나 교체하고 `swing_delete`가 삭제합니다. 인수는 `{"request": {...}}`에 넣으며, `project_id`, `state`, `request_id`를 함께 보냅니다.

- `swing_put`은 `id`로 기록하며, `targets`는 메시나 Warp 디포머입니다. 한 방향이라면 `kind`(`lateral` / `vertical`), `segments`, `parameters`와 형태 필드(`magnitude`, `lift`, `softness`, `zoom`, `parallel`, `flip`)를 최상위에 바로 씁니다.
- 두 방향을 함께 쓰려면 `motions: [{kind: "lateral", ...}, {kind: "vertical", ...}]`를 사용하며, 각 항목은 자체 필드, 파라미터, `physics`를 가집니다.
- 최상위의 `fulcrum`은 지점 변을 고르고, `tilt`는 지점 중점을 중심으로 한 흔들림 사각형의 회전(도, ±75)이며, `offset_along` / `offset_across`는 사각형의 오프셋(길이 / 너비 기준, ±1)으로, 두 방향이 공유합니다. `preset`(`hair` / `accessory` / `cloth`)은 패널의 추정에 해당합니다.
- `physics`를 생략하면 진자는 대상의 크기에서 추정되며, `physics_enabled=false`이면 진자를 생성하지 않습니다.
- `bake=true`를 준 `swing_delete`는 **키로 베이크**와 같습니다.

캔버스에서의 흔들림 편집은 미리보기 세션에 해당하며, 커밋할 때까지 문서와 히스토리에 들어가지 않습니다. `swing_preview`는 `mode=begin`과 `targets`로 시작하고, 이어서 `update`, `kinds`, `segments`, `preset`, `physics`, `select`, `handle`(캔버스 핸들과 같음), `play`, `cancel`로 수정합니다. `swing_preview_get`은 초안, 핸들 위치, 재생 포즈를 읽고, `swing_preview_render`는 현재 포즈를 렌더링하며, `swing_preview_commit`은 한 번에 커밋합니다. `swing_preview`와 `swing_preview_commit`은 백그라운드 작업 핸들을 반환하므로 `job_wait`로 결과를 받으세요.

`workspace_inspect`에 `scope=swings`를 주면 현재의 모든 흔들림을 나열합니다.
