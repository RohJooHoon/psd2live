# 사용자 빠른 참조

[문서 목록](../../README.md) · [中文](../../zh/guide/USER_GUIDE.md) · [English](../../en/guide/USER_GUIDE.md) · [日本語](../../ja/guide/USER_GUIDE.md)

먼저 `F1`을 눌러 도움말 페이지의 **튜토리얼**을 여세요. 대화형 강좌가 해당 컨트롤을 강조 표시하고 설정된 단축키를 보여 줍니다. 이 문서는 같은 강좌 순서를 따르는 짧은 보조 자료입니다.

## 기본 작업 흐름

PSD 가져오기(`Ctrl+Shift+O`) → 분류 확인과 미리보기 → 편집 → 저장(`Ctrl+S`) → 내보내기(`Ctrl+G`). 기존 `.psd2live` 프로젝트는 `Ctrl+O`로 엽니다.

기존 Cubism 모델은 **파일 → 새로 만들기 → CMO3에서 새 프로젝트…** 또는 **모델 → CMO3로 모델 교체…**로 엽니다. **CMO3로 모델 교체…**는 파일에 있는 오브젝트를 ID 기준으로 교체하고 새 오브젝트를 추가하며, 파일에 없는 것은 그대로 둡니다. **CMO3에서 새 프로젝트…**는 먼저 현재 모델을 비우므로 모델이 그 CMO3만으로 만들어집니다. 둘 다 프리셋을 생성하지 않으며, 가져온 파라미터, 키폼, 디포머, 텍스처, 물리는 프로젝트와 함께 저장됩니다.

## 시작, 도움말, 설정 페이지

작업 공간 띠의 맨 앞에는 앱 자체의 페이지인 **시작**, **도움말**, **설정**이 있습니다. 이 페이지들은 프로젝트와 함께 저장되지 않으며 대화 상자도 아닙니다. 패널이 편집기의 패널처럼 동작하므로 헤더를 드래그해 다시 도킹하거나, 패널을 탭으로 합치거나, 떼어 내 떠 있는 창으로 만들거나, 닫을 수 있습니다. **창** 메뉴로 닫은 패널을 다시 열고, 메뉴 끝의 **레이아웃 재설정**으로 기본 배치를 복원합니다. 페이지의 레이아웃은 로컬 환경 설정에 저장되어 다음 실행에도 유지됩니다.

**시작**은 실행할 때 표시됩니다. 프로젝트를 열거나 가져오거나 만들면 그 작업 공간으로 전환되고 시작 탭은 접힙니다. **파일 → 시작 페이지**나 빈 캔버스의 **시작으로**로 다시 불러옵니다. 세 페이지는 모두 같은 구조입니다. 왼쪽에 목차, 가운데에 고른 주제가 있고, 시작 페이지에는 동작이 무엇을 하는지 설명하는 상세 패널이 오른쪽에 더 있습니다. 주제 패널의 이름은 고른 항목을 따르며, 시작 페이지에서는 그 아래 동작 바에 주 버튼이 있고 `Enter`로도 누를 수 있습니다. ↑ / ↓로 목차를 이동합니다.

- **PSD에서 생성**: 상세 패널 위쪽에서 프리셋(최소 / 기본 / 전체)을 고르고 필요하면 각 값을 설정한 뒤, 창 아무 곳에나 PSD를 끌어다 놓거나, 뷰포트 또는 **생성…**을 클릭해 고릅니다. 모델은 편집 작업 공간에서 열립니다. 뷰포트 아래 **최근 PSD**에서 클릭하면 PSD를 뷰포트에 미리 보고, 더블클릭(또는 미리 본 뒤 **생성**)하면 표시된 프리셋으로 생성합니다. 썸네일 크기는 바꿀 수 있습니다. 프리셋은 기억되며, 메뉴나 최근 파일, 끌어다 놓기로 가져온 PSD에도 쓰입니다. **생성** 메뉴로 프리셋을 바꾸거나 열린 모델에 적용합니다. 한 레이어에 함께 그린 좌우 파츠는 **모델 → 메시별로 레이어 나누기…**로 나눕니다.
- **레이아웃 프로젝트**: 캔버스 미리보기와 크기를 한 패널에서 설정합니다. 왼쪽에는 비율대로 그린 캔버스, 오른쪽에는 자주 쓰는 크기(더블클릭으로 생성)와 너비, 높이가 있으며, 어느 자주 쓰는 크기와도 맞지 않으면 "사용자 지정"으로 표시됩니다. **레이아웃 프로젝트 만들기**를 클릭하거나 `Enter`를 누릅니다. 상세 패널에서 가져오기, 배치, 생성 단계와 캔버스 단위의 의미를 설명합니다.
- **CMO3 가져오기**: Cubism 모델로 새 프로젝트를 만들며, 현재 모델은 먼저 비웁니다. 상세 패널에 가져오기가 유지하는 항목이 나열되며, 모델이 열려 있으면 열린 모델의 오브젝트를 ID 기준으로 교체하는 **CMO3로 바꾸기…**도 제공합니다.
- **최근**: 페이지가 처음 열리는 곳입니다(최근 파일이 아직 없으면 대신 PSD에서 생성으로 열림). 최근 프로젝트와 PSD를 소재 패널이 이미지를 나열하는 방식처럼 그리드 또는 목록으로 보여 주며, 검색, 종류 필터, 썸네일, 수정 시각, 크기가 있습니다. 프로젝트의 썸네일은 저장할 때 기록되며, PSD는 포함된 썸네일이나 합성 이미지를 보여 줍니다. 더블클릭으로 열고, 상세 패널에서 폴더를 보거나 목록에서 파일을 제거합니다.
- **새 기능**: 버전별 릴리스 노트를 읽을 수 있는 텍스트로 보여 주며, 상세 패널에 이동할 버전이 나열됩니다. 대화형 튜토리얼이 있는 변경 사항은 그 튜토리얼로 연결되고, **전체 변경 내역**은 릴리스 페이지를 엽니다.

제목 표시줄의 메뉴는 **파일**, **보기**, **모델**, **도움말**입니다. **모델**에는 모델 전체에 작용하는 기능(PSD 다시 분석, CMO3로 교체, 메시별로 레이어 나누기, 텍스처 고해상도화, 생성 결과 업데이트)이 모여 있습니다. **도움말**에서 **도움말**은 도움말 페이지를 열고, **온라인 자료**는 GitHub 저장소, 문서, 예제 저장소, 릴리스, 이슈 트래커를 엽니다. 제목 표시줄 오른쪽에는 사이드바 토글, 언어, 라이트/다크 테마, **설정**(톱니바퀴)이 있습니다.

**도움말**(`F1`. 다시 누르면 작업 공간으로 돌아감)의 목차는 **매뉴얼**과 **튜토리얼** 두 트리에 이어 예제, 커뮤니티와 링크, 서드파티 라이선스, 정보로 이루어집니다. 매뉴얼과 튜토리얼은 Cubism Editor 매뉴얼과 튜토리얼 사이트의 폴더와 순서를 따르며, 각 페이지에는 Cubism과 **동일**하게 작동하는지, **조작 다름**인지, PSD2Live **고유** 기능인지, 아직 **미구현**인지(회색으로 표시되며 열 수 없음)를 나타내는 색 태그와 해당 Cubism 페이지 링크가 붙습니다. 위쪽 입력란에서 제목으로 페이지를 찾습니다. 대화형 튜토리얼은 해당 글 안에 **대화형 튜토리얼** 태그가 붙은 버튼으로 나타나며, 두 코스의 전체 경로는 **매뉴얼 → 시작하기 전에 → 제작 흐름**에 있습니다. 각 매뉴얼 페이지는 **MCP와 도구**로 끝나며, 실행 중인 서버가 설명하는 대로 해당 MCP 작업과 요청 필드를 나열합니다. 레이어 규격은 **매뉴얼 → 소재 나누기 · PSD 작성 → PSD 생성상의 주의점**에, 단축키는 **매뉴얼 → 에디터 정보 → 단축키 목록**(필터 포함)에 있습니다. **설정**(`Ctrl+,`)의 목차는 배율 및 디스플레이, 테마, 언어, 표시, 그래픽, 안내 창, 단축키, 파일과 데이터, MCP이며, 변경은 바로 적용됩니다(MCP 포트, 토큰 등은 **적용 후 다시 시작**이 필요). 배율 및 디스플레이는 디스플레이에 권장되는 배율을 제시하고 해상도와 시스템 배율을 보여 줍니다. 표시에는 창 모드(창, 최대화, 전체 화면. 최대화는 작업 표시줄이 보이고, 전체 화면은 작업 표시줄을 덮으며 제목 표시줄은 유지)가 있으며, `F11`로 전체 화면에 들어가거나 나옵니다. 그래픽은 게임처럼 배치되어 있습니다. 화질 프리셋(낮음, 중간, 높음, 최고, 그 밖의 조합은 사용자 지정)이 안티앨리어싱, 텍스처 필터링, GPU 캐시를 한꺼번에 정합니다. 디스플레이 및 성능에서는 렌더링 경로(GPU, 소프트웨어 캔버스를 쓰는 GPU 창, 모두 소프트웨어), 그래픽 카드(시스템 기본값, 고성능, 절전, Linux에서는 카드별 이름), 수직 동기화(켜기 또는 끄기, Windows에서는 적응형도), 미리보기의 최대 프레임 속도와 백그라운드 프레임 속도, Linux에서는 드라이버 스레딩을 고릅니다. 안티앨리어싱은 창(Skia 커버리지 또는 MSAA 2×–16×), 캔버스와 미리보기(끄기, MSAA 2×–8× 또는 SSAA 2×. 편집 캔버스, 아틀라스 페이지, p2lrt 미리보기에 적용), 텍스처 필터링(쌍선형, 삼선형, 이방성 4×–16×)을 다룹니다. 고급에는 창 캐시, GPU 캐시 크기, 성능 오버레이(창 오른쪽 위에 프레임 속도, 프레임 간격, 프레임당 UI 스레드 시간, 프레임별 막대)가 있습니다. 각 설정 아래에 선택한 값이 무엇을 하는지 설명하고 지금 캔버스를 어떻게 그리고 있는지 보여 줍니다. 모두 소프트웨어 경로, 그래픽 카드, 수직 동기화 끄기, 드라이버 스레딩은 페이지에 표시된 대로 다음 실행에 적용되고 나머지는 바로 적용됩니다. 캔버스가 잘못 표시되면 먼저 "GPU 창, 소프트웨어 캔버스"를, 창 자체가 그려지지 않으면 "소프트웨어"를 시도하세요. 파일과 데이터에서는 최근 파일을 지우고, 마지막 내보내기 폴더를 열고, 앱 설치 위치와 작업 공간, 내려받은 런타임, 고해상도화 캐시, 오류 로그, 명령줄 MCP 저장소의 위치와 크기를 보여 주며, 고해상도화 캐시와 로그를 지우고, 이전의 비정상 종료가 시스템 임시 폴더에 남긴 것을 지우고, 설정이 어디에 저장되는지 알려 줍니다. MCP에는 예전 **도구 → MCP…** 대화 상자의 내용이 있습니다. **파일 → 폴더 열기**는 프로젝트, 원본 파일, 출력의 폴더와 작업 공간 저장소, 앱 데이터 폴더를 엽니다. 목차 아래의 **기본값으로 초기화**는 모든 설정을 초기화합니다. 도움말과 설정 탭은 마우스를 올렸거나 표시 중일 때 닫기 버튼을 보여 줍니다.

프로젝트가 열려 있지 않으면 다른 작업 공간의 캔버스에는 안내와 **시작으로**만 표시됩니다.

## 작업 공간

UI는 작업 공간 탭으로 구성되며, 탭마다 고유한 캔버스와 패널 레이아웃이 있습니다. 탭 바 끝의 **+**를 클릭하면 8가지 프리셋이나 빈 레이아웃에서 하나를 추가하며, 오른쪽에 레이아웃과 용도가 미리 표시됩니다. 스크린샷은 중국어 UI입니다.

![새 작업 공간 메뉴](../../imgs/workspace-presets.webp)

| 프리셋 | 용도 |
| --- | --- |
| 편집 | 디포머, 키폼, 본을 위한 편집 캔버스 하나와 모든 속성 패널 |
| 메시 | 메시 토폴로지를 위한 계층, 편집 캔버스, 메시 패널 |
| 리깅 | 실시간 미리보기 옆의 편집 캔버스와 도킹된 파라미터 패널 |
| 애니메이션 | 모션 목록, 미리보기 캔버스, 애니메이션 편집기 |
| 미리보기 | 모션 목록만 있는 큰 미리보기 |
| 물리 | 파라미터와 물리 패널이 있는 미리보기 캔버스. 모델을 움직이며 조정 |
| 텍스처 | 아틀라스 페이지, 편집 캔버스, 텍스처 패널. 레이어별 픽셀 크기를 확인하고 조정 |
| 히스토리 | 히스토리 트리와 작업 목록만 있음. 히스토리를 둘러보고 체크아웃 |
| 빈 작업 공간 | 빈 도크. **창** 메뉴에서 캔버스와 패널을 추가 |

**레이아웃 재설정**은 현재 작업 공간의 프리셋 레이아웃을 복원합니다.

탭으로 묶인 패널 그룹에서는 탭 띠의 빈 부분과 끝의 희미한 손잡이로 그룹 전체를 드래그합니다. 다른 패널의 가장자리에 놓으면 그 옆으로 나뉘고, 다른 탭 띠에 놓으면 그 탭으로 합쳐집니다. 빈 부분이나 아무 탭이나 오른쪽 클릭하면 **모든 탭 닫기**가 있습니다.

### 텍스처 작업 공간

모든 레이어에는 세 가지 크기가 있습니다. 캔버스에서 덮는 사각형(캔버스 단위), 자체 래스터의 픽셀, 텍스처 아틀라스 안 타일의 픽셀입니다. 텍스처 작업 공간은 이 셋을 나란히 보여 주고 레이어별로 조정합니다.

- **아틀라스**(왼쪽): 페이지 이미지가 보기를 채우며 편집 캔버스처럼 조작합니다. 휠은 확대/축소, 가운데 버튼 또는 Space + 드래그는 이동, `F`는 선택에 맞추기, `Home` / `0`은 페이지에 맞추기, `Ctrl+A`는 페이지의 모든 타일 선택입니다. 타일을 클릭하면 그 레이어가 선택되고, 빈 페이지 위를 드래그하면 선택 상자가 그려지며(편집 캔버스처럼 Shift는 추가, Alt는 빼기), 캔버스와 레이어 목록과 동기화됩니다. **타일을 드래그**하면 픽셀이 포인터를 따라 실시간으로 움직이고 놓은 자리에 남습니다. 메시가 다른 타일의 메시와 만나는 곳(사각형이 아니라 메시가 쓰는 셀 기준)에 놓으면 움직이지 않으며 타일이 빨갛게 표시되고, 페이지 가장자리를 넘는 곳도 마찬가지입니다. 선택한 타일에는 편집 캔버스의 변환 상자가 붙습니다. 위쪽 변 밖의 **둥근 핸들**, 또는 모서리 바로 바깥(포인터 아래에 화살표 달린 호가 켜지는 곳)을 드래그하면 **기준점**을 중심으로 아무 각도로나 회전하며(Shift는 15°씩), 겹침도 회전한 메시로 판정합니다. 기준점(링이 둘린 십자)은 타일 중심에서 시작하고 어디로든 드래그할 수 있으며, 중심, 모서리, 변 중점에 스냅됩니다. 이동, 크기 조절, 회전은 페인트 모드처럼 **편집 세션**입니다. 아틀라스 페이지에 보이는 것만 바꾸고 아무것도 다시 만들지 않으므로 완전히 매끄럽습니다. 무언가 바뀌면 페이지 위쪽 가운데에 페인트 모드와 같은 세션 바가 내려와 바뀐 타일 수를 세고, 실행 취소/다시 실행(Ctrl+Z / Ctrl+Shift+Z), 취소, **적용**(또는 Enter)을 제공합니다. 적용하면 모두 한 단계로 커밋되어 재구성 한 번, 히스토리 노드 하나가 됩니다. 좁은 보기에서는 버튼이 아이콘만 표시하고 마우스를 올리면 이름이 나옵니다. 세션에 변경이 있는 동안 배치, 자동 배치, 예산, 잠금, 이미지 교체는 세션을 기다립니다. **선택한 타일의 모서리를 드래그**하면 반대쪽 모서리까지의 거리에 따라 단계 없이 연속으로 밀도가 조절되며, 반대쪽 모서리(Alt를 누르면 기준점)는 고정되고, 드래그하는 동안 타일이 새 크기로 표시됩니다. 나머지 선택도 같은 비율로 조절되어 세션에 들어갑니다. 다른 타일의 메시 위로 커진 타일은 빨갛게 표시되고 놓아도 아무것도 바뀌지 않습니다. 이동도 스냅되지 않고 포인터를 따라갑니다. 텍스처 패널의 밀도 슬라이더를 드래그해도 같은 방식으로 페이지와 크기 카드에 새 크기를 미리 보여 줍니다. 더블클릭하면 타일에 맞춥니다. 타일을 오른쪽 클릭하면 밀도를 두 배, 절반으로 하거나 재설정하고, 90° 회전하거나 똑바로 되돌리고, 페이지가 여러 개일 때 N페이지로 옮기고(왼쪽 위부터 다른 타일의 메시와 만나지 않는 첫 자리로, 세션에 들어감. 페이지에 공간이 없으면 거부), 크기를 잠그거나 풀고(선택 중 일부가 잠겨 있으면 항목에 몇 개인지 표시하고 나머지를 잠금), 선택한 타일을 배치하거나 이미지를 교체합니다. 빈 페이지를 오른쪽 클릭하면 모든 타일 배치, 페이지를 PNG로 저장(내보내기가 쓰는 것과 바이트 단위로 같음), 모두 선택, 페이지에 맞추기가 있습니다. 세션에 변경이 있는 동안에는 메뉴가 세션을 기다리는 명령 위에 그렇게 표시합니다. 페이지 번호의 툴팁은 페이지 크기, 타일 수, 채움률을 알려 줍니다. 왼쪽 위에는 편집 캔버스의 모드 바 같은 떠 있는 바가 있습니다. **배치** 버튼은 한 번 배치하고 결과를 유지하며, 드롭다운에는 옵션만 있습니다. 방식은 메시 모양 기준(기본값: 메시가 실제로 덮는 영역으로 타일이 맞물리며 가장 촘촘함) 또는 사각형 기준 중에서, 범위는 모든 타일 또는 선택한 타일만 중에서 고릅니다. **자동 배치** 버튼은 켜져 있는 동안 불이 들어오는 토글입니다. 켜면 변경이 있을 때마다 아틀라스가 사각형 기준(MaxRects)으로 스스로 패킹됩니다. 끄면(새 프로젝트의 기본값) 레이아웃을 유지하며, 새 레이어나 자리에 더 이상 맞지 않는 타일은 조용히 빈 공간을 채우고, 그렇게 놓인 타일은 자리를 유지합니다. 다른 타일을 옮기거나 줄여서 생긴 공간을 뒤의 타일이 채우지는 않습니다. 페이지가 여러 개면 페이지 번호도 있습니다. 오른쪽 위에는 아틀라스 예산(페이지 크기 1024–16384, 최대 페이지 수, 여백)이 있습니다. 오른쪽 아래에는 편집 캔버스와 같은 표시 레일이 있으며 마우스를 올리면 넓어집니다. 텍스처, 메시 와이어프레임, 윤곽, **밀도 히트맵**(기본값은 꺼짐. 캔버스 단위당 아틀라스 픽셀: 1 미만은 파랑, 1 근처는 초록, 그 이상은 주황, 범례 ¼–4)이 있습니다. 왼쪽 아래 상태 알약은 포인터 아래나 드래그 중인 타일을, 그 밖에는 맞춤률과 점유율을 보여 줍니다. 맞춤률이 100% 미만이면 예산이 너무 작아 잠기지 않은 모든 타일이 함께 축소된다는 뜻이며, 이런 메모는 로그 패널에만 기록됩니다. 분할이 남긴 원본을 포함해 삭제된 레이어는 아틀라스 공간을 차지하지 않으며 표시되지 않습니다.
- **텍스처 패널**(오른쪽): 캔버스 → 원본 → 아틀라스 카드가 선택한 레이어의 캔버스 사각형, 원본 픽셀, 타일 크기를 보여 주며, 유효 밀도가 히트 척도에 표시됩니다. **텍스처 밀도** 슬라이더와 ½× / 2× / 재설정 버튼으로 배율(원본 픽셀당 아틀라스 픽셀, 1/64–16, 선택 전체에 적용)을 정하고, **크기 잠금**은 아틀라스를 줄여야 할 때 레이어의 크기를 유지합니다. 레이어 하나를 선택하면 **회전**에 타일의 각도를 입력할 수 있으며(**똑바로**로 재설정), 페이지에서 회전한 것처럼 세션에 들어갑니다. **이미지 교체…**는 캔버스 사각형을 유지한 채 아무 해상도의 픽셀로 바꾸며, 늘이기 또는 전체 맞춤과 선택적 메시 재구성을 고릅니다. **텍스처 고해상도화…**는 프로젝트의 고해상도화 설정을 엽니다. 정확한 캔버스 사각형은 **정확한 캔버스 사각형** 아래에 접혀 있습니다. 아무것도 선택하지 않으면 패널에 아틀라스 요약(각 페이지의 크기, 타일, 채움률, 빈 공간, 페이지가 차지하는 비디오 메모리(RGBA), 잠긴 타일, 맞춤률과 그 의미)과 예산이 표시되며, 예산도 열린 세션을 기다립니다. 내보내기 대화 상자는 아틀라스를 요약하고 텍스처 작업 공간으로 연결할 뿐이며, 알파 임계값은 메시 패널의 전역 설정으로 옮겨졌습니다.
- **원본 픽셀 미리보기**: 편집 캔버스 오른쪽 아래 보기 레일의 **원본 픽셀**을 켜면 그 캔버스가 아틀라스 타일 대신 각 레이어 자체의 래스터를 샘플링해, 패킹된 선명도와 비교할 수 있습니다. 캔버스마다 저장되며 켜져 있는 동안 그 캔버스를 소프트웨어로 그립니다. 미리보기 캔버스(Cubism 또는 PSD2Live 런타임)와 내보내기는 항상 아틀라스 픽셀을 씁니다.

작성한 편집, 바인딩, 구체화된 메시가 있는 레이어는 캔버스 사각형 이동이나 메시 재구성을 동반한 이미지 교체가 거부되며, 이유는 아틀라스 페이지 위에 표시됩니다. 모든 변경은 히스토리 노드 하나이며 취소할 수 있습니다. 해당 에이전트 작업은 [MCP_AUTHORING.md](../agent/MCP_AUTHORING.md#텍스처와-아틀라스)에 나열되어 있습니다.

## 튜토리얼 코스

목록에는 20개 주제가 있습니다. 입문자 코스는 아래 19강으로 이루어지며, 경험자 코스는 Cubism과 PSD2Live의 용어 대응으로 시작하고 일부 입문 강좌를 건너뜁니다. 기본 워크플로를 제외한 모든 장은 모델이 열려 있지 않으면 먼저 PSD를 가져오거나 프로젝트를 열라고 안내합니다.

| 강 | 주제 | 기억할 점 |
| --- | --- | --- |
| 1 | 기본 워크플로 | 레이어로 나뉜 원화를 가져와 파츠와 모델 프리셋을 확인한 다음 내보내기 형식을 고릅니다. 텍스처 아틀라스 설정은 내보내기 대화 상자에 있습니다. |
| 2 | 작업 공간 | 편집은 모델을 바꾸고, 미리보기는 모델을 보여 주며, 히스토리는 버전을 복원합니다. 캔버스 탭마다 고유한 카메라와 오버레이가 있습니다. |
| 3 | 계층 및 모드 바 | 오브젝트를 선택, 검색하고 부모를 바꿉니다. 투명 원화를 트리에 놓고 배치를 확정합니다. 그리기 순서와 부모 변형은 서로 다릅니다. |
| 4 | 차분 | 없음은 태그가 가리키는 파츠를 리깅합니다. 토글 차분은 표시/숨기기이고, 전환 차분은 ID가 다른 파라미터 하나를 공유합니다. |
| 5 | 소재와 배치 | Layout 프로젝트를 시작하거나 PSD를 가져오고, 소재를 가져와 정리하고, 캔버스에 끌어다 놓고, 파츠에 태그를 붙여 생성합니다. 나중에 더 배치하고 태그를 바꿔 다시 생성해도 편집은 유지됩니다. [소재와 Layout](LAYOUT.md)을 참고하세요. |
| 6 | 파라미터 및 키폼 | 슬라이더나 XY 컨트롤을 드래그하고, 키 표시를 오른쪽 클릭해 맞춥니다. 키폼을 편집하기 전에 목표 키로 이동합니다. |
| 7 | 오브젝트 모드 | 캔버스 도구나 계층으로 오브젝트를 선택합니다. 선택만으로는 기하가 바뀌지 않습니다. |
| 8 | 디포머 생성 | 대상을 선택하고 툴바의 만들기 그룹이나 트리 컨텍스트 메뉴를 쓴 뒤, 배치 미리보기를 조정하고 확정합니다. |
| 9 | 변형 모드 | 현재 파라미터 포즈에서 점을 편집하거나 브러시를 씁니다. Warp 디포머에서는 정점과 베지어 수준을 전환하고(키 1 / 2), 메시에서는 정점, 변, 면 단위로 점을 고릅니다. |
| 10 | 편집 모드 | 메시 요소를 세분화, 연결, 자르기, 제거합니다. 그다음 기존 포즈를 확인합니다. |
| 11 | 페인트 모드 | 레이어를 선택하고 픽셀을 칠하며 세션 안의 실행 취소를 씁니다. 세션을 적용하거나 폐기합니다. |
| 12 | 인스펙터 | 선택한 오브젝트의 속성(이름, 소속, 마스크, 그리기 순서, 불투명도, 색)을 편집합니다. |
| 13 | 도구 옵션 | 캔버스 왼쪽 아래의 옵션 바에서 현재 도구의 반경, 경도, 강도 등을 설정합니다. 컨텍스트 메뉴는 같은 값에 도구의 동작을 더해 보여 주며, 도구 상세 패널에는 고급 설정이 있습니다. |
| 14 | 스켈레톤 리깅과 편집 | 스켈레톤 모드에서 본을 만들고, 돌출하고, 복제하고, 미러합니다. 아트메시를 일괄 바인딩하고, FK/IK로 포즈를 잡고, 스킨 가중치를 칠하고 정리하며, 포즈를 저장합니다. 패널에서 파라미터 샘플링 한도를 설정합니다. 내보내기는 이를 Cubism 파라미터, 디포머, 키폼으로 베이크합니다. |
| 15 | 애니메이션 편집기 | 각 프리셋의 조절 항목으로 생성된 모션을 다듬습니다. 자동 키, 기본 베지어 이징, 트랙 키 표시, 캔버스 간 포즈 공유와 함께 타임라인에서 파라미터 트랙과 키프레임을 편집합니다. |
| 16 | 캔버스에서 물리 조정 | 입력, 진자, 출력을 설정한 뒤 관찰된 범위에 맞춰 출력 배율을 보정합니다. |
| 17 | 천과 머리카락 시뮬레이션 | 모델 프리셋의 물리와 시뮬레이션 그룹에서 머리카락과 옷 시뮬레이션을 생성하고(없으면 먼저), 머리카락 모드와 옷 옵션을 익힙니다. 그다음 시뮬레이션 패널에서 바디를 확인하고, 시뮬레이션 모드에서 고정, 강성, 형태, 질량, 감쇠 가중치를 칠하고 이해하며, 글루, 재질 프리셋과 값, 입력과 출력, 베이크 옵션을 설정하고, 파라미터, 키폼, Cubism 진자로 베이크합니다. 내보내지는 것은 베이크뿐입니다. |
| 18 | 프로젝트와 히스토리 | 프로젝트를 저장하고, 간결한 히스토리 트리에서 노드를 검색하고, 분기 경로를 강조하거나, 더블클릭해 체크아웃합니다. 히스토리 트리는 기본적으로 연속된 선형 버전을 카드 하나로 합치며, 툴바의 간결 보기 토글로 노드별 전체 보기로 되돌립니다. 모든 단계는 왼쪽 작업 목록에 남으며, 하나를 체크아웃한 뒤 계속 편집하면 새 분기가 시작됩니다. 전용 히스토리 작업 공간 프리셋이 포함됩니다. 파일 > 최근 파일 열기로 최근 프로젝트와 PSD를 다시 엽니다. 모델 > 생성 결과 업데이트는 이 버전이 생성하는 결과 위에 편집을 병합합니다. |
| 19 | 텍스처 고해상도화 | 로컬 백엔드를 설정하고 2× / 4×를 고른 뒤 가장자리, 투명도, 내보내기를 확인합니다. |

## 중요한 구분

머리카락과 옷 시뮬레이션, 고정 가중치, 베이크, 내보내기 확인은 [시뮬레이션 그림 튜토리얼](SIMULATION_TUTORIAL.md)을 참고하세요.

- **저장과 내보내기**: 저장은 작업 공간과 히스토리를 보존하고, 내보내기는 대상 소프트웨어가 쓰는 모델 파일을 납품합니다. `.psd2live.json`은 보고서이지 프로젝트가 아닙니다. CMO3 내보내기는 모델의 모션도 같은 이름의 `.can3`에 기록하며, Cubism Editor의 Animator가 이를 cmo3 위에서 열고 편집합니다. 둘은 같은 폴더에, 같은 내보내기에서 나온 것으로 유지하세요.
- **내보내기 완료**: 내보내기(Live2D 모델, PSD, 다른 형식으로 내보내기의 모든 형식)가 끝나면 대화 상자가 닫히고 **내보내기 완료**가 파일 위치와 경고, 형식이 유지하지 못한 항목을 보여 주며 **폴더 열기**를 제공합니다. **닫고 다시 표시하지 않음**을 고르면 이후 내보내기는 로그와 상태 표시줄에만 보고합니다. **설정 › 안내 창**에 "다시 표시하지 않음"이 있는 모든 창(가져온 뒤의 시작 화면 포함)이 나열되며, 하나씩 다시 켜거나 **모든 안내 창 다시 표시**를 고를 수 있습니다.
- **키폼과 키프레임**: 파라미터 키의 키폼은 모델링에 속하며 키 사이에서 모델 형태를 보간합니다. 키프레임은 애니메이션 타임라인에 있으며 시점별 파라미터 값을 기록합니다.
- **변형과 편집**: 변형은 형태를 바꾸고, 편집은 제어 메시의 구조를 바꿉니다. 페인트는 격리된 적용/폐기 세션에서 픽셀을 바꿉니다.
- **표시와 차분**: 트리의 임시 단독 표시와 정적 레이어 표시는 편집을 확인하기 위한 것입니다. 파라미터로 구동하는 전환에는 차분이나 불투명도 키폼을 설정하세요.

### 앞뒤 분리: 한 레이어가 다른 파츠를 관통하게 하기

옷깃이 레이어 하나인데 "뒤 옷깃 → 목 → 앞 옷깃" 순으로 보여야 한다고 합시다. 계층에서 옷깃을 오른쪽 클릭해 **앞뒤 분리…**를 고르거나, 옷깃과 목을 선택하고 옷깃을 오른쪽 클릭해 **“옷깃”을(를) 앞뒤 레이어로 분리**를 고릅니다. 새 레이어 두 개가 원래 레이어 자리를 차지하며, 앞 레이어는 뒤 레이어를 따라가도록 글루됩니다. 그다음 앞 레이어에서 뒤 옷깃 부분을 지우고 적용합니다. 단계별 스크린샷과 세부 내용은 [앞뒤 레이어 분리 그림 튜토리얼](DEPTH_SPLIT.md)에 있습니다.

## 생성 결과와 이전 기록

**리그 모듈**: 새 프로젝트는 부위별(눈, 눈썹, 입과 얼굴 아래쪽, 머리와 얼굴, 머리카락, 몸, 옷, 표정, 모션)로 생성되며, 각 부위에는 기반과 하나씩 끌 수 있는 모듈이 있습니다. 웃는 눈이 있는 맞춤 눈꺼풀, 크게 뜨기, 감정 눈 모양, 시선을 따르는 눈꺼풀과 깜빡임의 여진, 눈꺼풀을 움직이는 맞춤 눈썹, 단계적으로 벌어지는 입, 모음, 얼굴 캡처 입 모양과 따라오는 턱, 깊이감 있게 도는 머리, 사슬로 된 머리카락, 치마, 리본, 가슴의 출렁임, 홍조와 그늘, 자연스러운 깜빡임과 시선입니다. **모델 프리셋 › 부위와 모듈**에 각 부위의 모듈이 스위치, 값, 각 모듈이 추가하는 파라미터와 키폼과 함께 나열됩니다. 프리셋은 중요도에 따라 최소, 표준, 전체 세트를 유지하거나, 파라미터 예산에 맞추기 위해 가장 덜 중요하고 비용이 큰 모듈을 끕니다. 모듈 도입 전에 저장한 프로젝트는 예전 그대로 생성되고 그곳에서 업그레이드를 제안받을 뿐이며, 스스로 업그레이드되지 않습니다. 업그레이드한 프로젝트는 언제든 원래 생성으로 돌아갈 수 있습니다. 맞춤된 이목구비는 캔버스에서 **특징점** 도구(`Shift+Y`)로 보정할 수 있습니다. [캔버스 편집](CANVAS_EDITOR.md#특징점)을 참고하세요.

**이전 프로젝트의 분할 기록**: 이전 버전에서 한 분할(메시 섬, 다각형, 앞뒤 분리)은 원래 레이어의 상태를 파츠에 고정해 두었습니다. 이런 프로젝트는 예전처럼 열리며, 첫 편집에서 현재 모델을 고정 데이터로 유지하고, 그 뒤로는 이전 기록이 더 이상 재생되지 않고 그 파츠는 직접 만든 메시로 남아 그에 대한 모든 변경을 유지합니다. 새 분할에는 이런 차이가 없습니다. 파츠가 생성에서 원래 레이어의 자리를 차지하고, 원래 레이어에 만든 셰이프 키, 패스, 가중치, 글루가 파츠로 옮겨지며, 이후의 얼굴 설정, 자세, 뼈대, 분류 변경도 파츠에 반영됩니다.

**생성 결과 업데이트**: 머리카락 시뮬레이션 켜기, 뼈대 추가나 변경, 레이어 분할처럼 생성 결과를 바꾸는 작업은 기존 편집을 새 출력 위에 병합하고 그 결과를 고정 데이터로 유지하므로, 앱의 새 버전이 스스로 결과를 바꾸지 않습니다. 새 생성기의 개선을 받으려면 **모델 → 생성 결과 업데이트**를 쓰세요. 손대지 않은 부분은 새 출력을 받고, 바꾼 부분은 유지되며, 깔끔하게 옮겨지지 않은 항목은 상태 표시줄에 개수가 표시되고 인스펙터에 나열됩니다. 이전 버전이 잘못 병합한 경우(예: 뼈대를 추가한 뒤 팔 메시가 본에서 빠졌거나, 아래팔을 굽히면 팔이 어깨에서 떨어지거나, 가져온 이미지가 상체와 함께 돌지 않는 경우)에는 병합을 새 방식으로 다시 하며 이후 편집은 유지됩니다. 프로젝트를 열거나 생성 리그가 바뀌면 앱이 백그라운드에서 이런 병합을 확인하고, 발견하면 편집 캔버스 위쪽에 **생성 결과 업데이트**와 **변경 사항 미리 보기** 버튼과 함께 알립니다. 닫으면 생성 리그가 다시 바뀔 때까지 알림이 나타나지 않습니다. 생성 결과가 같은 리그이면 아무것도 기록되지 않으며, 업데이트는 취소 가능한 히스토리 한 단계입니다. 업데이트가 무엇을 바꿀지 먼저 보려면 **모델 → 생성 결과 업데이트 미리 보기**를 쓰세요. 상태 표시줄에 리그가 바뀔지와 확인할 항목 수가 표시되며, 프로젝트는 그대로 유지됩니다.

## 기본 단축키

## 문제 해결

| 증상 | 먼저 확인할 것 |
| --- | --- |
| 파츠가 잘못 움직이거나 전혀 움직이지 않음 | [레이어 명명](../spec/PSD_LAYER_SPEC.md)과 레이어 표의 종류와 좌우. 마스크와 부모 |
| 정지 포즈는 맞는데 움직이면 깨짐 | 애니메이션이나 물리 패널에서 재생해 보세요. 정지 포즈 하나로는 동적 동작이 보이지 않습니다 |
| 패널이 없음 | 창 메뉴의 패널 토글, 또는 오른쪽 위의 레이아웃 재설정 |
| 모델이 보이지 않음 | 캔버스를 맞춘 뒤(`F` / `Home`) 레이어 표시를 확인 |
