# 그림으로 보는 시뮬레이션 튜토리얼: 머리카락과 의상의 자연스러운 흔들림

[문서 목록](../../README.md) · [中文](../../zh/guide/SIMULATION_TUTORIAL.md) · [English](../../en/guide/SIMULATION_TUTORIAL.md) · [시뮬레이션과 베이크](SIMULATION.md) · [캔버스 편집](CANVAS_EDITOR.md) · [사용자 빠른 참조](USER_GUIDE.md)

시뮬레이션은 머리카락, 밑단, 느슨한 옷에 늦게 따라오는 움직임, 지연, 튀어 오름을 줍니다. 이 튜토리얼은 먼저 앞머리의 전후 비교로 목표를 보여 준 다음, 고정 가중치와 베이크를 차례로 안내합니다. 스크린숏은 중국어 UI입니다.

## 문제와 목표

자동으로 생성된 고정 범위가 모든 원화에 맞는 것은 아닙니다. 이 예에서는 앞머리가 흔들릴 때 얼굴 양옆 머리카락의 형태와 위치를 조정해야 합니다. 뿌리는 계속 머리를 따라가게 하고, 그 아래의 자유 영역을 조정해 앞머리가 의도한 윤곽에 더 가까워지게 합니다.

![앞머리 시뮬레이션 전후: 왼쪽은 수정 전, 오른쪽은 수정 후](../../imgs/simulation-tutorial/preview-comparison.webp)

*왼쪽은 수정 전 전체 미리보기에서, 오른쪽은 수정 후 확대 미리보기에서 가져온 것으로, 둘 다 잘라 하나의 머리 비교 이미지로 이어 붙였습니다. 얼굴 양옆의 머리카락을 비교할 수 있도록 두 스크린숏의 원래 내용은 그대로 두었습니다. 움직일 때의 흔들림은 파라미터를 바꾸거나 모션을 재생해 따로 확인해야 합니다.*

진행 방법: **고정 확인 → 가중치 브러시로 고정 범위 변경 → 참조 시뮬레이션 확인 → 다시 베이크 → 내보내기 결과 확인**. 고정을 바꿀 때는 뿌리의 연결을 유지하고, 그라데이션으로 어느 영역이 머리를 따라가고 어느 영역이 흔들려도 되는지 조절합니다.

## 시작하기 전에

**참조 시뮬레이션**은 실시간으로 조정할 때 쓰고, **내보내기 결과**는 베이크가 어떻게 동작하는지 볼 때 씁니다. 이 움직임이 내보낸 모델에 나타나게 하려면 반드시 베이크해야 합니다. 메시와 리그가 이미 생성된 모델을 연 다음, 아래 단계를 따라 하세요.

## 1. 모델 프리셋에서 시뮬레이션 켜기

**모델 프리셋 → 물리 및 시뮬레이션**을 엽니다. 앞머리와 뒷머리에는 각각 드롭다운이 있어 움직임을 따로 설정할 수 있습니다.

![모델 프리셋의 물리 및 시뮬레이션 그룹과 머리카락 움직임 드롭다운](../../imgs/simulation-tutorial/model-presets.webp)

*이 스크린숏은 드롭다운의 위치를 보여 주며, 빨간 상자는 **기존 흔들림**을 표시합니다. 이 튜토리얼을 따라 하려면 바로 위의 **시뮬레이션**을 고르세요.*

| 옵션 | 용도 |
| --- | --- |
| 시뮬레이션 | 머리카락 바디와 고정 가중치를 만들고 베이크를 생성하며, 이후 다듬을 수 있음 |
| 기존 흔들림 | 기존의 머리카락 흔들림과 진자를 사용하며, 이 튜토리얼에서 쓰는 머리카락 시뮬레이션 바디는 없음 |
| 끔 | 그 머리카락의 흔들림을 끔 |

먼저 **앞머리**를 **시뮬레이션**으로 설정하고 생성이 끝날 때까지 기다립니다. 뒷머리도 참여시키려면 **뒷머리**도 **시뮬레이션**으로 설정합니다. 일부 레이어에만 적용하려면 먼저 그 레이어를 선택한 뒤 **선택 항목만**을 켭니다.

프리셋은 가닥의 뿌리에 고정을 자동으로 생성합니다. 먼저 기본 결과를 보고 직접 조정할지 정하세요.

### 의상도 여기서 켤 수 있습니다

**의상**을 체크하면 프로그램이 부위별로 시뮬레이션을 생성하여, 느슨한 영역만 움직이고 몸에 붙는 영역은 계속 리그를 따르게 합니다.

![의상 프리셋 아래에 나열된 상의와 치마의 느슨함, 몸에 붙는 옷](../../imgs/simulation-tutorial/clothing-report.webp)

*의상 행 아래에 시뮬레이션되는 부위와 그 느슨함이 표시되며, 몸에 붙는 옷은 "몸에 붙어 시뮬레이션하지 않음" 행에 모입니다.*

여기의 백분율은 원화가 얼마나 느슨한지에 대한 프로그램의 보고로, 프리셋이 어느 부위를 처리했는지 보여 줍니다. 실제 움직임은 여전히 고정, 재질, 미리보기로 확인해야 합니다.

## 2. 조정할 바디와 메시 선택하기

**시뮬레이션** 패널을 열고 **바디** 목록에서 **앞머리(프리셋)** 바디를 선택합니다. 목록 왼쪽의 확인란은 바디의 활성화 여부를 정합니다.

조정하는 동안에는 패널 상단의 미리보기 스위치를 켜서 레이블이 **참조 시뮬레이션**이 되게 합니다. 그러면 편집기의 실시간 시뮬레이션이 실행되며, 파라미터 패널에서 머리를 돌리고 몸을 기울여 머리카락이 어떻게 따라오는지 볼 수 있습니다.

고정을 바꾸려면 앞머리 메시를 선택하고, 캔버스 왼쪽 위의 모드를 **시뮬레이션**으로 전환한 뒤, 왼쪽 도구 모음에서 **가중치 페인트 → 고정**을 고릅니다. 시뮬레이션 패널의 **정점 그룹**을 펼치고 고정 행의 **페인트**를 클릭해 도구로 들어갈 수도 있습니다.

![고정 그룹을 선택한 시뮬레이션 모드: 앞머리 뿌리는 빨간색, 끝은 파란색](../../imgs/simulation-tutorial/pin-weights.webp)

*그림에서는 앞머리 메시가 선택되어 있고, 색이 현재 고정 가중치를 나타냅니다. 다른 부위는 편집 표시 때문에 어둡게 보입니다.*

| 색 | 고정 가중치 | 의미 |
| --- | --- | --- |
| 빨간색 | 1에 가까움 | 기존 리그를 단단히 따름. 뿌리와 이음매용 |
| 초록색 / 노란색 | 중간 | 부분적으로 고정됨. 전이 구간용 |
| 파란색 | 0에 가까움 | 시뮬레이션에 더 자유롭게 참여함. 끝부분과 밑단용 |

머리카락은 보통 뿌리에서 고정하고 끝으로 갈수록 점점 풀어 줍니다. 치마는 보통 허리에서 고정하고 밑단으로 갈수록 풀어 줍니다. 먼저 이음매가 잘 붙어 있는지 확인한 다음, 흔들려도 되는 영역을 조정하세요.

## 3. 가중치 브러시로 고정 범위 조정하기

캔버스 왼쪽 아래의 도구 옵션 표시줄에 가중치 브러시 설정이 표시됩니다(캔버스를 오른쪽 클릭해도 같은 설정이 열림). 먼저 가중치를 바꿀 방식을 고른 다음, **반경, 강도, 경도**를 조정합니다.

![가중치 브러시의 오른쪽 클릭 설정: 반경, 경도, 강도와 더하기, 빼기, 설정, 부드럽게](../../imgs/simulation-tutorial/weight-brush.webp)

*스크린숏에서는 **빼기**가 선택되어 있습니다. 고정을 약하게 해서 흔들릴 수 있는 영역을 넓힙니다.*

| 모드 | 적합한 용도 |
| --- | --- |
| 더하기 | 뿌리나 이음매를 더 단단히 붙잡을 때 |
| 빼기 | 지나치게 고정된 영역이 더 자유롭게 흔들리게 할 때 |
| 설정 | 가중치를 현재 강도 쪽으로 점점 끌어당길 때 |
| 부드럽게 | 이웃한 정점 사이의 가중치 변화를 부드럽게 할 때 |

예를 들어 머리카락이 너무 많이 고정되어 거의 흔들리지 않으면, 뿌리 아래를 **빼기**로 가볍게 칠해 전이 구간을 조금씩 풀어 주되, 실제로 머리에 붙는 뿌리는 유지합니다. 이음매까지 미끄러지기 시작하면 **더하기**로 뿌리의 가중치를 되돌립니다.

가장자리를 다듬을 때는 작은 반경을, 부드러운 전이에는 낮은 경도를 쓰세요. 조금씩 바꾸고 색을 확인한 다음 계속하세요. **부드럽게**는 급격한 변화를 정리하며, 한 방향을 따르는 전이에는 **가중치 그라데이션**도 쓸 수 있습니다.

## 4. 가중치 분포와 참조 시뮬레이션 확인하기

아래는 조정한 분포의 한 예입니다. 위쪽은 여전히 높은 고정 가중치를 유지하고, 양옆과 끝으로 갈수록 낮아집니다.

![조정한 앞머리 고정 가중치. 뿌리와 자유 영역 사이에 그라데이션이 있음](../../imgs/simulation-tutorial/weights-adjusted.webp)

*중요한 것은 안정적인 이음매, 연속적인 전이, 끝부분의 자유로움입니다. 고정 범위는 자신의 원화에 맞게 조정하세요.*

**미리보기** 모드로 돌아가 **참조 시뮬레이션**을 켜 둔 채로 둡니다. 머리를 천천히 돌려 보고, 이어서 빠르게 돌렸다가 멈추면서 늦게 따라오는 움직임, 튀어 나감, 되돌아 흔들림을 관찰합니다. 머리카락이 전체적으로 거의 움직이지 않으면 너무 많이 고정되지 않았는지, 뿌리가 떠다니면 이음매의 고정 가중치가 충분한지 확인하세요.

시뮬레이션 패널에서 **재질**을 조정할 수도 있습니다.

| 항목 | 용도 |
| --- | --- |
| 굽힘 | 가닥이 얼마나 쉽게 휘는지 |
| 감쇠 | 움직임이 잦아드는 속도. 높을수록 대체로 빨리 멈춤 |
| 형태 | 원래 그린 형태로 얼마나 되돌아가는지 |
| 늘어남 | 가닥 길이를 유지함. 머리카락은 보통 1에 가까워야 함 |

**머리카락** 재질 프리셋에서 시작해 한 번에 한 항목씩 바꾸세요. 그 밖의 재질 항목, 가중치 그룹, 글루 역할은 [시뮬레이션과 베이크](SIMULATION.md)에 설명되어 있습니다.

모델 프리셋의 **고정 가중치 자동 설정**은 가중치를 다시 계산하고 다시 베이크합니다. 고정을 직접 고쳐서 그 분포를 유지하고 싶다면, 계속 시뮬레이션 패널의 베이크 버튼을 사용하세요.

## 5. 변경 후 다시 베이크하기

가중치나 재질이 바뀌면 기존 베이크는 **오래됨** 상태가 됩니다. 시뮬레이션 패널에서 방금 바꾼 바디를 선택하고, **베이크**를 펼쳐 **다시 베이크**를 클릭합니다. 아직 결과가 없으면 버튼은 **베이크**로 표시됩니다.

![시뮬레이션 패널의 앞머리 바디가 오래됨 상태이며, 빨간 상자가 다시 베이크 버튼을 표시함](../../imgs/simulation-tutorial/rebake.webp)

*빨간 상자 안의 버튼은 현재 바디만 베이크합니다. 여러 바디를 업데이트해야 하면 패널 상단의 **모두 베이크**를 사용하세요.*

처음에는 **모드 2, 키 수 5, 과장 ×1.3**의 기본값을 그대로 두고 한 번 베이크해서 결과를 보세요. 모드는 전체적인 흔들림과 추가 변형을 몇 개의 파라미터로 표현할지 정하고, 키 수는 형태를 얼마나 촘촘하게 샘플링할지에 영향을 주며, 과장은 베이크 후의 흔들림 크기를 조절합니다.

**오래됨**은 현재 설정이 이전 베이크와 다르며 내보내기는 아직 이전 결과를 사용한다는 뜻입니다. 다시 베이크해야만 가중치와 재질 변경이 새 내보내기에 반영됩니다.

## 6. 베이크가 끝날 때까지 기다리기

베이크하는 동안 아래쪽 상태 표시줄에 진행 상황이 표시됩니다. 걸리는 시간은 메시와 바디가 얼마나 복잡한지에 따라 다르므로, 끝날 때까지 기다린 뒤 결과를 확인하세요.

![시뮬레이션 베이크 중, 빨간 화살표가 아래쪽 상태 표시줄의 진행 막대를 가리킴](../../imgs/simulation-tutorial/bake-progress.webp)

*화살표는 이번 베이크의 진행 상황을 가리킵니다. 끝나면 방금 베이크한 바디가 목록에 초록색 점으로 표시됩니다.*

멈추려면 진행 표시 옆의 취소 버튼을 사용하세요. **자동 베이크**는 기본으로 꺼져 있습니다. 가중치를 계속 직접 고쳐야 할 때는 모든 변경을 먼저 마치고 마지막에 한 번 베이크하세요.

## 7. 내보내기 결과로 돌아가 저장하기

시뮬레이션 패널 상단의 미리보기 스위치를 꺼서 레이블이 **내보내기 결과**가 되게 합니다. 이제 캔버스는 베이크된 키폼과 진자를 재생하므로, 내보낸 모델이 어떻게 동작하는지 확인할 수 있습니다.

머리 회전, 기울이기, 빠른 움직임 뒤에 멈추기, 몸의 상하 움직임을 확인합니다. 뿌리가 안정적으로 유지되는지, 끝이 자연스럽게 되돌아 흔들리는지, 옷이 원래 형태를 유지하는지 살펴보세요. 비교하려면 같은 모션에서 **참조 시뮬레이션**과 **내보내기 결과**를 전환하거나, 바디의 **비교** 섹션을 펼쳐 내보내기 위에 참조 시뮬레이션을 그리거나(**겹쳐 보기**), 두 캔버스에 **나란히 보기**로 재생하거나, 모션을 골라 **재생**해서 둘이 함께 정지 상태에서 시작하게 하거나, **검사**로 그 모션에서 흔들림, 지연, 안정화를 비교할 수 있습니다.

결과가 마음에 들면 `.psd2live` 프로젝트를 저장한 다음 모델을 내보내세요. 나중에 가중치, 메시, 재질을 바꾸면 베이크 상태를 확인하고 업데이트하는 것을 잊지 마세요.

## 문제 해결

| 증상 | 먼저 확인할 것 |
| --- | --- |
| 시뮬레이션 패널에 앞머리 바디가 없음 | 앞머리 드롭다운이 **시뮬레이션**으로 설정되어 있는지, 원화가 앞머리로 인식되었는지 확인하세요. 대상 메시를 선택하고 시뮬레이션 패널의 **새로 만들기 → 머리카락**으로 직접 만들 수도 있습니다 |
| 가중치 색이 표시되지 않음 | 대상 메시가 선택되어 있고 캔버스가 **고정** 그룹의 **시뮬레이션** 모드인지 확인하세요 |
| 머리카락 뿌리가 떨어지거나 거의 흔들리지 않음 | 고정이 너무 적거나 많지 않은지 확인하세요. 먼저 이음매를 붙잡은 다음 끝을 점점 풀어 주세요 |
| 참조 시뮬레이션은 움직이는데 내보내기가 업데이트되지 않음 | 베이크되지 않았거나 오래됨 상태인지 확인하고, 베이크하거나 다시 베이크하세요 |
| 일부 의상 부위가 시뮬레이션되지 않음 | 의상 느슨함 보고와 "몸에 붙어 시뮬레이션하지 않음" 목록을 보고 프리셋의 인식이 원화와 맞는지 확인하세요 |
| 베이크 결과가 참조 시뮬레이션과 다름 | 베이크는 실시간 시뮬레이션을 피팅한 것입니다. 품질 안내를 보고 필요에 따라 모드나 키 수를 조정해 다시 베이크한 다음, 실제 모션으로 개선되었는지 확인하세요 |
