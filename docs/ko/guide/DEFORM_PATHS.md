# 변형 경로(실험적)

[문서 목록](../../README.md) · [中文](../../zh/guide/DEFORM_PATHS.md) · [English](../../en/guide/DEFORM_PATHS.md) · [캔버스 편집](CANVAS_EDITOR.md)

경로는 ArtMesh에 붙는 편집 보조 도구이며, Warp와 Rotation에 이은 세 번째 디포머가 아닙니다. ArtMesh 하나에 경로를 여러 개 둘 수 있지만, 경로 하나가 여러 ArtMesh를 제어할 수는 없습니다.

## 빠른 단계

1. ArtMesh를 선택하고 트리에서 오른쪽 클릭해 **변형 패스**(기본 `P` / `D`)를 고릅니다.
2. 클릭해 제어점을 두 개 이상 놓습니다. Enter로 확정하고 Esc로 취소합니다.
3. **편집 모드**에서 경로의 바인딩 위치, 폭, 경도, 닫힘, 모서리를 조정합니다. 이 단계에서는 이미지의 형태가 바뀌지 않아야 합니다.
4. 파라미터 패널에서 목표 포즈를 정하고 **변형 모드**로 전환한 뒤 제어점을 드래그해 결과를 ArtMesh의 형태에 기록합니다.

오브젝트 모드에서는 오브젝트를 선택하기만 합니다. 경로는 L2와 L3 두 그룹으로 나뉘어 각각 따로 저장되며(`.cmo3`에는 경로의 편집 레벨로 기록), Warp 디포머의 **정점** / **베지어** 레벨과는 관계가 없습니다. 새 경로의 그룹은 배치 패널이나 **도구 상세**의 **패스 편집 레벨**에서 고르고, 기존 경로의 그룹은 인스펙터의 **편집 레벨**에서 바꿉니다. 캔버스는 현재 그룹의 경로만 표시하고 편집합니다. 가이드 선은 선택한 오브젝트와 편집 페이지의 보기 설정에 따라 표시되며, 미리보기 페이지에는 경로가 표시되지 않습니다. 일반 편집은 메인 캔버스 히스토리에 기록됩니다.

## 저장과 내보내기

| 파일 | 담는 내용 |
| --- | --- |
| `.psd2live` | 경로 설정, 바인딩, 재생 가능한 형태 편집 |
| `.cmo3` | 네이티브 컨트롤러 구조와 메시 키폼 |
| `.moc3` | 베이크된 메시 키폼. 런타임은 경로 알고리즘을 실행하지 않음 |

현재 알고리즘은 커브 샘플링, 이동 최소 제곱법(moving least squares), 삼각형 바인딩을 사용합니다. 컨트롤러를 읽고 쓸 수 있다고 해서 드래그 결과가 Cubism Editor와 일치한다고 검증된 것은 아닙니다. 특히 폭, 경도, 큰 변형, 불균일한 부모 스케일은 확인이 필요합니다.

메인 캔버스의 토폴로지 작업은 경로를 다시 바인딩합니다. 메시가 너무 성기거나 제약이 서로 충돌하면 변형이 거부될 수 있습니다. 공식 Editor에서 열고, 드래그하고, 다시 저장하는 완전한 호환성 검수는 아직 이 페이지에 기록되어 있지 않습니다.

에이전트는 `path_list`와 `path_get`으로 경로를 보고, `path_put`과 `path_delete`로 생성·변경·삭제하며, `path_preview`로 제어점 드래그를 시험하고, `path_deform`으로 드래그 결과를 키폼으로 기록합니다. `scope=paths`를 지정한 `workspace_inspect`는 모든 경로를 나열합니다. 필드는 [MCP 인터페이스](../agent/MCP_AUTHORING.md)를 참고하세요.
