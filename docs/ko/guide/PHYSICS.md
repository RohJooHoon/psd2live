# 물리

[문서 목록](../../README.md) · [中文](../../zh/guide/PHYSICS.md) · [English](../../en/guide/PHYSICS.md) · [흔들림 생성](SWING.md) · [시뮬레이션과 베이크](SIMULATION.md) · [MCP 사용법과 인터페이스](../agent/MCP_AUTHORING.md)

물리는 머리와 몸 같은 입력을 따라 파라미터가 관성으로 흔들리게 합니다. PSD2Live는 Cubism의 진자 모델을 사용합니다. 뿌리에 매달린 진자의 사슬(Cubism Editor 진자 설정에서 1, 2, 3…으로 번호가 매겨진 행)로, 입력이 뿌리를 밀거나 중력을 기울이면 진자가 관성으로 흔들리고, 선택한 진자의 각도가 출력 파라미터에 기록됩니다. 내보내기는 이를 `physics3.json`과 `.cmo3`에 기록합니다.

## 물리 그룹의 출처

모델의 모든 물리 그룹은 물리 패널에 나열되며, 출처는 다섯 가지입니다.

| 출처 | 설명 | ID |
|------|------|----|
| 프리셋 | 레이어에서 생성된 앞머리, 뒷머리, 눈동자 젤리(레이어에 해당 부위가 있을 때만) | `PhysicsHairFront`, `PhysicsHairBack`, `PhysicsEyeJelly` |
| 스켈레톤 | 스켈레톤의 두 번째 뼈부터의 꼬리와 날개의 추종 움직임 | `PhysicsSkel_<bone id>` |
| 흔들림 | 각 흔들림의 방향마다 진자 하나. [흔들림 생성](SWING.md) 참고 | `PhysicsSwing_<id>[_X\|_Y]` |
| 시뮬레이션 | 베이크된 시뮬레이션마다 피팅된 진자 하나로, 각 마디가 모드 파라미터 하나를 구동. 세로 움직임은 이동 입력을 가진 진자를 하나 더 받음. [시뮬레이션과 베이크](SIMULATION.md) 참고 | `PhysicsSim_<id>`, `PhysicsSim_<id>_y` |
| 사용자 지정 | 패널이나 MCP에서 만든 것 | 기본값은 `PhysicsCustom<N>` |

생성된 그룹은 직접 편집할 수 있습니다. 편집한 그룹은 **편집됨**이 되고 사용자가 만든 버전이 저장되며, 이후 출처(흔들림, 스켈레톤)가 바뀌어도 덮어쓰지 않습니다. 시뮬레이션의 진자는 다시 베이크하거나 출력 이름을 바꾸면 3방향으로 병합되어, 사용자가 바꾼 필드만 유지하고 나머지는 새 피팅을 따릅니다([시뮬레이션과 베이크](SIMULATION.md) 참고). **생성값으로 초기화**는 생성된 버전으로 되돌립니다. 모든 그룹은 개별적으로 끌 수 있으며, 끈 그룹은 내보내지지 않습니다. 사용자 지정 그룹이 생성된 그룹의 출력 파라미터를 구동하면, 그 생성된 그룹에는 **대체됨**이 표시되며 역시 내보내지지 않습니다.

가져온 CMO3의 물리 설정은 파일이 지정한 ID를 유지합니다. Cubism Editor는 한 ID 아래 여러 설정을 저장할 수 있는데, 이 경우 두 번째 이후의 설정은 `<id>_2`, `<id>_3`…이 됩니다(파일이 이미 쓰는 ID는 건너뜀). 그래서 모든 설정이 유지되고, 가져올 때마다 같은 ID가 붙으며, 내보내기도 그 ID를 사용합니다.

한 파라미터는 활성 그룹 하나만 구동할 수 있습니다. 유효하지 않은 그룹(없는 파라미터, 입력이나 출력이 없음, 입력이면서 출력인 파라미터)은 목록에 **유효하지 않음**으로 표시되고 내보내지지 않으며, 편집 영역에 이유가 표시됩니다.

## 물리 패널

물리 전체 스위치와 물리 프레임 레이트는 미리보기 캔버스의 왼쪽 도구 모음에 대기 애니메이션, 마우스 추적과 함께 있습니다. 물리 프레임 레이트는 30 / 60 / 90 / 120 / **무제한**(기본값 60) 중에서 고르며 프로젝트 설정입니다. 물리는 이 프레임 레이트로 계산되며, 내보낸 `physics3.json`(`Fps`)과 CMO3에 기록됩니다. **무제한**이면 렌더링되는 매 프레임마다 물리를 계산하고, 내보내기는 `Fps`를 선언하지 않으며, 런타임은 자기 프레임에서 물리를 계산합니다(CMO3에는 물리 FPS를 기록하지 않음). 미리보기 프레임은 이 값의 제한을 받지 않습니다. 미리보기 프레임 속도 상한은 캔버스 왼쪽 아래 상태 표시 알약의 메뉴에 있으며, 기본값은 **디스플레이 따라가기**이고 물리 프레임 레이트와는 관계없습니다. 물리는 단계 사이를 보간합니다.

패널 맨 위에는 물리가 실행 중인지, 현재 프레임 레이트, "n / m 활성" 개수와 함께 미리보기의 대기 애니메이션과 마우스 추적 토글이 표시됩니다.

대기 애니메이션과 물리는 서로 독립적입니다. 대기 애니메이션을 멈추고 물리를 켜 두면, 파라미터 슬라이더를 끌거나 마우스 추적으로 머리를 돌려도 미리보기에서 물리가 흔들리며, 움직임이 가라앉으면 미리보기는 프레임 렌더링을 멈춥니다. 물리를 끄면 편집한 포즈만 표시됩니다. 일시 정지 중에는 내보내기와 같은 엔진으로 물리를 계산하며(아래 "미리보기와 내보내기의 일관성" 참고), 일시 정지된 모션이 계속 재생되지는 않습니다.

파라미터 패널은 항상 미리보기와 일치합니다. 대기 애니메이션이 재생되는 동안 슬라이더는 미리보기를 프레임 단위로 따라가고, 멈춰 있을 때는 마우스 추적으로 구동되는 각도와 눈알 파라미터도 파라미터 패널에 실시간으로 표시되며, 물리 패널의 진자도 같은 포즈를 읽습니다.

물리를 집중해서 조정하려면 **물리** 작업 공간(탭 표시줄의 + 메뉴)을 만드세요. 왼쪽부터 미리보기 캔버스, 파라미터 패널, 물리 패널이 너비 약 2 : 1 : 1로 배치되고 다른 패널은 숨겨집니다. 필요하면 **창** 메뉴에서 여세요.

그 아래는 물리 그룹 목록으로, 계산 순서대로 번호와 함께 표시됩니다. 각 행에는 활성화 확인란이 있고 출처와 상태(**편집됨** / **유효하지 않음** / **대체됨**)가 표시됩니다. 머리글의 ↑ / ↓는 선택한 그룹의 계산 순서를 바꿉니다. Cubism은 그룹을 순서대로 계산하며, 뒤의 그룹은 같은 단계 안에서 앞 그룹의 출력을 읽을 수 있습니다. 그래서 한 그룹이 다른 그룹의 출력을 입력으로 받으면(연쇄 물리), 읽히는 그룹이 먼저 와야 합니다.

**+ 새로 만들기**로 다음을 할 수 있습니다.

- **빈 진자** 만들기: 기본적으로 머리와 몸의 흔들림을 입력으로 받고, 길이 10인 진자 하나가 있으며 출력은 아직 없습니다.
- 선택한 그룹을 **새 그룹으로 복제**(원본과 충돌하지 않도록 출력 파라미터는 비워짐).
- **physics3.json 가져오기…**: 파일의 각 그룹이 사용자 지정 그룹이 되며, 파일 순서대로 기존 그룹 뒤에 놓입니다. ID가 같은 그룹은 대체되고(생성된 그룹은 생성값으로 초기화할 때까지 대체된 상태로 남음), 같은 출력을 구동하는 다른 사용자 지정 그룹은 꺼지며, 파일에 선언된 `Fps`가 프로젝트의 계산 FPS가 됩니다. 모델에 없는 파라미터는 로그에 기록되고, 해당 그룹은 유효하지 않음으로 표시됩니다.
- 캔버스에서 선택한 메시나 Warp 디포머에 흔들림 만들기(**선택 항목에 흔들림 만들기…**, [흔들림 편집](SWING.md)이 열림).

### 진자 캔버스

그룹을 선택하면 편집 영역 맨 위에 그 진자가 표시됩니다. 실선은 실시간으로 흔들리는 진자이고, 점선은 실시간 뿌리에 매달린 정지 자세이며, 각 진자 끝에는 고리가 있습니다. 화면은 좌우가 반전되어 있어, 오른쪽으로 당기면 뿌리가 오른쪽으로 움직입니다.

| 조작 | 효과 |
|------|------|
| 빈 곳을 좌우로 드래그 | Cubism Viewer에서 모델을 옆으로 끌 때처럼 모델을 당기며(가로 방향만), 놓으면 부드럽게 돌아옴. 뿌리는 항상 맨 위 선을 따라 움직임 |
| 고리를 위아래로 드래그 | 그 진자의 길이. 클릭하면 그 진자가 선택되어(다시 클릭하면 선택 해제) 아래 슬라이더가 그 진자만 조정함 |
| 오른쪽의 출력 레이블 | 각 레이블은 자기가 읽는 진자와 같은 높이에 있으며, 그 진자의 실시간 위치로 이어지는 선과 현재 파라미터 값을 나타내는 막대가 있음. 위아래로 드래그하면 가장 가까운 진자가 강조되고, 놓으면 그 진자를 읽게 됨(출력 행의 **진자 번호**) |
| 출력 레이블(또는 출력 행 앞의 색 점) 클릭 | 그 출력의 범위 부채꼴을 진자에 표시함. 이 진자가 앞 진자에 대해 부채꼴의 각도만큼 흔들리면 파라미터가 한쪽 끝에서 다른 쪽 끝까지 움직임. 부채꼴 가장자리의 점을 드래그해 범위(즉 배율)를 조정함. 부채꼴이 좁을수록 흔들림이 강함 |

클릭은 선택만 하며, 짧은 거리 이상 드래그해야만 무언가가 바뀌므로 생성된 그룹이 실수로 바뀌지 않습니다. 마우스를 올리거나 드래그하는 동안 왼쪽 위에 항목의 의미와 값이 표시됩니다.

당기는 동안 포인터 위치가 목표가 됩니다. 모델은 Cubism의 CubismTargetPoint처럼 제한된 속도와 가속도로 포인터를 따라가며, 이를 CubismLook의 계수로 각도 X, 몸 X, 눈알 X로 변환합니다(그룹의 다른 입력 파라미터는 드래그 양을 범위 절반에 대한 비율로 받음). 실시간 진자는 미리보기가 재생되는 동안에는 미리보기 파라미터(모션과 시선 추적 포함) 위에, 일시 정지 중에는 파라미터 패널 값 위에 더해지므로, 파라미터 슬라이더를 직접 끌어도 반응이 보입니다. 오른쪽 아래 버튼은 진자를 즉시 정지시킵니다.

뿌리의 이동 범위와 중력 기울기 범위(입력 정규화)는 **고급** 아래에서 설정합니다.

### 응답 곡선

진자 아래의 곡선은 표준 당기기 한 번에 대한 그룹의 응답을 보여 줍니다. 오른쪽 끝까지 1초 동안 당겼다가 놓은 것으로, 출력마다 곡선이 하나씩 있고(파라미터 범위로 정규화, 점선은 파라미터의 양 끝), 당기기 자체는 흐린 곡선으로 표시됩니다. 곡선 아래에는 각 출력의 최대 진폭과 놓은 뒤 가라앉기까지 걸리는 시간이 나열됩니다. 길이와 동역학 슬라이더를 조정하는 동안 곡선이 업데이트되므로, 설정에 따른 오버슈트와 안정화를 바로 비교할 수 있습니다.

### 진자 설정

**프리셋** 행은 Cubism Editor의 진자 프리셋에 해당합니다. 프리셋을 고르고 **불러오기**를 클릭하면 이 그룹의 모든 진자를 그 프리셋으로 교체합니다(진자가 줄어들면, 제거된 진자를 읽던 출력은 끝 진자를 읽음). 기본 제공 프리셋은 생성된 앞머리, 뒷머리, 눈동자 젤리와 3단 진자입니다. "⋯" 아래에서 **추가…** 항목으로 현재 진자를 자신의 프리셋으로 저장하거나, 자신의 프리셋을 덮어쓰고, 이름을 바꾸고, 삭제할 수 있습니다. 프리셋은 이 컴퓨터에 저장되며 모든 프로젝트가 공유합니다.

**편집할 진자** 행은 아래 슬라이더가 무엇에 작용할지 고릅니다. **전체**는 모든 진자를 한꺼번에 조정하고, 번호는 그 진자만 조정합니다(캔버스에서 고리를 클릭해 고를 수도 있음). 이 행은 슬라이더가 어떤 진자를 바꿀지만 정하며, 출력의 **진자 번호**와는 관계없습니다. 오른쪽 버튼은 다음과 같습니다.

- ↑ / ↓: 선택한 진자를 옮깁니다. 그 진자를 읽는 출력도 함께 옮겨집니다.
- +: 선택한 진자 아래(값을 복사), 선택한 것이 없으면 끝에 진자를 추가합니다. 더 깊은 출력은 함께 아래로 밀리며 원래의 진자를 계속 읽습니다.
- −: 선택한 진자(선택한 것이 없으면 마지막 진자)를 삭제합니다. 그 진자를 읽던 출력은 앞 진자를 읽게 되고, 더 깊은 출력은 위로 당겨집니다.

| 슬라이더 | Cubism Editor 이름 | 효과 |
|------|-------------|------|
| **전체 길이** / **길이** | 길이 | 길수록 느리고 넓게 흔들림. **전체**를 골랐을 때는 모든 진자를 비례해서 조절함 |
| **흔들림** | 흔들림(Mobility) | 높을수록 정지하기까지 오래 걸림 |
| **반응 속도** | 반응 속도(Delay) | 높을수록 입력에 빨리 반응함 |
| **수렴 속도** | 수렴 속도(Acceleration) | 높을수록 중력이 강해 늘어진 자세로 빨리 돌아옴 |

### 입력

각 입력은 파라미터와 그 작용 방식입니다.

- **종류**: **위치 X**는 진자 뿌리를 좌우로 밀고, **각도**는 중력 방향을 기울입니다.
- **가중치**: 0–100%. 파라미터의 전체 범위가 입력 정규화 범위의 몇 퍼센트에 대응하는지입니다.
- **⇄**: 반전.

**+ 추가**는 사용할 수 있는 파라미터를 나열하며, 흔히 쓰는 머리와 몸 각도가 먼저 나옵니다.

**프리셋** 행은 Cubism Editor의 입력 프리셋에 해당합니다. 프리셋은 모든 입력과 입력 정규화를 담습니다. 기본 제공 프리셋은 머리와 몸 흔들림(±10°, 앞머리용, ±30°, 뒷머리용), 머리와 몸 상하(세로 흔들림용), 눈 뜨고 감기(눈동자 젤리용)이며, 모델에 없는 파라미터와 그룹 자체의 출력 파라미터는 건너뜁니다. 진자 프리셋과 같은 방식으로 관리합니다.

### 출력

각 출력은 진자 하나의 각도를 파라미터에 기록합니다.

- **진자 번호**: 출력이 어느 진자의 각도를 읽는지(앞 진자에 대한 상대 각도이며, 진자 1은 중력 방향에 대한 각도)입니다. Cubism Editor 출력 설정의 "진자 번호", `physics3.json`의 `VertexIndex`에 해당합니다. 위의 **편집할 진자**와는 관계없으며, 캔버스 오른쪽의 레이블을 진자 옆으로 끌어 놓아도 바뀝니다. 여러 진자를 서로 다른 파라미터에 연결하면 채찍처럼 마디마디 이어지는 추종 움직임이 생깁니다.
- **배율**: 흔들림 각도 1라디안당 파라미터 값이며, 결과는 파라미터 범위로 제한됩니다. 캔버스에서 부채꼴 호의 양 끝을 드래그해도 됩니다.
- **⇄**: 반전.

출력은 각도 종류만 있습니다. Cubism의 네이티브 런타임은 위치 X 출력의 배율을 읽지 않으므로 이런 출력은 항상 0이 됩니다. 불러온 이전 데이터에 위치 X 출력이 있으면, 클릭 한 번으로 각도로 바꾸도록 안내가 표시됩니다.

**+ 추가**에서는 이미 다른 활성 그룹이 구동하는 파라미터를 고를 수 없으며, 그 파라미터를 구동하는 그룹이 표시됩니다.

각 출력 행 오른쪽의 **최대 출력**은 Cubism Editor 출력 설정의 같은 이름 열에 해당합니다. 그룹을 연 뒤(또는 마지막으로 초기화한 뒤) 현재 배율에서 이 출력이 도달한 최대값을 파라미터 끝에 대한 백분율로 나타냅니다. 캔버스에서 당기거나, 미리보기를 재생하거나, 시선을 추적하는 동안 기록되며, 100%를 넘으면 경고 색으로 표시되는데, 이는 파라미터가 끝에서 잘렸다는 뜻입니다. 배율을 바꾸면 백분율이 즉시 새 배율로 환산되므로 다시 당길 필요가 없습니다.

- **최댓값에 배율 맞추기**: 각 출력의 최대 출력이 정확히 100%가 되도록 배율을 설정합니다. 아직 기록이 없으면 응답 곡선의 표준 당기기로 측정합니다.
- **출력 최댓값 초기화**: 기록을 지우고 다시 측정을 시작합니다.

### 고급

**고급** 아래에는 캔버스와 슬라이더가 이미 다루는 데이터가 접혀 있으며, 정확한 값이 필요할 때만 쓰입니다.

- 진자 설정 표: 각 진자의 길이, 흔들림, 반응 속도, 수렴 속도
- 출력 상세: 배율과 가중치
- 입력 정규화: 위치 X 입력과 각도 입력의 최소 / 중앙 / 최대

그룹 이름을 클릭하면 이름을 바꿀 수 있습니다. "⋯" 메뉴에는 **이름 변경**, **복제**, **흔들림 편집**(흔들림 출처), **생성값으로 초기화**, **삭제**(사용자 지정 그룹)가 있습니다.

드래그, 슬라이더 드래그, 숫자 입력은 각각 놓을 때 히스토리 항목 하나를 기록하며 실행 취소할 수 있습니다. 편집 내용은 프로젝트에 저장되며, 모델을 다시 빌드한 뒤에도 같은 그룹이 다시 생성됩니다.

## 미리보기와 내보내기의 일관성

패널의 진자, 응답 곡선, 내장 소프트웨어 미리보기, MCP 시뮬레이션은 같은 물리 엔진을 사용하며, Cubism Native Framework 5-r.5의 `CubismPhysics::Evaluate`와 단계별로 일치합니다. 입력 정규화, 프레임 사이에 입력을 보간하는 `Fps` 고정 단계, 파라미터 캐시를 통한 그룹 간 값 전달(뒤 그룹이 같은 단계에서 앞 그룹의 출력을 읽음), 마디 업데이트와 공기 저항, 출력 보간과 가중치 혼합, 그리고 SDK 자체의 몇 가지 특수한 동작까지 포함합니다. 저장소의 `PhysicsReferenceTest`는 내보낸 모델로 공식 Framework가 만든 프레임 단위 데이터(`native/physics_reference`)와 비교합니다. 불규칙한 프레임 간격, 연쇄 그룹, 반전, 부분 가중치, 이동 출력을 포함한 900프레임에서 최대 편차는 `Fps`가 있든 없든 약 1e-5입니다.

내보낸 `physics3.json`은 프로젝트의 프레임 레이트(`Fps`, 기본값 60. **무제한**이면 선언하지 않음)를 선언하고, CMO3의 물리 FPS도 같으므로, 흔들림이 렌더링 프레임 레이트에 따라 바뀌지 않으며 Cubism Editor를 거쳐 CMO3에서 다시 내보내도 일관성이 유지됩니다. 그룹은 목록 순서대로 내보내지며, 이것이 런타임의 계산 순서입니다. 공식 SDK 미리보기를 사용할 수 있으면 SDK가 내보낸 `physics3.json`을 직접 읽어 미리보기합니다.

물리는 파라미터만 기록합니다. 눈에 보이는 흔들림은 출력 파라미터의 키폼에 달려 있습니다. 사용자 지정 그룹이라면 먼저 출력 파라미터의 양 끝 형태를 만드세요. 그렇지 않으면 파라미터는 움직여도 모델은 움직이지 않습니다.

## MCP

물리 그룹 작업은 용도에 따라 여러 도구로 나뉘며, 인수는 `{"request": {...}}`에 넣습니다(모든 필드는 [MCP 사용법과 인터페이스](../agent/MCP_AUTHORING.md)를 참고하거나 `workspace_get_operation`을 호출). 변경과 샘플링에는 모두 `project_id`, `state`(`workspace_inspect` 또는 이전 결과에서 얻음), 고유한 `request_id`가 필요합니다. 백그라운드 작업으로 표시된 도구는 작업 핸들을 반환하며, `job_wait` / `job_get`으로 결과를 가져옵니다.

- `physics_put`(백그라운드 작업): `id`로 그룹을 만들거나 변경하며, 지정한 필드만 기록합니다. 기존 ID(생성된 그룹 포함)는 현재 그룹에서 시작합니다. `inputs` / `outputs` / `segments`는 목록 전체를 교체하고, `length` / `mobility` / `delay` / `acceleration`은 모든 마디에, `output_scale`은 모든 출력에 적용됩니다. `segment_count`는 마디 수를 바꾸고, `normalization`은 입력 정규화를 설정하며, `enabled=false`는 어떤 그룹이든 끕니다.
- `physics_delete`(백그라운드 작업): 사용자 지정 그룹을 삭제하거나, 편집된 생성 그룹을 생성값으로 초기화합니다. 생성된 그룹 자체는 `physics_put`의 `enabled=false`로 끕니다.
- `physics_simulate`(읽기 전용 백그라운드 작업): 정지 상태에서 시작해 `inputs`의 파라미터를 주어진 값으로 단계 변화시키고, `hold`초 동안 유지한 뒤 놓습니다. 유지 중과 놓은 뒤 각 출력의 시작값, 최대값, 최종값, 안정화 시간과 `samples`로 샘플링한 곡선을 반환합니다. `ids`는 지정한 그룹으로 제한하고, `duration`은 전체 길이를 설정합니다.
- `physics_fit`(백그라운드 작업): 그룹 `id`의 각 출력의 최대값이 파라미터 끝의 정확히 `target`%(기본값 100)에 도달하도록 배율을 설정합니다. `observed_peaks`가 없으면 응답 곡선의 표준 당기기로 측정하며, 이는 실시간 기록이 없을 때 패널의 **최댓값에 배율 맞추기**와 같습니다. 있으면 측정값을 사용하는데, 키는 출력 인덱스(`"0"`, `"1"`…)이고 값은 `physics_audition`이 보고한 `peaks`(1이 파라미터 끝)입니다.
- `physics_config`(백그라운드 작업): `order`는 계산 순서를 설정하고(나열된 그룹이 먼저 옴), `fps`는 프로젝트 프레임 레이트를 설정합니다(무제한은 0).
- `physics_import`(백그라운드 작업): 패널과 같은 규칙으로 physics3.json(`path`는 절대 경로)을 가져오고, 가져온 그룹, 꺼진 그룹, 없는 파라미터를 반환합니다.

진자 캔버스에서 당기는 것은 시청 세션에 해당하며, 문서, 히스토리, 저장된 포즈를 바꾸지 않습니다.

- `physics_audition`: `mode`가 `start`(`group_id`와, 파라미터 값에 더할 선택적 `values`)이면 시청을 시작하고 이 작업 공간의 이전 세션을 멈춥니다. `target`은 뿌리를 `x`, `y`(-1–1, 패널 포인터) 쪽으로 당기고, `release`는 놓으며, `reset`은 진자를 정지시키고, `reset_peaks`는 최대값 기록을 다시 시작하며, `stop`은 종료합니다. `start`를 제외한 모두가 `session_id`를 받습니다.
- `physics_audition_step`: `dt`초(최대 0.1) 단계를 `steps`번(1–240) 진행하고, 진자 정점, 출력, `peaks`를 반환합니다.
- `physics_audition_get`: 시간을 진행하지 않고 최신 프레임만 읽습니다.

시청 중에 문서를 바꾸면 세션은 새 그룹으로 계속 흔들립니다. 프로젝트를 다시 열거나 그룹을 삭제하면 세션은 무효가 됩니다. 당기고, 놓고, 몇 단계 진행한 뒤 `peaks`를 그대로 `physics_fit`의 `observed_peaks`에 넘기면, 패널에서 당긴 다음 **최댓값에 배율 맞추기**를 하는 것과 같습니다.

`workspace_inspect`에 `scope=physics`를 주면 계산 FPS와 모든 그룹을 계산 순서대로 반환하며, 각 그룹의 출처, 활성 여부, 무엇이 대체하는지, 유효하지 않은 이유가 포함됩니다.

입력 프리셋과 진자 프리셋도 MCP에서 사용할 수 있습니다. `physics_preset_list`는 기본 제공 프리셋과 자신의 프리셋을 나열하고, `physics_apply_preset`은 그중 하나를 그룹에 적용합니다. `physics_preset_put` / `physics_preset_rename` / `physics_preset_delete`는 자신의 프리셋을 관리하며, 목록이 반환한 `library_state`가 필요합니다.
